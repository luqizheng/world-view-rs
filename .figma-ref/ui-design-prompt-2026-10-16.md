Desktop application UI prototype for World-View, a single-player world-building / cartography editor (Bevy + egui style). Canvas 1920×1080, dark theme default with a light parchment theme as a first-class alternate (UI theme toggle Ctrl+J), 4-px base grid. Overall architecture: 2D map canvas in center; multiple draggable, resizable, collapsible floating semi-transparent egui-style panels overlaid on the map canvas; panels have rounded-10px frames, 1px border-strong stroke, opacity 0.96 (0.10 in "immersive" view mode), and NO native title bars — each panel uses a custom 30px header: 12px icon glyph + 12px title at left, optional status pill at right (e.g. gold "ACTIVE" on the brush panel), collapse triangle at far right, hairline bottom border. All panel x/y/width/height/collapsed/visible persist to a ui-layout.yaml file next to the project, together with theme ("dark"/"light"), density ("cozy"/"compact"), map theme ("daylight"/"dusk") and language ("zh"/"en"). Map canvas stays underneath all floating panels.

Top bar (height 38px cozy / 32px compact), 3-segment horizontal auto-layout, bg-app @96% with 1px border-subtle bottom stroke and soft drop shadow:
- Left: project menu button (24×24 rounded-6 accent-blue logo square containing a white 16px map icon + bold 13px project name + 12px chevron-down; opens a 268px popup menu with keyboard ↑/↓/Enter/Esc navigation and three sections — "Recent projects" (open recent · {name} rows), "Project" (New project… Ctrl+Shift+N, New map…, Open project… Ctrl+O, Save as… Ctrl+Shift+S, Export… Ctrl+E, Close project Ctrl+W, Project settings), "Panels" (12 panel checkboxes + "Reset all panel positions")) + breadcrumb "World › Zunyi › Government Office" using 12px chevron-right icon separators, last segment text-2, earlier segments text-3; an err pill "工程未加载" appears when the project failed to load.
- Middle (anchored, horizontally centered): segmented control [Browse | Edit] (64px per segment, 28px tall, English-only labels; container bg-app radius-7 with 1px border-subtle, active segment bg-active radius-5) + segmented map-theme toggle ["Dusk Old Paper" | "Sunlit Ancient Atlas"] (96px per segment, 10px font) + "Rebuild" button (refresh icon + 12px label, bg-raised fill, 1px border-subtle stroke, radius-6, 28px tall).
- Right (visual left→right): zoom percentage "86%" (mono 12px text-2), entity counter "N entities" (mono 12px text-2, N = units+characters+situations+events), dirty-state pill badge "● Unsaved changes" (warn tone, shown only when dirty), a ⌘K button (command icon + "K", raised, 28px tall, opens the command palette), and a language menu button "简"/"EN" (popup items 简体中文 / English).

Floating drill breadcrumb (below top bar at 12, 50): rounded-6 translucent chip; clickable parent levels 13px text-3 separated by "›"; current level 14px strong text-1; trailing scale label.

Status bar (height 22px, bottom, opaque bg-app, 1px border-subtle top stroke): left "U units · C characters · S situations · E events" (mono 11px text-3); right-aligned "ui-layout.yaml" (mono 11px text-3), "N warning(s)" warn pill when validation warnings exist, "Saved locally" ok pill when clean, current drill path "World / Zunyi / Government Office" (mono 11px text-2), "Zoom 86%".

Center: map canvas frame. Map hover tooltip: non-interactive bubble at cursor +(8,8): 8px colored kind-dot (place=accent, region=gold, faction=danger, event=purple) + "name · kind" label.

Right-edge anchored map control group (replaces bottom-right stack): vertically centered rounded container (radius 10, panel bg, 1px border-subtle, 5px inner padding, soft shadow) floating 18px from the right screen edge; vertical stack of 34×34 icon tiles with 4px gaps, icons 20px white; active toggle tile = accent fill: 1) line-distance measure toggle (polyline; right-click/Esc finishes), 2) rectangle measure toggle (two points), separator (8px pads), 3) zoom-in (×1.6), 4) zoom-out (÷1.6), 5) zoom-fit to whole map (maximize icon). Chinese tooltips, e.g. "测量：折线（多段；右键/Esc 收笔）". No brush/pan/eraser buttons in this bar.

Floating panels (all draggable, all persisted; 12 registered + minimap):
- P-1 Map Tree: hierarchy World → Region · Eastern Reach → City · Zunyi → Interior · Government Office (selected); 27px rows with indent steps; selected row = accent 18% fill + 6px gold-stroked square dot, others 12px chevron-right.
- P-2 Layers: header neutral pill "8"; 8 pill switches (25×14 capsules, ON = accent + white knob right, OFF = bg-active + text-3 knob) in a 2-column grid of 92×25 fully-clickable cells: Terrain, Terrain Smooth, Location, Event, Trail, Road, Building, Faction.
- P-3 Brush: gold "ACTIVE" pill in header when brush enabled; one-segment "Brush" button (60px, accent-soft when active); independent checkbox "Grid (independent of brush)"; "TOOL" combo with 7 tools: Paint (default), Mountain range, Plateau, Hills, Volcano, Lake, River. Intent tools show "Strength" slider 0.2–2.0 (value ×1.00), a logarithmic "Radius" slider in meters (hidden for River), and a one-line Chinese hint (mountain range: "拖一条脊线，山脊走向程序补；单点 = 一座圆山"). Paint tool shows "TERRAIN MATERIAL": 10-swatch grid, 2 columns × 5 rows (14px rounded-4 color squares + 11px names, selected = bg-active + 1.5px gold focus stroke): Deep water #8FA2B3, Shallow water #98A9B9, Beach #E3D5BC, Grassland #A8B898, Forest #93A684, Hill #DCCBAF, Mountain #B7A388, Snowfield #F8F4EA, Swamp #9AA88C, Road #735D48; plus logarithmic "Radius" slider and "Softness" slider 0–100%. Road-drawing collapsible sub-panel "Road drawing · N segments" (live counter): checkbox "Draw mode (left-click line / right-click finish)"; road-rank select of 12 ranks (Motorway, Trunk, Primary, Secondary, Tertiary, Residential (default), Service, Path, Cycleway, Track, Unknown, Unclassified); name input; decorative examples "Imperial Road" / "North Trade Route"; accent "Finish line" button (120px); "↶" undo-last-segment button (disabled with no segments).
- Compass panel: empty state "◐ 指南针 / 尚未选择地图"; circular widget up to 168px (raised disc, 1.5px border circle, 72 ticks every 5° with majors every 90°, rotating N/E/S/W labels, accent needle + tail + 7px tip + hub); drag to rotate (0° = north up, clockwise positive, 0.5° dead-band, commits a SetMapOrientation command); "朝向" mono angle input (60px) + "°" suffix; quick buttons "N 0°  E 90°  S 180°  W 270°".
- P-4 Minimap: fixed 168×168 live terrain thumbnail (radius 6, raised backing, 1px border), 1.5px gold viewport rectangle (radius 4, clamped to thumbnail), click-to-jump; quick layer checkboxes in 3 columns: Terrain | Places, Trails | Event points, Roads, Base fading.
- P-5 Inspector: empty state "◎ No object selected — click a map plot / event / character to inspect properties." When selected: header with 10px colored dot + "kind · id" (place=accent, region=gold, faction=danger, event=success, segment=text-3; read-only), then 4 compact rows (29px, raised, radius 5, decorative chevron, count pill at right): "Situations" warn pill "N active", "Characters" neutral pill, "Events" event pill, "Regions" neutral pill; below, up to 3 situation preview cards (42px, 3px danger color bar, name + "Y41 D41 — Y41 D45" span meta, open spans rendered "Y41 D41 — …").
- P-6 Situations: warn count pill in header (hidden at 0); flat list, each row with an event-purple color bar + name + day-span meta; empty state "▣ 暂无已登记事态 / 事态是叙事的骨架：登记一个，把事件串起来 / 登记事态 →". Read-only.
- P-7 Factions: "Map: {id}" label + "⋯" more-menu placeholder; full-width "+ Add faction" outlined button (default 新势力 / #1E6FCC); collapsible cards "◆ {name} ({id})" each with name text input and color TEXT input (raw hex string, not a color picker, autosaves), current-map geometry rows "[from, to) · N 顶点 · 删除", add-geometry row ("起 day：" input prefilled with the playback day, "止（留空=至今）：" input, "+ 新建疆界" button), and a red "删除整个势力" danger button.
- Regions panel: "当前地图：{id}" + "+ 新建区域" button (default 新区域); collapsible cards "⬡ {name} ({id}) — N 顶点" with name edit, "轮廓：N 个顶点" info ("（未绘制）" when empty), red "删除区域" button.
- P-9 Characters: neutral count pill; list rows (accent color), name only; empty state "◎ 暂无已登记人物 / 人物是叙事的载体：登记一个，让它走进历史 / 登记人物 →".
- P-10 Events: purple count pill; list rows (event purple) showing entity id + "第 N 天" / "第 N–M 天" span meta; empty state "○ 暂无已登记事件 / 登记事件 →". Opened by the timeline's "+ Register event".
- P-8 Validation: header pills "错误 N" (err) or "无错误" (ok), plus "提示 N" (warn); subtitle "四维校验：时间 / 引用 / 几何 / 一致性" (Time / Reference / Geometry / Consistency); Errors scroll list (6 rows visible) with "E" err badges and Hints scroll list (8 rows) with "H" warn badges; anchored entries are clickable → jump (drill to map + camera + playback day); all-clear text "一切正常"; footnote "校验只提示，不阻止保存".

Bottom floating Timeline panel (default 1256×164 full-width, no title bar, zero inner margin, full-bleed; immersive mode dims the whole panel to α=0.55 but stays interactive):
- Top row (50px tall, 10px side padding, full-width 1px `border_subtle` hairline at row bottom that bleeds to both panel edges — equivalent to web's `.timeline-top{border-bottom}`):
  - 32×32 self-painted circle play/pause (no font glyphs; `accent()` fill + white shape). Pause state = two 2.5×10px bars 4px apart. Play state = filled right-leaning triangle ≈ 7×10, vertex y ±5, 1px right of center. Toggles `playback.playing`.
  - Date block (width = max(main text, sub text, 110px) so the speed combo/chips start point never shifts with the date): main line = authoritative in-world date via `ui_time::current_date` (proportional small, text-1); sub line = `"Day N · Early Spring / Summer / Autumn / Winter"` (mono micro, text-3, 2px gap below the main). Season buckets are 90-day slices of a 360-day year, so Winter wraps.
  - Speed combo 108px wide (4px inner trim, 27px tall, `bg_app` fill + 1px `border_strong` stroke + radius 6, `accent` stroke on hover). Three options: 1 / 5 / 30 days-per-second, label `"1 天/秒"` / `"5 天/秒"` (zh) and `"1 day / sec"` / `"5 days / sec"` (en).
  - 4 track chips that SWITCH the active layer (not parallel toggles), 4px gap between chips. Each chip: micro proportional strong label, 2px × 6px padding, radius 4, semantic stroke + light fill. Tones: `Day` neutral, `Situation` warn/amber, `Character` event/purple, `Century` neutral. Selected state: neutral tones → `bg_active` fill + `border_strong` stroke; colored tones → semantic fill @32% on `bg_panel` + stroke @100%; hover @22%/0.55; rest @15%/0.55.
  - Right-aligned accent button "+ 登记事件 / Register event" (plus icon, factory `ButtonStyle::Accent`; click opens the Events list panel).
- Track area (114px; the ENTIRE rect is `Sense::click_and_drag()` for playhead scrubbing — no separate slider widget):
  - 9 vertical gridlines every 10% from track top to bottom (1px `border_subtle`).
  - 26px years row with 4 equal segments holding hardcoded Figma mock text `"Y213 · Winter / Y214 · Spring / Y214 · Summer / Y214 · Autumn"` (text-3, micro, centered) + full-width 1px `border_subtle` underline hairline at row bottom.
  - Active-layer content (centered horizontally in the rect, x mapping is `frac → x = rect.min.x + frac * rect.width`, y is fixed for the chosen layer):
    - `Day`: 21-tick ruler, every 5%, 8px long, 1px `border_strong` strokes starting at the years row baseline.
    - `Situation`: block row starts 38px from the track top, height 20px (`BLOCK_H`), 6px row gap for stacking. With no data: two mock blocks — "Border dispute" warn at frac 0.12, width 0.25; "Market opens" event at frac 0.57, width 0.16 — plus a 4px event-tone dot with a 7px-radius 25% halo at frac 0.45 on the dot row (top 69px). With real data: one event block per situation, badge radius 4, semantic fill @25% bg + @55% border, semantic fg, min 60px wide, open spans run to `range_to` (no end cap).
    - `Character` / `Century`: 3 horizontal hairlines spaced 24px apart (placeholder rails until M3 real data).
  - Playhead (gold `focus` color): 1px vertical line from `top 22px` (`PLAYHEAD_TOP`) down to track bottom; 8×7 down-pointing triangle anchored at the line top; gold date pill below the line at `top 72px` (`PLAYHEAD_LABEL_TOP`, micro proportional, `text_on_accent` color, `shell.focus()` fill, radius 3, min width 44, content = compact day count from `ui_time::format_date`, horizontally and vertically clamped inside the track so it never escapes the panel).
  - Click/drag anywhere on the track: pointer x → frac = (x − rect.min.x) / rect.width clamped [0,1] → `playback.current_day = range_from + (frac * (range_to − range_from)) as i64`.
