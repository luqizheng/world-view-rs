## 0.1 v0.1.1 修订记录（评审发现的缺陷）

本轮对 v0.1 做了自查，**发现并修复 12 个缺陷**，其中 5 个是功能失效级。
核心教训：**v0.1 的配色是"照感觉配的"，本次全部改为实测算出来**。

| # | 缺陷 | 严重度 | 原值 → 修正值 | 处置 |
|---|---|---|---|---|
| **B1** | **时间轴游标与事件条永远错位** | 🔴 功能失效 | `left = 12 + 比例×全宽`（基准错：轨道区前有 56px 标签列） | 改为**实测 `.lane-t` 的 offset/width**（`trackMetrics()`），不再硬编码算术 |
| **B2** | **裸 Tab 被沉浸模式占用** | 🔴 a11y 失败 | `Tab` → 沉浸模式（`preventDefault`） | **改 `Ctrl+Shift+I`**。裸 Tab 是键盘用户唯一焦点移动键，拦截违反 WCAG 2.1.1 |
| **B3** | **命令面板 `openCmd` 无法被内联 onclick 调用** | 🔴 运行时报错 | 函数未挂 window | 全部内联 onclick 改为 `data-*` + 事件委托；`openCmd` 显式挂 `window` |
| **B4** | **沉浸模式把时间轴与日期一起藏了** | 🟡 原则违背 | 隐 `.panel, .timeline, .demo, .map-hud` | 改为**只隐面板与演示控制**；时间轴保留但降至 55% 透明度 |
| **B5** | **`.panel` 拖动后立即重写 `height`** | 🟡 行为异常 | 拖动中也强制写 `style.height` | 仅非折叠态写入 |
| **C1** | **笔刷选中描边不可见** | 🔴 对比度 | `rgba(242,193,78,.35)` = **2.34:1**（需 3:1） | 抽 `--ui-focus-ring` 令牌，暗色 `.85` = **7.01:1** |
| **C2** | **HUD chip 压在雪原上不可读** | 🔴 对比度 | scrim `.72` = **3.92:1**（需 4.5:1） | 新增 `--ui-bg-float`（暗 `.94` = **6.73:1**） |
| **C3** | **亮色 HUD chip 更糟** | 🔴 对比度 | scrim `.34` = **2.86:1** | `--ui-bg-float` 亮 `.93` = **6.49:1** |
| **C4** | **`.bdg.err` 徽标不合格** | 🟠 对比度 | `#E8837A` = **4.01:1**（10px 文字，**不算大字号**，我误判为 AA-large） | → `#F09A91` = **4.91:1** |
| **C5** | **亮色焦点环不合格** | 🟠 对比度 | `#B47800` = **3.61:1**（v0.1 声称已解决，**实测未解决**） | → `#8A5A00` = **5.73:1** |
| **C6** | **小地图视口框会画出边界** | 🟡 视觉 | 缩小时 `vw > 地图宽`，框溢出 | 加 `clip()` |
| **A1** | **`.note.*` 三色未经核算** | ✅ 侥幸合格 | warn 7.25 / ok 7.08 / err 6.40 | 实测后统一到已验证值（说明 v0.1 是瞎配的，恰好蒙对） |

> **C4 的教训**：我曾把 4.01:1 标注为"PASS AA-large"。但该徽标字号 10px，**远低于大字号门槛**（≥18.66px 粗体或 24px）。**标签写"PASS"之前必须先确认适用的是哪条门槛。**

## 0. 结论先行

本方案**不推翻任何已落地的美术/动效/VFX 规格**，只在既有 28 色世界色板之上**补齐缺失的「界面外壳色」层**，并对五个已定痛点做定向修正。

| # | 问题 | 现状 | 本方案处置 |
|---|---|---|---|
| P1 | **外壳色缺失** | `palette.rs` 只有 28 个 `world.*` 令牌（地形/势力/语义/描线/强调），**没有任何一个用于画界面本身**（面板底色、描边、文字、hover）。当前 egui 用默认深灰，和美术色板毫无关系 | 新增 **`ui.*` 12 色外壳令牌**，与 `world.*` **并列而非替换**（§3） |
| P2 | **信息密度失控** | `top_bar` 用 `horizontal_centered` 把 7 组控件平铺，项目名/视图/日期/坐标/比例尺**权重完全相同** | 三段式：**身份 → 主控 → 读数**，读数降级为等宽小字并允许按窗宽隐藏（§4.2） |
| P3 | **面板缺少可发现性** | 10 个浮动窗全部同款外观，靠「窗口」菜单里的 checkbox 逐个开。开关状态与面板内容**无视觉关联** | 面板头加**类型图标 + 状态徽标**；新增 **`Ctrl+K` 命令面板**作为第二入口（§6.3） |
| P4 | **播放控件与时间轴分离** | 播放/暂停/速度在时间轴窗口内，日期显示在**顶栏和面板里各一份**，三处可能不同步 | 时间轴为**唯一时间权威**，顶栏日期为**只读镜像**；两者共用同一格式化函数（§5.3） |
| P5 | **无键盘路径** | 全靠鼠标点选，`egui` 默认 Tab 序在浮动窗里不连续 | 建立 **19 条快捷键**，全部在命令面板中可见可查（§6.3） |

**一句话定位**：这是一个**以地图为主角、面板为工具**的创作工具——所有 UI 元素都必须**可消失**（沉浸模式），可**找回**（命令面板），且**不侵占地图**。

## 1. 设计原则（5 条）

| # | 原则 | 判定标准（可测） |
|---|---|---|
| **D1** | **地图是主体，面板是客人** | 任何面板**不得推挤地图坐标系**。面板显隐/拖动/折叠，地图视野完全不变 |
| **D2** | **世界色归世界，界面色归界面** | 换 Theme Pack 只改 `world.*`，界面外观（面板、文字、按钮）**不变**——作者换画风不会导致软件变脸 |
| **D3** | **状态永不抑制，装饰可抑制** | 与动画规格 §抑制三分类同源：删掉一个 UI 元素会让人**少看懂什么**吗？不会 → 它是装饰，可隐藏 |
| **D4** | **一切可逆** | 破坏性操作（删除、重写历史）必须可撤销；**校验只提示不阻止**（承自 AGENTS §7.5「校验不是闸门」） |
| **D5** | **零隐藏功能** | 每个功能必须能被找到——要么常驻，要么在 `Ctrl+K` 里能被搜到 |

## 2. 视觉体系

### 2.1 两层色彩架构

```
Layer 1   world.*    28 色   ── 世界的颜色（地形 / 势力 / 事件 / 描线 / 强调）
                              由 ART_STYLE_SPEC §1.4 唯一权威，本方案不动一色
                              ↓ 通过语义槽位被界面引用
Layer 0   ui.*       12 色   ── 工具自身的颜色（新增）
                              面板底 / 抬升块 / 描边 / 三级文字 / 交互主色 / 焦点环
```

**为什么必须新增而不是复用 `world.*`**：
- `world.accent.select` 是金 `#F2C14E`——在地图上表示「选中地块」，语义是**世界内的高亮**。若拿它做界面按钮底色，作者会分不清「这个金色是地图上的选择，还是软件的选择」。
- `world.accent.cursor` 橙红 `#E8623C` 已被时间轴游标与生长笔尖**独占**（动画规格 §7.1 明令禁止拆成两令牌）。若再用作界面强调色，语义被稀释。
- `world.line.on_dark` 是 `#EFE9DC` 近白——那是**地图上**的描线（让深色地块有轮廓），不是界面文字色。

> **结论**：把 `ui.*` 做成独立一层，不是冗余，是**语义隔离**。UI 层允许微调明度，但不允许从 `world.*` 借色相。

### 2.2.1 状态色前景值（实测）

| 令牌 | 前景 | 暗色实测 | 亮色实测 |
|---|---|---|---|
| `.bdg.ok` | `#7FD593` | **4.61:1** ✅ | — |
| `.bdg.warn` | `#E8C065` | **4.79:1** ✅ | — |
| `.bdg.err` | `#F09A91` | **4.91:1** ✅ | — |

> **底色用的是 alpha 合成**——`.bdg.*` 的底是 `rgba(语义色, .16/.18)` 叠在 `ui.bg.active` 上，
> 合成后才是真实底色。**只看色卡上的语义色会算错对比度。**

### 2.3 排版

| 令牌 | 值 | 用途 |
|---|---|---|
| `--font-ui` | `Inter → PingFang SC → Microsoft YaHei` | 界面文字（承自 `fonts.rs` 系统字体栈纪律，**不打包字体文件**） |
| `--font-mono` | `JetBrains Mono → Cascadia Mono` | **所有数字**：日期、坐标、比例尺、ID、计数 |

**硬约束**：所有会跳动的数字必须等宽 + `tabular-nums`。日期从 `无仙 1 年 1 月 1 日` 变成 `无仙 10 年 10 月 10 日` 时，顶栏和面板**宽度不得变化**，否则顶栏会抖。

**字号阶梯**（7 级）：
`11px`（面板标题 / 徽标 / 弱标签）→ `12px`（正文 / 控件）→ `13px`（默认）→ `14px`（输入框 / 命令面板输入）→ `16px`（空状态标题）→ `19px` → `24px`（仅用于未来的大标题区）

### 2.4 间距与圆角

- **间距**：4px 基准。`4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48`
  - 面板内边距 `8px`；面板之间靠**浮空**分隔，不画分隔线（除面板自身头尾线）
  - 同组控件间距 `4px`，跨组 `12px`
- **圆角**：`4px`（徽标 / 色块）→ `6px`（输入框 / 按钮）→ `10px`（面板）→ `14px`（模态 / 空状态卡）→ `999px`（药丸 / 播放头）
- **面板描边**：`1px ui.border.strong` + 顶部 1px 高光渐变 → 给出"浮起"的实体感，而不是"贴上去"的平面感

### 2.5 高度（Elevation）

| 级 | 值 | 用途 |
|---|---|---|
| e0 | 无 | 地图 |
| e1 | `0 1px 2px rgba(0,0,0,.42)` | 顶栏 / 状态栏 |
| e2 | `0 4px 12px + 0 1px 2px` | 浮动面板 / 时间轴 |
| e3 | `0 16px 40px + 0 2px 8px` | 模态 / 命令面板 / 拖拽中的面板 |

拖拽中的面板**临时升到 e3** —— 这是唯一的动态 elevation 变化，用于给"我正在拿它"以物理反馈。

### 2.6 动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--t-fast` | `110ms` | hover / 按下 / 开关滑动 |
| `--t-base` | `180ms` | 面板折叠展开 / 进场 / Toast |
| `--t-slow` | `320ms` | 模态淡入、视野归位 |

**缓动统一** `cubic-bezier(.2, 0, .2, 1)`（快出慢入，适合 UI 反馈）。

> **重要边界**：以上动效**只作用于界面元素**。地图上的一切动画（轨迹生长、事件脉冲、势力易主）**仍由 `ANIMATION_SPEC` 的 day 空间插值驱动**，两套动效体系互不干扰——界面动效用真实时间，地图动效用游戏内天数。

## 3. 布局架构

### 3.1 全局骨架

```
┌─────────────────────────────────────────────────────────────┐
│ 顶栏 38px                                                e1   │  身份 / 主控 / 读数
├─────────────────────────────────────────────────────────────┤
│                                              ┌────────────┐ │
│  ┌──────────┐                                │  检视器    │ │  地图铺满
│  │ 世界树   │      ← 地图（永远在 z0）→     │            │ │  面板全部浮动
│  └──────────┘                                └────────────┘ │
│  ┌──────────┐                                ┌────────────┐ │
│  │ 导航     │                                │ 地形笔刷  │ │
│  └──────────┘                                └────────────┘ │
│         ┌──────────────────────────────────────────────┐     │
│         │  时间轴（日 / 事态 / 人物 / 世纪 四层）      │     │
│         └──────────────────────────────────────────────┘     │
├─────────────────────────────────────────────────────────────┤
│ 状态栏 22px                                                   │
└─────────────────────────────────────────────────────────────┘
```

**关键约束（承自基线 §1.11 R1–R4，全部保留）**：
- 地图**铺满**，永不因面板缩小
- 除顶栏（38px 固定信息条）与状态栏（22px）外，**不使用任何 `SidePanel` / `BottomPanel`**
- 所有面板是 `egui::Window` 浮窗，可拖动 / 折叠 / 关闭
- 面板位置**可记忆**（落盘到 `ui-layout.yaml`，与工程同目录）

### 3.2 顶栏三段式

| 段 | 内容 | 权重 |
|---|---|---|
| **身份**（左） | 品牌标 + 工程名（可点击重命名）+ 脏标记 + 保存状态徽标 | 中——工程名是身份锚点，但不该抢主控 |
| **主控**（中偏左） | **视图模式分段控件**（4 态） | **最高**——最高频操作 |
| **读数**（右） | 日期 · 坐标 · 比例尺 · 撤销/重做/保存 · 命令/主题 | 低——等宽小字，`ui.text.2` |

**视口自适应**：
- `< 1400px`：隐藏比例尺
- `< 1100px`：隐藏坐标
- `< 900px`：隐藏次要面板（检视器 / 笔刷可从命令面板唤出）

**为什么日期放顶栏**：作者的时间感锚点。播放时它必须**始终可见**——哪怕在沉浸模式下也要保留（只是移到画面顶部中央）。

### 3.3 面板清单（10 个）

| ID | 名称 | 默认位置 | 默认宽 | 层级 | 主要操作 |
|---|---|---|---|---|---|
| P-1 | 世界树 | 左上 `12,56` | 216 | 导航 | 展开/折叠、选择、切换地图 |
| P-2 | 检视器 | 右上 | 264 | 导航 | 属性编辑（表单） |
| P-3 | 地形笔刷 | 右侧（检视器下） | 264 | 工具 | 10 地形 2×5 网格、半径/软度 |
| P-4 | 导航（��地图） | 左下 | 216 | 导航 | 视口跳转、图层开关 |
| P-5 | 时间轴 | 底部通栏 | — | 时间 | 播放、拖拽、四层缩放 |
| P-6 | 事态登记 | 右侧居中 | 300 | 数据 | 列表 + 新建 |
| P-7 | 势力层 | 右侧居中 | 280 | 数据 | 势力/归属 |
| P-8 | 事件登记 | 右侧居中 | 300 | 数据 | 列表 + 新建（**可从时间轴进入**） |

### 3.4 时间轴四层（基线 §时间导航 L1–L4）

| 层 | 名称 | 内容 | 切换键 |
|---|---|---|---|
| L1 | 日 | 细刻度尺 + 播放头 | 切到「日」 |
| L2 | 事态 | 事态条 + 部队轨迹条（**默认层**） | 切到「事态」 |
| L3 | 人物 | 人物生卒条（`康熙帝 1654—1722` 这类区间） | 切到「人物」 |
| L4 | 世纪 | 按世纪聚合的柱状鸟瞰——**10 万年时间跨度下 L1 画不出来**（滑块宽度 ≈ 1/30000 px） | 切到「世纪」 |

**时间轴是唯一时间权威**：顶栏日期、地图上的轨迹生长、事件高亮，**全部从 `playback.current_day` 派生**，不允许任何一处自己算日期（违反 AGENTS §3.2）。

## 4. 组件规格

### 4.1 面板外壳（Panel Shell）

```
┌─────────────────────────────────────────┐
│ ⠿ ◉ 世界树              [3]  [−]        │  ← 30px 头，可拖动
├─────────────────────────────────────────┤
│                                         │
│  内容区（内边距 8px，可滚动）           │
│                                         │
└─────────────────────────────────────────┘ ↘ 14px 缩放热区
```

**头部的三段**：
1. `⠿` 拖动把手（`ui.text.3` 60% 透明）——**视觉上明示"这里可以拖"**
2. 类型图标（`ui.accent` 着色）+ 大写标题（11px，`letter-spacing: .05em`）
3. 状态徽标（数量/告警数）+ 折叠按钮

**状态**：
| 状态 | 表现 |
|---|---|
| 静止 | e2 阴影 |
| 悬停 | 右下角缩放热区淡入 |
| 拖动中 | **阴影升至 e3**，内容不变 |
| 折叠 | 仅剩 30px 头，内容 `display:none` |
| 告警 | 徽标变黄/红（校验面板） |
| 错误 | 徽标变红（工程未加载） |

> **实现提示**：拖动把手必须**独占指针事件**，且头部的按钮（折叠/关闭）**不触发拖动**。原型中已处理：`if (e.target.closest('button,input,label,select')) return;`

### 4.2 按钮（4 变体 × 3 尺寸）

| 变体 | 用途 | 规则 |
|---|---|---|
| `.btn-pri` | 每个面板/模态**至多一个**主按钮 | 蓝色实心；一屏出现两个就会失去"主"的含义 |
| `.btn` | 次要操作 | 抬升底 + 强描边 |
| `.btn-ghost` | 工具栏、面板头部 | 无底无框，hover 才出现底 |
| `.btn-danger` | 删除 / 重写历史 | **红色文字**而非红色实底——破坏性操作不该被视觉鼓励 |

**尺寸**：`sm 22px`（面板头部）· `md 26px`（默认）· `lg 32px`（模态主按钮）

**规则**：hover 变底色，active `translateY(1px)`（模拟下沉），**不使用缩放**——缩放会让相邻控件抖动。

### 4.3 表单控件

| 控件 | 规格 | 关键点 |
|---|---|---|
| 输入框 | 高 26px，`ui.bg.app` 底（比面板更深，形成"凹陷"） | focus 时边框转 `ui.accent` + **3px 光晕**（`--ui-accent-wash`），不只改边框色 |
| 下拉 | 自绘箭头（不依赖系统样式） | 右内边距 24px 防文字压箭头 |
| 滑块 | 轨道 3px，滑块 13px 带 2px 同色描边 | hover 时 `scale(1.15)`；数值用**等宽**显示在右侧 |
| 开关 | 28×16 轨道 + 12px 滑块 | 滑块位移 12px；`prefers-reduced-motion` 下取消过渡 |
| 分段（`seg2`） | 紧贴面板内的小型互斥选择 | 每段**等分宽度**，文字不截断 |

**必填校验**：本工具**不阻止保存**（AGENTS §7.5），但输入框在失焦时**必须**显示行内提示，不能只在保存时报错。

### 4.4 树（世界树）

- 层级缩进：每级 `12px`
- 选中态：`ui.sel.wash` 底 + **左侧 2px 金色竖条**（`world.accent.select`——因为"选中"确实是世界状态）
- 有子节点的行显示 `›` 折叠箭头，展开时旋转 90°
- 每行右侧可挂**元信息**（`tmeta`，等宽 10px）：数量、兵力、年份

**虚拟化**：人物多时（网文场景可能上千）必须虚拟滚动；原型未实现，属实现阶段要求。

### 4.5 工具网格（地形笔刷）

用户明确要求 **2 列 × 2 图标**（紧凑 Photoshop 式）。本方案细化为 **2 列 × 5 行 = 10 个地形**：

- 每个工具格 `44px` 高：**16px 色块 + 10px 文字**
- 选中态：金色描边 + `ui.sel.wash` 底（与树的选中语言一致）
- 色彩直接取 `world.core.terrain[k]`——**色块就是地形本色，不需要图标字体**
- 激活笔刷后**鼠标指针变十字**，地图上实时画 falloff 双环（外实线 = 半径，内虚线 = 软边）

> 这一处修正了原实现的 emoji 图标方案（🌊💧🏖🌾🌲⛰🏔❄🪵🛤）。理由：emoji 的**跨系统字形差异**会让 10 个地形在不同机器上长得不一样，且 `fonts.rs` 明确不打包字体——emoji 依赖系统字体回退，Linux 上很可能缺字。**色块方案零依赖、零缺字、且与色板严格一致。**

### 4.6 列表项（事态 / 事件 / 人物）

```
┌────────────────────────────────────┐
│ ▣ 四渡赤水            第 29—130 天 │  ← 类型色块 + 主标题 + 等宽元信息
└────────────────────────────────────┘
```

- 悬停：描边转 `ui.border.strong`
- 选中：`ui.accent.line` 描边 + `ui.accent.wash` 底
- **空状态**：虚线描边 + 居中灰字「暂无已登记事态」+ 一个引导按钮（不是干巴巴一句话）

### 4.7 徽标（Badge）

| 型 | 用途 |
|---|---|
| `.bdg` | 中性计数 |
| `.bdg.ok` | 校验通过 |
| `.bdg.warn` | 黄色告警（迟到） |
| `.bdg.err` | 红色错误（不可达 / 未加载） |
| `.bdg.ev` | 事件相关（紫 `world.accent.event`） |

**语义色纪律**：`ok/warn/err` 必须与 `world.ui_link.*`（`#3F9B4E` / `#C9971F` / `#B5453A`）**同色相**——地图上「可达/迟到/不可达」和界面上「通过/告警/错误」是同一件事，不能一个绿一个蓝。

## 5. 状态设计

### 5.1 四种全局状态

每个界面都必须设计这四种，原型左下「演示控制」可实时切换验证：

| 状态 | 设计要点 |
|---|---|
| **正常** | — |
| **加载** | 骨架屏（微光条），**不阻塞已有内容**；地图加载时显示「分形噪声生成海岸线 · 512×512」，让等待有信息量 |
| **空** | 图标 + 一句人话 + **一个可点的下一步**。禁止只写「暂无数据」 |
| **错误** | 错误码 + **人类可读的原因 + 建议的下一步**。工程未加载的错误必须附上**已尝试过的路径解析顺序** |

**错误文案范例**（对应真实 bug 修复）：
> **工程未加载**
> `examples/minimal-world 不存在或缺少 world.yaml`
> 已按序尝试：① 命令行参数 → ② 环境变量 `WV_PROJECT` → ③ 从可执行文件逐级上溯 6 层 → ④ 当前工作目录。
> [重新加载] [选择目录…]

### 5.2 空状态文案原则

- ❌ 「暂无数据」「No data」
- ✅ 「这个工程还没有地图」+「新建一张地图，或打开示例工程看看它长什么样」+ [新建地图] [打开示例]

### 5.3 时间相关状态的唯一真源

```
playback.current_day  ──┬──→  Calendar::format()  ──→ 顶栏日期（只读镜像）
   (唯一权威)           ├──→  地图投影（轨迹生长 / 事件高亮）
                        ├──→  时间轴播放头位置
                        └──→  时间轴 L4 鸟瞰高亮列
```
**任何组件不得自行格式化日期。** 三处日期曾不同步是原设计的隐患。

## 6. 交互设计

### 6.1 快捷键（19 条）

| 键 | 动作 | 键 | 动作 |
|---|---|---|---|
| `Ctrl+K` | 命令面板 | `1` `2` `3` `4` | 切换四种视图模式 |
| `Ctrl+S` | 保存 | `Ctrl+Shift+I` | 沉浸模式（仅地图） |
| `Ctrl+Z` | 撤销 | `F` | 全览地图 |
| `Ctrl+Shift+Z` | 重做 | `B` | 唤出地形笔刷 |
| `Ctrl+J` | 切换明暗 | `N` | 唤出导航面板 |
| `Space` | 播放/暂停 | `I` | 唤出检视器 |
| `[` `]` | 笔刷半径 ∓8 | `Home` `End` | 跳到时间轴首/尾 |
| `+` `−` | 缩放 | `Esc` | 关闭模态 |

> ⚠️ **禁止占用裸 `Tab`**（WCAG 2.1.1）。v0.1 曾把沉浸模式绑到 `Tab` 并 `preventDefault()`，
> 导致纯键盘用户**无法把焦点移出输入框**——这是功能性阻断，已在 v0.1.1 改为 `Ctrl+Shift+I`。

**输入框聚焦时全部快捷键失效**（除 `Esc`）——在打字时按 `1` 不应该切换视图。

### 6.2 三级可发现性

```
第 1 级  常驻（顶栏 / 状态栏 / 时间轴）—— 最高频，零成本
第 2 级  命令面板（Ctrl+K）—— 中频，可搜索
第 3 级  面板菜单 —— 低频，兜底
```

**任何功能不得只存在于第 3 级。** 命令面板收录**全部**功能，不是只收常用项。

### 6.3 命令面板

- 触发：`Ctrl+K` / `Esc` 关闭
- 支持模糊匹配（按分组标题 + 命令文本匹配）
- 分组：视图 / 编辑 / 面板 / 时间 / 界面 / 对象
- 每条**显示自己的快捷键**——这是快捷键的「可发现性文档」
- 键盘完全可操作（`↑` `↓` `↵`）

### 6.4 沉浸模式

`Ctrl+Shift+I` 一键隐藏所有编辑面板与演示控制，只留地图 + 时间轴（降至 55% 透明度）+ 顶栏。

**用途**：作者在核对「地图放大能看到发生过程，缩小显示『四渡赤水 正在发生』」时，需要一个**干净**的画面。

> **⚠️ 关键约束：沉浸模式不隐藏时间轴与日期**。
> v0.1 曾把时间轴一起藏掉，等于作者播放时**无法判断当前是第几天**——
> 这违背了"日期是唯一时间锚点"的设计原则。正确做法是**降低其视觉权重，而非移除功能**。

顶栏**保留日期**（半透明），因为它是全局时间锚点。

> **动效纪律**：此处只对 `opacity` / `transform` 做过渡（GPU 可加速），
> 不对 `width` / `top` 做动画——后者会每帧触发重排，在大地图上掉帧。

### 6.5 地图交互

| 操作 | 结果 |
|---|---|
| 拖拽 | 平移（**不改坐标系**，D1） |
| 滚轮 | **以光标为锚点**缩放——滚轮缩放时指针下的地块必须**钉住不动** |
| 单击事件点 | 选中 + 状态栏显示 + 检视器切换到该事件 |
| 单击空白 | 取消选择（状态栏显「已选：（空）」，不假装还有选择） |
| 笔刷激活时左键 | 涂抹地形 |

## 7. 无障碍（WCAG AA）

| 项 | 标准 | 本方案达成 |
|---|---|---|
| 对比度 | 正文 ≥ 4.5:1，非文本 ≥ 3:1 | **全部令牌经 `audit-contrast.py` 实测**，最低 4.37:1（非文本）／4.61:1（文本） ✅ |
| 焦点可见 | 2px 实心环 + 2px 偏移 | `:focus-visible` 金（暗 10.15:1）/ 深琥珀（亮 5.73:1） ✅ |
| 键盘可达 | 全部功能可用键盘完成 | 19 条快捷键 + 命令面板；**裸 Tab 完整保留给焦点移动** ✅ |
| 焦点管理 | 模态打开时焦点入内，关闭时归还 | 命令面板 `input.focus()` ✅ |
| 触控目标 | ≥ 28×28px（桌面工具的实用下限） | `--hit: 28px`，图标按钮全部满足 ✅ |
| 动效敏感 | 尊重 `prefers-reduced-motion` | 全局时长归零；**骨架屏改为静态描边框**（动效停摆后仍能辨识为"加载中"） ✅ |
| 文字缩放 | 200% 下不破版 | 面板可滚动、可折叠 ✅ |
| 语义标注 | `aria-label` / `role` / `aria-pressed` | 开关、分段、树节点、命令项均标注 ✅ |
| 错误预防 | 删除/重写前确认 | 破坏性按钮 `.btn-danger` + 二次确认 |
| 非颜色依赖 | 信息不能只靠颜色传达 | 徽标同时有文字；选中态同时有描边+底色+文字 ✅ |

> **亮色外壳的两个坑**（均实测坐实）：
> 1. `world.accent.select` 的金 `#F2C14E` 在白底只有 **1.62:1**，绝不能直接当焦点环或选中描边。
> 2. 亮色主题的 `scrim .34` 压在浅色地图上仅 **2.86:1** —— 比暗色主题的 **3.92:1** 更糟。
>    **结论：明暗两套外壳不能只做色相反转**，浮层不透明度必须分别标定。

## 8. 密度与响应

**两档密度**（`data-density`）：

| 档 | 顶栏 | 命中区 | 面板头 | 树行 | 适用 |
|---|---|---|---|---|---|
| 标准 `cozy` | 38px | 28px | 30px | 24px | 笔记本 / 首次使用 |
| 紧凑 `compact` | 32px | 24px | 26px | 20px | 大屏 / 熟练用户 |

**窗宽断点**：

| 宽度 | 处置 |
|---|---|
| ≥ 1400px | 全显 |
| 1100–1400px | 隐藏比例尺 |
| 900–1100px | 隐藏坐标；次要面板默认收起 |
| < 900px | 隐藏次要面板（可从命令面板唤出） |

> 桌面工具**不做移动端布局**——这是创作工具，不是消费应用。`< 900px` 的降级只是保证在分屏/远程桌面下不崩。
