## A. 项目管理菜单

### A.1 入口（顶栏下拉）

```
[品牌] | [工程名 ▾] [已保存徽标] | [视图模式 segmented] |  ... 
                                ↑ 
                                新增：下拉箭头按钮（折叠状态下不显眼，hover/展开时高亮）
```

**为什么不用菜单栏**：原顶栏已是三段式（身份 → 主控 → 读数），再开菜单栏会破坏密度。Figma / VSCode / Godot 的 File 菜单也是下拉或弹层形态，不是固定菜单栏。

### A.2 菜单内容

| 顺序 | 分组 | 条目 | 快捷键 |
|---|---|---|---|
| 1 | 最近工程 | 四渡赤水 · 行军图 | — |
| 2 | 最近工程 | 封神演义 · 架空 | — |
| 3 | 最近工程 | 贞观政要 · 大唐 | — |
| --- | --- | --- | --- |
| 4 | — | 新建工程 | `Ctrl+Shift+N` |
| 5 | — | 打开工程… | `Ctrl+O` |
| 6 | — | 另存为… | `Ctrl+Shift+S` |
| --- | --- | --- | --- |
| 7 | — | 关闭工程 | `Ctrl+W` |
| 8 | — | 项目设置 | — |

**不进入菜单的内容**：
- 保存（`Ctrl+S`，已在读数区放独立按钮，高频操作）
- 撤销 / 重做（已有专用按钮）
- 打开示例工程（属于"打开工程"的延伸，原型阶段以 `data-demo="open-sample"` 在状态覆盖层提供）

### A.3 交互契约

| 操作 | 结果 |
|---|---|
| 点击 `▾` 按钮 | 展开下拉，焦点自动落在当前选中项（最近工程的当前项） |
| `↑`/`↓` | 选择条目（带 `aria-selected` 同步） |
| `↵` / 点击 | 执行 + 关闭菜单 |
| `Esc` | 关闭 |
| 点击下拉外部 | 关闭 |
| 切换"最近工程" | 更新顶栏工程名 + **重置地图层级到世界**（防上次钻入遗留）+ 清空访问痕迹 + 徽标改"已加载" |

### A.4 判据

1. **顶栏三段式不破坏**：下拉是工程名的延伸，不挤占读数区
2. **三级可发现性统一**：常驻（按钮本身）/ 命令面板（搜"新建"/"打开"等也能命中）/ 菜单展开（兜底）
3. **快捷键不冲突**：`Ctrl+O` 是 OS 标准打开语义；`Ctrl+Shift+N/S/W` 是 VSCode 通用；`Ctrl+P` 留给项目切换（不绑定为打开文件，是切换 MRU 快速入口）
4. **不堆所有功能**：保存/撤销不并入，因已有独立按钮且高频

## B. 地图三级钻取

### B.1 层级模型

| 级 | 名称 | 承载内容 | 进入条件 | 退出条件 |
|---|---|---|---|---|
| **L0** | 世界地图 | 地形 / 势力 / 部队轨迹 / 事件点 / 部队标记 | 启动默认 / 面包屑 L0 点击 | 双击城市菱形 |
| **L1** | 城市地图 | 街区圆形 + 街道格网 + 城市名 + 简介 + 建筑菱形 | 双击城市菱形 / 命令面板"钻回遵义城" | 双击建筑菱形 / 面包屑 L0 点击 |
| **L2** | 建筑内 | 房间矩形 + 房间名 + 简介（或"室内布局待补"提示） | 双击建筑菱形 | 面包屑 L1/L0 点击 / `Backspace` |

**为什么不预留第 4 级（L3 房间）**：基线 §2.16 + §6.2「能力可预留，结构不落地」纪律。L3 已在 `FLOORS` 数据结构里给了一个建筑（`hq` 指挥部）的样例房间，**只为演示 L2 渲染能力**，不为产品形态下结论。

### B.2 钻入标记（菱形）

| 级 | 形状 | 大小 | 默认态 | 已访问态 |
|---|---|---|---|---|
| L0 城市 | 菱形 14px | 命中区 24×24 | `--ui-accent` 蓝实心 + 1.5px 背板色描边 | `--ui-text-3` 灰实心 |
| L1 建筑 | 菱形 12px + **中心实心点** | 命中区 24×24 | 同上 | 灰 + **内圈点改 ui-tx-1** |

**为什么不延用形状族**：菱形在地图产品里天然指向「层级跃迁」（与圆=位置点 / 六边形=地形格网 / 旗帜=领地 不冲突）。

**为什么不延用 `world.accent.select` 金**：与「选中地块」语义撞。钻入是**导航**，不是选中。

### B.3 面包屑

```
┌─────────────────────────────────────────────────┐
│ 层级  世界地图 › 遵义城 › 指挥部                │
└─────────────────────────────────────────────────┘
```

- 位置：浮动 chip，浮于地图区**左上角**（避顶栏 + 避时间轴）
- 背板：`--ui-bg-float .94`（与时间轴 HUD chip 同底色语言）
- 当前级：字重 700 + 14px + `--ui-text-1`，**不可点**
- 上级：字重 400 + 13px + 新令牌 `#8A93A6` 暗 / `#5B6373` 亮，**可点**（hover 加金下划线）
- 分隔符：`›`（U+203A），判据：避免与 `/` 路径语义 + `▸` 三角与地图钻入菱形撞语义
- 沉浸模式：保留可见，降 60% 透明度

**新增令牌**：1 个 `--crumb-text-3`（提案中标注为「可申请，必要」），与既有 `ui-text-3` 区分亮色值（`#5B6373` vs `#6B7383`），因底从 `bg.panel` 变为 `bg-float over snow`（合成后底更亮）。

### B.4 切换过渡

| 维度 | 行为 |
|---|---|
| 时长 | **380ms** ease-out（与全站 `cubic-bezier(.2,0,.2,1)` 一致） |
| 相机动画 | 平滑 zoom-to-bounds（`animateCam` 用 `requestAnimationFrame` + `easeOutCubic`） |
| 内容替换 | **直接替换**，旧级不作为背景淡出（v0.2 不预留 fly-out） |
| 笔刷光标 | 城市级 / 建筑级**不显示**（与笔刷只对世界地形生效的语义一致） |
| 时间轴 | 跨级有效，但播放进度以 L0 day 为准 |
| LOD 标签 | 自动替换：L0 显示「四渡赤水 · 正在发生」，L1 显示「<城市名> · 城区」 |

### B.5 状态归属

| 状态 | 归属层 | 钻入时行为 |
|---|---|---|
| 视口（x/y/zoom） | 壳层 | **跟随级切换**（缩放到目标中心） |
| 选中实体 id | 壳层 | 钻入时**保留选中**（若选中的不在新级，会变成视觉外但 ID 还在——靠 HUD 高亮兜底） |
| 时间游标 | 壳层 | **保留**（不响应级切换） |
| 访问痕迹 | 壳层 | 钻出时**写入 visited Set**，钻入标记变 `data-visited="1"`（灰填充 + 内圈点） |

### B.6 判据

1. **3 级够用**：当前故事数据没有"房间内"叙事，强行闭合会变成空 demo
2. **双击主路径**：单击保留为「选中 + 检视器显示」语义，双击专给钻入——与现有「单击事件点显示详情」不冲突
3. **`Backspace` 钻回上一级**：与浏览器"返回"心智一致；与时间轴的 L1-L4 缩放完全独立（两套交互不抢）
4. **菱形 + 内圈点区分级**：避免引入形状族（形状族稳定是品牌资产）

## E. 不做（明确列出）

| 不做 | 理由 |
|---|---|
| **第 4 级房间内叙事** | YAGNI + 故事数据无支撑；想留 N+1 时按基线 §6.2「能力可预留，结构不落地」处理 |
| **面包屑下拉菜单**（同级并列项） | v0.2 假设层为一对一路径；后续有「多城市并列」再评估 |
| **面包屑用 emoji 图标** | 与扁平 token 视觉冲突 + 跨系统字形不一致 |
| **钻入标记形状族扩展**（六边形 / 旗帜） | 菱形 + 内圈点已够，形状族稳定是品牌资产 |
| **钻入时旧级作为背景淡出** | 单人开发成本过高；与时间轴 L1-L4 的「内容替换」语言一致 |
| **沉浸模式下面包屑 / 钻入标记隐藏** | 隐藏会丢失导航上下文；保留 + 降 60% 透明度 |
| **面包屑用 `--ui-accent` 蓝** | 蓝色专留给「交互对象」语义，路径「视章」刻意回避 |
| **不渲染工程文件树侧栏** | 与浮动 chip 信息重复 + 占空间 |
| **工程菜单里加「保存」** | 已在顶栏读数区放独立按钮 |
| **最近工程支持删除 / 固定** | MRU 自动维护；增删逻辑留待产品形态稳定后再做 |
| **Backspace 全局钻回**（包括命令面板打开时） | 输入框聚焦时不响应快捷键（已有 typing 检查）；避免误触 |

### Q4 闭合理由（采纳倾向）

工程菜单里的「最近工程 / 4-6 项」即 MRU（**Most Recently Used**，最近使用）。

**不绑 `Ctrl+P` 的理由**：
- VSCode / Sublime / 多数 IDE 的 `Ctrl+P` 是「快速打开文件」语义
- 我们的 `Ctrl+K` 已是命令面板；如果未来加 `Ctrl+P` 命令面板快捷键（VSCode 风格）会冲突
- MRU 切换是低频动作（打开新工程一天最多几次），不是值得抢快捷键的高频操作
- 想用 MRU 时点「项目管理 ▾」即可，2 次点击成本可接受

### Q5 落地位置（v0.3 备忘）

钻入时旧级作为背景淡出（fly-out）：
- 实现路径：`drawCityGrid`/`drawFloor` 保留但加 `opacity` 过渡（380ms 内从 1→0）
- 同步当前级从 0→1（错开 100ms 营造层叠感）
- 渲染成本：需双 canvas 层（现存与绘制层）—— 内存占用翻倍
- 触发条件：仅 `drillTo` 时（不响应滚轮/拖拽）
