# 辛亥一九一一（示例工程）

覆盖 1911 年保路运动 → 武昌起义 → 清帝退位的因果链示例。它是 minimal-world
之后的第二个示例工程：同一套 schema v2，改用**公历历法**（ADR-0006）与
**多地图层级**（原则四：父图只存子图 Id）。

## 目录结构

```
xinhai-1911/
├── world.yaml                    # 工程元数据（root_map: map_world，[1, 425)）
├── timeline/
│   ├── axis.yaml                 # gregorian 历法 + 3 个锚点
│   ├── events/                   # 8 个事件（每实体一文件）
│   ├── narrations/               # 8 段旁白（因果链文案）
│   └── situations/               # 3 条事态
├── maps/
│   ├── world/index.yaml          # 世界图 4096²，children 引用两张城市图
│   ├── city_wuchang/index.yaml   # 武昌城图 1024²，parent: map_world
│   └── city_chengdu/index.yaml   # 成都城图 1024²，parent: map_world
├── distances/                    # 16 地点 / 10 边 / 2 交通工具
├── units/                        # 3 个单位（运动主体）
├── tracks/                       # 3 条轨迹
├── characters/                   # 3 个角色
└── relations/graph.yaml          # 空表（本示例不含势力层）
```

## 日期换算表

历法 `gregorian / prefix 公元 / start_year 1911`，第 1 天 = 1911-01-01。

| 真实日期 | day（天数计数器） | 事件 |
|---|---|---|
| 1911-05-09 | 129 | 铁路国有诏下 |
| 1911-06-17 | 168 | 保路同志会成立 |
| 1911-09-07 | 250 | 成都血案 |
| 1911-09-08 | 251 | 同志军围城 |
| 1911-09-15 | 258 | 端方新军西调入川 |
| 1911-10-10 | 283 | 武昌起义 |
| 1911-10-22 | 295 | 湖南陕西等省响应 |
| 1911-12-02 | 336 | 南京光复 |
| 1912-02-12 | 408 | 清帝退位 |

换算规则：1911 年内 day = 当年积日（如 5/9 = 31+28+31+30+9 = 129）；
1912 年 day = 365 + 1912 年积日（1912 为闰年，2/29 = 425，即 timeline_range 上界）。

## 因果链

铁路国有诏下，四省路权被夺；四川保路同志会聚众请愿；总督赵尔丰制造成都血案，
同志军蜂起围城；清廷调湖北新军西调入川平乱，武汉防务空虚；武昌新军乘虚举义，
一夜光复；各省相继响应独立，南京光复奠定共和支点；终至清帝退位，两千余年帝制
落幕。因果叙述由 `timeline/narrations/` 的旁白文案承担，不设箭头字段。

## 非目标

- 不含势力层；`relations/graph.yaml` 保持空表。
- 不追求史实完备：人物、部队、日期均为演示 schema 用途的最小集合。
