# 小样张（small-demo）

**内容轴 × 模式的目视夹具**：六张图、每张 256² 栅格、一张只强测一件事。

定位与 `layer-showcase` 不重叠——那份测**图层体系**（9 种 LayerKind / z 偏移 / 子图接管），
这份测**内容与呈现规则的相互作用**：地形带怎么着色、道路不同级别在哪个缩放档出现、
河流与海岸怎么衔接、POI 的呈现级别怎么淘汰。问题出现时要能一眼归因到「哪条轴」，
所以刻意不做综合世界观，也不挂任何叙事数据。

体积（不含本 README，避免数字把自己算进去）：六张 `terrain.bin` **370 430 B（361.7 KiB）**、
YAML **12 236 B（11.9 KiB）**，合计 382 666 B（373.7 KiB）。
**几乎全是栅格**：YAML 那 12 KiB 装下了 6 张图的图层声明、39 个地点、12 条边、10 条手绘河。

## 打开 / 校验 / 再生成

```bash
# 打开（索引页起手，双击图标钻入任一内容轴）
cargo run -p wv-app --features app --bin wv -- gui -m examples/small-demo

# 结构校验（当前零诊断）
cargo run -p wv-app --features app --bin wv -- validate examples/small-demo

# 重新落盘（含内置自检；README 不会被覆盖）
cargo run -p wv-app --example gen_small_demo
```

生成器走 `wv_io::Project::save_world` 标准链路（每实体一文件 §4.5、`terrain.bin` 由
`write_terrain_if_any` 写出并回写 `RasterRef`），生成物与加载器 schema 同源。

| `t_river` | 水系与出海口 | 西高（山）东低（海），主河沿线刻谷 | 8 条手绘河 | 河口三态；河宽；rank 门槛 |
| `t_poi` | POI 与图标 | 平坦草原 | 12 个地点（rank 3/2/1/0）+ 5 种图标 | 呈现级别淘汰；图标形状 |
| `t_combo` | 综合小样张 | 海 / 草原 / 林带 / 丘陵穹顶 | 5 地点 / 4 边 / 2 河 / 1 疆域 | 叠加后 8 模式是否仍成立 |

> 幅面统一 `4096 × 4096`、栅格 `256²`（cell = 16 wu）。**这不是美术尺寸，是 LOD 尺寸**：
> `LOD_NATION_SCALE = 3.0` / `LOD_REGION_SCALE = 1.0` 是绝对 `scale` 阈值，幅面若缩到 512，
> 打开即落 Edit 档，「拉远只剩干线」这类判据根本触发不了。

## 口径（为什么数据长这样）

1. **`template: None`**：派生河（ADR-0037 D5）的 `rivers_seed` 是**工程级**字段，一旦声明，
   每张图都会按各自地形长河——那会污染「只测手绘河 / 河口三态」的口径。所以本工程不声明模板，
   河流全部走 `Place.line`（ADR-0046），纯 YAML、零二进制。
2. **`extent` 4096² / 栅格 256²**：见上文 LOD 说明。
3. **渲染用群系编号，不用 `migrate_v1_kind` 的折档**：旧 kind 5..=7 → `BIOME_NONE(0)` 会让
   丘陵 / 山地 / 雪原同色，地貌展示退化成一条褐带；本工程显式写 12 / 13 / 9。
4. **「水面」按 `surface == 0` 算（含浅水）**：`channels_of` 把旧 kind 0 与 1 都记 `surface=0`，
   所以 `t_river` 的水面西界在 `gx ≈ 0.51`（x ≈ 2080 wu），**不是**按「深水 t<0.30」推出来的 0.58。
   后者靠东约 300 wu，拿它摆河口会把末点整个埋进水里（这正是首轮验收 D1 的成因）。
5. **标签层只在 4 张图落盘**（`map_index` / `t_road` / `t_poi` / `t_combo`）：`t_terrain` 与
   `t_river` 没有需要标注的实体，不写空配置。

## 生成即验证

`gen_small_demo` 落盘后会跑 `verify()`，五条断言：

1. **可达性**：六张图都能从 `world.yaml.root_map` 沿 `children` 走通（`drill_to` 是 BFS，孤图进不去）；
2. **栅格完整性**：凡声明了 `LayerKind::Terrain` 的图，必须真有栅格（补 G6 的盲区）；
3. **手绘河分级**：八条河按自己的折线长度重算占比，对照 ADR-0047 D5 的 0.40 / 0.15 得 3/3/3/2/1/1/1/1；
4. **路网切片**：`t_road` 的段数按 rank 现数，必须为 Edit 8 / Region 6 / Nation 3；
5. **河口三态（cell 级）**：直接读 `cells[i].surface`（0=水含浅水 / 1=陆）——
   澜江末点为水且向东 600 wu 仍为水；平口河末点为水且向西 200 wu 为陆；
   断口河末点为陆且向东 250 wu 为水。判据不推断高度，避免再按错口径估岸线。

改数据后若断言炸，说明 README 里的判据与数据已经不同步——先对账，再改判据。

**余量实况**（实测，不是设计值）：`rv_main` 0.793 / `rv_flush` 0.433 / `rv_short` 0.426。
`rv_short` 距 0.40 的 rank 3 门槛只剩 **+26 wu**——动它的末点坐标必须重跑生成器，
否则静默掉到 rank 2（Nation/Region 档看不见），而界面上不会报错。

> **未接入 CI**：`gen_small_demo` 是 example，`cargo test` 不会执行它——这五条断言只在
> 手动跑生成器时生效。是否挂进 CI（跑该 example 并 grep `verify:` 结论行）是待裁项。

## 边界（这份示例不测什么）

- **LOD 分档曲线**（淡出带 / 阈值）→ 看 `examples/lod-demo`；

- **真实地理数据**→ 看 `examples/guangdong`（Overture 导入）。
