### 字符串触面（22 文件 / 241 处）的清理原则

- 同一短语多处复用 → 单一 Key 变体（如 `Key::Modified` / `Key::Saved`）。
- 同语义但英文版本不同 → 一开始也合并；遇到真不能合并再裂（迭代收敛即可，但 v1 不主动做任何上下文特化）。
- dev-facing 字符串（`assert!` / `panic!` / `unreachable!` / `bevy::log::warn!`）**不**翻译，与代码注释同语言（中文），遵守 AGENTS §7.4。

## 3. 数据与 API 设计

### 3.1 `Locale` 枚举

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash, Serialize, Deserialize, Default)]
pub enum Locale {
    #[default]
    Zh,  // 简体中文
    En,  // English
}
impl Locale {
    pub const ALL: [Locale; 2] = [Locale::Zh, Locale::En];
    pub fn as_str(self) -> &'static str { match self { Locale::Zh => "zh", Locale::En => "en" } }
    /// 接受 `"zh"`/`"zh-CN"`/`"zh-Hans"`/`"en"`/`"en-US"`。
    /// 不区分大小写；未知时返回 `None`。
    pub fn parse(s: &str) -> Option<Self>;
}
impl std::fmt::Display for Locale { /* 用 as_str */ }
```

### 3.2 `I18nKey` 枚举

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum I18nKey {
    // —— topbar ——
    TopBarUnsaved,
    TopBarSaved,
    TopBarUnsavedDot,
    TopBarForceRedrawTooltip,
    TopBarNoSelection,
    // —— welcome ——
    WelcomeRecentEmpty,
    WelcomeOpenProjectBtn,
    WelcomeNewProjectBtn,
    WelcomeRecentBtn,
    // —— dialogs ——
    NewProjectDialogTitle,
    NewMapDialogTitle,
    // —— common ——
    Delete,

    // —— about 60 个变体——按出现位置归类
}
```

总数预计在 **80–110 个变体**之间（241 处字符串做归一）。

### 3.3 查表

```rust
// table.rs
pub(crate) fn lookup_zh(key: I18nKey) -> &'static str { match key { ... } }
pub(crate) fn lookup_en(key: I18nKey) -> &'static str { match key { ... } }

// mod.rs
pub fn t(locale: Locale, key: I18nKey) -> &'static str {
    match locale {
        Locale::Zh => table::lookup_zh(key),
        Locale::En => table::lookup_en(key),
    }
}

/// Resource-only 便捷：UI 面板绝大多数都靠 `Res<CurrentLocale>` 调用，
/// 提供 `t_key(&CurrentLocale, key)` 减少传 Locale 的负担。
pub fn t_key(loc: &CurrentLocale, key: I18nKey) -> &'static str {
    t(loc.0, key)
}
```

**调用点形式**（`top_bar.rs` 示意）：
```rust
fn top_right_status(ui: &mut egui::Ui, loc: &CurrentLocale) {
    ui.label(i18n::t_key(loc, I18nKey::TopBarUnsavedDot));
    if dirty { ui.label(i18n::t_key(loc, I18nKey::TopBarUnsaved)); }
    else    { ui.label(i18n::t_key(loc, I18nKey::TopBarSaved)); }
}
```

### 3.4 持久化字段

`crates/wv-app/src/ui_layout.rs::LayoutFile` 加一行：
```rust
#[serde(default)]
pub language: Option<String>,   // serde_yaml 把 "zh" / "en" 存成字符串即可
```

故意用 `Option<String>` 而非 `Option<Locale>`：`Locale::parse` 失败时静默忽略该字段，
不阻塞启动（与 `theme`/`map_theme` 同口径——那两个也是 `Option<String>`）。

`LayoutFile::save` 时 `language` 字段由 `persist_layout_on_change` 负责：从
`Res<CurrentLocale>` 拿当前 Locale 写盘（仅在 change 时）。`load_map_theme_on_project_open`
改名 `load_layout_on_project_open`，并新增：
```rust
if let Some(lang) = &file.language {
    if let Some(l) = Locale::parse(lang) {
        current.0 = l;
    }
}
```

### 3.5 `CurrentLocale` Resource

```rust
#[derive(Resource, Debug, Clone, Copy)]
pub struct CurrentLocale(pub Locale);
```

在 `app_bootstrap.rs` `run()` 内：
```rust
.init_resource::<CurrentLocale>()
```
此时 `loc.0 == Locale::Zh`（默认），后续 `load_layout_on_project_open`
覆盖之。无工程打开时，仍是 Zh，符合"代码当前唯一工作语言"的语义。

### 3.6 Bevy canvas 文字（`render::drill`、`terrain_view` 等）

`Text2d::from(s)` 中 `s` 由当前帧 Egui 上下文计算 = `t(loc, key)`。需要调用点注入。
最干净是 `drill.rs` 里的 `marker_label_text(...)` 之类的辅助函数已经存在（待确认），
sign 一个 `&CurrentLocale` 参数即可，否则在 system 内 `let loc = world.resource::<CurrentLocale>();` 一次拿。

### 3.7 字体

不引入 locale-aware 字体切换。`fonts.rs:81-165` 在 `PreUpdate` 注一次，
egui 字体回退栈中"先 Latin 默认字、再 CJK 比例字"已天然生效——
当文本不含 CJK 时，egui 不会触发 CJK fallback；含 CJK 时自动命中。
英文用户长期不会感受到 CJK 注册的副作用（多注册一组字体而已）。

**反向问题不存在**：英文文本不会触发 CJK，故无需改 `cjk_font_name()`。

## 7. ADR-0018 提纲

文件：`docs/adr/ADR-0018-i18n.md`

| 节 | 内容 |
|---|---|
| 处境 | 工程当前唯一 UI 语言是简体中文（默认 CJK 字体栈），241 处硬编码中文；用户启动 GUI 时无法切到英语。 |
| 决策 | 1. **手写键查表**（Locale + I18nKey + match 表）。2. **.ui-layout.yaml 新增 `language: Option<String>` 字段**。3. 字符面量为整页布局，调用点 `format!` 自行组合。 |
| 理由 | AGENTS §9 默认拒绝新依赖；P2 强制偏好随工程，`ui-layout.yaml` 是该工程唯一合规出口；纯文本无复数 / 性别 / ICU 选择变量。 |
| 代价 | 1. 新增语言需全 enum + match 表手动扩。2. 与未来 FTL 文件 / 复数变量暂不兼容——届时按 ADR 流程开 ADR-N+1 推 Fluent。 |
| 被否决的备选 | (a) Mozilla Fluent（3 个新依赖、违反 §9）。(b) sys-locale crate + 自动探测（用户已"随工程"拍板，自动探测仅留作空编辑器默认值兜底）。(c) 全局 XDG 配置（违反 P2）。(d) 自增 int ID 替代 enum（diff 不可读，违反 AGENTS §4.4 精神）。 |
