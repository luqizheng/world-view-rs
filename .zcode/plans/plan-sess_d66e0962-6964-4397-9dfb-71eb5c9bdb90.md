## M2 氛围渲染（三条规则落地）

1. **缩放联动降饱和 = 纸面雾霭 quad**：纸色（暮色用深纸色）全图四边形，Z=0.06（等值线 0.04 之上、道路 0.09 之下），alpha = f(scale) 连续插值。关键设计：不动 CPU 纹理重建（每帧改 alpha 零成本）；近景 alpha→0、远景趋近上限，手算断言边界值。
2. **纸张噪点**：启动时定种子程序化生成噪声 Image，ColorMaterial{texture} 世界锁定平铺 quad（UV 按世界坐标计算，随图平移缩放，如真实纸张），Z=0.5（盖文字 0.4、低于笔刷光标 0.9），alpha≈0.035。零自定义 shader。
3. **文字晕边**：地名/街名每条 label 加 4 向偏移 halo 副本（日间纸色/暮色深纸色），复用现有 Text2d 池化，Z=labelZ−0.005，先画 halo 后画本体。

测试：雾霭 alpha 曲线手算、噪声同种子同字节（确定性）、halo 实体数=4n。

## M3 2.5D 建筑挤出（重定界：走街道同款路径）

探索发现：Overture 链路目前只产出 PlaceEdge 距离边，Polygon 在 wv-overture/fetch.rs:43-44 被显式跳过；街道本体的正规入口是作者手绘 EditCommand。因此建筑 v1 = 数据模型 + 编辑命令 + 渲染，Overture Polygon 导入列为后续待裁（渲染不依赖数据来源，测试用 fixture YAML）。

1. wv-core/source/building.rs：BuildingLayer { buildings: Vec<Building { name?, height_m, ring: Vec<Point> }> }，仿 street.rs（P3：YAML 矢量数据，不涉二进制例外）。
2. wv-io/project.rs：读写仿 load_streets/write_streets_layers，虚拟脏路径 buildings/<layer_id>。
3. wv-edit/command.rs：增删改命令 + 回滚测试（仿街道命令）。
4. LayerKind::Building 变体（layer_frame.rs kind_index 穷尽匹配强制登记，编译期防漏）+ ViewState.buildings_visible + 图层面板复选框。
5. render/buildings.rs：耳切三角化（凹多边形支持，手算测试用例）+ 环边挤出 quad（世界固定方向，高度×夸张系数——待决标注）+ 柔影 = 2-3 层错位低 alpha 叠加近似弥散（无 shader；光源左上→影向右下）；Z：影 0.125 / 体 0.13-0.15（道路之上、POI 之下）；LOD 省级+才显示。
6. YAML round-trip load(save(w))==w（§7.2 强制）+ 手算挤出几何断言。
