# 标准化 Button 控件（wv-app · UI 标准化第 1 项）

## 现状
工作区已有未提交的 `ToolButton`（widgets.rs L311–466，方案 B 成品）：纯图标 + tooltip + active/enabled + Lucide SVG（7 个图标常量）+ SVG loader 装配。缺口：① 无文字 / 图标+文字形态；② 默认 `tint`/`active_bg` 是 WHITE，caller 不覆盖就出错；③ 尺寸硬编码 38×38，不接 `UiDensity`；④ 颜色不接 `UiShell` 令牌。

## 改动（全部在 `crates/wv-app`，渲染层 feature `app` 门控内）

### 1. `ui/widgets.rs` — 把 `ToolButton` 升级为标准 Button
- 新增内容枚举 `ToolButtonContent<'a>`：`Icon(ToolIcon)` / `Text(&'a str)` / `IconText(ToolIcon, &'a str)`。
- 构造器三态：`ToolButton::icon(icon, hint)`、`::text(label, hint)`、`::icon_text(icon, label, hint)`（内部统一 `egui::Button::image_and_text` / `Button::new`）。
- `show` 签名改为 `show(self, ui, shell: &UiShell, on_click)`：默认值从 shell 解析——`tint = shell.t1()`、`active_bg = shell.active_bg()`、默认尺寸 `hit×hit`（随密度 28/24）；显式 `.tint()/.active_bg()/.size()` 覆盖仍优先（保住 map_controls 的 Google 白色控件配色）。
- tooltip 统一 `on_hover_text`（空 hint 跳过，现状保留）。
- 文字用 `font_size::SMALL`、颜色同 tint；遵守「禁止裸 hex」纪律，全部取自 `UiShell`。

### 2. `ui/mod.rs` — 导出新符号（`ToolButtonContent` 等，沿用现有 re-export 层）。

### 3. `ui/map_controls.rs` — 迁移到新签名（唯一现役调用点）：传 `UiShell`（若无现成参数则补 `Res<UiShell>`，实现时确认其资源形态），Google 配色改由显式 `.tint()/.active_bg()/.size()` 覆盖表达。

### 4. 测试（`--features app` 下）
- 三种内容形态的构造与默认解析：默认色不再是 WHITE、来自 ShellPalette 令牌；显式覆盖生效。
- 空/非空 hint 行为；active/enabled 的 fill 选择逻辑（纯函数断言，附上下文值）。
- 命名按 §7.3 完整英文短句。
