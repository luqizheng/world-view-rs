## 0. 范围

**做**：地形边界的渲染方向（等值线矢量平涂）；编辑/浏览两态的网格可见性；多边形地物生成工具（手势即命令）。

**不做**：
- 势力图渲染（讨论中明确排除）；
- 河流（有流向与连通性，矢量语义，归矢量图层，不进类型格——后续另案）；
- 地形时间轴化（见 D8）。

## 1. 已定方向（D 组）

| # | 决策 | 依据 / 说明 |
|---|---|---|
| D1 | 网格双通道（I16 高度 + U8 类型）是地形的**唯一事实** | 对齐基线 §2.3；二进制是 P3 唯一例外（AGENTS §5） |
| D2 | 边界分两个事实来源：**水体/崖线由高度场等值线驱动**（海岸 = 海平面等值线，崖 = 坡度阈值线）；**地表覆盖由类型场驱动**（软边过渡） | 等值线免费获得自然蜿蜒；作者只画高度，不手维护水陆边界 |
| D3 | 渲染模式定位：**A 等值线矢量平涂**（地基，先做）；**C 像素纹理填充 + 矢量裁切**（挂同一多边形管线，后做）；**B 整瓦片 autotile**（边缘硬是构造性限制，仅严格复古诉求时做） | 三模式共存于同一网格数据，属视图层（P5 精神），数据层零改动 |
| D4 | 网格可见性 = 编辑态的显示开关；浏览态渲染连续图形，无网格 | 同一数据两种投影，对齐 ViewMode 机制 |
| D5 | 多边形工具 = **手势即命令**：圈选 + 配方 + 种子构成一条宏 `EditCommand`，执行后写格子；多边形只留撤销历史，**不留存为实体** | 网格是唯一事实，避免「特征留存」的双源真相；重新生成 = 重跑换种子 |
| D6 | 确定性：一切派生与生成 = **(数据, 参数, 种子, 坐标) 的纯函数**；种子存地图元数据 | 否则重建即抖动、缓存无从谈起、无法回归测试 |
| D7 | 地物配方数据化（YAML）：内置缺省 + 工程可覆盖 | 「经验」的归宿是参数文件，不是代码常量（P3 / P2） |
| D8 | 地形**不时间轴化**：按「地形无时间轴」实现（最易回退形态）；未来若要历史化地形须新开 ADR | P6/P7 约束事态类数据；地形栅格区间化成本极高且当前无需求 |
| D9 | 曲线、多边形、等值线等派生几何**永不落盘**，渲染期计算 | 「存参数、算结论」在渲染侧的同构（呼应 AGENTS §4.2） |

### 组一 · 数据语义（其余各组都依赖）

**Q1 高度值语义**（与 README §12-10「地形双通道编码」合并裁决）——**已裁 2026-10-14，见 §8**
背景：I16 高度通道的单位与基准，决定海岸等值线的定义（海平面 = 0？）。
选项：A. 1 单位 = 1 米、海平面 = 0、负值水下（±32767 m 覆盖地球极值）；B. 0.1 米精度（±3276.7 m，地球放不下）；C. 归一化定标（需换算层）。
**缺省建议：A**。

**Q2 类型词汇的语义层权威源**（2026-10-14 外部评审后重述）——**已裁 2026-10-14，见 §8**
背景：`wv-terrain` **刻意用 `u8` 而非枚举**（`crates/wv-terrain/src/lib.rs:38-43`，理由与势力层 D2 同源——类型是开放集，Theme Pack 可增减种类）；**编号 → 名称 → 色值的映射由 Theme Pack 承载**（`wv-app/theme/colors_*.rs` 已存在），瓦片图集另有 `TerrainKind → 格位` 映射（缺项回退纯色）。即：**呈现层权威源已存在（Theme Pack）**——本计划初稿所写「没有单一词汇权威源」不准确，已修正。真正缺的是**语义层**：类型优先序（Q5）与高度分带（配方）没有归属。
**硬约束**：`wv-terrain` 零第三方依赖（lib.rs:13）——YAML 加载属 `wv-io`；缺省语义表可作为 `wv-terrain` 内的**常量表**（纯数据），不得为注册表给该 crate 引入解析依赖。
选项：A. 语义字段（优先序 / 分带）**并入 Theme Pack 注册表**——单一表，但换主题包会连带换生成语义（外观与语义耦合）；B. **两表分离**——名称 / 色值留在 Theme Pack（维持 `lib.rs` 既有契约），优先序 / 分带做数据级语义表（`wv-terrain` 常量缺省 + `wv-io` YAML 覆盖，生成 / 渲染算法以参数接收）。
**缺省建议：B**（AGENTS §3「数据与渲染分离」的直接推论：换皮不该换语义）。

**Q3 生成参数的比例语义**（挂 README §12-20 地面尺度）——**已裁 2026-10-14，见 §8**
背景：理想形态是配方参数用物理单位（「山体直径 200 km」）按格径换算；但虚构图 cell size 口径未定（§12-20）。
选项：A. 第一版配方参数用**格数**，§12-20 收敛后再 km 化；B. 阻塞等待 §12-20。
**缺省建议：A**（最易回退：收敛点在配方字段的解释层）。

### 组二 · 边界提取规则

**Q4 采样点**：格心 vs 格角。——**已裁 2026-10-14，见 §8**
**缺省建议：格心采样 + 对偶格插值**（等值点落在相邻格心连线上，曲线天然穿行格子内部；单格小岛退化为菱形，可预期）。

**Q5 类型优先序**（多型交汇的全局裁决序；只影响渲染归属与生成默认，不改数据）。——**已裁 2026-10-14，见 §8**
**缺省建议**：深水 < 浅水/岸 < 沼泽 < 平原 < 沙漠 < 森林 < 丘陵 < 山地 < 雪原。

**Q6 鞍点与三型以上交汇**：对角同型（棋盘格）时的确定性裁决。——**已裁 2026-10-14，见 §8**
**缺省建议：四邻均值法**（鞍点归属取四角均值决定），保证同数据必同结果、曲线不随机翻转。

**Q7 邻域定义**：类型场过渡带判定用 4 邻域还是 8 邻域。
**缺省建议：8 邻域**（对角接触算边界，一格宽细条不漏画；等值线主路径是连续场，不受此影响）。

### 组三 · 渲染参数

**Q8 曲线平滑与抽稀**：Chaikin 轮数、Douglas-Peucker 容差分档。
**缺省建议：Chaikin 2 轮**（对齐基线 §2.4 已采纳参数）；DP 容差按 LOD 分档（远 0.5 格 / 近 0.125 格）。

**Q9 LOD 分档**（与 ADR-0009 级缩放区间 / LodTier 对齐）。
**缺省建议**：远景（Nation/Region）只画水体等值线 + 大类平涂；中景加类型边界；近景（Edit）全要素，网格开关可用。

**Q10 晕渲参数**（2026-10-14 扩容为**高度派生叠加层家族**：晕渲 + 推后的分层设色/雪线 tint）。
**缺省建议：光源方位 315°（西北）、俯角 45°、叠加不透明度约 20%**（经典制图缺省）。
**范围裁定（2026-10-14 用户裁定）**：雪覆盖本版本走**生成期高度分带**——雪 = 类型数据（M4 配方自带，作者可手刷覆盖，保「高原草甸」表达力）；渲染期分层设色（按高度盖色 tint、不落盘、跟随笔刷变化）**推后**并入本条叠加层管线，做可开关项（P5）；触发条件 = 「作者手刷抬升后雪不自长」的摩擦真实出现。

**Q11 浏览态默认底图与 ADR-0008 的关系**（吸收 README §12-14(b)）
背景：本计划 A 模式（矢量平涂）与 ADR-0008 已接受的**亚像素纹理平滑**是同一「平滑边界」目标的两条技术路径；§12-14 原案则以 JRPG 瓦片图集作浏览态。
选项：A. 浏览态默认 = 等值线平涂，瓦片/纹理路径降为可切换模式；B. 保留亚像素纹理为默认，平涂为新增模式；C. 按 LOD 分工（远景纹理、近景矢量）。
**缺省建议：A**，「真实地形」视图模式的实现切到矢量路径（具体挂点在 M0 对照现有代码后收口）。
**裁决门（2026-10-14 外部评审补，已核实）**：本问任何「浏览态默认不再是亚像素纹理」的裁决（含缺省建议 A）均构成对 **ADR-0008（Accepted）§2④** 的推翻——按 AGENTS §6.4「不许沉默推翻」，须**先新开 ADR**（处境 / 决策 / 理由 / 代价 + 被否决备选，并在索引标注修正关系）再进 M2 实现；裁为 C（LOD 分工、亚像素仍是默认之一）不触发此门。

**Q12 模式 C（像素纹理 + 矢量裁切）的启动时机**。
**缺省建议：延后**——M4 完成后视作者需求启动。

### 组四 · 草图生成

**Q13 类型通道的写入口径**（与基线 §1.14「不自动改类型、建议 + 一键采纳」的衔接）
背景：§1.14 裁定海拔圈选不自动改类型（保护「高原草甸」类组合的表达力）；但多边形工具里作者**显式选择了地物**，语境不同。
**缺省建议：分区处理**——目标区为空白/水面时双通道同写（显式意图）；区域内已有非空类型时，类型通道按 §1.14 口径给「建议 + 一键采纳」，高度通道照写。
**落地备注（2026-10-14 外部评审补）**：「建议 + 一键采纳」**不引入持久 staging 层**——建议是派生数据，驻留编辑面板 UI 态（不落盘、不进世界），采纳时发第二条 `EditCommand` 写类型通道。即一次圈选可产生「高度写入（立即）+ 类型写入（可选、待采纳）」两条命令，与 D5 手势即命令一致。若未来建议需跨会话留存，再开 §12 待决。

**Q14 融合权重曲线**。
**缺省建议：高斯**，且**复用笔刷已有的衰减权重（Falloff）实现**——同一函数两个用途（笔刷软边、生成融合），公式不二实现；σ 由配方的过渡带宽度参数派生。

**Q15 噪声缺省参数**。
**缺省建议：fBm 4 octaves / lacunarity 2.0 / gain 0.5** 起步，全部进配方可调；种子按 D6 进地图元数据。

**Q16 撤销粒度**。
**缺省建议：一次圈选 = 一条宏命令**（撤销一次全回）；大区域性能在命令内部解决（分块并行），不切片命令。

**Q17 配方初版清单与存放**。
**缺省建议：四配方起步**——山（锥剖面 + 脊噪声 + 分带）、森林（平顶 + 斑块噪声）、沙漠（缓丘）、湖（负高度盆地 + 岸带）；存放：软件内置缺省 + 工程目录可覆盖（P2，具体路径 M4 定）。

## 5. 测试要求（AGENTS §7.2 具体化）

1. **案例表完备枚举**：2 型 16 案例 + 鞍点案例，断言曲线端点与连通性（Q6 定案后逐条手算期望）。
2. **生成剖面手算**：关噪声 + 三角形包络 + 线性剖面，格心高度逐点断言，附实际值（§7.4）。
3. **确定性回归**：同 (数据, 参数, 种子) 两次生成逐格相等。
4. **融合连续性**：生成区边界两侧坡度无跳变（接缝检验）。
5. **双通道 round-trip**：`load(save(g)) == g`。
6. 渲染层命令一并跑：`cargo app-test` / `cargo app-clippy`（AGENTS §7.1 追加门槛）。

### 2026-10-17 · 世界图生成讨论（气候带 / 大陆尺度）

「世界地图的画法」讨论（笔刷 / 地理生成续篇）的三项裁定：

| 项 | 裁决 | 理由 |
|---|---|---|
| 气候带（寒 / 温 / 热） | **不区分**——生成配方不感知纬度；类型分带仍只按高度（Q5 语义表 +「雪走生成期分带」口径不变） | 用户 2026-10-17 裁定「气候忽略」。虚构世界无地球物理义务，作者手绘零约束（V1/V2）；被否决的备选 = 生成参数化气候带（按图内 y 调制类型权重）与每格存气候通道（违反 §5 二进制例外，双通道契约已冻结）。未来若要做，走新 Q，不动存储 |
| 大陆尺度提示 | **校验面板只读提示**——世界图声明 `unit_per_km` 后，面板显示图幅折算公里（X×Y km）、按高度场估算的大陆近似尺度、常见交通方式（步行 / 骑马 / 船）横穿天数；复用 `Vehicle::effective_daily_speed` + `DistanceGraph::segment_days` 唯一换算入口，**不新增换算实现** | 用户 2026-10-17 裁定。定位 = 「叙事换算自动化」（作者按『横穿大陆要几天』反推 `unit_per_km`），而非给正确答案；V1 只提示不阻止。跨 wv-app 校验面板 + wv-core 距离图，不属本计划 M0–M4 任一档——独立追踪于 README §12-39 |
| 世界图缺省宽高比 | **16:9**——生成 / 新建世界图缺省按此比例（格数档如 4096×2304，在 4096² 门禁内），**用户可改**，非硬约束 | 用户 2026-10-17 裁定「大陆生成走 16:9 的比例，除非用户自己更改」。落点 = M4 配方参数缺省 + 新建地图流程缺省值；作者显式改比后依作者（V1 精神） |

### 2026-10-17 · 大陆生成工作流（意图包络 → 配方，续前节讨论）

| 项 | 裁决 | 理由 |
|---|---|---|
| 工作流 | **多边形意图包络批量生成**：多边形工具圈 1..N 个意图（UI 态驻留不落盘，词条见 GLOSSARY「意图包络」）→ 点「生成世界」弹**大陆配方属性面板** → 「生成」= 距离场 + fBm + 高度分带 + Q14 高斯融合，双通道写入打包为**一条宏命令**（Q16 原子撤销；Q13 分区处理） | 用户 2026-10-17 提出并确认。「大陆配方」列为 Q17 四条（山 / 森林 / 沙漠 / 湖）之后的**第五条内置配方**，落 M4；多次执行 = 多条宏命令，各自可撤销（P6） |
| 参数归属 | **全局单一配方参数面板**，每个圈不单独带参数 | 用户裁定「1 同意」 |
| 意图归宿 | **生成即消费**（圈消失）；「取消」关闭面板且圈保留 | 用户裁定「2 同意」 |
| 同区调整 | **不做叠加 / 重骰语义**——走属性面板调参回路：Ctrl+Z 撤销宏命令时地形回滚**且被消费的意图圈回驻留**（UI 态恢复），作者改参数再生成 | 用户裁定「3」（原「高斯叠加」提案被否，改为弹出属性面板调参）。撤销恢复意图圈是裁定 2/3 并存的配套机制：圈不落盘，但随命令撤销回驻留 |
| 默认海洋世界 | 新建世界图初始 = **全格深水类型 + 均匀负高度基准**（建议 −100 m，具体值 M4 定）——替代现 `TerrainGrid::new` 全零格 | 用户原提案。全零格的「height=0 深水」在海平面契约（Q1：海平面 = 0，负值水下）下是歧义态，预填负高度消歧 |
