# ADR-0036: 全局档地貌呈现——Nation 装饰带 + 坡度浮雕 + 雾降档 + 沙漠装饰

- **状态**：已接受（Accepted，2026-10-19，用户对话拍板「开 worktree 做，我要看看效果」）
- **关联**：ADR-0031（D2「Nation 不画装饰」被本 ADR 取代；D4 合批纪律延续）、ADR-0035（日间 JRPG 中高饱和色板）、ADR-0016（纸面雾霭）、ADR-0023（ThemePack 载体）

## 处境

2026-10-18 换 A 方案色板后，全局档（`LodTier::Nation`，scale ≥ 3.0）实测仍然读成「平涂色块 + 密集路网」：

- `decor_band` 对 Nation 档直接返回 `None`（ADR-0031 D2 的「色块承带」假设）；
- 纸雾峰值 0.35 把草绿 `#8CB95F` 洗成 `(185,205,151)`（实机采样），饱和度被吃掉一档；
- 栅格着色只按 `kind` 取色，没有坡度光照，山脉在全局没有体积；
- 装饰六类不含沙漠，参考图右半的沙丘脊线无法表达。

参考图（AI 生成的世界地图）在全局恰恰靠**地貌团 + 山体明暗 + 满饱和色**承载信息，而不是靠放大后的细节。用户要求默认观感向参考图靠拢，并先在 worktree 看效果。

## 决策

**D1 · Nation 装饰带**：新增 `DecorBand::Nation`，采样步距 **96px**、符号尺寸 **1.45×**；`decor_band` 三档都返回 `Some`。全局只保留「大地貌团」——粗步距保证 1024² 栅格上不会糊成噪点，放大档的 26/46px 步距不变。

**D2 · 坡度浮雕**：栅格烘焙时按邻格高差计算明度乘子（光源左上 45°，与 `ART_STYLE_SPEC` §1.5 一致）：
`mul = clamp(1.0 + (−(dh/dx + dh/dy)) × 0.0012, 0.84, 1.16)`。
只在陆格、只在 `VectorFlat` / `RealTerrain` 生效；水域已有深度渐变，不叠坡度。纯函数、无缓存，全图烘焙与笔刷增量 patch 走同一条路径。

**D3 · 纸雾降档**：`VEIL_MAX_ALPHA` 0.35 → **0.18**。淡化机制（`veil_alpha` 线性曲线、编辑态免雾）不变，只降峰值——保留「远景向纸面退散」的空气感，不再吃掉地形色相。

**D4 · 沙漠装饰类**：`DecorKind::Desert`（第 7 桶），`BIOME_DESERT` / `BIOME_GOBI` → 沙丘符号（盐滩不画，保持纯色平面）（两道错位扁半圆脊，沙褐墨色 α0.55）。装饰桶 6 → 7，合批 / 原地改写纪律（ADR-0031 D4）不变。

**D5 · 数据零迁移**：不动 terrain.bin / YAML schema；新观感是纯渲染层。演示世界由 `crates/wv-app/examples/gen_jrpg_world.rs` 生成（冷北—绿中—干旱南），只写 `terrain.bin`，索引 YAML 手工贴回（与既有生成器同纪律）。

## 理由

- 参考图的全局信息密度来自地貌团与明暗，不是细节；Nation 档不画等于把最重要的一层关掉。
- 坡度浮雕是全局性价比最高的一层：一次烘焙、零实体、零每帧成本，却能让山脉在全局「立起来」。
- 雾与色板是耦合参数：0.35 是为低饱和古舆图设计的；JRPG 色板下必须同步降档，否则色板白换。
- 沙漠类是参考图「两份气候」中右半的必需词汇；没有它，干旱世界只能是一块平沙。

## 代价

- Nation 档新增最多 7 个合批 mesh（每类一个，顶点数按 96px 步距受视口面积约束）；实测需在 1024² / 1600×1000 窗口下复核帧率。
- 坡度浮雕会让旧截图与旧像素断言失效；平地的像素断言不受影响（梯度为 0 → 乘子 1.0）。
- 雾降档后远景对比度上升，可能让密集路网更抢眼——道路 LOD（ADR-0030 后续）仍需单独处理。
- 沙漠符号是程序化近似，达不到参考图手绘沙丘的细节；资产化留 M3。

## 被否决的备选

- **保持 Nation 不画，只调色板**：上一轮实测已证明平涂色块无法承带参考图的信息密度。
- **全局直接复用 Region 步距（46px）**：1024² 栅格在全局会生成过密符号，糊成噪点且顶点数翻倍。
- **只加浮雕、不加装饰**：山体有体积但森林/雪原/沙漠仍无词汇，参考图的「地貌团」表达不完整。
- **把雾直接关掉**：失去 ADR-0016 的远景空气感；降档是折中。

## 待裁

- Nation 档的符号密度 / 尺寸（96px / 1.45×）是首版经验值，需在 1024² 与 4096² 世界各做一次实机复核。
- 道路在 Nation 档的过滤策略（ADR-0030 的 rank 门是否延伸到道路层）。
