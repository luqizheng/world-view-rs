# ADR-0081：自然图层分区（自然蛋糕）

- **状态**：已接受（Accepted，2026-10-28，用户对立项问题清单五问按推荐执行「继续」放行；实施期微调见 §7）
- **决策者**：用户对话拍板（2026-10-28，承接 ADR-0079 的「自然图层分区」候选 + ADR-0080 的「Map 主职=画 region」定位）
- **关联**：复用 [ADR-0079](ADR-0079-faction-partition-cake-cutting.md) 全套分区引擎（不推翻其任何结论）；分层依赖 `wv-terrain` 族表（ADR-0032）

## 1. 处境

用户定位（ADR-0080 追记）：**Map 工作区的主职是画自然 Region**。但自然区域的编辑仍是
圈选 + 意图菜单的旧流（ADR-0045 `NatureRegion` 实体），与势力图切蛋糕（ADR-0079）
的「零和 + 铺满 + 共享边界」编辑体验存在代差。ADR-0079 立项时预留的「自然图层分区」
候选——同一套切蛋糕引擎承载自然区域——到了启动时机。

## 2. 决策（五问全按推荐）

| # | 问题 | 决策 |
|---|---|---|
| 1 | 数据归属 | **不另起 NatureLayer 实体**：`FactionLayer` 加 `usage` 字段（`Political`/`Nature`，serde 缺省 Political，存量零迁移）。层模型同构（命名/z/可见性/眼睛/分区挂载），差异只在脸携带什么属性 |
| 2 | 与 NatureRegion 的关系 | **本轮并存不迁移**：分区脸是几何真源候选，`NatureRegion` 实体（命名/父子/合并重生成）保留——统一几何是后续 ADR，不在本轮 scope |
| 3 | 命名规则 | 脸加 `kind: Option<u8>`（群系族下标，`wv-terrain::BIOME_FAMILY_ORDER` 序即契约、**只增不改**）；显示名 = `<族名><N>`，N = 同 kind 脸按 face id 升序的序号（id 随 YAML 持久化 → 名字跨会话稳定）。参与自然蛋糕的族 = 六个陆面族（森林/草原/干旱/湿地/寒带/高地）；水域/道路族不参与 |
| 4 | 时间语义 | 复用引擎**自带** span——「改群系」= fork 换 kind（`SetPartitionFaceKindCommand`，与政治层易主同配方）：火山掩草原从某天生效是白拿能力，不用也不亏 |
| 5 | 入口 | Map 档既有势力层列表同位：`+ Add nature layer` 按钮 + 层行 pen（弹框「新增」分支的归属输入换群系族下拉，默认草原族） |

### 手势语义分派（按层 usage）

| 手势 | 政治层 | 自然层 |
|---|---|---|
| 切刀松手即提交 | 新块自动归占位势力「无名N」 | **不加势力**——kind 随脸两分（切草原出两块草原） |
| Assign（点脸弹窗） | 既有势力 / 新建 / 无主 | **群系族选择**（六族，当前族标 ●）→ fork 换 kind |
| 拖边界 | 零和拖顶点（语义相同） | 同左 |
| 脸填色 | 势力色 / 无主灰 | 族色软表（wv-render 固定表 V1；主题化留未来轮） |

## 3. 理由

- **引擎复用**：零和/铺满/共享边界对自然区域同样成立（植被带之间没有空隙）——
  第二套几何编辑器是纯浪费；
- **判别字段优于平行实体**：两套 Layer/两套命令/两套渲染 only 差「脸属性」，
  一个 enum 判别最便宜；HTTP/诊断/校验面板零新增词表（还是 FactionLayer）；
- **kind 存族下标而非群系编号**：族是 ADR-0032 的规则键粒度（「草原」= 4 个
  编号的族），与自然区域的表达粒度一致；u8 是 wv-core（禁依赖 wv-terrain）与
  wv-terrain 的唯一交汇——序即契约写入族序表文档与测试。

## 4. 硬约束

- `BIOME_FAMILY_ORDER` **只增不改**（新族必须追加表尾）；`family_at` 越界返回
  `None`（坏 YAML 不崩，V1）；
- 自然脸 `owner` 恒 `None`（建模断言，写入引擎测试）；
- 一切编辑仍走 `EditCommand` 链，dirty = `"partitions"`（AGENTS §3.3，与 ADR-0079 同）。

## 5. 后果

**正面**：自然区域获得与势力图同级的编辑体验（切/拖/改 + 预览 + span 历史）；
「Map 主职画 region」从口号变成主工具；命名跨会话稳定。

**负面 / 代价**：`PartitionFace` 加字段（存量 YAML 零迁移但校验器加 kind 越界
条目的空间，本轮未加——诊断面板走既有悬空引用通道）；族色固定表是主题债
（ADR-0072 同款，登记待办）；`NatureRegion` 与分区脸的双几何并存期是显式 tech
debt，统一几何另开 ADR。

**被否决的备选**：另起 `NatureLayer` 实体（平行结构税）；kind 存群系编号
（粒度碎裂，违背 ADR-0032 族键教训）；自然层不带时间（fork 机制白拿却弃用）。

## 6. 与既有 ADR 的关系

- **复用** ADR-0079 分区引擎与全部裁定（不推翻）；
- **沿用** ADR-0032 族模型（`family_of`）与 ADR-0045 NatureRegion（并存期）；
- **承接** ADR-0080 的 Map 主职定位。
