# ADR-0090: 三工作区统一选择器仲裁

日期：2026-10-29 ｜ 状态：已接受 ｜
分轨：承接 [ADR-0089](ADR-0089-map-interaction-grammar.md)（地图交互语法）预留的「统一选择器仲裁」分轨；工具 UI 命名沿用其定（槽 1「点选」/ 槽 3「圈选」）｜
修订：[ADR-0074](ADR-0074-cellmap-point-select-arbitration.md)（仲裁序/Alt 语义）、[ADR-0080](ADR-0080-workspace-partition-and-tool-whitelist.md)（工具白名单）｜ 扩展：[ADR-0081](ADR-0081-nature-layer-partition.md)（切蛋糕）

## 处境

选择交互由两枚工具承载：`MapToolId::Select(SelectionShape)`（UI 名「圈选」，包络圈选→意图菜单，三工作区可用）与 `MapToolId::PointSelect`（UI 名「点选」，ADR-0074 万能选择器，仲裁 = Alt单格 > 图钉 > 群系区）。四个错位：

1. 「图钉」与 Place/POI 实为同一实体（拖钉提交 `UpdatePlaceCommand`、双击弹地点表单，ADR-0074 追记三），仲裁表却名目分立；
2. Select 的包络意图全部是地形/世界意图（七意图），却挂在 Browse（叙事）/ Map（政治图档）工作区，与 ADR-0080 的三工作区分工相悖；
3. PointSelect 兼职格子选择（Alt 单格）与实体选择，一个工具两种心智；
4. 群系在 Map/Browse 不可选，而国家疆域大多随群系/地貌走（群系分界≈自然国境），现在只能手切蛋糕，边界不自然。

## 决策

- **D1 名目合一**：图钉 = Place = POI，仲裁表三类并作一类「POI/Place」。
- **D2 PointSelect = 三工作区通用实体选择器，不再选格子**：
  - CellMap 仲裁：POI/Place > 群系（无闸门，沿 ADR-0074）；
  - Map 仲裁：按图层 z-index 自上而下命中，hidden 图层不可选；LinePoi 工具激活（河/路编辑态）时线 POI 优先级最高；
  - Browse：同 Map 仲裁，但**只读**——命中只弹属性卡，无移动/编辑/意图菜单。
- **D3 Select（UI 名「圈选」，ADR-0089 槽 3 改名）= CellMap 专用格子选择器**：白名单收成 Topographic-only；拖拽成形（多边形/矩形/椭圆）选格子集合；**单击无位移 = 选单格**（接住 ADR-0057「敢随手点」肌肉记忆）；Alt 单格修饰**退役**。
- **D4 群系闸门（Map）**：群系默认不可选；图层面板进入**势力层编辑态**且「群系」checkbox 勾选（**默认勾**）时可选；Ctrl 多选群系 → **替换**该势力既有疆域（多群系并集一次写入，可撤销）。
- **D5 切蛋糕「贴近群系」checkbox（默认勾）**：切线自动吸附群系分界（几何源 = `biome_boundary` / `BiomeField`）；不勾 = 自由切（现状）。
- **D6 河/路数据正身 = 线 POI 几何**（ADR-0070），非地形派生；派生河流（`rivers_from_terrain` 等）定位 = 生成期辅助。CellMap 维持 2026-10-28 裁定②「只看线、不选线、不画线」，线选择仲裁仅存在于 Map。

## 理由

- D1/D2：选择器按「实体 vs 区域」拆分，各守一个心智；实体链路（选中/拖移/双击属性）在两枚工具间不再重复实现。
- D3：格子是地形域关注点，区域选择是地形工作台的高频动作；包络意图本就全属 CellMap 职责（生成大陆已 Topographic-only、划分势力走独立切手势，收编无功能断链）。
- D4：替换语义保证势力疆域单一真源；群系并集比手画国境自然，且 Ctrl 多选与格子多选同一手势语言。
- D6：一格 2km 时河比格细，降格距到 100m 会格数爆炸——河的正身只能是自由几何（线 POI），这与「场管线不接管河/路」（2026-10-29 裁定）互为印证。

## 代价 + 被否决的备选

**代价**：① Browse/Map 失去包络圈选与意图菜单入口；② Alt 单格肌肉记忆退役；③ ADR-0074 的 Alt 分支实现回退；④ 势力疆域两套写入口径并存（群系赋值 / 切蛋糕），依赖替换语义与 UI 文案说清。

**被否决的备选**：
- PointSelect 保留 Alt 单格作隐藏捷径——否决：破坏「点选不碰格子」纯度；
- 群系赋值与既有疆域共存——否决：两套真源必打架；
- 河/路编辑进 CellMap——否决：维持 ADR-0080 裁定②，线几何编辑主场在 Map；
- Browse 开群系闸门（只看属性）——否决：闸门依赖势力层编辑态，Browse 无编辑态，恒闭更简单且符合只读定位。
