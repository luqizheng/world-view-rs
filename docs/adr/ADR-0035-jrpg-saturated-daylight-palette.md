# ADR-0035: 日间地形色板换 JRPG 中高饱和 A 方案

- **状态**：已接受（Accepted，2026-10-18，用户实机验收后拍板——「commit 颜色不错」）
- **关联**：ADR-0016（日间古舆图色板——本 ADR 取代其「地形十色 + 淡化强度」部分，暮色与其余令牌继续有效）、ADR-0023（`PaletteColors` / ThemePack 载体）、`ART_STYLE_SPEC` §1.4.5（本 ADR 的规格投影）、commit `442ec82`

## 处境

2026-10-14 定稿的日间古舆图色板（ADR-0016）是为「泛黄宣纸 + 褐墨」的低饱和历史感设计的：地形十色整体灰度化，底图淡化只保留 35% 本色。这套值在抽象示意图上成立，但在真实地形上失败——2026-10-18 广东 DEM 导入后，栅格底图是连续高程分带的真实地貌，低饱和的草 / 林 / 丘在 1024² 格上互相糊成一片灰绿，「1 秒内读出这是水 / 林 / 路」的可读性承诺（`ART_STYLE_SPEC` §3.2）不再成立。

同时，项目标题层面的 JRPG 方向（`ART_STYLE_SPEC` §1.1「中高饱和水彩打底」）与实际观感已经脱节：古舆图是 JRPG 的**低饱和传统派变体**，而用户最终要的是 16-bit 晚期的高饱和手绘质感。

用户对比实机截图后选定 **A 方案**：中高饱和十色 + 提高淡化保留比例。

## 决策

**D1 · 日间地形十色换值**（`CORE_TERRAIN`，索引语义不变，`TerrainKind` 编号零迁移）：

| # | 槽位 | 古舆图（旧，§1.4.4） | JRPG A 方案（新） |
|---|---|---|---|
| 0 | `core.water_deep` | `#8FA2B3` | `#2C6389` |
| 1 | `core.water_shallow` | `#98A9B9` | `#57A0C0` |
| 2 | `core.sand` | `#E3D5BC` | `#E8D6A2` |
| 3 | `core.grass` | `#A8B898` | `#8CB95F` |
| 4 | `core.forest` | `#93A684` | `#3F7A46` |
| 5 | `core.hill` | `#DCCBAF` | `#B5A765` |
| 6 | `core.mountain` | `#B7A388` | `#8A7A66` |
| 7 | `core.snow` | `#F8F4EA` | `#F5F8F9` |
| 8 | `core.marsh` | `#9AA88C` | `#6F8564` |
| 9 | `core.road` | `#735D48` | `#C8A272` |

**D2 · 日间淡化强度 0.35 → 0.85**（`JRPG_SOFTEN_KEEP`）。淡化机制本身（`soften_color` + 目标纸色 `#F2EAD8`）不动，只改保留比例：85% 本色 + 15% 纸面。**暮色主题沿用 `SOFTEN_KEEP = 0.35`**——暮色地形色未换，仍是古舆图暗调。

**D3 · 雪高光联动**：`SNOW_HIGHLIGHT` `#FBF7EB` → `#FCFEFF`。新雪色 `#F5F8F9` 已近满亮，旧高光反而更暗，双调关系会反转；提到冷白满档保住「highlight 比 `core.snow` 亮」的契约。

**D4 · 边界（本次不动）**：暮色旧纸色板、Google 色板、POI / 道路 casing / 标签 / 等值线 / 网格 / 建筑 / 势力色 / 轮廓图三色全部不变；渲染管线、LOD、地形装饰、ThemePack 契约、YAML schema 均不动。本次是**纯色值与一个强度参数的变更**。

**D5 · 记录纪律**：`crates/wv-render/src/theme/colors.rs::CORE_TERRAIN` 仍是唯一代码投影；`ART_STYLE_SPEC` §1.4.4 原文保留为历史（§6.3 只增不改），新增 §1.4.5 为现行值；ADR-0016 正文不删改，索引表标注被取代的子句。

## 理由

- **可读性优先**：真实栅格地形需要草 / 林 / 丘在 1 秒内可辨。草 `#8CB95F` 与林 `#3F7A46` 靠明度 + 色相差双重区分，色弱冗余也成立。
- **淡化强度必须配套**：0.35 是为低饱和色设计的；中高饱和色被洗 65% 会退成灰白（草绿 `#8CB95F` → `#CED9AE`，实机截图验证过这一失败）。85% 保留本色，同时保留淡化机制本身——笔迹 / 要素的对比让位关系不变。
- **大地色仍留呼吸位**：沙 / 丘 / 山没有推到全饱和（与 `ART_STYLE_SPEC` §1.2「大地色系降到 S 25%–40%」一致），避免全图刺眼。
- **暮色不跟**：暮色旧纸是独立的暗调叙事档，本次没有实机验收；同步换色会追加一轮校准，超出范围。

## 代价

- 日间失去古舆图的纸调统一感。宣纸底仍通过 `soften_toward`、POI 外环、道路 casing、文字晕边保留，画面不会完全脱离暖纸基调，但底色关系已变。
- 日间（中高饱和）与暮色（低饱和古舆图）色系拉开，切换时观感跳变明显。
- 旧截图与旧验收基准（古舆图日间）失效，不能作为回归对照；广东工程的部分旧截图与新色板不对应。

## 被否决的备选

- **保留 0.35 只换色**：实测草绿退成 `#CED9AE` 灰白，等于没换。
- **只提高 `soften_keep` 不换色**：低饱和本色放大后仍灰，且会把宣纸底一起拉浓。
- **暮色同步换 JRPG 色**：超出本次范围，无实机验收，且暮色叙事档需要单独校准。
- **全图统一高饱和**：违反 `ART_STYLE_SPEC` §1.2 的饱和度分层（大地色系保留呼吸位）。

## 待裁

- **暮色是否跟进 JRPG 色系**：当前未决。留待日间色板稳定后的实机反馈；若跟进，需另立 ADR 并给出暮色十色与淡化强度的校准依据。
