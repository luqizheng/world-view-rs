## 1. 处境（Context）

CellMap 已有三条「读高度」通道，但**高度差读不出来**。用户期望：山体连续而非孤立贴图；山脊受光/背光分明；缩放到整个州仍见大型山脉结构；放大后逐渐呈现局部坡面、支脉与细部；笔刷编辑实时。

| 通道 | 实现 | 症状 |
|---|---|---|
| 坡度浮雕 | CPU `cells.rs::relief_mul` / GPU `field/material.rs` | **逐相邻格高差算明度**（0.0012/m，钳 ±12%/±16%）：宽缓地形（百米高差铺十几格）每格明度变化仅 1–3%，肉眼不可见；只有陡崖边缘亮——「**山形有了、体量没有**」 |
| 分层设色 | `hypsometric.rs` 8 阶 | 绝对阶梯首刀 200 m：**0–200 m 整段同色**，手绘世界主体恰在此段 → 低地一整片平色；窄域兜底（< 300 m 跨度）覆盖不到典型图幅 |
| 等值线 | `isoline_overlay.rs` | 有，但密了难读、疏了无用，**非本轮对象** |

另有一个**与目标相反的现行行为**：WGSL 远观时 `lod_t = 1 − smoothstep(1, 3, px_per_cell)` 把 relief **整体收敛到 1.0（浮雕完全关闭）**——这是 T33 噪声抑制口径（`terrain_field.wgsl:180`），也是「缩放到整个州看不到山脉结构」的直接原因之一。

**根因两条**（与参数调轻无关的结构性问题）：

1. **梯度无概括**：单尺度逐格差分只响应局部台阶，不响应宏观形态。专业界的答案是晕渲从**概括后的地形**算（Swisstopo / Google 先低通/多尺度概括再打光），我们缺这一层。
2. **低段无分辨**：色带 8 阶在低端一刀 200 m，低地内部高度差完全不参与颜色。

## 2. 决策（Decision）

### D1 双光源美术光照（替换钳制路线）

```
I = 0.4 + 0.48 · max(0, N·L₁) + 0.12 · max(0, N·L₂)
```

| 参数 | 初始值 | 说明 |
|---|---|---|
| 主光 L₁ | 方位 315°（西北），高度角 45° | 与现行光源方向约定一致（左上受光） |
| 辅光 L₂ | 方位 45°（东北），高度角 45° | 弱辅助光，治「山脉恰与光照平行时山脊山谷消失」 |
| 环境光 | 0.4 | 三系数和 = 1.0，`I` 天然界内 [0.4, 1.0]，**RELIEF_LO/HI 钳制退役** |

这是**美术化光照而非物理太阳模拟**（用户明示）。`I` 作为明度乘子作用于最终色（只压明度、不动色相——Imhof 纪律）。对 [ADR-0067] D2 的修正关系见文首「修正」栏。

### D2 Horn 3×3 梯度 + 米制量纲

```
N = normalize(−s·hₓ, −s·h_y, 1)，s = Z_EXAG / meters_per_cell
```

- `hₓ / h_y` 用 **Horn 算子**（`[1,2,1]ᵀ·[1,2,1]/8` 加权隔格差分），步长 1 格；比中心差分抗噪（手绘数据有台阶噪声）。
- **梯度与高度插值分工**：高度**取值**仍走双三次插值（海岸线/取色依赖其平滑）；**梯度**三档尺度一律从 mip 采样面上取 8 邻域 Horn（GPU 侧现用的双三次解析梯度退役——多尺度下它只服务单一尺度，两套梯度并存会让档间混合出现语义断层）。CPU 侧中心差分同步退役。
- `meters_per_cell` 由地图栅格元数据换算（`unit_per_km` 声明时 `cell_size_wu × 1000 / unit_per_km`），**唯一换算入口**，禁止第二份硬编码。**无比例尺的虚构图按「1 wu = 1 m」回落**——待决登记见 README §12-53，代码注释标 `TODO(阶段: 晕渲)` 指向该条。
- **Z_EXAG（垂直夸张）初始 2.0**（用户给定）；现行 `shape.z` 的 0.55 退役。验收期唯一校准点。
- y 方向约定：数据行号向下增大、坡面朝左上受光——与现行 `LIGHT_DIR` 注释同款，WGSL 与 CPU 同约定。

### D3 多尺度概括（mip 三级混合，替换 T33 远观关灯）

```
I_final = 0.45·I_macro + 0.40·I_medium + 0.15·I_detail
```

- 三尺度 = 同一张高度纹理的**三个 mip 级**（mip 即盒式低通；高度为仿射编码 ⇒ 编码域滤波 ≡ 米域滤波）。每档尺度独立按 D1/D2 算 `I`，再加权混合。具体 mip 级偏移 / 采样半径由实施期校准（spec §8 裁量）。
- **detail 权重随缩放衰减**：远观（px_per_cell ≈ 0.5）细纹理成噪点 → detail 趋零、衰减量回流 macro/medium；近观（≈ 4 px/格）detail 全额。复用现有 `lod_blend` uniform 通道，曲线形状由实现校准，但必须随 px_per_cell **单调**。
- **替换关系（builder check 钉死）**：现行 WGSL `relief = mix(钳制对, 1.0, lod_t)` 在远观把浮雕**整体关闭**（T33 噪声抑制口径）——本设计以「**detail 档衰减、macro/medium 持续**」**取代**「整灯关闭」。这是对 T33 意图的**有意推翻**：T33 的噪声顾虑由 detail 衰减承接，宏观山脉结构在远观反而首次可见。`lod_t` 对高度采样与海岸的混合**原样保留**。
- GPU 成本：三组 8 邻域 Horn（24 tap）/像素，比现状（16 tap 双三次 + 解析梯度）多；chunk 按视口拣选 + mip 已就位（[ADR-0053] 地基）。若实测超预算，medium 档可复用 detail 档 tap 跨步采样降回 16 tap（实施期裁量）。

### D4 CPU/GPU 同公式（带声明的例外）

- **GPU 场管线**（VectorFlat / 主题浏览态）：完整 D1+D2+D3。
- **CPU 块状烘焙路径**（`cells.rs`，Topographic 块视图 + 笔刷 patch）：D1+D2 **单尺度**（全分辨率 = 中观档）。三尺度卷积在 CPU patch 路径上成本不成比例，且块视图本就是示意块美学。
- 这是「同格任何渲染路径同乘子」旧纪律的**显式放宽**：两路径在单尺度段逐格一致，多尺度段差异记录为视图模式语义，不是缺陷。

### D5 低地色带分辨（修订 ADR-0055「8 阶」语义，不碰阶梯）

问题精确定位：不是「低地不参与」（CellMap 的 `tint_rgba` 本就全强度混入），而是 **0–200 m 一刀同色**、段内高度差零分辨。

1. **CellMap 色带改连续插值**：8 个锚点色不变，阶内按高度在两锚点色间线性过渡（band 0 内部 0–200 m 即有渐变）。DOMAIN_CUTS 绝对阶梯与窄域兜底**原样不动**（[ADR-0056] 语义、阈值不随数据漂移的性质保留）。
2. **GPU 侧同步**：现 shader `elev_ramp_color(elev_band(h))` 是离散取色——改为「段内按高度 lerp 相邻锚点色」，uniform 布局（`elev_cuts` 2×vec4 + `elev_ramp` 8×vec4）不变，仅 shader 取色逻辑改动。顺带清理 `material.rs` 陈旧注释（仍写「ADR-0055 百分位」，ADR-0056 已改绝对阶梯）。
3. **低端锚点色可顺带加深区分度**（`RAMP_SRGB[0..2]` 微调，保持明度单调上升的既有测试约束）——具体色值实施期校准。
4. **专业制图 `ElevationBand` 与 `BAND_WEIGHT` 原样不动**（wv-render 侧阶梯语义 + 2026-10-26 白洗修复不回退）；连续插值只落 CellMap 数据视图路径。

### D6 参数落点：`wv-world-cell-map` crate 常量，公式唯一真源

光照 / 梯度 / 权重常量与纯函数收在新模块 `wv-world-cell-map/src/shading.rs`（`pub const` 表：双光源方向与三光系数、`Z_EXAG`、三尺度权重、`meters_per_cell` 换算入口；禁散落字面量），WGSL 与 CPU 烘焙引用或镜像之。依据 [ADR-0054] D4「数据视图不随主题」——光照常量属数据视图语义，**不引 theme**（固定色 crate 级禁令不破）；主题化（某风格包想换光）留未来 ADR 走桥接层。

## 3. 理由（Rationale）

- **结构性问题不用调参解决**：宽缓地形读不出，根因是「单尺度差分 + 无概括」，调轻/调重钳制只改幅度不改分辨率——[ADR-0067] D2 已试过「调轻」这条路线，治不了「体量没有」。
- **双光源是专业晕渲的成熟做法**：单光源下山脉走向恰与光照平行时受光/背光面同时消失，辅光补这一盲区；三系数和 = 1 使 `I` 天然界内 [0.4, 1.0]，**界内性免费获得**，钳制整个退役 = 少一个调参自由度。
- **mip 是免费的多尺度低通**：高度纹理的仿射域编码保证「编码域盒滤 = 米域盒滤」，三尺度零新增纹理、零数据层改动；chunk 3 级 mip 与视口拣选是 [ADR-0053] 既有地基。
- **连续渐变保锚点可平退**：连续插值在锚点处与旧阶梯色一致，既有观感不跳变；绝对阶梯「阈值不随数据漂移」的核心判据（[ADR-0056] 替换百分位的理由）原样保留。
- **Horn 比中心差分抗噪**：手绘/生成数据有台阶噪声，加权隔格差分抑制单格毛刺。
- **测试纪律**：光照 / 梯度 / 权重 / 色带全部纯函数，手算期望值锚点；WGSL 无法直接单测，用同公式 Rust 参照实现逐格对比（1e-6）+ 固定 fixture 钉住。

## 4. 代价与风险（Consequences）

- **CPU 路径单尺度例外**：GPU 三尺度与 CPU 单尺度在多尺度段观感分叉（显式放宽旧纪律，D4）；CPU Horn 比中心差分多 4 次采样/格，笔刷 patch 成本复核留实施期。
- **uniform 槽位重载**：`relief.xy`（现明暗钳制槽）改载三光系数、`light_dir.w`（预留死槽）改载 `meters_per_cell`、尾部追加 `light_aux`——Rust `FieldParams` 与 WGSL struct 必须**同一提交**双边同改（std140 只在尾部追加才安全），不同步编译期不报错、运行时上传才炸（`material.rs` 既有注释警告的坑）。
- **Z_EXAG = 2.0 需实机校准**（预期可能上调）；`RAMP_SRGB[0..2]` 低端色值、detail 衰减曲线、mip 级偏移均待实机校准。校准结果按 §6.3 追记回本文。
- **GPU 每像素成本上升**：24 tap vs 现状 16 tap；超预算时降档方案已预登记（D3）。
- **T33 行为被有意推翻**：远观从「干净关灯」变「宏观结构可见 + detail 衰减」；若实机远观噪声回潮，校准点是 detail 衰减参数，**不是恢复关灯**。

## 5. 被否决的备选（Alternatives）

| # | 备选 | 否决理由 |
|---|---|---|
| 1 | **调轻钳制路线**（维持 [ADR-0067] D2 现状，继续在 0.90~1.12 上做文章） | 症状是「梯度无概括」的结构问题：逐格差分对宽缓地形每格只出 1–3% 明度差，钳多轻都读不出体量；该路线已在 2026-10-26 试过，收益耗尽 |
| 2 | **高度纹理改 R32Float** | 现 R16Unorm 仿射域编码步长 ≈ 0.15 m（H_MIN=-4000 / H_MAX=6000 / 65535 级），晕渲精度足够；R32Float 带宽翻倍无精度收益 |
| 3 | **真实 mip 链**（为晕渲单独构建完整金字塔 / 多分辨率纹理组） | 三档固定尺度用现成 chunk 3 级 mip 已够（D3）；自建全链 = 更多显存 + 脏块重烘失效链复杂化，额外档位无验收诉求支撑 |
| 4 | **CPU 三尺度**（烘焙路径也跑完整 D1+D2+D3） | 三尺度卷积在笔刷 patch 热路径上成本不成比例（D4）；块视图本就是示意块美学，单尺度段两路径已逐格一致 |

## 7. 验收（Acceptance）

1. fixture 宽缓高原（300 m / 20 格坡）在 GPU 场管线下受光/背光两面肉眼可辨（WV_SHOT 前后对比）。
2. 远观（px_per_cell ≈ 0.5）见山脉宏观结构、近观见支脉细节，随缩放平滑过渡（两档 WV_SHOT）。
3. 0–200 m 低地内部渐变可读，公园绿等群系色不被洗白（白洗回归测试通过）。
4. 公式单测：三系数和 = 1 / `I ∈ [0.4, 1.0]` 界内性 / Horn 3×3 fixture 手算法线 / 同物理坡不同 `meters_per_cell` 同法线（量纲）/ 三档权重和 = 1 / detail 衰减单调 / 连续插值在锚点处与旧阶梯色一致。
5. CPU 实现与 Rust 参照实现（= WGSL 公式移植）在固定高度阵上逐格相等（1e-6）。
6. 笔刷拖画帧时间不回退；全门禁 + `cargo app-test` / `app-clippy` / `smoke-gui.sh` 绿。

## 9. 追记（2026-10-30）：Z_EXAG 校准落参 6.0

> 本节为 §8 遗留第 1 条「Z_EXAG 终值」的校准结论追记；上文正文按只增不改保留。

**结论**：`Z_EXAG` 2.0 → **6.0**（2026-10-30 用户目验拍板；候选 {4, 6} 取 6）。实报触发：用户「browse / map / cell-map 都没看到（高度）效果」。

**依据**（同机位对比帧组，jrpg-world 演示大陆，工程副本防 GUI 自动保存污染）：

- 三工作区 × {2, 4, 6} 九帧 + `WV_STRIP=15` 裸浮雕对照两帧。z=2 时 Browse / Map（Themed 分支）山体完全平、CellMap（BiomeRaw）仅极弱明暗——用户实报属实；z=4 山体明暗可读；z=6 山脊明显（裁剪拼图 ridge / arc 两组逐档可辨）。
- 裸浮雕对照（剥色板 / soften / wash / veil，保留浮雕）证明：z=2 时浮雕本体同样弱——**夸张不足是主因**，Themed 加工链冲淡是次因（同 z 下裸帧对比度高于全链帧，饱和度差肉眼可辨）。
