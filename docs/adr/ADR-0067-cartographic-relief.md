# ADR-0067: 专业制图的山地表达——晕渲 + 海拔色带

- 状态：**已接受**（2026-10-26，随 `feat/cartography-relief` 落地）
- 关联：ADR-0060（山地表达与山峰 POI，本 ADR 落地其阶段 1~2）、
  ADR-0061（专业制图范式）、ADR-0066（单一默认风格层）、
  ADR-0036（坡度浮雕）、ADR-0055 / 0056（CellMap 海拔色带）
- 取代：ADR-0060 §6 实施计划表的阶段 1~2（阶段 3 等高线**不列入本轮**，见 §5）

## 1. 处境（Context）

ADR-0066 把艺术主题整体退役时，顺手关了 `DecorRecipe` 的山符号与林团
（`mountain_style` / `forest_style` 均为 `None`）。这符合主理人的裁定（「山不贴图」
「全靠用户自己把山峰加入」），但**留下一个空洞**：

> 专业制图的底图是「近白陆地 + 淡水 + 公园绿」（`GOOGLE_CORE_TERRAIN`），
> 而 `shade_google` 把沙 / 草 / 丘 / 山 / 雪**全部折叠成同一个近白**。
> 于是山地区域在图上 = **一片与平地无异的近白色块**。
> 符号已关、颜色无差 → **山地彻底失语**。

ADR-0060 §D2 早已把这条写成硬约束：「若在底图尚无海拔色带与晕渲时就把
`mountain_style` 设为 `None`，山地会彻底失语——既没有符号，也没有色阶与阴影，
只剩一块同色高原。**顺序必须是：色带 → 晕渲 → … → 才允许关符号**。」
ADR-0066 关了符号，所以本 ADR 补上前两步。

**现成部件**（核对结果，比 ADR-0060 的估量级乐观）：

| 部件 | 状态 | 位置 |
|---|---|---|
| 坡度浮雕（晕渲） | ✅ **已实现**（左上年 45° 光源、0.84~1.16 钳制、有单测） | `wv-world-cell-map::terrain_view::cells::relief_mul` |
| 海拔切点 | ✅ **已实现**（绝对阶梯 200/500/1000/1500/2500/4000/6000 m + 窄域兜底） | `hypsometric::cuts_for_cells` / `band_of` |
| 固定 8 阶色带 | ✅ 已实现，但**是数据视图的 crate 级固定色**（ADR-0054 D4） | `hypsometric::RAMP_SRGB` |
| GPU 场管线 hillshade | ✅ 已实现但**默认关闭**（`field_render: false`） | `field/material.rs` + `terrain_field.wgsl` |

即：**两处接线 + 一份新配色**，不是从零实现。

## 2. 决策（Decision）

**D1 · 走 CPU 烘焙路径，不启用 GPU 场管线**

场管线（`view.field_render`）有完整的双三次 hillshade 与 8 阶色带，但它默认关闭，
且其 `Themed` 分支只有**三阶**色（低 / 中 / 高）——那是为「地形块面」设计的，
与专业制图的「近白陆地 + 公园绿」不兼容（Google 普通地图的陆地是单色，不按
海拔分色）。

CPU 路径（`terrain_view::cells`）是当前的默认底图管线，色板直接来自风格层，
**与 ADR-0066 的单一风格架构天然对齐**。故本 ADR 在 CPU 路径上接线。

**D2 · 晕渲：GoogleMap 接入 `relief_mul`，但用更轻的钳制**

- 模式门控放开：`VectorFlat | RealTerrain` → 加上 `GoogleMap`；
- 钳制区间**分档**：专业制图用 `0.90 ~ 1.12`（ADR-0060 §4 预览期校准值），
  艺术主题维持 `0.84 ~ 1.16`。

**为什么专业制图要更轻**：艺术主题的强浮雕是「让山有体积」的美术选择；普通地图
要的是「暗示坡」，底图上一旦阴影过重，地图会从「专业制图」滑向「3D 地形图」，
且要素（道路 / 注记 / POI）会被压掉。ADR-0060 的预览期校准正是这条。

晕渲只对**陆格**生效（水面已有深度渐变，叠坡度会脏）——与既有路径同口径。

**D3 · 海拔色带：风格层自带 8 阶 + 固定切点**

- **配色住在风格层**（`wv_default_theme::colors_google::GOOGLE_ELEVATION_RAMP`），
  不复用 `hypsometric::RAMP_SRGB`——后者是**数据视图的 crate 级固定色**
  （ADR-0054 D4：换风格不许影响数据视图），而专业制图的色带是**地图风格的一部分**。
  这是 ADR-0060 §2「配色跟主题，不复用固定 8 阶」的直接落地。
- **切点复用** `hypsometric::cuts_for_cells`（绝对阶梯 + 窄域兜底）——阈值是
  **地形事实**，与配色无关，故两条路径同源。
- **方向与 CellMap 相反**：CellMap 是「低 = 深绿、高 = 近纸白」（对齐「低地 = 绿」
  的直觉）；专业制图取**「低 = 近白、高 = 深岩褐」**——底图是近白陆地，色带若
  也从深绿起步，整幅图会变成「一片绿的海」，底图的克制被破坏。反方向让「山」
  表现为**离陆地色更远的一块**，而不是另一片彩色。
- **混入强度 0.62**：色带是辅助信息，底图仍以「近白陆地 + 要素」为主；强度过高
  会让地图变成地形图。

**D4 · 接线在两个闸口，保证两条路径同色**

底图有两条上色路径：逐格直铺（`block_for` 分支）与亚格采样（`sample_kind`）。
色带叠在**两处**（`apply_elevation_band` 同一方法调用），否则同一块地形在直铺
区与采样区颜色不同。

**为什么不在 `shade_google` 里做**：那个函数只有 `kind` 没有高度，而色带按海拔
分。放在「已着色 → 输出」的闸口，天然覆盖两条路径。

**D5 · 等高线：本轮不做**

见 §5。

## 3. 理由（Why This）

- **补洞而非加料**：符号已关（ADR-0066），色带 + 晕渲是**恢复可读性**的最小
  充分集——色带读「高」，晕渲读「坡」，两者正交互补（ADR-0060 §2）。
- **复用既有部件**：晕渲与切点都是现成的，本 ADR 的代码量主要在「新配色」与
  「模式门控」——比 ADR-0060 估的「色带小、晕渲中、等高线中偏大」小得多。
- **不启用 GPU 场管线**：它是另一条底图管线（默认关闭），启用它会牵动纹理
  上传 / 编码 / 分支切换一整套，与本 ADR 的目标（补上山地表达）无关。
- **端到端验证**：加了**烘焙级**单测（3000 m 高地像素必须比 50 m 低地暗），
  而不只是测纯函数——ADR-0061 追记一刚修完「`shade_google` 读错色表」那种
  「只测结构体字段、像素无效」的假绿。

## 4. 代价与风险（Cost）

- **底图不再纯平色**：专业制图从「近白陆地」变成「近白陆地 + 高处渐深的
  岩褐」。这是**有意的**（否则山不可读），但与「Google 普通地图陆地单色」的
  观感有偏差——取舍写在 §3：可读性优先。
- **色带是逐格的**（每格一色），放大后可见格状台阶。晕渲（逐格浮雕）同款
  限制，两者叠加后台阶感会被浮雕打散一部分。彻底解决需要 GPU 逐像素求值
  （场管线），不在本轮。
- **强度 0.62 是拍的**：需实机校准。改 `GOOGLE_ELEVATION_STRENGTH` 一处即可。
- **0.90~1.12 的钳制可能偏轻**：极平缓的山地可能读不出来。实机看。

## 5. 被否决的备选（Alternatives）

- **启用 GPU 场管线**（`view.field_render = true`）：见 D1——三阶色板与专业制图
  不兼容，且牵动整套纹理路径。
- **等高线（ADR-0060 阶段 3）**：**本轮不做**。理由：**百度 / Google 普通地图
  不画等高线**——等高线是「地形图」要素（1:5 万比例尺图才有），普通地图用色带
  + 晕渲 + 数字高程。本 ADR 的定位是「普通地图 UI」，加等高线会跑偏。
  将来若要「地形图模式」再单开 ADR。
- **复用 `hypsometric::RAMP_SRGB` 固定色带**：那是数据视图的固定色（ADR-0054
  D4），专业制图用它是「让数据视图的色带渗进地图风格」——方向反了。
- **色带从深绿起步**（与 CellMap 同向）：专业制图底色是近白，深绿色带会让整幅
  图变成「一片绿的海」，要素被压。
- **对所有模式统一开晕渲**：会改动艺术主题的既有观感（无回归要求）。

## 6. 验收（Acceptance）

1. `cartographic_elevation_band_darkens_high_ground_only`：高处比低处暗；
2. `cartographic_relief_is_clamped_lighter_than_artistic_one`：
   `0.90 > 0.84` ∧ `1.12 < 1.16`；
3. `cartographic_high_ground_bakes_darker_than_low_ground`：**烘焙级**端到端
   （3000 m vs 50 m 的像素明度）——证明接线真的生效；
4. `wv-world-cell-map` 302 测全绿；`wv-render` / `wv-app` 不回归；
5. 门禁：三套 clippy `-D warnings` / `fmt --check` / `smoke-gui.sh` PASS。

## 7. 遗留

- **强度与钳制的实机校准**：0.62 / 0.90~1.12 需看图调整。
- **逐格台阶感**：彻底解决要 GPU 逐像素求值（场管线的 `Themed` 分支扩到 8 阶
  专业色板）——另立 ADR。
- **地形图模式**：等高线 + 更密的色带 + 数字高程，属「普通地图」之外的能力。
- **山峰 POI 仍待落地**：ADR-0060 的「地标归 POI 符号」阶段（`kind: peak`
  的数据侧已通，见 ADR-0064，但山峰地点仍需作者手写）。
