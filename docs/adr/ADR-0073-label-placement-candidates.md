# ADR-0073: 标签候选位摆位——统一占位池、8 方位候选、沿街旋转与密度预算

- **状态**：提议态（2026-10-26；实机截图初验通过——街名沿街直立、统一避让，
  待主理人裁定转已接受）
- **关联**：ADR-0017（标签层 v0.1 摆位口径，本 ADR 修正其 §2.6）/ ADR-0065
  （标签可读性：字号分档 / 优先级，全部沿用）/ ADR-0047（呈现级别 rank，沿用）/
  `MAP_GENERATION_AND_POI_TYPOGRAPHY_PLAN_v0.1.md` Q3（密度收敛方向，本 ADR 给出首版落地）
- **外部依据**：知乎《奇幻地图程序生成（五）：名称标签的摆放》
  （zhuanlan.zhihu.com/p/112060843，2026-10-26 用户提供）——区域标签候选位择优、
  沿线旋转与翻转、统一碰撞检测三技法

## 处境

1. **放不下就删，不挪位**。v0.1（ADR-0017 §2.6）每条标签只有「锚点上方
   0.9×字号」一个位置，碰撞不过直接丢弃。一屏里「城市名压着它的街名」时，
   先到者留、后到者凭空消失——标签时有时无。
2. **六类标签各自为政**。place / street / faction / event / region / sea 六个
   系统各自跑自己的 `filter_collisions`，互相不感知：地名与街名、区域名与
   海名可以叠在同一处。
3. **碰撞盒与渲染盒错位半盒**。v0.1 把锚点当盒的**左下角**算碰撞，渲染时又
   把文字整体上移——碰撞盒比实际渲染位置低约半个盒高，垂直相邻的标签
   漏检。
4. **街名永远水平**。折线街道是斜的，名字横着钉在路段中点上，斜街上
   「字正路斜」；朝左的段若旋转会倒置，v0.1 干脆不转。
5. **密度无预算**。六处散落的 `truncate(200)`，同屏理论上限 1200 条；
   TYPOGRAPHY PLAN 实测超行业基准（JRPG 参考图 12–15 条/屏）13–16 倍。

## 决策

摆位从「单一位置 + 过滤」改为**候选位择优**（全部落在 `wv-render::
label_collision`，六个系统共享）：

1. **统一占位池 `LabelOccupancy`**：全帧一个资源记账已落位标签的 AABB。
   链首 `reset_label_occupancy` 每帧清场并按 LOD 档重设预算；六系统按链序
   （place → faction → event → region → sea → street）依次落位，先到先得、
   互相避让。街名系统在 `plugins.rs` 以 `.after(DrillLabelChain)` 显式挂到
   钻取标签链尾（跨插件链无隐式顺序；游戏路径不装钻取链时集合为空，约束
   自然退化）。
2. **候选偏移表**：每条候选带一组按偏好排序的候选偏移，过滤时逐位试
   （区域约束 → 占位重叠），首个可行位落位，全失败才丢弃。
   - 点标签（地名 / 事件 / 海名）：8 方位表（屏幕像素倍率 × 各自字号），
     首选「正上方 0.9×字号」= 旧口径，未放下的标签才有备选——视觉零回归
     起点；
   - 面标签（势力 / 区域）：以质心为基点、按自身盒宽高取步长，且
     `inside_rings` 强制候选位盒中心**留在自己区域内**（势力带洞环，
     区域取轮廓环）——区域装不下这个名就不画，画出去比不画更糟；
   - 街名：只试段中点原位（街名必须钉在路上）。
3. **沿街旋转 + 直立翻转**：街名候选携带屏幕倾角
   `φ = upright_angle(段方向角 − 相机偏航角)`，文字实体旋转 =
   `rot_z(φ) · cam_rot`。`upright_angle` 归一到 (−π/2, π/2]——朝左的段翻
   180°，文字永远头朝上、从左往右读；该构造保证文字在屏幕上与街段平行，
   与旧「相机旋转的逆」在零朝向 + 水平段时同值（零回归）。碰撞盒取旋转
   矩形的保守 AABB。
4. **碰撞盒 = 渲染盒**：盒以**最终渲染位置为中心**构造
   （`Aabb::from_center_size`），锚点错位半盒的问题随候选位机制一并消失；
   命中注册（`LabelHits`）同源。
5. **密度预算表 `budgets_for_tier`**：按 LOD 档 × 通路给每帧配额
   （Nation 44 / Region 68 / Edit 116，通路序 = Place/Street/Faction/Event/
   Region/Sea），替代六处 `truncate(200)`。街名在 Nation 档只留 8（远观
   街名本该稀）；势力留 8（多领土势力一图多块）。
6. **验收探针 `WV_DRILL=<map_id>`**（wv-app `debug_probe`，与 `WV_MODE`
   同族）：工程加载完成后自动钻到指定图——城市级标签的实机截图验收
   「开机即在城市图」，双击手势无法从命令行模拟。缺省零开销。

## 理由

- **文章三技法对号入座**：统一碰撞 → 占位池；候选位择优 → 偏移表；
  沿线旋转 + 翻转 → 街名。「标签必须在区域内」→ `inside_rings`。
- **贪心不动摇**：O(n²) 贪心 + 优先级排序是 v0.1 以来的验证口径
  （ADR-0065 D4），候选位只是给每条候选**多个位置可试**，算法骨架不变、
  测试全部沿用。
- **首选位 = 旧位置**：8 方位表以「正上方」为首选，已验收过的图不会因为
  本轮改动换位置——只有原本被删掉的标签才会出现在新方位。

## 代价

- **旋转标签的碰撞盒偏保守**（外接 AABB，斜街多占一点位）——精确旋转
  矩形相交（分离轴）留给真需要时。
- **区域约束按盒中心近似**「整个标签在区域内」——贴边长名可能出界
  一角；四角检查是真需要时的收紧点。
- **预算数值是首版手工标定**（44/68/116），未做用户实验；TYPOGRAPHY
  PLAN Q3 的「总量 60」仍是**待裁**目标——预算表是一张可调表，收敛时
  只动 `budgets_for_tier`。
- **沿线弯曲文字未做**：文章的「整体弯曲跟随河湾」需要逐字符排布
  （Text2d 无曲线排版），本轮只做直线段旋转；河流名（派生数据，尚无
  河名实体）同样留给后续。
- **六系统仍各自收集候选**：没合并成「收集 → 求解 → 应用」三段式
  统一管线（那要拆掉五个池系统的单遍结构）；链序 + 共享池已达成
  跨类型避让，结构重构留给需要「全局最优摆位」的那天。

## 被否决的备选

- **四叉树 / 网格加速碰撞**：n 被视口裁剪 + 级别硬门压到屏幕量级
  （≤ 数百），O(n²) 不是瓶颈（ADR-0017 v0.1 口径复核成立）；先上树是
  过早优化。
- **两阶段「收集 → 全局求解 → 应用」管线**：能做全局最优（优先级真正
  跨类型排序），但要拆五个对象池系统的单遍结构、引入一帧延迟或拆系统，
  改动面与本轮「摆位质量」目标不成比例——见代价第 5 条。
- **自动海名定位（离岸最大内切圆）**：文章给海洋标签的技法。我们的
  海名是作者手写的 `sea.x/y`（数据主权，V2 作者想改就改），自动挪位
  违背「作者定的位置就是对的」；本轮只给海名 8 方位避让，不做自动选址。
- **逐字符弯曲排布**：见代价第 4 条；Text2d 无曲线排版，自研逐字符
  锚定是独立一轮的量级。

## 实施（随分支 `feat/label-placement-candidates`）

- `wv-core`：`StreetSegment::polyline_midpoint_with_dir`（中点 + 所在段
  单位方向；`polyline_midpoint` 改为委托）。
- `wv-render::label_collision`：`LabelPass` / `LabelOccupancy` /
  `reset_label_occupancy` / `budgets_for_tier` / `point_label_offsets` /
  `area_label_offsets` / `rotated_extents` / `upright_angle` /
  `Aabb::from_center_size` / `filter_collisions`（新签名：候选位 + 共享池）。
- `wv-render::drill`：五标签系统迁移（候选构建期生成偏移 / 环约束；
  过滤走共享池；移除统一上移与 truncate）；链头挂 reset。
- `wv-render::streets`：街名候选带 `angle`（段方向 → 屏幕倾角直立化），
  文字实体旋转 `rot_z(φ) · cam_rot`；占位池最后落位。
- `wv-render::plugins` + `drill::register`：`DrillLabelChain` SystemSet
  跨链接线。
- `wv-app::debug_probe`：`WV_DRILL` 探针。
- 测试：label_collision 16 条（候选位回退 / 区域约束 / 跨通路共享占位 /
  预算 / 旋转外扩 / 直立化 / 中心盒）、wv-core 中点方向 1 条、
  streets 中点表口径 2 条、drill Topographic 清场 1 条（补占位池资源）。
- 实机：`examples/_accept-world2`（临时副本，验收后已删）加两条对角街名
  「斜阳大道 / 逆水巷」，WV_DRILL 钻入东港城截图——三处街名全部沿街
  直立、无重叠（逆水巷自然方向朝左，翻转规则生效）。
