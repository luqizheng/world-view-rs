# ADR-0012：浏览态地形默认底图由亚像素纹理切到等值线矢量平涂

**状态**：已接受（Accepted，2026-10-14 用户确认「执行」）
**日期**：2026-10-14
**决策者**：用户（2026-10-14 三轮讨论收尾，授权「后继按好的选择」批量裁定 Q 组；Q11 落到 A 缺省建议）
**关联**：[ADR-0008](ADR-0008-google-default-map-experience.md)（§2④ 被本 ADR 部分修正）、[ADR-0009](ADR-0009-graded-tile-zoom-to-street.md)（分级缩放 + LodTier）、`docs/TERRAIN_RENDER_AND_SKETCH_TOOL_PLAN_v0.1.md`（Q11 裁决与 Q1–Q10 来源）、README §12-14(b)

## 1. 处境（Context）

浏览态地图的「**默认底图渲染**」是地图工具的第一观感。ADR-0008 把大地图默认入口定成「离线 Google Default Map 式视觉与交互」（2026-10-13 Accepted），其 §2④ 写明：

> 底图边界使用亚像素渲染：Google 模式在没有图集时也按 4–8 亚像素 / 逻辑格合成，并在 chunk 纹理上使用线性采样；专题色块视图保持最近邻与清晰格界。

这条亚像素路径在 2026-10-13 是为「让栅格的硬边格子感消失，模拟 Google Maps 平滑边界」而设的，是**「平滑地形边界」目标的一条技术路径**。

与此同时，2026-10-14 三轮讨论走向了一个**不同但更结构化的方案**：把地形边界的渲染从「像素合成」抬到「**几何派生**」——即地表覆盖用类型场驱动、水陆用高度场等值线驱动（marching squares → Chaikin → DP），然后做矢量平涂。三模式共存于同一网格数据，属视图层（P5 精神），数据层零改动。

两条路径是**同一目标的两条技术路径**：

| 目标 | 路径 A（已接受，ADR-0008 §2④） | 路径 B（本 ADR） |
|---|---|---|
| 平滑地形边界 | 亚像素纹理合成（视域 4–8 / 逻辑格） | 等值线矢量提取 + 多边形平涂 |
| 山脊 / 海岸 | 像素混合 | 几何闭合线，自然蜿蜒 |
| 风格 | 接近位图滤镜 | 接近矢量制图 |
| LOD 与缩放 | 沿用既有纹理预算 | 走 ADR-0009 的 LodTier |

按 AGENTS §3「数据与渲染分离」与 P5「渲染是图层」的精神，**目标相同**就该让数据层只承担「数据」，而把「怎么画」留给视图层。这意味着：浏览态默认底图在哪条路径上，应是**视图层决策**，而不是 ADR 锁定。

但 ADR-0008 §2④ 把默认态写成了亚像素，且已被外部评审（plan v0.1 §Q11 裁决门）认定为「同目标异路径下选哪条是视图层选择，不构成原则冲突」。AGENTS §6.4「**不许沉默推翻**」要求任何推翻既有 ADR 的改动都要走 ADR。Q11 落到 A 缺省建议后，必须先把这条路径选出来单独记录。

## 2. 决策（Decision）

1. **浏览态地形默认底图**由 **ADR-0008 §2④ 的「亚像素纹理合成」** 改为 **「等值线矢量平涂」**（路径 B）：
   - **水体与崖线边界**由高度场 marching squares 等值线驱动（海岸 = 海平面等值线，崖线 = 坡度阈值线），派生几何只在渲染期计算、不落盘（D9）；
   - **地表覆盖边界**由类型场驱动（软边过渡 + 邻域定义），同样走矢量管线；
   - 多边形平涂挂 marching squares 输出，呈矢量制图视觉。
2. 亚像素纹理合成**保留为可切换模式**——按 plan v0.1 D3 的三模式划分（**A 等值线矢量平涂**地基 / B 整瓦片 autotile / **C 像素纹理 + 矢量裁切**挂同一多边形管线），§2④ 的技术实现搬进 C 类附属项；按 Q12「**模式 C 延后**」，M4 完成后再视作者需求启动。
3. 瓦片图集 / 复古 autotile（B 类）**同上**——保留为可切换模式，不动。
4. ADR-0008 的其余七项决策（左键平移 / 笔刷显式开启 / 近白陆地色板 / 道路 casing+fill / POI 红点白环 / 右下角控件 / 不接在线瓦片）**继续有效**，不受本 ADR 影响。
5. 浏览态默认底图在切换的同一实现要求：**默认模式下不出现栅格硬边界**——等值线平涂天然带几何边界，与 ADR-0008「边界平滑」的初衷自洽。

## 3. 理由（Rationale）

按 AGENTS §3「数据与渲染分离」与 P5「渲染是图层」的直接推论，逐项列出：

1. **结构化产物多于像素合成**。等值线 + 类型场驱动 + LOD 分级，**几何对象在渲染层显形**，而不是埋在像素位图里。山脊 / 海岸 / 大类色块的边界都成了可挂动画、可挂样式、可挂 LOD 的对象，未来要做选区高亮、势力蒙版、笔刷预览都对得上。
2. **几何与现有 ADR 同构**。等值线 + Chaikin 平滑 + LOD 分级与 [ADR-0009](ADR-0009-graded-tile-zoom-to-street.md) 的分级瓦片缩放是**同一控制面**——LOD 分档沿用 `LodTier`，marching squares 输出尺寸按级变档，不为地形单独再起一套 LOD。
3. **沿用基线 §2.4 既定路径升格**。基线 §2.4 早已记「栅格海岸线平滑 = Marching Squares → Chaikin → 噪声，🟡 原型延后」；等值线平涂是该路径从「原型」升格为「默认实现」。
4. **与亚像素路径目标一致，不是替代**。亚像素纹理合成解决「让栅格的硬边格子感消失」（像素层），等值线矢量平涂解决「让地形边界显形为几何对象」（几何层）。两条路径**互补**，本 ADR 只是把浏览态默认放在几何层——像素层不是取消，是降级为可切换。
5. **美术纯净度更高**。矢量平涂是制图学正统视觉语言（地形晕渲 + 等值线 + 分层设色），与项目现有「JRPG 瓦片图集 vs Google Default Map」之外的第三条路径——「制图式 / 拟真地形」——对齐。这正好对应 `world.yaml` 里把 `ViewMode::RealTerrain` 当作「真实地形分析视图」的语义。
6. **不破既有原则**：
   - **P1** 不动——本方案全程离线，不引入任何在线底图或服务；
   - **P2 / P3** 不动——派生几何不落盘（D9），配方 / 词汇表走 YAML；
   - **P4** 不动——多层地图每层独立栅格，等值线在每层独立求值；
   - **P5** 不动——本方案是渲染模式切换，数据层零改动；
   - **P6 / P7** 不动——地形不时间轴化（plan v0.1 D8），与既有结论一致。
7. **可回退**。删除「等值线矢量平涂」默认态只需把 ViewMode 的挂点改回原路径，**数据契约不变**；亚像素路径原地保留，未来若有作者偏好可一键切回。这与 plan v0.1 的 D3「三模式共存于同一网格数据」精神一致。

## 4. 代价（Consequences）与被否决的备选

### 4.1 代价（必须承认）

1. **实现成本**：等值线矢量管线（marching squares 案例表 + Chaikin 平滑 + DP 抽稀 + 多边形平涂 mesh + LOD + 网格开关）是 plan v0.1 的 M2 主交付物。粗估会让本路线比「维持亚像素默认」多 3–5 个冲刺的工作量（仅浏览态默认切换，不含草图生成 / 多配方）。
2. **视觉差异**：与现有 Google Default Map 的「近白陆地 + 公园绿 + 淡水蓝」配色（ADR-0008 §2②）相比，等值线矢量平涂会更接近「制图学正色板」。两套视觉语言并存于同一项目，主题包选择决定画面：Google Default 仍是首批可选主题之一，「真实地形」主题切到等值线路径。这是**主题包选择问题，不是缺陷**。
3. **大纹理采样语义保留**：纹理层（chunk Image、minimap）仍按 `WVTR` magic + 4096² 纹理预算（[ADR-0008 §7 补充测算](ADR-0008-google-default-map-experience.md)）。等值线所求几何与纹理层共存，模式切换时主题包统一调度。
4. **分级过渡的视觉摩擦**：等值线几何在 LOD 切换时可能产生**等值线密度的突变**，需要级间淡化（Q10 衍生的可切换 tint 叠加 + ADR-0009 §2⑦ 的淡化机制）协同压制。这是 plan v0.1 M3 的明确收口项。
5. **文档依赖关系变更**：本 ADR 通过修正 ADR-0008 §2④ 进入，与 §6「与旧文档的关系」产生新的修正关系（详见 §5）。

### 4.2 被否决的备选（按推荐度倒序）

| # | 备选 | 否决理由 |
|---|---|---|
| **B** | **保留亚像素纹理为浏览态默认，平涂作为新增可切换模式** | 不解决「地形边界是几何对象而不是像素」的诉求；让浏览态默认继续走像素合成路径，等于把 AGENTS §3 的精神悬置——视图层应该提供几何对象，不是只给像素滤镜。Plan v0.1 D3 的精神是「三模式都可达」，但**默认态**是另一层决策 |
| **C** | **按 LOD 分工：远景用亚像素纹理、平涂用于近景** | 两点不利：(1) 复合路径会让两种视觉语言在同一画面交接，边界附近的语义不连续；(2) ADR-0009 的分级是**离散级别 + 平滑插值**，不是连续 LOD，LOD 内只有一种默认视觉才简洁 |
| **A**（裁决） | **浏览态默认切到等值线矢量平涂，亚像素纹理 / 瓦片降为可切换模式** | ✔ 选中（即本 ADR §2） |
| **D** | **完全删除亚像素纹理路径** | 不可回退——一些作者偏好「Google Maps 像素感受」，删除会逼出重实现，且违反「三模式共存」精神 |

> A / B / C 对应 plan v0.1 Q11 的三个选项；D 是新增的否决项。

## 6. 落地路径（仅记录即将发生，不构成新的编号空间）

- **M2（plan v0.1）**：完成 marching squares 案例表与等值线提取 → 矢量多边形平涂 mesh → 浏览态 ViewMode 挂点切换；亚像素路径代码保留，作为 Theme Pack 选项挂入可切换模式。
- **M3**：晕渲 + LOD 分档（plan v0.1 Q10 / Q9）；沿用 [ADR-0009](ADR-0009-graded-tile-zoom-to-street.md) 的 `LodTier`，与 ADR-0009 §5 Phase 3「换级淡化」协同压制等值线密度突变。
- **不再画等值线的模式**：B 瓦片图集与 C 像素纹理+矢量裁切（plan v0.1 D3）继续为可切换主题，不动实现入口。
- **测试门槛**：plan v0.1 §5 测试要求 + AGENTS §7.1 的两套门槛（含 `--features app` 渲染层）一并过。
