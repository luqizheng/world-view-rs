# ADR-0079：势力图切蛋糕分区（partition）

## 1. 处境

ADR-0027（2026-10-18）落地了势力层（`FactionLayer`：命名一族政治划分维度——国界 / 贵族 / 宗教覆盖），但三块缺口使用户「势力图没法画」：

1. **层可见性无 UI 入口**：`UpdateFactionLayerCommand.new_visible` 在 wv-app 零调用者，只能改 YAML；
2. **没有画势力图的工具**：唯一沾边的入口是 ADR-0028 的「划分势力」圈地指派流——圈一块选区、一次性指派给某势力，不是画图工具；
3. **独立多边形没有零和语义**：`faction_geometry` 各势力独立多边形，画歪出缝、叠出重叠，工具不管。用户裁定核心语义：**「这些势力没有空隙，拖动某边界的扩大，就意味着某个地方缩小」**——势力图 = 区划拼图（partition），不是各画各的多边形。

同时，region 自然图只有会话级开关，用户要的是**素底上只看势力填色的政治图集页**（political page）。

## 2. 决策

### D1. 分区数据模型：快照式——共享顶点表 + 脸环引用

一份分区（`FactionPartition`，map × layer 一份）的历史由若干 **span** 组成，每个 span 是一份**完整拓扑快照**：

- `vertices: Vec<PartitionVertex>`——共享顶点表（`{id: u32, xy: [f32;2]}`）；
- `faces: Vec<PartitionFace>`——脸（`{id: u32, owner: Option<Id>, ring: Vec<u32>, holes: Vec<Vec<u32>>}`），ring/holes 存**顶点 id**；一张脸的环引用的顶点 id 同时被相邻脸的环引用——**共享顶点是零和的构造基础**；
- span 带 `[from, to)` 时间区间（`TimeSpan` 同口径，`to==None` 至今）；某天的划分 = `partition_span_at(world, map, layer, day)` 求值。

铺满不变量：该图陆地每一点属于恰好一张脸（海不参与切分；蛋糕 = 落刀时地形栅格的海陆掩膜**快照**，之后海岸线变了不自动重切，海陆错配只进校验提示）。

### D2. 编辑命令四件（wv-edit）

| 命令 | 语义 | 时间语义 |
|---|---|---|
| `BeginPartitionSpanCommand` | 该层无 span → 用 `land_outlines` 造首段（整块地，湖为洞）；已有 span → 在 `from` 处 fork：命中段拆 `[a,from)` + `[from,b)`，新段快照复制 | 新段 = 画刀的工作段 |
| `CutPartitionFaceCommand` | 边到边笔画把脸一分为二；切完点选归属侧（D7 切后点选）；端点吸附 4px、复用命中顶点 id；校验失败 Err 不落盘 | **就地改选中 span**（改旧，V2） |
| `MovePartitionVerticesCommand` | 拖边界 = 刚体平移共享边链上全部顶点；被移动顶点必须被 ≥2 张脸引用（零和构造保证），否则 Err | 就地改选中 span |
| `AssignPartitionFaceCommand` | 整块易主（D8）：几何零改动，owner 换人 | **fork 型**：在生效日 fork，fork 段换 owner |

### D3. 动刀入口：层内 pen → 弹框问新增 / 修改（D4/D5 裁定）

- 势力层列表行 **pen 按钮**（门控：当前图 World/Region ∧ 有自有地形栅格）；
- 弹框：**新增**（填生效时间，预填时间轴当前日 + 起始归属可空=无主）/ **修改**（列历史 span 段，选段 → **移动全局时间轴**到该段——单时间轴哲学，不引入第二编辑时钟）；
- 编辑态 HUD 常驻「地图属性·当前时间」选择器（D5）。

### D4. 手势三种

切分笔（边到边折线，magnet 可选贴格）、拖边界（零和）、整块易主（点脸改归属+生效日）。

### D5. 呈现

- 分区渲染每帧按 `PlaybackState.current_day` 求值（AGENTS §3.2：渲染层禁自比时间）；活动层填势力色、其余层只描边（沿用 ADR-0027 D6 呈现规则）；
- 自然图关 = **只换底图**：平面海陆两色 + 海岸线保留，其余内容层开关独立照旧（政治图集页）；
- 层眼睛进图层面板「势力图层」组，经既有 `UpdateFactionLayerCommand` 落盘；自然图开关升为声明级落盘。

### D6. 声称（claim）不再可新建（D9 裁定）

分区是零和的，装不下重叠主张——分区 = 唯一形态（= 实控语义）。存量 claim 多边形保留渲染兼容、逐步退役；ADR-0028 圈地指派入口整建制退役（意图菜单瓷砖、对话框、门控），存量数据不动。`Membership` 归属边语义不变。

## 3. 理由

- **快照式 vs 操作日志式**：改旧历史段（V2）在快照式下是「就地改一份快照」，无重放、无传染；操作日志式改旧需重放后段，代价大且易错。spec §7 倾向快照式，本 ADR 采纳。代价：每段完整存拓扑，存储略胖——分区数据是小型矢量（相对地形栅格），P3 YAML 可承受。
- **共享顶点表 vs 独立多边形+几何吸附**：吸附只能「事后补救」，拖动一侧仍可能撕裂；共享顶点让零和成为**构造保证**（同一顶点 id 被两侧环引用，动它两侧必然联动）。被否决：独立多边形 + 吸附（ADR-0027 M2 共边弧已证明逐点共边维护成本高，且不保证整层铺满）。
- **脸环引用 vs 显式边表（DCEL）**：DCEL 是完整平面拓扑，支持任意查询，但 YAML 可读性差、round-trip 复杂；脸环引用足以下达本需求全部编辑原语（切、拖、易主），YAML 手写友好（AGENTS §4.4 精神）。被否决：DCEL。
- **全局单时钟 vs 编辑态第二时钟**：本仓库 P7 单时间轴哲学，所有时间求值（事件、地界、轨迹、membership）都走 `PlaybackState.current_day`；第二时钟会造出「编辑中画面与时间轴不一致」的第三种真相。被否决：编辑态第二时钟。

## 4. 硬约束

- 分区拓扑走 YAML（P3）；owner 只存 Faction `Id` 引用、可空 = 无主（P4，不因建层造合成实体）；只存 span 化状态（P6/P7）；
- 编辑一律 `EditCommand → History → dirty("partitions")`，System 禁直改（AGENTS §3.3）；
- 校验（悬空 owner / 环引用缺失 / span 重叠 / 海陆错配）只提示不阻止（V1）；改旧不质问（V2）；
- 坐标 map-local flat f32，与 `GeometryData::Polygon` 同口径；禁 raster_origin 混用。

## 5. 后果

**正面**：零和与铺满成为构造保证而非约定；改旧 = 改一份快照，无重放；政治图集页补上图集「政治页」形态；层可见性终于是可点的。

**负面 / 代价**：每段历史完整存一份拓扑（存储胖）；切刀几何（线段求交 + 环重织）是本项目第一块真正的平面切割代码，测试负担重；ADR-0028 入口退役，熟悉旧入口的作者需换手势。

**被否决的备选**：操作日志式 span（改旧需重放）；独立多边形 + 几何吸附（无铺满保证）；DCEL 显式边表（YAML 不友好）；编辑态第二时钟（破坏单时间轴）。

## 6. 与既有 ADR 的关系

- **取代** ADR-0028 的「划分势力」UI 入口（数据存量 claim 保留渲染兼容，逐步退役）；
- **沿用** ADR-0027 的层模型（FactionLayer / Membership / 一次一层填色呈现规则），不推翻其任何结论；
- 与 ADR-0063（专业制图边界线层）并存：分区渲染是填色语义，制图国境线是描边语义，活动层填色优先。
