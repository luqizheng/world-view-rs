# ADR-0101: 地形晕渲表现升级（绝对高程色带 + 光照重标定 + LCH 合成 + 山脊高光）

- 状态：已接受（2026-11-05，用户裁定「按照你推荐」——外部制图评审结论经
  代码核实后采纳 P0+P1 全部四项；theme 解耦一并裁定「这套系统先不做
  theme，2.0 才做」）
- 关联：ADR-0077（晕渲建制，参数面被本 ADR 推翻）、ADR-0092（归一化域，
  分母口径被修正）、ADR-0043（主题包架构，地形接线被推迟 2.0）、
  ADR-0061（专业制图，不受影响——Map/GoogleMap 走 Flat 素底）、
  ADR-0072（群系填色混合结构沿用）、ADR-0100（CellFlat 零加工契约，不受影响）、
  GLOSSARY「山脊高光」「LCH 明度调制」

## 处境

用户拿着「山脉扁平、对比度低、陆地色相趋同、立体感弱」的观感问题向外部
制图专家求方案；专家给了完整参数包。经逐条对照代码与实测数据核实：

- **专家的 Z_EXAG=2.5 是误读**——本仓 200 是归一化域系数（「全图跨度按
  200 格起伏」），等效米制夸张 ≈38×；直接填 2.5 会把山脉压成 ≈6° 缓坡。
  实测 jrpg-world（1024²，全域 span 5246 / 陆地 span 3548，中位陆地坡度
  5.7 m/格）：现口径下中位坡 12.2°、p90 坡 56.8°——「山不陡」的主因是
  **数据本身平**，其次是色阶失能。
- **真问题 ①**：Themed 三阶切点 0.33/0.66 在归一化域 ≈ −700 m / 2600 m，
  实测 demo 97% 陆地落「中」一阶——**颜色对海拔近乎零贡献**。
- **真问题 ②**：环境光 0.4 保底 + 45° 双灯 → 明暗比仅 2.5:1，背光面不沉。
- **真问题 ③**：RGB 直接相乘的合成把暗部饱和度打掉，山体越暗越灰。
- **真问题 ④**：宏观半径 12 格（12 km）低通把山脊链抹平。

## 决策

1. **保持归一化域**，修正分母：`height_span_of` 只统计 `height > 0` 的格
   （陆地 span）。海底深洼不再灌大分母（demo：5246 → 3548，浮雕 +1.48×）。
   全海图回落下限 1。**Z_EXAG=200 不动**（可试 150–250）。
2. **光照重标定**（推翻 ADR-0077 D1 的数值面，机制不动）：主光高度角
   45°→**38°**、辅光 45°→**50°**；能量 0.4/0.48/0.12 → **0.33/0.52/0.15**
   （评审方案 B）。三系数和仍 = 1、单位光向量、免钳制；真实法线下
   `I ∈ [0.33, ≈0.935]`。
3. **Themed 底色改绝对高程色带**：`themed_land`（归一化三阶主题色）退役，
   陆面底色 = `elev_ramp_continuous(h)`（复用 ADR-0055/0077 的 8 阶绝对
   米色带 + uniform `p.elev_ramp`，与 CellMap 数据视图同源）；群系填色
   混合结构（`p.pad0.z`）不变——高程主导、群系为修饰。
4. **固定水色**：海基色 = `WATER_SRGB`（`#2A5D8F` crate 常量）；浅滩向色带
   最低阶混 0.35、深海 ×0.82（沿用旧派生比）；`p.theme` 槽位保留（政治页
   素底分支仍读）。
5. **LCH(ab) 明度调制**取代 RGB 相乘：`lch_shade`（CPU 真源）/ `lch_hillshade`
   （WGSL 逐式镜像）——只缩 L、色相严格不动、阴影区色度回补 ≤
   `SHADE_CHROMA_BOOST`（0.12，Lab 域）；中性色跳过补偿；`shade=1` 恒等
   （Flat/CellFlat 天然不受影响）。**评审版代码的两处缺陷已修正**：
   WGSL 不允许嵌套函数（`lab_finv` 提为模块级）；两份 3×3 变换矩阵按行
   书写会被列主序构造器转置（白色映射不到 L=100，已重排为列主序）。
6. **山脊高光**（新装饰层，仅 Themed 分支）：三尺度从「各档打光加权明暗」
   改为「**三法线加权混合 → 统一打光**」（混合法线即判定输入）；混合法线
   满足 `dot(n, L₁) > 0.75` ∧ 坡角 > 12° 时，在 LCH 结果上加灰色向量
   `RIDGE_BOOST`（0.12）。 WV_STRIP bit4 剥浮雕时高光随行关闭。
7. **theme 解耦**：地形渲染不再消费 ThemePack（色带/水色固定常量），主题
   整合推迟 2.0。CPU 烘焙回退路径同步接 LCH（`cells.rs` 合成点）；
   **山脊高光是 GPU 装饰层，CPU 回退不做**（允许的分叉，已在此登记）。
8. **多尺度参数**：宏观半径 12→**8**；权重 0.45/0.40/0.15 → **0.35/0.45/0.20**。

## 理由

- 分母修正与「晕渲管陆面」自洽：水面本就不进明暗，分母却含海底。
- 38° 主光是经典晕渲惯例（Imhof 系）：仰角越低坡面对比越锐；45° 接近
  无影照明。0.28 环境光保底让 0.28–0.4 成为真实的背光面区间。
- 绝对米阶梯让「颜色 = 海拔」跨图恒定（作者读的是海拔不是相对高度），
  且与生成侧语义同源（山地 1150–1500 / 雪线 2250–2750）。
- LCH 色相锁定防「乘法发灰」；法线混合防多档明暗互相冲淡，且免费给出
  山脊高光的判定输入。
- 实测数据（97% 陆地同色 / 明暗比 2.5:1 / 中位坡 12.2°）把「改什么」从
  审美分歧变成可验证的缺陷清单。

## 代价 + 被否决的备选

**代价**

- 主题包（水墨等）切换地形底图失效，直到 2.0（用户裁定接受）。
- CPU/GPU 在山脊高光上分叉（CPU 回退档无高光）。
- LCH 回路每像素 ≈2 次 mat3 + 若干 pow（4096² 预算内，实测无感）。
- 首版标定值（水色 `#2A5D8F`、RIDGE/BOOST 家族）待实机验收微调。

**被否决的备选**

- **米制 Z_EXAG=2.5 + 局部梯度**（专家原案）：误读归一化域常量；照抄会把
  山脉压平（等效夸张 0.48×）。Horn 梯度本就是局部的，全局 span 只是统一
  缩放——「全局归一吃掉局部坡度」的说法不成立（1.48× ≠ 8×）。
- **明暗下界 0.2**：0.28+0.55+0.17=1 的配比下下界就是 0.28，硬 clamp 到
  0.2 只会破坏界内性纪律。
- **SSAO / 屏幕空间遮蔽**：1 km 格无微几何，AO 出脏噪且与晕渲打架。
- **山谷闭塞 Compute Pass**：默认关闭的可选项，需引入本管线没有的
  compute 基建；先验山脊高光收益。
- **LCH 先行完整制图管线（LAB LUT 纹理）**：现管线 per-pixel 求值成立，
  LUT 引入纹理绑定面改造，收益不匹配本轮 scope。
- **等高线（100/500 m）**：结论是做，但走既有 CPU marching-squares
  矢量等值线（`cellmap_bridge/isoline.rs` + `height_segments` 多 level），
  不引入专家的 WGSL overlay——**留给下一轮（P2）**，本 ADR 不含。

## 验收

- wv-world-cell-map 357/357、wv-render（app）487/487 全绿（手算锚点测试
  随参数同步重算：平地强度 0.8243→0.7488、北坡 0.9121→0.8830、
  span fixture 改陆地口径等）。
- 实机（jrpg-world）：Browse 远近两机位对比——山脊链可读、海陆色相分离、
  阴影有「沉下去」的背光面；CellMap（CellFlat）零变化（零加工契约）；
  政治页素底不受影响。两轮验收校准见上方追记（白斑/灰相/光环/配比）。

## 验收轮校准追记（2026-11-05 实机第一轮反馈，本 ADR 未提交前修订）

首轮实机（jrpg-world 双岛远观）暴露三处，当轮修：

1. **山脊高光过曝成白斑**：定值 0.12 加在近纸白的色带高阶上直接饱和；
   坡度 12° 门槛太松，噪声格命中。修：`RIDGE_BOOST` 0.12→**0.06** 且按
   `1 − 目标明度` 自削弱（WGSL 侧实现）；`RIDGE_SLOPE_DEG` 12→**18°**；
   `RIDGE_DOT_THRESH` 0.75→**0.80**。
2. **陆地偏灰白**：ThemePack 默认 `biome_tint` 0.5→**0.65**（群系绿相
   回来；`BIOME_TINT_DEFAULT` 同步）。
3. **海岸「磨边光环」**：白滩 0.18→**0.10**、浅滩混色带 0.35→**0.25**
   （三段色带宽度 = SPEC §3.8.4 不动，只降亮度）。
4. 小地图黑竖条 = 同一张 GPU 场纹理缩小采样的混叠（右岛山脊背光带），
   非缺陷；#1/#2 落地后对比软化自然缓解；根治需给场纹理做 mip/盒滤波
   （挂账工程轮）。
5. **中景山体暗侧过重**（第二轮实机）：配比 0.28/0.55/0.17 →
   **0.33/0.52/0.15**（方案 B，和 = 1 不变，暗侧微抬）。
6. **岛端直角矩形灰块**（待裁）：疑似 demo 数据中 biome = 0 的陆格经
   群系混合显示为蓝灰——旧版同在，非本轮回归。待裁两条路：陆格
   biome = 0 时回退纯色带（渲染侧），或 demo 工程刷格子补数据（数据侧）。
