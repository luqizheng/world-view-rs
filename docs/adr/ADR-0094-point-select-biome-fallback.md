# ADR-0094: CellMap 点选器「POI 命中优先，其余一律选群系」

- 状态：已接受（2026-10-31 用户裁定：「我觉得是除了点中 poi，否则应该都是选择群系，哪怕它没有创建」）
- 关联：ADR-0074（点选裁定原始形态）、ADR-0090 D2（点选退化为纯实体选择器——本 ADR 修订其「点选不碰格子」半句）、ADR-0088（泛洪判据机器）

## 1. 处境（Context）

ADR-0090 D2 把点选器收窄为纯实体选择器（标签 > 图钉 > 群系区实体），格子职责移交圈选「单格」。实机暴露的断层：**工程没有群系区实体时（jrpg-world 实况，Nature Region = 0），点选器点非 POI 毫无反应**——作者对着满图群系色块「什么都选不中」，必须先建自然层 + pen 切块才有得选（认知门槛倒挂：选择先于创建）。

## 2. 决策（Decision）

CellMap（Topographic）点选裁定改为：

1. **标签 / 图钉命中 → 选 POI 实体**（不变，POI 是精确靶子）；
2. **群系区实体命中（自然层 overlay 开且命中）→ 选 Region 实体**（不变——建了群系区就能选实体、改属性）；
3. **其余一切点击 → 同群系连通域泛洪**（新）：脚下格按 `Biome` 判据泛洪（`wv-terrain::cellops::flood_region`，与圈选单格的泛洪同一套机器），结果写格选区、实体选中让位（单焦点模型）。

「哪怕它没有创建」的两半都有回归测试锚定：实体存在但 overlay 关（不可选）→ 泛洪；实体根本不存在 → 泛洪。

## 3. 理由（Rationale）

- **选择先于创建**：群系是地形数据本身（每格都带 biome），不是需要先建实体才存在的东西——点选器不该要求作者先 pen 切块才能「选中一片森林」；
- **零新机器**：泛洪复用 ADR-0088 的判据管线，格选区/单焦点/Esc 清空全是既有会话态语义；
- **修饰键不改变语义**：Alt/Shift 在点选下不再有格子加减法（那是圈选单格的职责），非 POI 点击一律泛洪。

## 4. 代价（Consequences）

- **ADR-0090 D2「点选不碰格子」被部分推翻**（本 ADR 显式记录，非沉默推翻）——点选器重新成为「实体 ∪ 群系格」的复合入口；
- **同群系连通域 ≠ 群系区实体边界**：建了自然层后，点选优先生选实体（区边界 = 分区边界）；要跨区选格仍走圈选「单格」+ 判据；
- **点海也选中**：水域是群系之一，点海 = 选中连通水域格（符合「否则都应该选择群系」的字面与意图）；
- **被否决的备选**：维持 ADR-0090 D2（先建自然层才能选）——被用户裁定否决；点选器加「模式开关」区分选实体/选群系——多一个状态位，违背「默认行为就是作者想要的」。
