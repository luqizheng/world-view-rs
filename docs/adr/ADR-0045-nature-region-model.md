# ADR-0045: 自然区域模型——覆盖物的归属层、biome 连通区分区、嵌套与合并

> 状态：**已接受（Accepted）**（2026-10-20 用户逐项拍板：D1 自动划分按 biome 连通区 / D2 覆盖物归属 region / D3 扩展现有 `Region` 实体 / D4 自动分区不落盘、按需物化 / D5 合并 = 几何并成一个 + 旧成员变子块）
> 关联：ADR-0039（主题演绎——cell 属性派生的覆盖物变体；本 ADR **不推翻**其「cell 派生变体不持久化」结论）、ADR-0023（ThemePack 契约——D10 是其 M3「演绎规则 ThemePack 化」的第一块）、ADR-0043（主题层抽 `wv-theme`——覆盖物键词表归主题层）、ADR-0029（生物群系标记——「识别或生成」与边界快照的先例）、ADR-0028（势力划分——掩膜 / 环提取管线与共边保证）、ADR-0017（标签层——区域标签）、GLOSSARY「主题演绎 / 自然区域 / 覆盖物键 / 自动分区 / 物化」
> 原则：P2 / P3 / P4 / P5（不引入新图层）/ P7（边界为快照）

## 处境

地图上的**覆盖物**（装饰符号：树冠团、山形、沙丘脊、浅海白波）此前只有一个来源：
**渲染期从 cell 属性派生**（ADR-0031 建装饰系统、ADR-0036 加 Nation 档、ADR-0039 加
海洋波浪 / 森林气候变体 / 高山雪岩）。作者能表达"这片地用另一种表现"的地方只有
**改 cell 本身**（biome marker 写群系、`BatchEditCellsCommand` 批量改格）。

但作者的需求常常在**表现层**而非事实层：一片雪山格所在的江南，按纬度该是温带绿林——
作者原话「cell 本质没有改变，只是表示不同」「覆盖物是示意图，针叶林、阔叶林的覆盖物；
隔壁可能是乱石头滩涂，把覆盖物改为石林」。cell 的三通道（height / surface / biome）
里**无处安放**这一层意思：`biome` 是本质分类（深林），"用针叶林还是阔叶林表现"是另一维。

仓库里已有三个与"自然区域"部分重叠的物：

| 既有物 | 是什么 | 与自然区域的差距 |
|---|---|---|
| `Region`（`wv-core/src/model/region.rs`） | 命名面：`{id, name, map, polygon}`，每实体一文件 `regions/<id>.yaml`，有 `RegionLabels` 渲染 | 扁平（无 `parent`）、`name` 必填（装不下无名区）、无覆盖物属性、无自动划分 |
| 生物群系标记（ADR-0029） | `Place.biome + Place.envelope` → 识别或生成 → 边界环 | 点锚（Place 有 x/y）、单层、边界是识别快照、覆盖物走 Place 族的 `FeatureRule` |
| `Faction` + `faction_geometry`（ADR-0027/0028） | 势力领土：带洞多边形 + 共边无缝 | **政治层**，与自然区语义不同、不可合并（一个自然区可跨多个势力，一个势力也可跨自然区） |

## 决策

### D1 · 自动划分依据 = biome 连通区

自动分区把活动地形栅格按 **biome 连通分量**切成若干区：同一 biome 的相邻格属同一区。

- **内核现成**：`wv_terrain::isoline::kind_segments`（每对**相邻异类**格在共享边上出一段
  阶梯折线）+ `assemble_chains`（装配成闭合链）——渲染层正用它画海岸线与群系界
  （`terrain_view/isoline_overlay.rs:348`）。复用同一管线，不新写洪泛算法。
- **平铺与共边由构造保证**：biome 分区天然满足「每格恰属一区」（biome 是全函数），
  相邻区边界来自同一段异类格边 → 共边无缝，无需 ADR-0028 那样的弧段拼接。
- **确定性天然满足**：无 seed 依赖，栅格重生成（ADR-0037 M4）后分区逐格一致。
- **实现要点（坑）**：`kind_segments` 只在**异类格共享边**出线，**地图外边界无线**——
  贴图边的区会得到开链。分区边界须**沿图幅矩形补边**才能闭合成环，否则边缘区不是闭合多边形。

### D2 · 覆盖物归属 region（两来源，优先级分明）

覆盖物有**两条来源**，渲染期按优先级解析（唯一入口见 D9）：

| 来源 | 载荷 | 落盘 | 例子 |
|---|---|---|---|
| **cell 派生**（既有，ADR-0039） | cell 的 height / biome / 归一化 y | **不落盘**（P7 纯投影） | 高山 → 雪岩；y<0.30 的森林 → 针叶 |
| **region 显式声明**（本 ADR 新增） | `Region.overlay: Option<String>`（覆盖物键） | **落盘**（作者声明的事实） | 这片深林 → 覆盖物键 `conifer`；隔壁滩涂 → 覆盖物键 `boulder_field` |

**关键区分**：`cell.biome` = **本质**（深林 / 沙漠 / 高山）；`region.overlay` = **表现声明**
（针叶 / 阔叶 / 石林）。二者不是同一维，因此**不构成第二真相源**——region 声明的不是
"这格是什么"，而是"这片的**长相**按哪条规则画"，cell 无此表达能力。

> **与 ADR-0039 的关系（不推翻）**：ADR-0039 已接受「覆盖物是渲染期派生、**不持久化**，
> 存了就是第二真相源」。那条结论的对象是 **cell 属性派生的变体**——同一件事从 cell 算两遍
> 才是第二真相源。本 ADR 新增的是**另一条来源**：作者显式声明、cell 表达不了的粒度。
> 两条来源并存，**region 显式声明优先于 cell 派生**；ADR-0039 的结论在其原对象上依然有效。

**覆盖物键是开放字符串**：键的词表由**主题**拥有（见 D10），数据侧只存字符串
（AGENTS ADR-0001 D2「数据承载开放集」；ADR-0032 的教训——枚举化会碎裂成
"写 1 漏 10/11"）。当前主题没有该键 → **回退到 cell 派生默认**，不静默消失
（与 `FeatureOverlaySet::rule_for` 的缺省回退同纪律），并在校验面板提示（V1 只提示不阻止）。

> ⚠️ **本段的「回退到 cell 派生默认」已被下文「追记一」取代**（2026-10-20 用户裁定：
> 改为**白底红斜线的缺失标记**——回退等于冒充作者声明的另一个语义）。保留原文以存可追溯性。

**作用域（v1）**：region 覆盖物只改**装饰符号层**（terrain decor，Z 0.075）；**底色仍由
cell 的 biome 决定**（4.1 的"沙漠黄自动变森林深绿"是改 cell 的结果，属事实层）。
底色是否也可被 region 覆盖 → 移入待裁（§待裁）。

### D3 · 实体归属 = 扩展现有 `Region`（不新造 `NatureRegion`）

新开 `NatureRegion` 实体会让仓库出现两个语义重叠的面状实体（`Region` /
`NatureRegion`）+ 两套几何底座 + 标签 / 选取 / 校验全双份。故扩展 `Region`：

```rust
pub struct Region {
    pub id: Id,
    pub name: String,              // 空串 = 无名（见 D7）
    pub map: Id,
    pub polygon: Vec<f32>,         // 外环
    pub holes: Vec<Vec<f32>>,      // 新增：洞环（自动分区常见：林中湖）
    pub kind: RegionKind,          // 新增
    pub parent: Option<Id>,        // 新增：嵌套（仅 Nature 生效）
    pub overlay: Option<String>,   // 新增：覆盖物键（仅 Nature 生效）
}

pub enum RegionKind {
    /// 区域（默认）：作者划定的命名范围。不承载覆盖物、不嵌套。
    Area,
    /// 自然区：承载覆盖物声明、可嵌套、可由自动分区物化、边界可重生成。
    Nature,
}
```

- **旧 YAML 零迁移**：四个新字段全部 `#[serde(default)]`；`kind` 缺省 = `Area`，
  与现状 `Region` 语义逐位一致。
- **`kind` 的判别标准**（这是它存在的理由，不是装饰）：
  `Area` = 泛用命名面（现状「关中平原」「武昌城垣范围」全部落这里）；
  `Nature` = 自然区域（承载覆盖物 + 可嵌套 + 可由自动分区物化 + 边界可重生成）。
- **`holes` 的必要性**：biome 连通区常带洞（林中湖）；`Region.polygon` 单环装不下。
  沿用 `Region` 的内联风格（不引入 `GeometryData` 的 untagged 复杂度）。
- **`overlay` / `parent` 仅 `Nature` 生效**：`Area` 携带二者视为无效（校验面板提示，
  V1 不阻止）——泛用面挂覆盖物 / 嵌套会引入无意义的组合爆炸。

### D4 · 自动分区**不落盘**，按需物化

biome 连通区是**派生视图**，不是实体：作者点中一个候选区、给它起名 → 才生成
`regions/<id>.yaml`（`kind: nature`、`polygon` = 外环、`holes` = 洞环）。

**为什么必须这样**：512×288（默认新建工程）栅格切出数十~数百个连通区，全落盘意味着
数百个 YAML 文件 + 数百段多边形；1024×1024（jrpg / 广东世界图）则是数千个。落盘量级
与 git diff 可读性都不可接受，且栅格一变全部过期。派生则每次现算，成本是
`kind_segments` + `assemble_chains` 的 O(格数)，毫秒级。

「命名即实体」是本 ADR 的分界线：**作者命名过的才落盘**（D7 的无名不显示是同一原则的
延伸）。

### D5 · 合并 = 几何并成一个 + 旧成员变子块

合并 A、B 两个自然区 → 新建区域 C：

- **几何** = A ∪ B。算法现成：`rasterize_ring(A.polygon)` ∪ `rasterize_ring(B.polygon)`
  → 掩膜 → `mask_boundary_rings` + `split_outers_and_holes` → 外环 + 洞
  （`wv-terrain/src/divide.rs`，ADR-0028 D3 用的同一条管线）。共边在并集后自然消失
  （内部边不再是边界），由掩膜构造保证。
- **层级** = `A.parent = B.parent = C`；A、B **保留**（变子块），不删除。
  「合并」因此是「嵌套」的一种特例：一套语义打天下（平铺只在顶层成立）。
- **覆盖物**：C **不继承** A / B 的覆盖物（各子块保留自己的表现）。→ §待裁。
- **一次撤销**：`MergeNatureRegionCommand` 单事务（照 ADR-0028 划分命令的形状）。

### D6 · 边界 = 快照 + 可重生成

沿用 ADR-0029 的先例（"边界是生成快照而非领域状态区间"）：region 的 `polygon` / `holes`
是**物化时刻的快照**，笔刷改了地形后**不自动跟随**；提供 `RegenerateNatureRegionCommand`
（照 `RegenerateBiomeMarkerCommand` 的形状）由作者显式重算。

### D7 · 无名区域不显示在地图上

`Region.name` 为**空串** = 无名 → `update_region_labels`（`wv-render/src/drill.rs:1366`）
跳过该区，不产生标签候选。自动分区候选根本不落盘（D4），自然也无标签。

### D8 · 格归属判定与嵌套优先级

- **归属判定**：region 的 `polygon` / `holes`（图内局部 wu）经 `rasterize_ring`
  （even-odd，边界算在内）栅格化为掩膜；格心落在掩膜内即属该区。
- **嵌套优先级**：一格可同时落在父区与子区内 → **最深优先**（子区覆盖父区）。
  父区若也声明了覆盖物，在被子区覆盖的格上**不生效**。
- **成本**：只有**声明了覆盖物**的 region 需要参与逐格查表（通常个位数）；
  其余 region 仅在作者显式查询"这格属于哪个区"时栅格化。

### D9 · 覆盖物解析顺序（渲染期唯一入口）

```
该格命中的最深 region 的 overlay 键，且当前主题有该键的规则  → 用该规则
否则（含未知键 / 无 region 声明）                          → cell 派生默认（ADR-0039）
```

落点：`wv-render::terrain_decor` 的 `decor_kind_for_biome` 是当前唯一的
「cell → 装饰类别」投影入口；本 ADR 要求该投影升级为**带 region 覆盖的解析**
（cell 属性派生 + 最深 region 声明的覆盖物键 → 最终规则），**不改六桶合批 / LOD 三档
/ splitmix64 确定性**的既有纪律。

### D10 · ThemePack 增「区域覆盖物规则表」

- 规则表的**词表与长相由主题拥有**：`wv-theme` 的 `ThemePack` 增区域覆盖物规则表
  （键 → 覆盖物规则）。外部主题 crate 只依赖 `wv-theme`（ADR-0043 D2），不依赖
  `wv-render`。
- **`wv-core` 不依赖 `wv-theme`**（AGENTS §2.1 红线）→ `Region.overlay` 是裸字符串，
  解析发生在渲染 / 主题层。
- 这是 **ADR-0023 M3「演绎规则 ThemePack 化」的第一块**：cell 属性派生的那套
  （ADR-0039 的规则表，当前仍是 Rust 常量）随后同样迁入主题层——届时
  "换 theme = 换每个自然区的覆盖物表现"才在**两条来源**上同时成立。

## 代价

- `Region` 加四个字段（全部 serde default，旧 YAML 零迁移）；`World.regions` 与
  `regions/<id>.yaml` 的读写路径要带新字段；
- `RegionLabels` 要加"空名跳过"分支；
- `terrain_decor` 的投影入口要接 region 覆盖（需按格查 region 掩膜）；
- 主题层要加规则表构造面 + 外部主题 crate 的兼容面；
- 自动分区需要"沿图幅矩形补边"的闭合处理（D1 的坑）；
- `Region` 的 `holes` 是新增几何维度，校验 / 绘制 / 命中判定都要认洞。

## 被否决的备选

| 备选 | 否决理由 |
|---|---|
| 新开 `NatureRegion` 实体 | 与 `Region` 语义重叠，两套面状实体 + 两套几何底座 + 标签/选取/校验双份 |
| 覆盖物落 cell（加第四通道） | cell 三通道是**事实层**；表现层进格子会让"改表现"污染地形数据，且与 ADR-0039「派生不持久化」正面冲突 |
| 覆盖物枚举化（`OverlayKind` 有限枚举） | ADR-0032 的碎裂教训（"写 1 漏 10/11"）；词表应随主题开放 |
| 自动分区全部落盘 | 数百~数千 YAML 文件 + 大量过期多边形（D4 的规模论证） |
| 自动分区按流域 / 按地貌单元划分 | 需新写汇流算法 / 新分类器，且与"覆盖物按 biome 派生"不同源；biome 连通区语义自洽且内核现成 |
| 合并 = 纯几何并集、成员删除 | 丢掉"这块地曾是什么"的层级信息；改成"建父子 + 并集"一套语义打天下 |
| region 覆盖物优先级低于 cell 派生 | 作者显式声明的意图被派生规则盖过，声明形同虚设 |

## 触及原则

| 原则 | 触及 | 说明 |
|---|---|---|
| P1 单机可运行 | 未触 | 零新增依赖、零网络、零服务端 |
| P2 目录即工程 | 触 | 自然区域落 `regions/<id>.yaml`（§4.5 每实体一文件），不写 AppData / 注册表 |
| P3 YAML 为主 | 触 | 几何内联（沿用 `Region` 口径），**不新增二进制例外** |
| P4 多地图层级 | 触 | region 挂 `map` + `parent` **引用**，父图不内联子区域 |
| P5 图层化编辑 | **未触** | 自然区域**不引入新图层**：它改的是表现声明，不新增 `LayerKind`，不改 `LayerFrame` 的九个槽位 |
| P6 非破坏编辑 | 未触 | region 的 `overlay` 是**追加式声明**，不改写任何历史值；cell 仍是当前地形（栅格无时间轴） |
| P7 时间轴驱动 | 触（须明写） | region 边界是**快照**不是区间序列（D6）；覆盖物键当前不带时间窗（§待裁） |

## 待裁（移出本 ADR）

1. **格子要不要有 span（cell history）**——2026-10-20 用户提出：「万一被陨石打了一下呢」。
   触发场景真实（时间轴上地形被改变），但代价是 `terrain.bin` 升格式（v3）、编辑命令
   从"覆写"改为"追加区间"、渲染必须经 `TimelineQuery::at` 求值（P7 §3 禁渲染层做时间比较）、
   自动分区与 region 边界都要时间化。**暂 pending**，登记于 README §12-47。
2. **region 覆盖物要不要改底色（tint）**——v1 只改装饰符号；底色是 cell biome 的直接投影。
   若要改，需再加一个声明位并让 `terrain_view/cells.rs` 的底色合成读 region。
3. **region 覆盖物要不要带时间窗（span）**——与待裁 1 同源：格子若时间化，覆盖物声明
   大概率也要时间化（"这片曾经是针叶林，后来砍成伐木场"）。
4. **合并时覆盖物的继承规则**——D5 取"C 不继承、子块各自保留"，若作者希望"合并后
   整体取 A 的表现"，需另开规则。
5. **自动分区的粒度与噪声**——biome 连通区可能碎（噪点 biome 会切出许多小块）。
   是否按最小面积阈值过滤、是否做形态学开运算，待实机观察后定。

## 追记一（2026-10-20，用户裁定：覆盖物键缺失的渲染口径 = 白底红斜线缺失标记）

**原结论**：D2 写「当前主题没有该键 → **回退到 cell 派生默认**」。
**修正为**：**画缺失标记——白底 + 红色斜线，覆盖该区域**（接管底色与该区域的装饰符号）。

### 理由

1. **回退等于冒充。** 区域声明 `conifer`（针叶），主题无此规则时回退到 cell 派生默认会
   画出**阔叶**——那不是"森林"这种泛化退路，是把作者明确声明的**另一个语义**顶上来；
   地图上看不出异样，作者却已丢了一次声明。工具不该替作者决定"你的声明不重要"。
2. **数据并未损坏。** 键还在 `regions/<id>.yaml` 里，完好无损；缺的是**当前主题里没有
   这条规则**。因此缺失标记是「主题 × region」的函数，**不是数据完整性检查的产物**——
   同一工程换主题，斜线出现 / 消失，数据一个字节没动。诊断文案据此分两种情形：
   - 「键 `conifer` 在当前主题中无规则」（换主题丢失）；
   - 「键 `conifer` 不存在于任何主题」（作者手误键名）。
   两者**视觉相同、文案不同**。
3. **未兑现的声明必须可见。** AGENTS §7.2「悬空引用必须被检出并列出」+ §7.5 V1
   「工具的职责是让作者看见问题」。

### 视觉规格

| 项 | 口径 |
|---|---|
| 形态 | **白底（不透明）+ 45° 红色斜纹** |
| 覆盖范围 | **接管**该区域的底色**与装饰符号**（绘制在 decor 之上）——不是半透明叠加 |
| 红色 | **固定诊断色**（不随主题色板）——古舆图等主题的土红系会与斜线混成"装饰"，问题隐形 |
| 白底 | 保证斜纹对比度与主题无关；红纹固定色 → 任何主题下都读作"警示" |
| LOD | **三档全画**（Nation / Region / Edit）——缺失标记不可被降档隐藏：装饰在 Nation 档本就不画，若跟着降档，作者切到全局视图反而在最需要发现时看不到 |
| 落盘 | **不落盘**（P7 纯渲染派生，与 cell 派生变体同纪律） |

### 作用域与优先级

- 逐格解析，取**最深**声明覆盖物的 region；该 region 的键在当前主题**无规则** → 该格画
  缺失标记。
- **更深的 region 若能正常解析 → 不画标记**：父区的缺失标记**不得**盖住子区已正确
  渲染的部分。实现上，父区标记掩膜须减去「更深的声明区」掩膜（`rasterize_ring` +
  掩膜布尔，`wv-terrain/src/divide.rs` 现成）。

### 诊断（与地图配合）

- **地图**给"在哪"：白底红斜线直接标出位置。
- **校验面板**给"是什么"：列出 region 名 / 覆盖物键 / 所在图（AGENTS §7.2）。
- 两者都**不阻止保存**（V1）。

### 实现要点

- 三角化：`earcut_with_holes`（`wv-render/src/faction_overlays.rs:526`，自写 earcut 零新依赖）
  + `build_polygon_with_holes_mesh`（`feature_overlays.rs` 已复用）——region 的
  `polygon` + `holes` 直接可用。
- 条纹：**单张"白底红斜纹"小贴图 + 世界空间 UV**（静态 mesh，**不逐帧重建**——ADR-0030
  的"每帧重建 mesh = 资产泄漏"教训）；贴图需 `ImageSampler::repeat()`（否则边缘拉伸成
  糊条）。世界空间 UV 的代价是远档条纹变细 → 靠 mipmap + 各向异性缓解，不改 UV 策略。
- **不碰 WGSL**（按 ADR-0042 定调，WGSL 是中期方向而非当下）。
- Z：**0.078**（地形装饰 0.075 之上 / 道路 0.09 之下）——属底图族，不压过 POI 与标注。
- 主题层需提供**键存在性查询**（`ThemePack` 规则表的键集合）。

### 代价

- 大面积未解析区域会变成红白块——这是**诊断状态而非常态**，作者补主题规则或改键名即恢复；
  但在补上之前，该区域的底色与装饰被遮住（事实仍在数据与面板里）。
- 需主题层新增"键存在性"查询面。

### 与 ADR-0023 族规则回退的关系：**不统一，且是有意不统一**

| 情形 | 口径 | 理由 |
|---|---|---|
| **族规则缺失**（主题没定义"森林族"整族） | **回退**（回退色晕 + 地界 + 名字，`FeatureOverlaySet::rule_for` 现状不动） | 回退色断言的仍是"森林"——**正是该族的事实**，语义诚实 |
| **region 键缺失**（主题没定义"conifer"这个具体变体） | **白底红斜线缺失标记** | 任何回退都**冒充另一个变体**（拿阔叶当针叶），是替作者做决定 |

两者并存不矛盾：**回退用于"少了细节"，标记用于"声明没兑现"**。

## 追记二（2026-10-20，实现落点 + 间距倍率语义修正）

**原结论**：D10 的规则表含「采样间距倍率（`spacing_scale`）：`< 1.0` = 更密」。

**修正为**：**`spacing_scale > 1.0` = 更疏**（`≤ 1.0` = 与默认同密）。

**原因**：装饰采样走**固定步距网格**（`stride = 屏幕步距 ÷ cell_size`），
「更密」在固定步距下**不可达**（要更密只能缩小全局步距，那会波及全图），
而「更疏」可由**逐格的保留概率**实现：`keep_prob /= spacing_scale`。
故把可实现的方向定为「更疏」，原方向作废。

### 2 · **两套原点修正**（本轮发现并修掉的正确性缺陷）

区域多边形是**图内局部 wu**，而地形格属于**栅格所在的图**——子图上这两者
**不是同一坐标系**（`GridConfig::map_origin` vs `raster_origin`）。本轮实现
最初按「wu ÷ cell_size = 格坐标」单一换算走（与 `marker.rs` 同款），在根图上
正确，**在子图上整体错位**。

修正：换算链全程携带偏移 `raster_to_map = map_origin - raster_origin`：

| 层 | 修正点 |
|---|---|
| `wv-render::region_overlay` | `build_index` / `region_mask` / `mask_to_shape` 多带一个偏移参数 |
| `wv-edit::nature_region` | `MergeNatureRegionCommand` / `RegenerateNatureRegionCommand` 多带一个偏移参数 |
| `wv-app::nature_region_actions` | 物化时把偏移加回（格坐标 → 图内局部 wu） |

两个测试钉死该行为：`raster_to_map_offset_shifts_the_covered_cells`（渲染侧）、
`merge_uses_the_raster_offset_when_mapping_polygon_to_cells`（命令侧）。

> **为什么现在才暴露**：自然区域是第一个「作者声明的**面**」——它的坐标既要
> 对齐**渲染**（图内局部 wu）又要对齐**地形格**（栅格系），两边坐标系不同就
> 必然错位。已有的 `Place`（点）没有这个问题（点只有一个坐标）。

## 追记四（2026-10-20，区域可视化三件套 + 作者小河交互）

### 1 · 区域轮廓 + 底色覆盖（`wv-render::region_outline`）

区域实体此前**只有标签、没有轮廓**——作者看不出圈了哪块地，改覆盖物也就无从
下手。补上两条：

- **轮廓线框**：外环 + 洞环画成线（复用 `build_stroke_batch_mesh` 合批），
  Z **0.076**（装饰 0.075 之上 / 道路 0.09 之下），固定蓝灰不随主题色板——
  「作者划的边界」是语义不是配色；
- **底色覆盖**：声明了覆盖物键的区域，用该键的**主题规则色**画半透明色块
  （alpha 0.28），Z **0.064**（底图族内）。

**为什么底色走覆盖层而不是改烘焙**：烘焙有「局部重画 = 全图重画逐字节一致」
的契约（行带并行 + 增量 patch 都依赖它）；底色进烘焙则「改一个区域的键」要触发
纹理重建 + 脏区按覆盖范围膨胀。覆盖层则**改键即生效**，契约零影响。

**洞的扣减**：`earcut_with_holes` 的洞桥接会产生**绕向相反**的零宽走廊三角形，
三角网面积必须用**有符号**求和（绝对值会把走廊也算进去，实测 32 → 44）——
测试 `region_fill_mesh_area_excludes_the_hole` 钉死。
