# ADR-0048: 海洋表现——离岸距离场、近岸浅滩带与浪花带

- 状态：已接受（Accepted，2026-10-21，用户裁定「好，然后按照你的推荐」——先抽 SeaRecipe 再调配方）
- 范围：S0（观感调参）/ S1（离岸距离场）/ S2（浅滩带）/ S2.5（SeaRecipe 抽取 + 水彩配方）**已落地**；S3（白色浪花带）**未做**，方向预登记于本文末
- 关联：ADR-0035（soften_keep 值被本 ADR 修订）、ADR-0036（VEIL_MAX_ALPHA 值被修订）、
  ADR-0039（主题演绎规则——本 ADR 的岸线表现同属 cell 驱动演绎）、ADR-0044（水彩晕开——
  浅滩 tint 同样收在 base_color_of）、README §12-48

## 处境

work-view-test 实机验收（2026-10-20）：海占视口约 44%，其中 56% 的海色挤在两个颜色上；
整幅「发闷发灰」。逐层归因（`diag_sea_bake` 探针，烘焙 vs 截图直方图对表）：

1. **深度量程错配**：`water_depth_t` 线性量程 3500 m，而该图 1/4 水格深 < 400 m
   （线性 t ≤ 0.11）——近岸与远海在色板上几乎同色；
2. **双层洗白叠加**：烘焙期 soften（15% 向纸色）+ 默认浏览缩放吃满的 veil（18%），
   把海面主导色从烘焙基色 (68,134,168) 抬到实测 (121,160,180)；
3. **近岸缺几何事实**：用户要「近岸更浅 + 浪花」，而全仓库没有任何离岸距离场——
   水深与岸线位置无几何关系（DEM 近岸剖面陡缓不一，深度浅 ≠ 离岸近）。

## 决策

**S0（观感调参，已落地 c74a175）**

- `water_depth_t` 线性 → **平方曲线**：浅水段动态范围约 3×（400 m：0.11 → 0.34），
  近岸/远海一眼可辨；
- `JRPG_SOFTEN_KEEP` 0.85 → **0.92**（修订 ADR-0035 的锚值，方向不变：洗白更轻）；
- `VEIL_MAX_ALPHA` 0.18 → **0.12**（修订 ADR-0036 的锚值；保留远景纸面空气感）。

**S1（离岸距离场，已落地）**

- 新模块 `wv_terrain::shore`：多源 BFS（8 连通均匀代价 = **切比雪夫格距**），陆格为种子，
  截断在 `DEFAULT_MAX_DIST = 12` 格；**纯函数、有界支撑**（任一格的值只依赖半径内
  水陆分布——渲染增量 patch 按支撑半径膨胀脏区即可保持「局部 = 全图」逐字节一致）；
- 与主题无关（水彩 / 水墨共用）；归 wv-terrain（域规则层，`is_water_cell` 先例），
  不归 wv-render。

**S2（近岸浅滩带，已落地 wip/ocean-shore-band）**

- 新主题槽位 `PaletteColors.water_shore`（日间 `#A9D3D5` / 暮色 `#6C8090`）+
  旗标 `TreatmentFlags::shore_shallow`（HAND_DRAWN 开 / EMPTY 关）；
- tint 收在 `base_color_of`：离岸 ≤ `SHORE_BAND_CELLS = 6` 格的水格向 `water_shore`
  smoothstep 混合（水线峰值 `SHORE_TINT_MAX = 0.85`）——放在基色一步，
  「模糊输入 = 直铺输出」契约（ADR-0044）不破；
- 仅 VectorFlat / Schematic（平涂语法，与 bleed 同口径）；
- `patch_terrain_image` 内部把脏区按场支撑半径（12 格）膨胀——契约收在 patch 自身，
  调用方无感。

**S2.5（SeaRecipe 抽取 + 水彩配方，2026-10-21 评审后）**

视觉评审结论：S2 后的海「是等深色带滤镜，不是水彩」——三条硬证据：
水域明度 std = 0.0（唯一色 1，`land_grain` 对水系恒 1.0）、水陆画法断层
（陆有逐格颗粒、水是纯渐变）、近岸只有色带没有墨线。对照 civ-atlas
（`fantasy.ts`）：其水彩感来自 **墨线**（`RIPPLE_D=[4,9,15]`、σ=0.55、
α=0.42/0.30/0.18；近岸排线 `HATCH_D=9`），**不是色阶**；且 `grain` 对海
逐像素生效（`1 + 0.035*(fiber-0.5)`）。

- **配方抽取**：新增 `wv-theme::sea::{SeaRecipe, RippleSpec}`，`ThemePack.sea`
  承载全部海面数值参数（深度量程/指数、浅滩带宽/峰值、水纹振幅、波纹圈、
  抖动幅度、墨色）。渲染层 `image_from_terrain` 等改为收 `&ThemePack`——
  **一次性把 palette + treatment + sea 收敛成单一主题入参**。抽取这一步以
  烘焙 PNG 的 SHA256 对拍验证**逐位不变**（`be378e97e9914c16`）。
- **P0-A 水面纸纹**：`water_detail()` 逐像素双倍频值噪声（0.045 / 0.19
  周期），振幅 `water_grain = 0.035`；**必须在晕开之后施加**（放在
  `base_color_of` 会被 5×5 模糊抹平）。水域 std 0.0 → 0.8~1.7、唯一色 1 → 19。
- **P0-B 离岸墨线**：逐像素对 `shore` 距离场做双线性采样，三圈高斯带
  （4/9/15 格）叠墨，`ripple_warp_cells = 1.2` 的值噪声抖动把同心圆打散成
  手绘不规则线。距离场截断半径改由 `SeaRecipe::field_radius()` 推导（现 19 格），
  patch 脏区膨胀同步跟随——**配方改带宽/加波纹，场与脏区自动跟着扩**。
- **P1 浅滩带减重**：峰值 0.85 → 0.55（原值读作「发光」，水彩的边缘是
  积墨不是提亮）。
- **闸门**：`water_detail_enabled` 与既有 `grain` 同口径——GoogleMap /
  Topographic / Coastline / Event 四者不掺纸纹与墨线。
- 外部主题获得同一能力：`wv-theme-chinese-ink` 已有自己的配方（无浅滩带、
  两圈更疏的皴线），**零改渲染层源码**——ADR-0043 的注入契约在海面上成立。

**S3（浪花带，未做，方向预登记）**

- **独立渲染 pass**（新 `PassId`），不烘进地形纹理——绕开局部脏区契约；
- 几何 ribbon：从距离场提取「离岸 X 格」等值线（`height_segments` 本就 level 参数化），
  对场做 fbm 扰动后 marching squares，浪花线自然破碎；顶点色 alpha 沿法向渐变；
- Z 落在海岸 halo（0.036–0.038）之上、主线（0.04）之下；新色板槽位 `surf_foam` +
  旗标 `shore_foam`。

## 理由

- **修曲线先于修色板**：色板两端（shallow/deep）本就区分度足够，是量程把区分度压没了；
  平方曲线一行改动、可随时回退。
- **洗白让位给覆盖层**：soften（烘焙期）与 veil（覆盖层）职能重叠（都洗向纸色）；
  把烘焙期洗白压轻、保留覆盖层职能，要素让位机制不动。
- **距离场必须截断**：真全局距离场与「局部脏区 patch」契约根本冲突（填掉一个湾，
  湾内所有格的距离都变）；截断在 12 格 = 有界支撑，是增量正确性的充要条件，
  且浪花/浅滩带用不到 12 格以外的距离。
- **tint 放基色而非采样末端**：水彩晕开以基色为模糊输入；tint 若在末端，
  晕开与直铺两条路径会漂移出拼接缝。

## 代价

- 洗白减淡是**全局观感变化**：修订 ADR-0035 / ADR-0036 两个已接受锚值（方向与两 ADR
  原意一致——都为「保色相」而调）；暮色主题共享 `VEIL_MAX_ALPHA` 常量，雾感随之略减
  （其自身 0.35 soften 主导，影响小）。
- 浅滩场每次合成重算（O(N) BFS，1024² ≈ 数 ms）：接受（同 Topographic 阈值口径，
  ADR-0039 §4.1.1）；后续若成热点，缓存口子 = `terrain_data_hash` 键控（isoline 先例）。
- patch 脏区膨胀 12 格：岸线附近笔刷的 patch 面积变大（约 +24 格环带），换增量正确性。
- 浅滩带只在平涂两模式生效：RealTerrain / GoogleMap 等不参与（语法不同源）。

## 被否决的备选

- **复活位图图集（tile atlas）**：4096² 纹理预算下逐格贴图只有 4 px/格（work-view-test）
  ——马赛克；且参考对象 civ-atlas 的质感实为**程序噪声**而非位图（fantasy.ts = 平涂 +
  boxBlur + hillshade；realistic.ts = 连续色板 + fBm）。「贴图」路线只在「世界空间平铺
  无缝纹理 + biome 掩膜」下才有意义，留待后续单独评估。
- **真全局距离场 + 全图重算**：正确性无懈可击但每次笔刷都全图重算，浪费；
  截断场 + 脏区膨胀以零感知成本达成同洁局。
- **浪花烘进地形纹理**：受 res（px/格）限制锯齿化，且把「随缩放变化的带宽」烧死在
  纹理里；独立 pass 可用亚格精度。

## 追记二（2026-10-21 · S3 浪花带 + DecorRecipe 抽取）

**S3 近岸浪花带（白色泡沫）**

- 落地形态：**与离岸墨线同一套机制**（距离场双线性采样 + 高斯带），但色白、
  位更靠岸——三层叠起来才是手绘海图的水岸层次：**岸线墨 → 白浪花 → 离岸波纹墨**。
  - 这与本 ADR 初稿预登记的「独立 PassId + 几何 ribbon」不同：**改口径**。
    理由：① 像素级比 ribbon 精度更高（软边、亚格、破碎颗粒都自然）；② 复用已
      验证的距离场采样，零新通道、不触碰增量 patch 契约；③ 泡沫的破碎本质是
      **逐像素高频噪声**，几何 ribbon 反而更难做碎。按 §6.3 只增不改，保留初稿原文。
- `SeaRecipe` 新增字段：`foam`（泡沫带，复用 `RippleSpec`）、`foam_ink`（泡沫色）、
  `foam_break`（破碎度）、`foam_warp_cells`（边缘参差）、`foam_break_freq`（碎块频率）。
- 配方值（日间水彩）：两道贴岸白带（离岸 1.0 / 2.6 格，σ 0.45 / 0.50，α 0.60 / 0.26），
  破碎度 0.78、参差 1.4 格、碎块频率 1.15/格。
- 水墨包的浪花**不是白浪而是淡墨痕**（α 0.16、不破碎）——「水墨的岸线是连续皴笔」。

**DecorRecipe 抽取（ADR-0039 D1 挂账项关闭）**

- ADR-0039 D1 写明「规则先落 Rust 常量表，签名稳定后随 ADR-0023 M3 迁 ThemePack」
  ——那次迁移一直挂账（README §12-30），后果是**换主题时陆地视觉纹丝不动**，
  水墨包想用皴笔而不是三角山都做不到。
- 新模块 `wv_theme::decor::DecorRecipe` 收编全部装饰数值参数：高度阈值（山 1500 /
  丘 550 / 雪帽 1800 / 露岩 3400 / 脊点吸附 1500 m）、气候带切点（fy 0.30 / 0.72）、
  变体墨色（针叶 / 阔叶 / 绿洲 / 露岩 / 山背光面）、8 族桶墨色、LOD 步距
  （26 / 46 / 72 px）与尺寸系数（1.0 / 0.8 / 1.6）、浅海白波深度带（−220 m）与密度尺度。
- **刻意不进配方**：biome → 符号族的分类映射（`decor_kind_for_biome`）——那是「这个
  群系属于哪一族」的**词表**（与 `wv_terrain::biome` 同源，属事实层）；符号的几何
  形状（三角 / 圆 / 半圆 / 弧的构造）是渲染实现。主题管「长什么样」，不管「是什么」。
- **行为不变的三重证据**：
  1. `terrain_decor.rs` 的 diff 逐行审查 = **纯常量 → 配方的机械替换**，无逻辑漂移；
  2. `wv-theme` 新增 6 条配方测试逐条钉住旧硬编码值（阈值 / 切点 / 步距 / 尺寸 /
     变体色 / 8 族墨色）；
  3. **实机像素对拍**：抽取前后两张 GUI 截图，地图区 **0 个 >8/255 的差异像素**
     （最大 4/255，且只落在等值线描边的亚像素 AA 边缘）。灵敏度对照实验：把
     `mountain_min_h` 1500→1600 后差异立刻放大到 237 个 >30 像素——证明装饰参数
     **确实生效**，那 4/255 的残差与装饰无关。
- 连带修掉 main 上三处**既有带病**（`cargo clippy -p wv-render --all-targets
  --features app` 才能暴露——标准门禁不带 app feature 时不编译那些测试目标）：
  `region_outline.rs` 的死函数 `triangle_area` + 多余引用 `&pos`；`vector_layers.rs`
  的 `vec!` → 数组。

## 性能锚点

- 全图烘焙（1024×768 格 → 4096² 纹理，含逐像素水纹与墨线）：**≈2.2 s**
  （`diag_sea_bake` 探针打印，2026-10-21）。水纹 / 墨线是逐像素工作，占
  烘焙耗时的主要增量；异步合成路径（`rebuild.rs`）下不阻塞主线程，
  但模式切换 / 调色板切换的等待会变长——若成为体感问题，第一刀是把
  纸纹做成**覆盖层贴图**（世界空间平铺，一次采样）而非逐像素噪声。
- 距离场 O(N) BFS（1024² ≈ 786k 格）≈ 数 ms，摊进合成量级。

## 测试与验收锚点

- `wv-terrain`：shore 模块 11 测（直岸递增 / 切比雪夫 / 截断 / 全水全陆 / 湖 /
  支持有界性 / 双线性采样 / 退化输入）；
- `wv-render`：`shore_shallow_tint_lightens_waterline_and_spares_offshore`（带内提亮、
  带外与旗标关逐位一致）、`shore_tint_patch_with_dilated_rect_matches_full_bake`
  （膨胀后 patch = 全图重算逐字节）；
- 实机：`diag_sea_bake` 归因探针 + `shore_heatmap` 距离场热力图 + GUI 截图直方图
  （海明度 5%–95% 带宽 146–169 → 126–155，主导海色 #79A0B4 → #628BA5）。
