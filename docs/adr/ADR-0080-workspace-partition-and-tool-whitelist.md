# ADR-0080：工作区功能分区与工具白名单（方案 A·声明表）

- **状态**：已接受（Accepted，2026-10-28，用户五项裁定「A / 1修 / 2可以 / 3… / 4确认」）
- **决策者**：用户对话拍板（2026-10-28 实机验收轮，起因=「CellMap 用完地形笔刷回来势力选择器没了」）
- **关联**：修订 [ADR-0039](ADR-0039-topographic-viewmode.md)（追记八：CellMap 开道路）、
  承接 [ADR-0069](ADR-0069-retire-schematic-mode.md)（BROWSING 数组构成）、
  补 [ADR-0079](ADR-0079-faction-partition-cake-cutting.md) 实机验收链路

## 1. 处境

顶栏工作区三段（Browse / Map / CellMap）只切**底图模式与面板编排**，工具不去分工作区：

- **旁路泄漏（实机 bug）**：CellMap 工作区的「快照全部面板 → 只开笔刷/地标」退出编排
  只挂在顶栏三段按钮上；快捷键 1/2、命令面板、HTTP `set_view_mode` 直接写
  `view.mode` 绕过退出——快照泄漏：Inspector 持续隐藏、势力层/事态页签持续禁用
  （实机表现「回来势力选择器没了」）。
- **持久化污染**：`persist_layout_on_change` 无工作区守卫，工作区期间的「全面板
  隐藏」态会写进 `ui-layout.yaml`——重启后 Inspector 永久消失（与上一条叠加）。
- **工具无分区**：地形笔刷 / 单格编辑 / 测量 / 河路绘制在任何档都可激活，作者
  面对一整条与当前工作不相干的工具条。

## 2. 决策（用户五项裁定）

| # | 裁定 | 落点 |
|---|---|---|
| ① | 旁路 bug 修进本分支 | `exit_cellmap_workspace` 单一退出入口（顶栏/分发器/HTTP 三路共用）+ persist 工作区守卫（工作区期间跳过隐藏面板的可见性记盘） |
| ② | CellMap 可见道路河流 | `MODE_TABLE` Topographic 行 Roads 开灯（河流本就开）——**修订 ADR-0039**，追记八 |
| ③ | 势力在 Map 和 Browse 都可开关 | `ViewMode::Faction` 退出 `BROWSING`（快捷键 3 空缺、命令面板不再列出）；势力开关 = 图层面板势力层组眼睛 + 政治图集页（ADR-0079），两档都在场 |
| ④ | POI 编辑确认在 CellMap | 现状即如此（地标面板随工作区自动开）；POI **浏览**三档公共（Browse 图钉 = 钻取入口；点选工具三档公共承载，ADR-0074） |
| ⑤ | 工具过滤走**方案 A：声明式白名单单表** | `MapToolId::available_in(mode)`；工具条灰化、快捷键拦截、命令面板隐藏、分发器终审四处置共用同源 |

### 三工作区功能分区（用户分类，已确认）

| 工作区 | 关注 |
|---|---|
| **Browse** | 事件任务、事态、时间（播放器只在场，已裁定） |
| **Map** | 势力、自然 Region、道路河流、城市交通、距离（政治图集页主场） |
| **CellMap** | 地形地貌、群系、POI 编辑、道路河流（**可见**，编辑入口在 Map）、海洋、气候线（赤道/回归线/寒带——随 sim-climate-layer 轮落地） |

### 白名单表（`available_in`）

- **三档公共**：抓手、选择（圈选）、点选（万能选择器，ADR-0074）
- **Browse/Map**：测量三件（CellMap 的 Topographic 行 Measurement=false，表与工具同口径）
- **Map**：LinePoi（河/路绘制；CellMap 只看线不画线）
- **CellMap**：笔刷、橡皮、单格编辑、泛洪、群系分界、大陆生成、地标放置

分发器闸门语义：白名单外的**开启**拒绝并提示；**关闭不拦**（工作区退出编排排的
`SelectMapTool(EditCell)` 就是关动作，拦了会把退出搞成半残）。

## 3. 理由

- **方案 A 优于快照编排（B）**：白名单是**数据**（一张 match 表），四处消费点
  同源、可单测、行为可预测；B 沿用面板快照思路会重演今天的快照泄漏类 bug，
  且不表达「工具属于哪个工作区」的语义。
- **Faction 退出 BROWSING**：势力填色已是图层关注点（层组眼睛 + 政治页），
  独立模式与「Map 段看势力」重叠；枚举保留（HTTP 词表 / 管线兼容），只是不再
  是作者入口。
- **退出统一入口**：三条切模式路径（顶栏 / 快捷键+面板 / HTTP）行为必须一致，
  否则编排类状态（快照、工具、旗标）总会从没走到的路径漏。

## 4. 硬约束

- 白名单**单表**：任何新工具入 `MapToolId` 时必须进 `available_in` 的 match
  （漏写 = 编译错误，exhaustive match 强制）；
- 工具条**灰化不隐藏**：作者要看得见工具在哪，切档即亮（悬停说明归档工作区）；
- 快捷键拦截优先于分发器报错：热键在排队前过滤（免弹无端报错打扰），
  分发器闸门仍保留（防 HTTP 探针 / 旧布局残留绕过）。

## 5. 后果

**正面**：切工作区后工具条只呈现本档工具；旁路泄漏与持久化污染根修；
「势力选择器消失」类状态错乱不再复发。

**负面 / 代价**：Browse/Map 里用 B/C 等热键的习惯被打破（瓷砖灰化 + 悬停指路
缓解）；HTTP `set_view_mode` 进 CellMap 不做工作区**进入**编排（面板不动——
探针场景够用，需要时再补）。

**被否决的备选**：方案 B（工具集快照编排——重演快照泄漏，无归属语义）；
按地图层级（World/Region/City）而非工作区分区（层级是数据轴，工作区是
任务轴，混轴后 CellMap 在城市图里的工具语义说不清）。

## 6. 与既有 ADR 的关系

- **修订** ADR-0039（追记八：Topographic 开 Roads）；
- **承接** ADR-0069 的 BROWSING 构成变更（Faction 退出，3 键空缺）；
- 不推翻 ADR-0052 的 Gate-1/2（播放灰化 / 无图灰化与工作区白名单**叠加**生效）。

> **追记（2026-10-28，用户澄清）**：Map 工作区的**主职是画自然 Region**
> （选择工具 + 意图菜单 + Region 面板在该档在场）；势力分区是同档在场的
> 另一件事，两轴互补（自然图开=地形+群系色；关=素底政治页）。
> 概念澄清留痕：**势力层 ≠ 群系层**——势力层=`FactionLayer`+分区（政治
> 归属，带 span）；群系=地形格 `biome` 字节；自然 Region=`NatureRegion`
> 实体。「自然图层分区」候选（ADR-0079 立项预留）将来复用分区引擎承载
> 自然蛋糕，但那是引擎复用，不是两层合一。
