## 1. 处境（Context）

右侧地图工具条没有「选择」概念：大陆圈画、城市落点、测量折线各自为政——多边形
手感分裂（圈画无橡皮筋、闭合后锚点不可编辑）、没有「先圈一块地方、再对它干活」
的统一入口；`region_panel.rs` 头注释明写「几何绘制是未来『区域绘制工具』的职责」
却一直无人接。作者想对一块区域干活（生成大陆 / 落城市 / 生成地形），必须分别学
三套手势。

同时城市创建流程卡在「多边形 vs 面积谁说了算」与「zoom 要不要 zoom 进城市」两个
问题上——后者经核查是**伪问题**：`drill.rs` 标记命中 + `LevelZoom` 每级夹持 +
覆盖物设计 D2「非跨图跳转」早已锁定 portal 模型（zoom 物理上跨不进子图）。

## 2. 决策（Decision）

1. **选择优先交互模型**：任何图级，先用**选择工具**圈区域 → 画布底部居中浮现
   **意图菜单** → 意图生效即选区清空。目录按图级过滤（有地形栅格 ∧ 级 ∈
   {World, Region}；City/Interior 占位文案，不隐藏工具）。
2. **Pen 方法**：多边形选择抽成共享件——`wv_render::state::SelectionState`
   （会话态资源）+ `wv_render::selection`（命中纯函数 + `handle_click` 状态机 +
   输入/绘制系统）。手感对齐 Figma pen：逐点 + 橡皮筋、双击 / 回车 / 点首锚闭合、
   Backspace 删锚、Esc 丢弃、≥3 点才可闭合；闭合后锚点单击选中可拖、双击删除、
   点边插入。命中优先级 **锚点/边 > 图标下钻（Closed 态双击）> 空白**；
   Drawing 态 `drill_pick` 全让位（防「图标旁收笔」误下钻致草稿蒸发）。
3. **意图目录**（v1 世界图 / 区域图）：生成大陆（选区喂既有八参面板）/
   生成城市（M2）/ 高山 / 丘陵 / 平原 / 湖泊（M3，`wv-terrain` intent 算法的
   区域掩膜版，一键应用无弹窗）/ 森林（M4，骑覆盖物 v1）。
4. **城市 portal 收敛**：多边形只当「位置圈」——质心 = 落点、包围盒面积预填
   对话框（名字 / ID / 底图 / 面积可改）→ 16:9 方正画布 → 确认即建图并
   **自动钻入**编辑器；父图城市轮廓是未来独立绘制需求，用同一 pen 方法单独画。
5. **退役**：大陆圈画瓷砖（`ContinentSketch` 整体删除，撤销回驻留 stash 改写
   `SelectionState`——单槽位：回驻留仅在无活动新选区时发生）与城市落点瓷砖
   （`CityToolState` 族整体删除，M2 以意图菜单形态回归）。

## 3. 理由（Rationale）

- **选择优先**是 Figma / 主流编辑器的既成心智：作者对「先选东西、再挑动作」零
  学习成本；工具条不再为每种意图长一块瓷砖。
- **Pen 方法共享**：区域绘制（Region）、父图城市轮廓、意图菜单全骑同一手势底座
  ——一次实现，处处一致；这正是 `region_panel` 欠了很久的那块。
- **portal 城市**：性能上只驻留一张图的栅格；语义上免去城市与世界图的地形拼接
  （ADR-0022 D3/D4 松耦合既有裁定）。「多边形 = 位置圈」消解了形状 vs 面积的
  双真相。
- **一键地形意图**：§7.5——工具是「让作者随便改」的，撤销即回滚，弹窗只会
  挡试错。

## 4. 代价（Consequences）

- 工具条瓷砖 9 → 8，布局测试同步；命令面板暂无 SelectTool 入口（待裁）。
- 选区是**会话态**不落盘：重开工程后选区消失（生成意图不受影响——成果已进 YAML）。
- Gizmos 无多边形填充原语，闭合区 v1 只有描边 + 顶点（设计稿追记的已记偏差）。
- 撤销回驻留从「多包络并存」降为「单槽位让位」：撤销生成后若作者已画新选区，
  旧圈不找回（确定性 seed 下重画同结果，损失可忽略）。
- 城市创建在 M1-M2 之间短暂不可达（瓷砖已退役、菜单入口未建）。

## 5. 被否决的备选（Rejected Alternatives）

- **zoom-through（跨图连续缩放进城市）**：需双级栅格同驻 + 地形边界拼接，性能与
  复杂度双输；且覆盖物 D2 已拍「非跨图跳转」。
- **多边形即城市轮廓（面积只读）**：父图上城市只以图标 + 标签呈现，轮廓形状在
  世界缩放带根本不被渲染——为不被看见的几何要作者精圈是纯负担；轮廓绘制留给
  未来父图高级放大带（届时用 pen 方法）。
- **地形意图带参数弹窗**：与「一键试错 + 撤销兜底」的整理工具定位相悖；参数
  常量集中 `wv-terrain` 待实机校准。
