# ADR-0042: 手绘 Nation 表现层——山链 / 等深海 / 陆格颗粒

- **状态**：已接受（Accepted，2026-10-20，用户看到参考图后裁定「开干」）
- **关联**：ADR-0035（JRPG 色板，本文修正其 `core.mountain` 一项）、ADR-0036（Nation 装饰带，本文调整步距与尺寸）、ADR-0039（主题演绎规则——**注意 0039 编号被两份文件并用**：`ADR-0039-theme-derivation-rules` 与 `ADR-0039-topographic-viewmode`，2026-10-19 并行会话撞号；后续编号从 0042 起）、`gen_demo`（演示生成器）

## 处境

用户拿 work-view-test 实机截图对比手绘 JRPG 参考图（冰火风豆包插画），判定「地图还是不够精美」。归因有三（实机截图逐项确认）：

1. **白色巨墙**：`wv-gen-demo` 山脊高斯宽度 22 格 → 每条山脉两侧 ~40 格的山地走廊，8 条山系把整个半岛吞成雪原条带；雪（`#F5F8F9`）+ 岩褐（`#8A7A66`）填充 + 坡度浮雕条带，画面被连续「缎带」污染。
2. **海面平**：深海只到 -1500 m，渲染端等深渐变（`water_shade_at`，t = depth/3500）最多走到 0.43——海面永远停在中间蓝，没有「越远越深」的读懂感。
3. **条带感**：气候轴是纯纬度阈值（0.30/0.42/0.72），撒哈拉/草原/森林画出横贯全图的水平直线；陆地平涂无颗粒，塑料感。

## 决策

**生成端（`wv-gen-demo`，只影响演示工程，可重新生成）：**

- **D1 山脊收窄**：高斯宽度 22 → 10 格（`--peaks` 缩放逻辑不变，下限 6 → 5）。「山脉是链，不是高原」。
- **D2 山脊噪声化**：`ridge_lift *= 0.65 + 0.7 * fbm(0.09x, 0.09y)`——等高线边缘破碎成有机曲线，不再产出干净平行条带。
- **D3 分类阈值抬高**：雪线 2250 → 2750、山地 1150 → 1500（丘陵 550 不变）——白/褐填充收到山芯，山的体积感交给装饰图标层。
- **D4 气候边界噪声化**：纬度阈值前对 `fy` 叠低频噪声（±0.07）——气候带边界变成有机曲线。
- **D5 等深五档 + 渐变**：浅海档不变（-10/-60/-400），新增 -1500 档（21..55 格），55 格外按距离 40 格线性下探至 -3200——渲染端渐变真正走到深蓝，且档位边界不再画出锐利多边形（第一轮实机截图确认过硬边界）。

**渲染端（`wv-render`，全工程生效）：**

- **D6 陆格颗粒**：陆上各类格（沙/草/林/丘/山/雪/沼/路）按格 ±4.5% 明度确定性抖动（`hash01(cx, cy, 0x5EED_C0DE)`），全渲染路径共用（全图烘焙 / 行带并行 / 增量 patch / VectorFlat 采样，先颗粒后淡化同序）。水系两槽不抖（等深渐变是连续函数）。瓦片直铺（Google 模式）刻意不抖——普通地图气质要干净。
- **D7 `core.mountain` 提暖**：`#8A7A66` → `#9E9070`，收近丘陵色。山体身份交给装饰图标承担，填充只做「高地变灰」的水彩过渡。**修正 ADR-0035 的定稿值**（修正关系按 §6.3 追记，原文不改）；`ART_STYLE_SPEC §1.4.5` 同步追记。
- **D8 山形图标两面化**：装饰三角山右侧叠一道深色背光面（`#474033` α0.85）——参考图的山是「受光 + 背光」两面体，单色三角只是剪影。
- **D9 Nation 档提密提大**：步距 96 → 72px、符号系数 1.45 → 1.6——山链图标要成「链」不是孤点。
- **D10 波浪提亮**：OceanWaves 弧 2.4×1.4 @ α0.5 → 3.4×2.0 @ α0.62——Nation 档读得出「海在动」。

## 理由

参考图的手绘感来自三层叠加：**离散图标**（山/树/城堡）承担地貌身份、**水彩颗粒**承担材质、**等深渐变**承担海域纵深。此前渲染栈的图标层（ADR-0031/0036/0039）已经存在，被填充条带压住发挥不出来；本 ADR 的核心取舍是「填充色退后、图标层向前」——这比往填充色上继续堆效果更接近参考图的构图语法。

## 代价

- **演示工程 terrain.bin 变更**（checksum 变化）——`wv-gen-demo` 可再生成，内容层（places/factions 等）不受影响（生成器只写 `maps/` + world.yaml template 段）。
- `core.mountain` 变色影响**所有日间主题工程**的山地填充——旧工程打开即新色（P7：颜色是派生呈现不是数据）。
- 陆格颗粒对性能影响 ≈ 0（每格一次 hash，直铺快路径内联）。
- ADR-0035 的色板表从此与代码有一处偏差，由 ART_STYLE_SPEC 追记条目 + 本文 D7 记录。

## 被否决的备选

- **只调色板不动生成**：白墙的主因是填充面积不是颜色值——颜色调得再暖，40 格宽的走廊还是走廊。
- **渲染端把雪/山填充压暗了事**：同样治标；面积收窄后现有雪白恰好是参考图的「雪顶」观感。
- **纸纹叠加（参考图第三层）同轮做**：做旧是全屏后处理，与「修山/修海」正交，且需要先定 D3（程序化噪声 vs 贴图资产）——留下一轮。
- **书法字体打包**：10–20MB 资产决策未拍板，留下一轮。

## 验证

- `wv-gen-demo examples/work-view-test` 三轮迭代截图（`.figma-ref/wvt_style_after*.png`）：山链取代巨墙、等深渐变平滑、气候边界有机、颗粒可见。
- `wv validate examples/work-view-test` 通过。

## 追记（2026-10-20 同日，纸纹 + 地标尺寸落地）

原「被否决的备选」中「纸纹叠加留下一轮」与「书法字体留下一轮」，当日续做前者：

- **D11 纸纹叠加（D3 裁决 = 程序化噪声）**：新模块 `wv_render::paper_overlay`——
  两张 256² 程序化贴图（暖褐斑驳 α≤0.13 可平铺三阶 value noise；椭圆径向晕影
  α≤0.16），以两张全幅面四边形叠在装饰（0.075）之上、河流（0.082）之下
  （斑驳 0.080 / 晕影 0.0805）。`GridConfig` 幅面值指纹变化时重建（钻取进城
  自动跟随）；贴图逐字节确定性生成（P7 派生），零外部资产。
- **D12 地标尺寸修复**：`sync_landmarks` 旧公式 `BASE_H_PX * 0.04 * scale`
  折算屏幕恒 **1.04px**——城堡图标自实现以来从未真正显示过（实机截图确认）。
  改为屏幕像素恒定按档微调：Nation 26px / Region 32.5px / Edit 39px
  （`BASE_H_PX` × 1 / 1.25 / 1.5），Sprite 与 mesh 兜底两路同口径。

书法字体（D4）仍待裁——10–20MB 资产入库是不可逆决策，等用户拍板。

## 追记二（2026-10-20，D13 山脉不规则化）

用户实机反馈两连：「山，太整齐了」「zoom out，白色就是道路」。归因与修法：

| 现象 | 根因 | 修法 |
|---|---|---|
| 山脉排成规则栅栏 | 装饰布点 `wx/wy` 恒等步距格心，符号是一张完美棋盘 | 站点级 ±0.45 步距确定性抖动（`hash01(cx,gy,0x51/0x52)`） |
| 同一种三角山重复 | 尺寸恒定、无簇生 | 每座山 ±35% 尺寸 + 三成概率簇生次峰 |
| 山脊是笔直缎带 | NE 脊线本体是几段直线折线；距离场无扰动、宽度恒定 | 距离场低频扰动（±3 格，**必须小于山宽**——±7 格实测把峰高削半、整条阿尔卑斯退化成丘陵）+ 宽度沿线 ±35% 起伏 |
| 白色雪带读作道路 | 纯白雪原填满整条山脊 | 雪线内按高频噪声约三成留作岩（峰群斑驳）；山地分类同样按高频噪声约三成回落丘陵（断裂成离散峰群） |

实施踩坑记录：把 `exp(-d/w)` 写成了 `-(exp(d/w))`（括号位置），负指数变巨大负数，
山高全部被 clamp 到 10 m——**满图没有山**且 terrain 校验和三轮不变，靠对比 warp=0/±3
的校验和才发现（校验和相同 = 代码路径没生效，是最好的回归信号）。
