# ADR-0052: 森林团块层——§七 的第二尺度（底纹填充 + 边缘团块）与素材换代

- **状态**：已接受（Accepted，2026-10-22，用户裁定「我以为你会贴图贴为这样」→「好」）
- **关联**：ADR-0050（森林视觉层：林底 + 位图树冠）、ADR-0051（密度场分块）、ADR-0031（程序化装饰）、`codex_forest_design.md` §七 / 参考图 `100+ Hand-drawn Trees and Plants`

## 处境

ADR-0050 落地后，实机画面的森林是「**草地底色 + 零星几棵树**」。对照用户给的
参考图（一堆手绘素材表），差距不在单株质量，而在**尺度**：

| 参考图的用法 | 当时实现 |
|---|---|
| **上半部分：森林团块**——大片有机形状，边缘是连续树冠轮廓 | ❌ 没有 |
| 下半部分：单株素材——成排的针叶 / 阔叶 / 棕榈，近距离用 | ✅ 有（3 变体图集撒点） |

手绘地图的森林在**地图尺度**上读作「一整片」，不是「一棵棵点数」。缺了这一层，
再怎么加密单株也只是「更多点」。

**第一次尝试还失败了**：直接把仓库里现成的 `forest_fill.png`（暖褐水彩）与
`forest_patch.png`（棕调素描）铺上去，同时 132px 的团块每 22px 步距盖一次
（一块盖住几十个邻点）——画面变成一整片**焦土色糊块**，比不做还差。
这次失败给了两条硬约束，写进决策：**素材必须与色板同族**、**盖章必须稀疏**。

## 决策

**D1 · 新增第二尺度：`DecorRecipe.forest_mass: Option<ForestMassSpec>`。**

两段式，各是一张内嵌贴图：

| 段 | 贴图 | 作用 |
|---|---|---|
| **填充**（`fill_*`） | 可平铺的**俯视密林底纹** | 铺满林地内部，读作「一整片林」 |
| **边缘**（`patch_*`） | **森林团块**（一小丛林，自带不规则边缘） | 盖在密度边界带上，把填充层的格状边界打散成树冠轮廓 |

数值（步距 / 平铺周期 / 起铺密度 / 透明度 / tint）全部住主题层——
换主题即换观感，渲染层只做执行器（ADR-0048 追记二的配方纪律）。

**D2 · 填充只铺「内部」，边界交给团块——形态学腐蚀。**

「内部」= 本格与其四邻（一个步距外）都达到 `fill_min_density`。只按本格判定会在
阈值附近留下**孤立方块 / 条纹**（首版实机可见），腐蚀掉之后边界带自然是团块的
地盘：团块自带不规则边缘，正好吃掉台阶。

**D3 · 边缘团块按哈希稀疏化（保留约 42%）。**

边界上**每个**步距点都盖会重叠加糊（D1 首版就是这么糊的）。团块边长（~104px）
远大于步距（24px），四成仍连得成轮廓；再配逐块的位置抖动 / 大小抖动 / 旋转，
边界不会读成「一排等距同款」。

**D4 · 素材换代：GLM 出图 + 洋红抠像，产出四张俯视素材。**

| 新素材 | 用途 | 处理 |
|---|---|---|
| `tree_atlas_day_gen.png`（384×128，3 株） | 单株树冠（替换旧图集） | 洋红底抠像 → alpha，trim，底对齐入 128² 格 |
| `tree_atlas_dusk_gen.png` | 暮色单株 | 由日间**乘冷暗 tint** 派生（同一套素材的两个调子） |
| `forest_fill_gen.png`（512²） | 团块填充 | 裁掉水印角 → 512²，对比压到 72%、整体提亮 10% |
| `forest_patch_gen.png`（256²） | 边缘团块 | 洋红抠像 → alpha，trim |

**为什么用出图而不是继续手写程序化符号**：参考图的语言是**手绘**（水彩 + 墨线），
ADR-0031 D5 的程序化三角化表达不了；而「加一种形态 = 改主题」的契约已经就位
（ADR-0050 D1），缺的只是**素材**。旧素材保留（`FeatureRule` 的地界覆盖物仍在用），
新素材走独立的键，互不影响。

**D5 · 三层分工（都由同一个密度场驱动）。**

| 层 | 尺度 | 图层 Z | 角色 |
|---|---|---|---|
| 林底蒙版（`cells.rs`，CPU 烘焙） | 格子 | 烘焙进地形纹理 | 底色，跟着水彩渗色晕开 |
| **团块层（本 ADR）** | 区域 | 填充 0.0765 / 团块 0.0775 | 远 / 中景主力 |
| 单株树（`forest_canopy`） | 个体 | 0.078 | 近景点缀 |

三层都是**派生量、不落盘**（P7）；「哪里有林」只有一个真相：密度场（ADR-0051）。

**D6 · 采样格世界锚定**（沿用 ADR-0051 D4 的纪律）：填充块与团块的抖动熵源都是
**世界格号**，平移相机不会让森林整体滑动。

**被否决的做法**：

- **按连通区做多边形 + earcut 铺贴图**：能严格贴合林地，但要引入「区域版本」
  这第二套真相（与逐格判定重复），且区域边界一变就要重算多边形。逐格判定 +
  腐蚀已经够用。
- **把旧素材调色（双色调）复用**：结构能保住，但旧图是**侧视／素描**视角，
  与俯视的树冠不是一回事——调色救不了视角。
- **让模型直接生成「一张地图」**：不可控、不可复用、无法分层；生成**素材**
  才是对的粒度。
- **边缘全铺团块**：见 D3（糊）。

## 代价

- 单帧多两层 mesh（填充约 2–3 千 quad、边缘数十 quad），一次合批、一把绘制；
  实测无感。
- `forest_patch_gen.png` 只有**一个**形状，铺多了会看出重复（当前在小片林上
  尚可，大林区能看出同一团块反复出现）。**这是当前最明显的余留问题**。
- 新素材是**位图**（P3 的例外只针对地形网格；贴图属渲染资产，与既有 4 张同待遇），
  入库体积 +0.8 MB。
- 出图流程不可复现（模型非确定性）——故成品 PNG 入库、生成记录写在这里，
  不再依赖重跑。

## 待裁

- **团块变体**：当前 1 个形状；要做 3–5 个变体（旋转/镜像只能骗过一部分眼睛）。
- **填充接缝**：`forest_fill_gen.png` 非严格可平铺（靠低对比 + 小尺寸淡化），
  真要做无缝需要「偏移 + 交叉淡化」预处理。
- **LOD 切换**：是否远景只画团块、近景只画单株（当前三层全开，靠 Z 与透明度
  叠合）——需要一次目视调参再定。

## 追记一（2026-10-22，晚）：改用委托设计素材，按说明图**关掉底纹**

**处境**：本 ADR 的团块层落地后，用户提供了**委托设计**的一整套素材
（`树木/` 5 行 × 8 列，附「在世界地图中的使用示例」说明图），并指出
「这是使用方式」。说明图把五行按**尺度**分工：

| 行 | 名称 | 数量 |
|---|---|---|
| 1 | 阔叶树 | 8 |
| 2 | 针叶树 | 8 |
| 3 | 密林树木 | 8 |
| 4 | 森林树簇 | 8 |
| 5 | 灌木草丛 | 8 |

示例地图里，森林是**树簇 + 单株混合堆叠**出来的，**没有连续底纹**。
本追记纠正两处我此前的识别错误：行 4 是**森林树簇**（不是灌木丛）、
行 5 才是**灌木草丛**；且这套素材是**斜俯视（有透视、见树干）**，
不是纯俯视——与用户最初给的参考图、JRPG 地图图标语法一致。

**决策（改 D1 的取值与三处契约，不改分层结构）**：

1. **单株层**改用 `tree_atlas16.png`（行1 阔叶 8 + 行2 针叶 8 = 16 变体）；
2. **树簇层**改用 `forest_cluster16.png`（行3 密林树木 8 + 行4 森林树簇 8
   = 16 变体，逐块按哈希选格）——这直接解决了「单张团块重复可见」；
3. **关掉底纹**：`ForestMassSpec::fill_texture` 由 `&'static str` 改成
   `Option<&'static str>`，本主题给 `None` ⇒ 不铺连续底纹，只靠树簇重叠成片
   （底纹保留为可选手段，测试用夹具显式打开它）；
4. **契约补两个量**：`ForestSymbolSpec::cell_aspect`（格宽 ÷ 格高，192/260）
   与 `ForestMassSpec::patch_variants` / `patch_aspect`——委托素材的格**不是
   正方形**，用方形 quad 会把树横向拉扁；`size_px` 一律记**高度**；
5. **树根下沉 15% → 3%**：新素材的构图是「底边贴地」（着墨底边离格底 2–6%）。

**暮色版**：由日间图集乘冷暗 tint `[0.72,0.77,0.80]` 派生
（`tree_atlas16_dusk.png` / `forest_cluster16_dusk.png`），保证两套调子同源。

**代价**：

- 单株图集 3072×260、树簇图集 3072×225（各 ~0.9 MB），入库体积 +2.6 MB；
- 行 5 灌木草丛（8 变体）**已拼版入库 `bush_atlas8.png` 但还没接层**——
  缺「林下植被」这一层，属下一步（见待裁）。

**待裁更新**：原「团块变体」项**已闭**（16 变体）；原「填充接缝」项**已降级**
（默认不铺底纹，只剩可选用途）；新增「林下植被层（灌木草丛）是否要做」。

## 追记二（2026-10-22，晚二）：**世界级视距不画森林符号**（档位门控）

**处境**：接上委托素材后，用户指出「**依然不好看**」，并提问「如果在世界地图上，
就不采用这种贴图呢？」——判断正确。**素材是近景语言**（一棵树占几十像素、
带透视与阴影），而说明图右上角的「使用示例」本身是**区域级特写**，不是全图。
世界级视距（一屏看整块大陆）下把这些树簇贴上去，读起来就是「贴纸」。

**决策（新增 D7，不改 D1–D6）**：

1. **档位门控**：`DecorBand::Nation`（`view.scale >= 3.0`）**不画**森林符号与树簇；
   只在 Region / Edit 档出现。两处规格各加一个主题开关 `nation_visible: bool`
   （默认 `false`；主题想要「全世界都贴树」仍可显式打开）。
2. **世界级视距由什么承担**：**烘焙进地形纹理的林底色调**（M1 / ADR-0050 D2）+
   已有的地形装饰（山 / 丘 / 雪）。这是「区域读法」，且是**烘焙**的——
   与世界级视距的颗粒度天然匹配。
3. 门控顺序：先判形态（主题给了规格没）→ 再判 pass / 图层 → 再判档位，
   全在**几何生成之前**返回，Nation 档因此零成本（不算候选、不解码贴图）。

**理由**：同一份素材在不同尺度上的合理与否差一个量级——这正是 ADR-0031 D2
（三档 LOD）与 ADR-0036（Nation 档只画大地貌团）一路的纪律。森林此前一直在
「照密度撒符号」，缺的正是这一道尺度门。

**代价**：

- 世界级视距的森林**只剩色调**，没有树形细节（这是取舍，不是缺陷）；
- 主题需要同时维护两套观感（远 = 底色、近 = 符号），调参面变大。

**验证**：`trees_are_hidden_at_the_nation_band` / `clusters_are_hidden_at_the_nation_band`
（负向）+ `trees_appear_at_the_region_band` / `clusters_appear_at_the_region_band`
（正向）；实机两张图：世界级（20%，只见林底）与区域级（53%，树簇 + 单株回来）。

**待裁更新**：无新增；原「LOD 切换」项**部分闭合**（已按档位门控，但
「远景要不要画极简符号」仍可再议）。

## 追记三（2026-10-22，晚三）：林下植被层（§七 第三尺度）

**处境**：单株与树簇落地后，近景（Edit 档）的林地**地面是空的**——树与树之间
只有平涂草色。委托素材行 5「灌木草丛」8 变体正是补这一层的。

**决策（新增一层，不改前两层）**：

1. **新层 `forest_understory`**（`wv_render::forest_understory`），
   `DecorRecipe.forest_understory: Option<ForestUnderstorySpec>`；
2. **只在 Edit 档出现**（`view.scale < LOD_REGION_SCALE`）——它是**最小尺度**
   的一层，Region 档一屏看几座山，几像素的灌木只会变噪点；
3. **摆放**：世界锚定采样格（平移不滑动）+ 只要**森林群系**且密度 ≥
   `min_density`；保留率 `keep_prob` 为基准，**林缘 ×`edge_boost`（1.9）**
   ——林心地面上有树冠遮荫，灌丛本来就稀；
4. **Z = 0.0776**：树簇（0.0775）之上、单株树（0.078）之下——灌木挡团块底边
   才有厚度，但永远压不住树；
5. 复用团块层的 `LayerPool`（实体 / mesh / 材质 / 贴图 / 指纹缓存），
   不重复实现一套资产纪律。

**代价**：Edit 档多一两个 mesh（千级 quad，一次合批）；`bush_atlas8_dusk.png`
派生入库（+0.2 MB）。

**验证**：`understory_grows_in_forest_at_edit_band` / `understory_is_edit_band_only`
（Region / Nation 都不画）/ `understory_is_inert_without_the_spec` /
`understory_does_not_accumulate_assets_across_frames` /
`understory_layout_is_deterministic`，加主题契约测试
`watercolor_recipe_declares_understory`。

**待裁更新**：委托素材（5 行 × 8 列）**至此全部接完**——单株 16 / 树簇 16 /
灌木草丛 8。剩「树种按气候带分流」（行1 温带、行2 寒带）与「统一左上光源的
投影」两项，都是打磨级。
