# ADR-0039: 主题演绎规则——cell 属性驱动的覆盖物变体（海洋波浪 / 气候带植物 / 高山雪岩）

- **状态**：提议（Proposed，2026-10-20）
- **关联**：ADR-0023（ThemePack——本 ADR 是其挂账 M3「演绎规则 YAML 化」的第一块实体）、ADR-0031（terrain_decor——装饰系统本体，被本 ADR 扩展）、ADR-0036（Nation 装饰带）、ADR-0035（JRPG 色板）、ADR-0016（水域渐变 / 雪双调的手绘特性先例）

## 处境

M1（ADR-0036）把装饰做成了「按 biome 选符号」：森林绿团、山三角、沙丘脊。
但符号本身**不分变体**——热带森林和寒带森林画一样的绿团，浅海和深海一样平。

用户观察参考图后提出三层诉求：

1. **海洋按深度分装饰**：浅海 / 一般深度 / 深海不同颜色 + 浅海点点白波；
2. **植物按纬度气候带分变体**：同是 FOREST，热带 / 温带 / 亚热带 / 寒带
   应长不同的树（参考图的直白观察）；
3. **极高山配色**：超过雪线的高山应为「白色带点黄」（雪 + 露岩），
   而非纯白或纯棕。

同时用户确认了两个边界：

- **数据持久化已满足**（cell 的 height/surface/biome 已在 `terrain.bin`，
  AGENTS §5）；渲染结果（这格画了什么符号）是 P7 派生投影，**不持久化**——
  同一数据 + 同一 theme 必然算出同一画面，存了就是第二真相源。
- **气候带沿用现有分类**：`wv_terrain::climate` 的 4 档纬度轴
  （雪 / 森林 / 温带 / 沙漠），不新造热带/亚热带枚举。

## 决策

**D1 · 演绎规则的载体：Rust 常量表 + 后续 YAML 化**

「cell 属性 → 覆盖物变体」的查表逻辑先以**纯函数 + 常量表**落在
`wv-render::terrain_decor`（与 `DecorKind::ink()` v1 常量同纪律）；
签名稳定后随 ADR-0023 M3 迁 ThemePack。**不**提前做 YAML schema——
规则表还在长，先让 Rust 类型把形状钉住。

**D2 · 海洋波浪装饰（OceanWaves 装饰类）**

- 新装饰类 `DecorKind::OceanWaves`（第 8 桶）；
- 采样：`height ∈ [-220, 0]`（浅海带，≈ NE 数据的 -10/-60 档 + 余量）的**水格**，
  splitmix64 确定性散点；
- 符号：1–2px 白色小弧 / 点（alpha ~0.5），密度随深度衰减
  （-10m 处密、-200m 处稀疏到无）；
- 深海（< -1000m）**不画**波浪——参考图的深海是安静的深蓝。

**D3 · 森林气候变体（ClimateVariant）**

- `DecorBand::Region / Edit` 档的 Forest 桶按**格 y 轴**（归一化 0=北）
  分三个变体，沿 `climate.rs` 现有纬度轴切档：
  - `fy < 0.30`（雪/森林带）→ **针叶**：深绿（`#2E5C36`）细三角，成排；
  - `0.30 ≤ fy < 0.72`（温带）→ **阔叶**：现有绿团（`#2B5731`）不动；
  - `fy ≥ 0.72`（沙漠带里的绿洲/河谷）→ **稀树**：孤立的暖绿小团
    （`#4A6B35`），密度砍半——绿洲语义。
- Nation 档不细分（96px 步距下变体不可辨），维持现有森林团。

**D4 · 高山雪岩配色（Alpine 变体）**

- 山装饰（Mountain 三角）在 `height ≥ 3400m` 时雪帽改「雪 + 露岩」双色：
  帽顶 60% 纯白雪（现有 `Snow` 桶），帽缘 40% 黄褐岩色（新常量
  `#C9B98A`，落在 Snow 桶里以子色画第二层小三角）；
- 阈值 3400 是**画雪岩的线**，与数据层雪线（`display_kind` 2600、
  装饰雪帽 1800）并存不冲突：1800 白帽 → 2600 数据层雪原 → 3400 露岩峰。
  用户口述的「4000 米」取 3400 是因为本图最高山 lift≈3400（阿尔卑斯量级），
  4000 在当前高度场上永远不触发。常量进 `terrain_decor`，theme 化时随 D1 迁移。

**D5 · 关闭覆盖物时的底色语义（确认现状，无新代码）**

覆盖物是叠加层；关掉后 cell 底色 = biome 分类色（`CORE_TERRAIN`），
森林绿 / 沙漠黄 / 山棕已可辨「这格是什么」。此条按用户确认收口，
不做额外「移除态特殊色」——biome 色就是那个颜色。

## 理由

- **查表先于 YAML**：演绎规则还没收敛（变体数量、配色都在长），
  Rust 常量 + 纯函数让编译器钉住形状；ADR-0023 M3 迁移点是签名稳定时。
- **气候变体只在 Region/Edit 画**：Nation 档 96px 步距 + 1.45× 大符号下，
  针叶/阔叶的形态差异低于人眼分辨率，画了等于白画还费顶点。
- **波浪密度随深度衰减**：参考图的浅海碎浪是「海岸带的活力」，
  深海点纹会变成噪点——与 M1 的「Nation 档防噪」纪律一致。
- **雪岩用子色不改桶结构**：7→8 桶已经一轮，雪岩是 Mountain 的配色
  细化不是新类，复用 Snow 桶加第二层图元，避免桶膨胀。

## 代价

- `terrain_decor` 桶 7 → 8（OceanWaves），`TerrainDecorPools` / 材质数组 +1；
- 森林变体使 Forest 桶顶点数 ×~1.2（针叶排比团簇多几个图元）；
- 实机需复核：波浪密度、绿洲稀树在 Nation 档是否泄漏（不应画）。

## 被否决的备选

- **渲染结果持久化**（存「这格画了什么」）：违反 P6/P7（第二真相源），
  且换 theme 时要全量迁移——用户已确认数据层持久化足够。
- **新建热带/亚热带枚举**：用户拍板沿用现有 4 档；变体由 y 轴在
  渲染期派生，零 schema 迁移。
- **波浪画成连续纹理**（等值线式）：与程序化符号体系（三角/团/弧）
  不一致，且格密度下变成色带。散点白弧是参考图观感的直接翻译。
- **雪线常量统一成一个**：1800（帽）/ 2600（数据雪原）/ 3400（露岩）
  是三个不同语义（装饰帽、群系分带、配色变体），强行统一会让其中
  两层失去表达。

## 待裁

- 波浪的「点白波」形态（小弧 vs 圆点 vs 短横线）——实机三选一；
- 绿洲稀树是否进 Nation 档（当前决定不进，若全局观感缺「绿点」再开）；
- 演绎表迁 ThemePack YAML 的时机（ADR-0023 M3，与 §12-30 合并推进）。
