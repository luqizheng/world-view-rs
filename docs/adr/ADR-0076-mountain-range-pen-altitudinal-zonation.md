# ADR-0076: 山系笔与山脉垂直带谱——山脉作为结构化对象，群系按高度落带

- 状态：**已接受**（Accepted，2026-10-27，用户批准设计稿「就这么定」+「go」起草 ADR 与计划）
- 设计稿：`docs/superpowers/specs/2026-10-27-mountain-range-pen-design.md`（builder check 已过）
- 实施计划：`docs/superpowers/plans/2026-10-27-mountain-range-pen.md`
- 关联：ADR-0031（程序化装饰）、ADR-0056（绝对地形学阶梯——同「绝对高度口径」先例）、ADR-0060（山地表达草案——本 ADR 只动数据侧 kind 赋值，不触其符号/POI 分工）

## 1. 处境

作者逐格涂抹山脉，产物有两类硬伤：**纹理乱套**（逐格独立写入，无共享走向/结构约束，出来的是补丁不是山系）与**整片同群系**（贴了「山地」标签的格子显示跟随标签，真实山脉沿高度应有的垂直带谱——山脚衔接周边环境、山腰丘陵、山脊山地、雪线积雪——完全缺失）。用户由此提议引入地球的板块系统来约束山脉走向。

代码核实（2026-10-27）：结构化机械大半已在——`Intent::MountainRange`（ridged 噪声脊线、两头收尖、跨海岛链）与地图级 `BrushTool::MountainRange`（一次笔触 = 一个可撤销事务）均已存在；缺口只有两处：kind 赋值只有「增量 ≥500 m 写山地」单档、无带谱；「山系笔为主力」的定位从未明确。

## 2. 决策

**不引入板块实体；采纳板块的本质而非其物理——山脉 = 有结构的对象（轴线给走向、剖面给起伏、高度给带谱）**。山系笔（即既有 `BrushTool::MountainRange`）为主力，手涂（`PaintKind` / CellMap 逐格）降为微调、语义零改。具体三刀：

1. **D1 带谱双判据**：`apply_mountain_range` 的 kind 赋值改为——只处理**实质抬升**（增量 ≥ `RANGE_KIND_ADD_M`(500 m)）的格子（门槛保既有地貌标签原样不动），门槛之上按**增量后绝对高度**落带：`<300` 草原（出水低肩，沿用先例）/ `300–1200` 丘陵 / `1200–2600` 山地 / `≥2600`（`SNOW_LINE_M`）雪原。常数同源 `wv-terrain/src/continent.rs:289-293`（与 `display_kind` NONE 回退、ADR-0056 阶梯同口径），不新增第二份阈值。
2. **D2 生效面**：`MountainRange` 与 `MountainMassif` 同享（共用 `apply_mountain_range`）；火山/高原/丘陵意图的 kind 口径本次不动。
3. **D3 主力编排**：工具枚举顺序不动（`BrushTool::ALL` 下标即命令绑定）；i18n 文案改「山系笔」语义、`PaintKind` 补「微调」提示；CellMap 工作台不新增入口。

## 3. 理由

- **板块是手段不是目的**：用户要的是「走向一致 + 带谱」，轴线画一条线就有，板块实体（数据模型、运动学、边界求值）是数量级更重的生成期原语，且与 V1/V2「作者随便改」的工具定位有张力。
- **门槛判据保护作者意志**：曾考虑「纯绝对高度、reach 内全部重贴」——否决，因其会把山系笔掠过的既有高原/旧山体按落带重贴标签，等于回头改非本次创作的结果（违反设计稿反目标 A2）。增量门槛保留现状代码的保护语义，只把「门槛之上写什么」从单档山地换成带谱。
- **雪原封顶、不扩词汇**：「高山草甸 / 裸岩」意味着动群系词汇表与 0–9 色板槽位（`display_kind` 契约），代价与当下收益不匹配；默认强度下只有部分高峰过雪线（调幅 0.78±0.32 所致），恰是「峰间差异」的正确表现。
- **渲染层零改动预期**：纹理乱套的根因在数据（无结构高度场）；脊线机械已在，数据结构了，坡度浮雕/分层设色/等高线自然结构。

## 4. 代价 + 被否决的备选

**代价**：低地上新画的山肩从「山地」变「丘陵」（行为变化，实机验收覆盖）；带谱只服务山系笔，CellMap 手涂格仍按作者标签显示（刻意保留，V1/V2）；世界工作台若山系笔不可达需后续轮补入口（见设计稿 §6-2）。

**被否决的备选**：① 板块实体系统（重、生成期、偏离编辑器定位）；② 纯绝对高度判据（回写既有地貌，违 A2）；③ 新增群系词汇（动词汇表+色板槽位契约）；④ 保留增量判据单档不动（不解决「都叫山脉」）。

## 5. 验收

实机（jrpg-world 世界图）：拖一条横穿森林与草原的山系 → 山脚各自衔接森林/草原、山腰丘陵、山脊山地、个别高峰带雪帽；山系笔掠过既有高原 → 高原群系不动；一次 Ctrl-Z 整条消失。手算期望值测试钉四档边界与门槛边界（计划 Task 1）。
