# ADR-0028: 势力领地表示与划分语义（势力交互 M1）

> 状态：**已接受（Accepted）**（2026-10-18 起草并实现；2026-10-18 用户确认接受）
> 关联：ADR-0027（势力层多兼容模型，已接受——D2「势力自持几何、渲染不推导领地」**继续有效**）、
> spec `docs/superpowers/specs/2026-10-18-world-from-zero-map-design.md` §5 + 追记一、
> 计划 `docs/superpowers/plans/2026-10-18-faction-interaction-m1.md`

## 处境

三通道底座已落 main（`62e88a9`）。世界从 0 生成的第二段是**势力图画法**：作者在宿主势力中间画意图多边形，
选「贴地」（边界吸附河流中线/山脊线/湖岸）或「越地」（直边），系统划分出新势力并保证势力图拼满、无缝、
相邻共享同一条边界（spec D2/D3/D5/D8）。spec §7 把四个表示层问题挂账待裁：Q8（领地表示机制）、
Q1（划分树重放）、Q2（贴地失败退化）、Q3（贴湖）。本 ADR 一并收敛，并处理一个实现期发现的硬前提：
**国中国会让宿主余部成为带洞环，而 `GeometryData::Polygon` 是单环**——不解决洞，D5（「在某个势力中间
画一个多边形」）无法成立。

## 决策

**D1 · 领地表示 = 生成即存储（spec Q8 的 a′）**。
划分动作时，内核把意图多边形 + 宿主几何 + 地形栅格一次生成为：新势力的边境环 + 宿主余部（可为带洞环），
**双双持久化为势力自有 `GeometrySpan`**。渲染永远只读 span（ADR-0027 D2 原文不动摇）；「重调意图多边形」
是作者显式动作 = 以当前宿主状态重跑生成并替换该势力 span，**不级联**子势力（Q1）。
理由：自持 span 让渲染/查询/序列化全部零改动复用 ADR-0027 管线；共边由「同一次切割的两沿」构造性成立，
不需要一等边界图。代价：重生成只到直接宿主粒度（子势力越界靠提示，见代价节）。
被否决：**(b) 一等共享边界图**（边界为节点、势力引用边——查询/编辑全链路重造，ADR-0027 零复用，过大）；
**(c) 格子所有权栅格 + marching-squares 派生**（渲染推导违反 ADR-0027 D2，且 16M 格所有权栅格是第二个
二进制例外，§5 纪律不许）。

**D2 · 除法语义 = 同一刀切两沿**。`DivideFactionCommand`（wv-edit）一次事务内完成：生成新势力边境环、
重生成宿主余部、`AddFactionCommand` + 两个 `UpsertFactionGeometryCommand` 语义的等价写入；undo 原子回滚
（宿主几何快照 + 新势力及其几何整体删除）。意图多边形把宿主切成不连通碎块时 → `Precondition` 拒绝 +
人话回执（v1 不支持碎块化余部；作者可分步划分达成）。
理由：单事务保证 D3（共边）与撤销完整性；拒绝优于静默丢地。代价：地峡切割场景 v1 不可为。
被否决：多命令拆分（中途失败会留下半划分状态）。

**D3 · 洞支持 = `GeometryData::PolygonWithHoles { outer: Vec<f32>, holes: Vec<Vec<f32>> }`**。
untagged 序居 `Polygon` 之后（serde 兼容：旧 YAML 零迁移）；`point_in_geometry` 取代裸 `point_in_ring`
成为「点在领地内」的唯一判定（洞内 = 不在）；wv-render 的填充改 earcut（外环 + 洞），边界描边画 outer 与
各 hole 的环。理由：国中国（D5）必然产生环形余部；洞是几何事实不是补丁。代价：渲染 mesh 构建器、
query、`FactionTerritory` 暴露面三处接洞（各一任务）。被否决：**容器式重叠**（宿主保持原环、新势力叠在其上
——违反 D3「不重叠」的用户原裁定，且 query 歧义）；**多 span 分片**（ADR-0027 的 span 身份
`(map, owner, from, relation)` 只容一张控制环，改身份是更大的 schema 动作）。

**D4 · 空势力 = 派生补集，v1 不建实体**。渲染势力层时，未被任何真实势力 span 覆盖的陆格即「未分配」，
着未分配色；选区质心无宿主时的划分对象 = 全图陆地（此路径不写任何宿主 span）。spec D4 的「正经实体、
独立 Id」语义在政治/历史段（需要把地「归还」空势力、空势力参与 Membership 时）以预留 id
`faction_null` 兑现。理由：v1 无任何操作需要空势力的实体身份；派生补集在笔刷造陆/沉陆时自动正确
（builder check 判断 #2）。代价：面板里暂时看不到「空势力」这一行。被否决：立即建实体（几何仍是派生的，
实体只是空壳，徒增序列化面）。

**D5 · 贴地吸附目标 = 地物线三族**（GLOSSARY「地物线」）：水陆界面（海岸/湖岸，surface 通道 marching
squares 0 等值线）、河流水格链骨架（细水链的格心连线）、山脊线（**v1 近似**：边界采样点搜索窗口内的
高度峰值格连线；真正的分水岭提取挂账 spec §7）。搜索无果 → 直线 + notice（Q2）；贴湖 = 绕岸，湖面归
空势力（Q3）。
理由：三族都从地形栅格纯派生，wv-terrain 零依赖红线内可实现；峰值近似对「山脉中心切开两边」的用户语义
足够（山体对称时峰值带 ≈ 分水岭）。代价：不对称山体切偏，v2 换真分水岭。
被否决：v1 只做水陆界面 + 河（山脊缺席会让「沿山脉分界」的核心用户案例落空）。

**D6 · 时间 = 划分自带 `from`**。新势力 span 与 membership 沿用既有 `TimeSpan`（ADR-0027/0015 管线），
时间轴回拨自动显示旧版图（P7 免费获得）；变迁动画仍为「可能」项（spec D6），数据层不做任何预埋。

## 代价（汇总）

- `GeometryData` 加变体 → wv-core/wv-io/wv-render/wv-edit 四 crate 接洞（约 4 个任务的改造面）；
- earcut 三角化进 wv-render（自写 ~120 行，零新依赖）；
- 山脊吸附 v1 为近似，不对称山体可能切偏；
- 地峡切割（余部碎块化）v1 拒绝；
- 空势力无实体行（政治/历史段兑现）。

## 被否决的备选（汇总）

一等边界图（过大）、所有权栅格（违 §5 + ADR-0027 D2）、容器式重叠（违 D3）、多 span 分片（动 span 身份）、
立即建空势力实体（空壳无操作价值）、真分水岭（v1 过重，峰值近似先走）。

## 追记（2026-10-18 终审后）

**共边精确性的边界（终审 I3 的显式裁定）**：新切边与宿主余部分享**同一条环**，在
「切割形成洞」的情形由 `mirror_shared_edge` 反序镜像保证**逐点相等**；在「意图贴宿主
外缘切割」（余部无洞）的情形，两侧环分别经 chaikin/DP 平滑，存在 **< 0.2 格**的偏差
（实测 0.06–0.1 格；8 wu/格约 0.5–0.8 wu，低于描边像素）。宿主**未被动到的**外沿与
既有洞在每次划分时被重新栅格化提取，同样带该量级的重平滑漂移。

裁定：M1 接受该亚格级偏差（视觉与查询均不可辨），把「贴边切割与外沿逐点保真」列为
M2 候选（做法：余部外环按切弧拼接，或保留原环顶点只替换切弧）。不把 D3 静默降级为
「大致共边」——本文即记录该边界。

**空势力宿主的水域**：`divide_geometry`（有宿主）只减去既有洞、不按水格裁剪；水域归
空势力（Q3）目前只在 `divide_land_host`（空势力路径）强制。宿主路径保留作者既有疆界
的完整性优先，M2 再议。
