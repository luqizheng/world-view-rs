# ADR-0065: 地图标签可读性——无衬线体回归、级别字号分档、街名建立碰撞

- 状态：**已接受**（2026-10-25，用户裁定「要修复字体，zoom in 或者地图上几乎无法
  分别 POI 的字体」）
- 关联：**修正 ADR-0042 D4**（画布标签书法体，正文不改）、ADR-0019（打包字体）、
  ADR-0017 §2.6（标签碰撞）、ADR-0030 / 0047（呈现级别）、ADR-0061（专业制图范式）、
  `docs/MAP_GENERATION_AND_POI_TYPOGRAPHY_PLAN_v0.1.md` §2.3（标签缺陷清单）

## 1. 处境（Context）

用户实机反馈：地图上（尤其 zoom in 后）**几乎无法分辨 POI 的字**。

拆开是四个叠加原因，前三个都不是「换一个更好看的字体」能解决的：

| # | 现状 | 后果 |
|---|---|---|
| 1 | 画布标签**全部**用霞鹜文楷（书法体，24.7MB），12px | 中文笔画被压到 1px 宽，笔锋与牵丝在低分屏糊成噪点 |
| 2 | 8 向纸色晕圈偏移固定 1.1px（与字号无关） | 12px 的细笔画被晕圈反吃掉一圈，字越细越糟 |
| 3 | 所有地点**不分级别同一字号 12px** | 首都与微点一样大，POI 之间「分不开」；碰撞优先级按名字**字节数**，长中文名反而更早被丢弃 |
| 4 | 街名 9px 且**完全不过碰撞过滤** | 违反 `ART_STYLE_SPEC` §4.2「中文 ≥ 12px」；编辑级视野一屏几十条街字叠字 |

ADR-0042 D4 选文楷的语境是「手绘水彩地图的书法地名」，与当前目标——**专业地图
UI（百度普通地图范式，ADR-0061）**——冲突：专业地图的标签字体身份是**可读性
优先的几何无衬线**，不是书法。

## 2. 决策（Decision）

**D1 · 画布标签默认字体改 Noto Sans SC，文楷保留为可选**

- `LoadedFonts::label_handle()` 返回 Noto（全覆盖中文），`drill` / `streets` /
  `measurement` 七个 `Text2d` 消费方零改动即可换字体。
- 新增 `LoadedFonts::calligraphy_handle()` 返回文楷；**资产与注册不删**，留给
  未来水墨 / 古舆图主题显式选用。egui 命名族 `wv_map_label` 族序改
  `[Noto, 文楷]`，与默认标签字体一致。
- 依据：两种字体在同一字号下的对照渲染（12px / 13px）——文楷笔画明显更细、
  字面率更低；Noto 在 12px 已能稳定读清。

**D2 · 地点标签按呈现级别分字号（16 / 14 / 13 / 12px）**

| rank | 含义 | 屏幕字号 |
|---|---|---|
| 3 | 国家级 | 16px |
| 2 | 区域 / 市镇 | 14px |
| 1 | 局部 | 13px |
| 0 | 网络节点 / 微点 | 12px |

级别来源与显隐门槛同源（`Place::effective_rank` → `rank_visible_at_tier`），
不会出现「按 A 规则显示、按 B 规则排字号」。

**附带**：势力 / 区域 / 海名从 16.8px（旧「地名 ×1.4」）提到 **20px**——
地名最高档升到 16px 后，旧的 ×1.4 只剩 0.8px 差，层级被压平；20px 让
「国/大区 > 城市 > POI」的阶梯重新成立。

**D3 · 晕圈随字号成比例**

`HALO_RATIO = HALO_PX / 12`，偏移 = 比值 × 该标签字号 × 世界单位/像素；
大字不再显得晕太细，小字不再被晕吃掉。

**D4 · 碰撞优先级 = 呈现级别 → 名称长度（字符口径）**

`priority_for(rank, name)`：先按 rank 分桶（级别高的先活下来），同级别长名优先
（长名更难被看清）。名称长度从 `len()`（字节，中文 ×3）改为 `chars().count()`。
`LabelCandidate` 增 `font_size_px`，碰撞盒按**每条候选自己的字号**计算。

**D5 · 街名 12px 并纳入碰撞过滤**

街名与最小一级地名同档；主次靠字色与层级，不靠压小字号。街名仍不参与拾取
（`target = None`），但互相让位。

**D6 · 顺手修两处标签池缺陷（同一批代码）**

- 事件标签 spawn 错挂 `FactionLabel`（应 `EventLabel`）——会被势力系统的池
  回收/复用。
- 势力 / 区域 / 海名的池复用分支写基础字号、新建分支写 ×1.4 字号——首帧大字、
  之后每帧被改回小字。改为两分支同取候选的 `font_size_px`，同时消灭这个回归。

## 3. 理由（Rationale）

- **可读性是地图标签的第一属性**：地名读不出，级别、配色、装饰都失去意义。
  `ART_STYLE_SPEC` §4.2 已把「中文 ≥ 12px」写成硬约束，街名 9px 是既有违规。
- **专业制图范式（ADR-0061）要求视觉层级由字号 / 字重承担**：百度 / Google
  的「首都 > 市镇 > POI」正是字号阶梯，而不是全部同字号再靠颜色区分。
- **碰撞优先级必须与显隐门槛同源**：rank 已经是全要素统一词表（ADR-0047），
  标签排序复用它是零新增概念；按字节长度排序会让中文名系统性吃亏。
- **不引入新字体**：Noto Sans SC 已随 ADR-0019 打包并在三处装配，换用它是
  零体积增量的修复；文楷保留使「书法地名」仍可按主题恢复，不烧掉既有资产。

## 4. 代价与被否决的备选（Consequences / Alternatives）

**代价**

- 默认失去手绘书法地名（JRPG 水彩的「手写感」少一块）。文楷资产仍在，主题
  显式调用 `calligraphy_handle` 即可恢复；如需默认恢复，改一行即可。
- 两级字号（16/14/13/12）是固定档，不随主题配置；将来若主题要自定义字号阶梯，
  需要把档位搬进 `ThemePack`（当前不做，避免为一件事开契约）。
- 街名加入碰撞后，编辑级视野会**少显示一部分**街名——这是「不叠字」的代价，
  换来的是留下的一条都能读。

**被否决**

| 备选 | 否决理由 |
|---|---|
| 只换字体，不动字号 / 碰撞 | 解决不了「POI 分不开」与 zoom in 街名叠字 |
| 文楷换更粗字重（Bold） | 需新增 24.7MB 级字体文件；且书法体加粗只会更糊，不解决字面率 |
| 保留文楷、仅把字号提到 16px | 16px 中文仍明显弱于同字号 Noto；且全部标签放大后密度更差 |
| 标签随相机缩放变大 | 违反「屏幕像素恒定」既定口径；缩放时字会与地图一起糊 |
| 删除文楷资产 | 目前无体积压力（内嵌资源），且会永久失去主题恢复书法地名的能力 |
| 主题字段控制标签字体 | 需要扩 `ThemePack` 契约；本轮先以「默认可读」收敛，按主题选字体留待真实需求 |
