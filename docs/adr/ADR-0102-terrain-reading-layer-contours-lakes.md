# ADR-0102: 地形读数层——高程等高线与内陆湖色

- 状态：已接受（2026-11-05，用户裁定「1-3-2」排期后实施；ADR-0101 验收
  追记挂账项 #1 的落地）
- 关联：ADR-0101（晕渲表现基线，本 ADR 是其挂账的兑现）、ADR-0055/0056
  （绝对米阶梯，等高线级表同一口径）、ADR-0061（专业制图，GoogleMap 恒
  coast-only 不变）、ADR-0051 追记（`view.isolines` 会话旗标默认关，沿用）、
  GLOSSARY「主/副等高线」「湖面海拔绑色」

## 处境

ADR-0101 落地后山脉立体感成立（色带 + 晕渲 + 山脊高光），但「读海拔」还差
两块：① 坡面上的**等高线**——粗栅格 DEM 上最强的海拔判读辅助（外部制图
评审判为「刚需」，本项目等值线矢量管线自 ADR-0012 起就有，但只画 0 m 海岸
与群系界，从未画高程级）；② **内陆湖**仍用固定海水色——山顶湖与海边湖同
色，出现「高山顶冒深海蓝」的违和（评审 §④：湖是卡在某一海拔平面的水体，
应绑定湖面海拔）。

## 决策

1. **等高线级表**：主等高线 **500 m**、副等高线 **100 m**（主间距的 1/5，
   制图「间曲线」惯例），绝对米语义（与 `hypsometric::DOMAIN_CUTS` 同轴）。
   副级表跳过 500 倍数（主线承担，不双线），上限 60 条。
2. **LOD 门**（`contour_levels_at_tier` 口径）：Nation（远观）= 全关——
   0.2 px/格上等高线是糊噪声，海岸线 + 色带已够；Region = 仅主 500 m；
   Edit = 主 + 副 100 m。`view.isolines` 会话旗标沿用（默认关，ADR-0051
   追记不推翻）；专业制图（GoogleMap）恒 coast-only 不变（ADR-0061）。
3. **单遍多级提取**：`wv-terrain::isoline::multi_level_segments`——对偶格
   只扫一遍，四角值域二分窗口 `(min, max]` 落级才展开。与逐级调
   `height_segments` 段集合逐位等价（测试钉住）；35 级副表从 37 次 O(N)
   降为 1 次 O(N + 交点数)。链缓存（`CachedChains`）扩 `elev_main/sub`
   两路；`IsolineKey` 增 `contour_sub` 位（Region↔Edit 跨档只重跑 DP +
   mesh，不重跑提取）。
4. **绘制分层**：主等高线并入主墨线 mesh（同色、宽 `CONTOUR_MAIN_PX`=
   1.1px）；副等高线独立 mesh + 淡墨材质（`CONTOUR_SUB_PX`=0.65px，
   alpha = 基准 × 0.45）——细而淡读作辅助读坡，不抢主墨线。
5. **内陆湖色**：湖 = 水面 ∧ **本格存储高度 ≥ 海平面**（GPU 用 Nearest
   取本格原值判别——平滑 `h` 在岸边会混入陆格高度，不能当海/湖判据）。
   湖水色向该海拔的色带色偏 `LAKE_TINT_RAMP`=0.35：高山湖取高阶冷调、
   低湖近水色，与周边陆地色带衔接；海（高度 < 0）不偏。仅 GPU Themed
   分支；CPU 回退路径不跟进（分叉登记，同山脊高光先例）。

## 理由

- 等高线与色带共用绝对米轴：作者读到的「颜色 = 线 = 海拔」三者在同一
  语义下互相印证，这是世界设定工具「读海拔」的核心诉求。
- 单遍提取是密集级表唯一可负担的形态：逐级调用的重算 hitch 在笔刷编辑
  场景不可接受。
- 副线独立材质而非降 alpha 混入主 mesh：主 mesh 材质跨重建复用 +
  palette 快路径重上色都按单一 alpha 假设，混入会破坏这两条既有机制。

## 代价 + 被否决的备选

**代价**

- 笔刷改高度仍触发链重建（含副级表提取），1024² 预估 +30~60 ms 一
  次（单遍提取的增量；实机验收核）。
- `view.isolines` 默认关 → 等高线默认不可见：沿用既有裁定（默认翻面
  是产品决策，留实机验收后拍板）。
- CPU 回退档无等高线/湖色（与山脊高光同款分叉，已登记）。

**被否决的备选**

- **等高线明暗取反色**（专家案：亮坡深线/暗坡浅线）：需逐段查晕渲
  强度，v1 复杂度不成比例；等高线本身高对比可读，留 v2 观察项。
- **雪线 2250 单独高亮线**：第三条线族 + 一个特判语义，本轮不做。
- **WGSL 屏幕空间等高线**（高度纹理 fract 阈值）：与既有矢量等值线
  管线重复，且矢量线可拾取/可导出，栅格线不可。
- **湖色 CPU 同步**：CPU 回退档是留守路径，湖色是 Themed 观感语义；
  分叉登记即可。

## 验收

- wv-terrain：多级 ≡ 逐级（逐位）、窗口左开右闭、平图空——17/17。
- wv-world-cell-map：级表（步进/跳 500 倍数/上限/零陆地）、装配路由
  （主并主线/副按门）、键 `contour_sub` 位——359/359。
- wv-render（app）：487 + 键位/装配编译面全绿；实机（jrpg-world）
  开 `view.isolines`：Region 见 500 m 主线、放大到 Edit 见 100 m 副线、
  远观退场；高山湖冷调。
