# ADR-0089：地图交互语法——三键统一 / 双击一律属性窗体（进城改道按钮）/ 两层进入 / 默认点选

## 1. 处境

四工作区（Browse / Map / CellMap / 场景编辑）的交互语义碎片化，同一手势在不同工作区含义漂移：

1. **右键被 6 处分工具占用**：平移（camera.rs 全局）、撤回锚点（选择工具）、丢笔（EditCell / 分区 / 街道）、收线（LinePoi）、退模式（测量）、取消选中（仅 CellMap nature overlay）——无一有统一语义，全靠各系统自嗨。
2. **双击语义分裂**：浏览族双击 = 下钻进城（drill.rs，ADR-0074 追记反复给它让位）；CellMap 双击图钉 = 属性 Inspector。图钉双击在浏览族**永远没有属性位**。
3. **默认态是隐式的**：进入地图后所有工具关闭、左键走 drill_pick 兜底（标签 > 图钉 > 空白清除）——行为上≈点选，但没有任何显式的「默认工具」概念，用户与代码都不知道「现在是选择模式」。
4. **option bar 显隐只覆盖笔刷族**（ADR-0086：CellMap 常驻 / 其他笔刷开着才现），LinePoi、测量等工具的参数没有归处。
5. **两把工具同名「选择」**：槽 1 点选（PointSelect）与槽 3 圈选+意图菜单（Select）UI 文案撞名，模式预期必错。

## 2. 决策

### D1 语法总表：两级仲裁，全工作区统一

任何地图输入按「**手势进行中 > 通用语义**」两级仲裁——手势（画多边形 / 落笔 / 收线 / 拖锚 / 拖钉等）进行中，三键全归手势；否则走通用语义：

| 输入 | 通用语义 |
|---|---|
| 左键单击 | 选择（命中当前工作区选择仲裁链的最高实体） |
| 左键拖拽 | 归当前激活 control（笔刷落笔 / 圈选画包络 / 挪钉 / 抓手平移） |
| 双击 | **一律开属性窗体**（见 D2） |
| 右键单击 | 取消选择（点空白等价） |
| 右键拖拽 | 平移（全局常备，与单击按位移阈值区分） |
| Esc | 取消选择；先让位进行中手势（现状 `clear_cell_selection_on_escape` 的让位序保留） |
| 进入地图（浏览性） | 全工具复位，默认激活槽 1 点选（见 D3、D5） |

**阈值收口**：双击窗口（0.40s）与位移阈值三处实现（drill.rs / pin_drag.rs / selection.rs）收口为**单点常量**；拖拽起手阈值（如挪钉 4px）与双击位移阈值是两个关注点，允许不同值，但各自单点定义、不散落魔法数。

既有 6 处右键占用全部**收编进此表**（不是推翻）：撤锚 / 丢笔 / 收线 / 退模式归「手势层」，取消选中归「通用层」，右键平移归「拖拽层」——行为不变，语义归位。

### D2 双击一律属性窗体；进城改道按钮

- 双击任何对象 = **属性窗体**，无例外。带子图的实体（城 / 场景 Place）窗体内显示「**编辑城市 / 编辑地图**」主按钮；无子图的实体（普通 POI / 图钉 / 格子）只有属性、无按钮。
- **Browse / Map 的双击直接下钻退役**（drill.rs 双击进城分支）：进城 = 双击开属性 → 按钮进入。CellMap 双击图钉开 Inspector（pin_drag.rs）本就合规，零改动。
- **CellMap 格子 / 群系区双击开属性窗体**（新增能力——现在双击空白格无事发生）；窗体展示内容（terrain / biome / 分区码 / 海拔）留给实施定义。
- 滚轮 ZoomCross（撞边界换级）与地图树入口**不动**，仍是独立导航旁路。

### D3 两层进入

| 进入方式 | 性质 | 默认态 |
|---|---|---|
| 切视图 / 开工程 / 关属性窗体回地图 | **浏览性进入** | 全工具复位，默认激活槽 1 点选 |
| 属性窗体「编辑城市」按钮进城 | **显式编辑意图** | 默认激活该场景的编辑工具（M1 分区笔刷就位，无需再点） |

口径一句话：**浏览进来看，按钮进去改**。顶栏点 CellMap 段（现自动开 EditCell，`top_bar/bar.rs:297`）改为浏览性进入——默认点选，EditCell 手动开；场景编辑 M1 的「进去即刷」由按钮进入路径保住。

### D4 入口-参数分离；option bar 显隐改写

- map control 条（工具条）只管「选哪个工具」= 编辑入口；**道路、河流都是 map control**（LinePoi 既有落点不变）。
- top option bar 只放**当前激活工具的参数**；显隐规则改写为「**随激活工具有无参数**」（替代 ADR-0086 的「CellMap 常驻 / 其他笔刷开着才现」——CellMap 常驻中的海拔滑条属视图读色参数，保留常驻，笔刷参数段仍随开关让位）。
- 补齐参数段：LinePoi（线型 / 宽度等）、测量的参数进 option bar；点选 / 抓手等无参数工具不出现（或仅残留视图级参数段，如海拔滑条）。

### D5 默认工具 = 槽 1 点选；槽 3 改名「圈选」；默认态显式化

- 「进入地图默认『选择』」= **槽 1 点选（PointSelect）**，两把工具维持分离不合并。
- 槽 3（圈选 + 意图菜单，`MapToolId::Select(SelectionShape)`）UI 文案改「**圈选**」，让出「选择」一名；工具条图标区分度同步核查。
- **默认态显式化**：浏览性进入时排 `SelectMapTool(PointSelect)` 开启（现状是全关 + drill_pick 兜底，行为≈点选但无显式身份）。显式化后 drill_pick 的图钉命中门（要求 PointSelect 激活）天然满足，标签命中 / 空白清除链不变。
- 工具状态仍为会话态不落盘（`ui-layout.yaml` 口径不变）——每次进入即复位，规则自洽。

## 3. 理由

- **D1**：一致性（C.1.1.01）是当前最缺的收口——同一手势跨工作区一个含义，用户只需学一次。6 处右键占用收编而非推翻：手势层本来就是「临时吞掉通用语义」的正确模型，现在只是把它写成明文。
- **D2**：双击属性窗体统一了两种读法——「下钻进城」重新定义为「打开它的编辑器」，编辑器入口从隐式（双击直达）改为显式（按钮），进城同时从导航行为变成**编辑意图声明**，这正是两层进入的前提。图钉双击在浏览族终于有属性位。
- **D3**：「进入默认=选择」若一刀切到按钮进城，M1「进去即刷」被多一步打断；若一刀切保留工具，规则失去意义。按意图分层两头都成立。
- **D4**：入口 / 参数分离与业界心智一致（工具箱 vs 属性栏）；河 / 路选项归 option bar 是该原则的直接推论。
- **D5**：槽 1 是工具条第一块瓷砖，「默认第一个 map_control」字面自洽；点选行为与现状 drill_pick 兜底几乎重合，显式化改动面最小。
- uxui-evaluator 内部框架审计 **80/good**：两个 warning（进城多一步→主 CTA + ZoomCross 旁路缓解；双「选择」撞名→D5 改名即修）均不阻塞。

## 4. 代价 + 被否决的备选

- **代价**：
  - 进城从「双击直达」变「双击 → 属性 → 按钮」三步（缓解：按钮做窗体首行主 CTA；ZoomCross / 地图树旁路不变）；
  - 顶栏进 CellMap 不再自动开 EditCell（原 ADR-0088 时代惯了一步直达的用户多按一次 S）；
  - 槽 3 改名「圈选」有文案 / 文档 / 习惯迁移成本（GLOSSARY 已同步登记）；
  - drill.rs 下钻链改造 + CellMap 格子属性窗体为新增工作量。
- **被否决的备选**：
  - *双击下钻保留、CellMap 例外*——双击语义继续分裂，图钉双击永远无属性位；否。
  - *按钮进城也回落点选*——M1「进去即刷」被破坏，编辑意图被工具切换打断（用户裁定「编辑城市编辑地图」直接否）；否。
  - *点选 + 圈选合并为一把工具（统一选择器 Q③ 的合并选项）*——用户裁定维持两把（2026-10-29「槽 1」）；否。
  - *等统一选择器 4 问收敛合成一份 ADR*——语法已闭环，落盘被扣住不值；分轨（本 ADR）；否。
  - *默认态保持隐式（全关 + drill_pick 兜底）不改*——「默认=选择」沦为口头约定，代码无身份、测试无抓手；否。

## 5. 验收口径

1. 四工作区：单击选择 / 双击属性窗体 / 右键单击取消 / 右键拖拽平移 / 空白单击与 Esc 取消——行为一致；进行中手势内三键归手势。
2. 双击城 / 场景标记 → 属性窗体带「编辑城市」按钮 → 点击进入后分区笔刷（或该场景编辑工具）已激活；双击普通 POI / 图钉 → 属性窗体无按钮；CellMap 双击格子 / 群系区 → 属性窗体。
3. 双击城市标记**不再**直接下钻；滚轮撞边界仍 ZoomCross 换级。
4. 切视图 / 开工程后：唯一激活工具 = 点选（工具条槽 1 高亮），无其他工具残留；工具选择不跨会话保留。
5. option bar：激活工具无参数时不显示参数段；LinePoi / 测量激活时出现各自参数段；CellMap 海拔滑条仍常驻。
6. UI 中槽 3 文案为「圈选」，与槽 1「选择」不再撞名。
