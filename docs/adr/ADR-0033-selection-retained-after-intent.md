# ADR-0033：意图生效后保留选区（推翻「意图生效即选区清空」）

## 1. 处境（Context）

ADR-0025 与选择工具设计稿 D9 定下「意图生效即选区清空」：作者圈出选区后点任意
意图，选区立刻消失。大陆生成另外用一套 `ContinentGenerationStash` 机制，在
Ctrl+Z 撤销生成命令时把意图圈「还回来」；地形四意图则明确「撤销不回驻留」。

实际使用暴露两个问题：

1. **「圈 → 生成 → 微调 → 再生成」的循环断了。** 作者生成后发现轮廓多一块、
   少一个锚点，只能整圈重画——而重画后的选区与上一次生成命令再无关系。
2. **清空的收益并不存在。** 意图菜单已经承担了「下一步做什么」的引导；选区
   消失并没有换来界面更干净，反而让作者失去了对刚做过的事的参照。

选区是**会话态**（不落盘、不进 YAML），它的成本只有屏幕上的几条线；它不是
一条命令的一次性参数，而是作者的临时工作台。

## 2. 决策（Decision）

1. **意图成功后不再主动清空选区。** 覆盖不切换当前图的全部意图：
   生成大陆、地形四意图（高山 / 丘陵 / 平原 / 湖泊）、生成森林标记、划分势力。
2. **选区仍按既有规则被动清空**：点空白、Esc、切工具、切图（含「生成城市」的
   自动钻入——那是切图规则的自然结果，不是意图主动清空）。
3. **删除撤销/重做时的选区恢复机制**：`ContinentGenerationStash` /
   `ContinentGenerationState` / `sync_selection_after_history_step` 一并删除。
   选区从未离开，不需要「还回来」；`apply_history_command` 不再接收
   `SelectionState`。
4. **撤销/重做只回滚世界数据，不触碰选区。** 作者在生成后改画的选区 B 不会
   被撤销/重做换回旧圈 A。

## 3. 理由（Rationale）

- **与作者操作层的定位一致（AGENTS §7.5 V2）**：作者想改就改。意图 = 对当前
  选区做一次操作，不是把选区「交出去」。
- **消除状态耦合**：不再需要 `tx_seq` 精确辨认「这次撤销是否对应那次生成」，
  也不再有「新选区赢 / stash 丢弃」的让位规则。实现从「两套状态互相协调」
  降为「一个状态不被触碰」。
- **工作流价值**：地形四意图是一键试错，保留选区后可以连续点高山 → 丘陵 →
  平原，每次只调轮廓，不必重画。
- **与「生成城市」不冲突**：城市意图确认后自动钻入新图，选区按既有切图规则
  清空——这是 portal 语义，不是本 ADR 要保留的对象。

## 4. 代价（Consequences）

| 代价 | 说明 |
|---|---|
| 意图菜单在生效后继续驻留 | 直到作者取消选区（点空白 / Esc / 切工具）。这是有意的；菜单底部已有取消提示 |
| Esc 语义变成「收菜单 + 取消选区」一步 | 作者想只收菜单、保留选区时没有快捷键。两段式 Esc（先收菜单再取消选区）被否决——多一个状态，且与「Esc = 取消选择」的既有肌肉记忆冲突 |
| 旧测试语义作废 | `undo_after_generate_restores_selection_and_grid` 等 5 项改写为「生成/撤销/重做全程保留选区」的断言 |
| 大陆生成面板的「撤销 → 调参 → 再生成」 | 参数仍由 `ContinentDialog` 自持，不受影响；变化的是选区不再消失/回驻留 |

**被否决的备选方案：**

- **B：把选区升级为持久 Region / 地界实体，确认即落盘，之后从面板重新进入编辑。**
  长期形态更完整，但要把 D11「选区是会话态不落盘」一起推翻，并引入新的存储
  语义（何时写盘、与 Region 是否同一实体、撤销粒度）。留待后续独立 ADR。
- **只改地形四意图、保留大陆的「生成即消费」。** 同一个工具在不同意图上表现
  不一致，作者无法形成稳定预期。
- **保留选区 + 保留 stash。** stash 的恢复分支永远走不到（槽位不空），成为
  死代码，并暗示一个不存在的行为。

## 5. 落地

- `wv-app::ui::intent_menu`：地形四意图成功后不再 `selection.cancel()`。
- `wv-app::ui::continent_dialog`：`commit_continent_generation` 不再接收/消费选区。
- `wv-app::ui::feature_place_dialog` / `faction_divide_dialog`：成功后不再取消选区。
- `wv-app::edit::editing`：删除 stash 与恢复判定；`apply_history_command` 签名收窄。
- `wv-app::state`：删除 `ContinentGenerationStash` / `ContinentGenerationState`。
- 测试：大陆生成 5 项改为「选区全程保留」断言；`cargo test --workspace` /
  `app-test` / `app-clippy` / `fmt` / `smoke-gui.sh` 全绿。
