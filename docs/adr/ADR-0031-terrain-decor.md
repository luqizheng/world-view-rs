# ADR-0031: 地形装饰——栅格群系驱动的程序化符号覆盖层

- **状态**：已接受（Accepted，2026-10-18，用户对话拍板「六大类一起做 + 地形驱动 + 三层 LOD」）
- **关联**：ADR-0025（M4 森林地界覆盖物的前身）、ADR-0029（biome 三通道——本装饰的数据源）、ADR-0030（合批 / 原地改写纪律的来源）、`theme::overlays`（Place.feature 地界驱动的既有覆盖物）、`ART_STYLE_SPEC` §3.6（程序化绘制承诺）

## 处境

主题覆盖物 v1（森林）是 **Place.feature 地界驱动**：作者声明事实地界才长树。用户裁定 JRPG 方向时明确覆盖物要**六大类一起做**（森林 / 平原 / 丘陵 / 山地 / 雪原 / 沼泽）且**地形驱动**——栅格长什么就长什么装饰，不依赖作者摆 Place。广德 DEM 导入后（1024² 真实高程 + 高程分带 biome），地形数据第一次有了可供演绎的完整群系场。

## 决策

**D1 · 数据源 = 活动地形栅格的 biome 通道**。采样经 `active_terrain`（与底图纹理同一份继承链），格 → 装饰类别的投影唯一入口 `decor_kind_for_biome`（词汇与 `display_kind` 同源）；水系与荒漠不演绎（海面有水彩带、沙漠留纯色，避免噪声）。

**D2 · LOD 三档**：Nation 档不画（纯色带承带）；Region 档步距 46px、符号 ×0.8；Edit 档步距 26px、全尺寸。步距换算成格 stride，采样数天然以视口面积为界；单类单帧兜底上限 2200 组。

**D3 · 确定性采样**：落点抖动 / 变体 = splitmix64(格坐标 + seed)——无 rand 依赖、跨进程稳定（重开工程树不跳）。密度阈值（平原 / 丘陵 40% 保留）同源。

**D4 · 渲染 = 六桶合批 + 原地改写**（ADR-0030 D4 纪律延伸）：每类一个 mesh + 一个实体；重建判据 `{顶点指纹, 步距尺寸, Z}`；变化才经 `Assets::get_mut` 原地改写。雪帽（山地格海拔 ≥ 1800m）跨桶进 Snow 桶——`SitePrim.bucket` 由采样器显式给出，三角化器不管路由。Z = 0.075 + 桶序 × 0.0004（地形族之上、道路之下）。

**D5 · 符号 = 程序化三角化**（ART_STYLE_SPEC §3.6 承诺的落地）：森林 3×Φ2.6px 圆、平原 Φ1.2px 点、丘陵半圆、山地三角（12 段 / 半圆 12 扇区手工三角化）、雪原扁半圆、沼泽双苇。尺寸全部屏幕像素 × `view.scale`（缩放中每帧重建 ≤6 个 mesh——桶级成本，与 POI 四桶同量级）。

**D6 · 配方接线**：新 `PassId::TerrainDecor`；MODE_TABLE 在 VectorFlat / RealTerrain / Schematic / Faction 开，Event / GoogleMap / Coastline 关；`terrain` 图层不可见级联关。

被否决：**位图瓦片图集**（JRPG 图集已弃用；程序化保 ThemePack 可演绎）；**GPU instancing**（v1 成本收益不成立，挂账 v2）；**每类独立 PassId**（六类共享开关语义，一个 pass + 桶足够）。

## 代价

- 缩放中每帧 ≤6 次 mesh 顶点重写（桶级，实测可忽略）。
- 符号颜色 v1 为常量（每类一枚墨色），主题化随 ADR-0023 M3。
- 12 段圆近似（≤14px 半径下不可见）。

## 待裁

- 符号颜色 / 形状随 ThemePack 演绎规则（`FeatureOverlaySet` 的地形版）——README §12-30 推进时合并。
- 沙漠（新月沙丘）、戈壁（砾点）装饰——当前不演绎，群系扩充后补。
