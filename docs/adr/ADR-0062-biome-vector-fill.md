# ADR-0062: 群系矢量面——把绿地从格子块换成平滑多边形

- 状态：**已接受**（2026-10-25，随 `feat/professional-cartography` 落地）
- 关联：ADR-0061（专业制图范式）、ADR-0012（等值线矢量平涂）、ADR-0053（场管线 /
  Felzenszwalb EDT）、ADR-0051（CellMap 固定色）、ADR-0044（手绘边界画法，本 ADR 不改）
- 前置评审：ADR-0061 §4 风险 1、§5 备选 3（本文把它从「被否决」变成「实施」）

## 1. 处境（Context）

专业制图（`ViewMode::GoogleMap`）的绿地来自 `shade_google` **逐格平涂**：群系是
栅格，颜色边界就是格子边界。放大后是台阶；而百度 / Google 的公园是**矢量多边形**
（边平滑、可加描边）。

既有两条边界管线都不给面：

| 管线 | 产出 | 为什么不够 |
|---|---|---|
| `isoline::kind_segments` | 格缘阶梯折线 | 只有线；Chaikin 磨角后仍带梯田感，无法三角化 |
| `isoline_overlay` | 海岸线 / 类型边界**描边** | 只画线，不填充 |

ADR-0061 §5 曾把「多边形平涂的 mesh 化填充」估成「工作量数天」并推迟。本次实测
**算法不是瓶颈**——两块硬骨头（精确 EDT、通用 marching squares）都已存在，缺的
只是「把距离场喂给等值线」这一层胶水与三角化。

## 2. 决策（Decision）

**D1 · 输入场 = 掩码的符号距离场（不新写等值线算法）**

`wv_world_cell_map::terrain_view::field::mask_sdf::signed_mask_distance`：

- 复用 [`coast_sdf::distance_field`] 的 Felzenszwalb 精确欧氏距离（O(W·H)，双通道）；
- 掩码内取 `+(d − 0.5)`、外取 `−(d − 0.5)`。

**为什么减半格**：`distance_field` 的种子是格心。直接按 `±d` 取号时，内侧深处
（d=5）与相邻外侧（d=1）的零交点会滑向格心一侧，边界整体偏移；减半格后浅格是
`+0.5 / −0.5`，零交点**恒在格边界**。这是与 `coast_sdf` 的「海岸 = 距离 0 等值」
不同的编码，勿混用。

**D2 · 提取与平滑：全部复用现成部件**

`height_segments(w, h, value_at, level = 0)`（该函数对**任意标量场**通用，此前只
喂过高度场）→ `assemble_chains` → `simplify_dp(0.30)` 去共线 → `chaikin(2)`。

**D3 · 成面：环嵌套奇偶深度 + earcut**

- 深度 = 该环被多少环包含（射线法 + 包围盒粗筛）；
- 偶数深度成面，奇数深度作为父环的**洞**；深度 2 是「洞中岛」，再次成面；
- 三角化复用 `faction_overlays::earcut_with_holes`（区域 / 势力多边形已在用）。

**D4 · 只做两个视觉组**

`FILL_KINDS = [4, 8]`（森林 / 公园绿、沼泽 / 湿地）——与 `shade_google` 实际
上色的四个槽（水 0/1、森林 4、沼泽 8）同源。其余 biome 在专业制图里折叠为
近白陆地，没有可见面；为它们造多边形是纯浪费。

**D5 · 只在 `ViewMode::GoogleMap` 生效**

艺术主题（水彩 / 水墨）的边界是**手绘语汇**（晕染 / 颗粒 / 纸张，ADR-0044）。
叠一层硬边多边形会与那套画法打架，且既有无回归要求是「其余模式逐位不变」。
故本模块在非 GoogleMap 下直接退场。

**D6 · 层级：归底图，不新增 PassId**

Z = `0.028`——压在地形纹理的格子块之上、海岸线（`0.04`）之下。顺序有语义：
海岸线不能被公园色盖住；公园色必须盖掉纹理里的格子边界。

门用 `PassId::Terrain`（底图通道）+ `layers.terrain.visible`。不新增 pass 的
理由：`PassId::COUNT` 是编译期常量，加一条要动全部模式行与测试；语义上群系面
就是底图的一部分。

**D7 · 两级缓存**

| 层 | 键 | 何时重算 |
|---|---|---|
| 提取（EDT + marching squares + Chaikin） | `(图, 地形指纹)` | 内容变化 / 换图 / 首次进入 |
| 成面（DP + 嵌套 + earcut） | `(图, 指纹, DP 容差档)` | 缩放跨档也重建（只重跑 DP） |

**D8 · 颜色与烘焙纹理同源**

填充色 = `CellPalette.core[kind]`，且当 `view.terrain_soften` 为真时再过一遍
`CellPalette::soften_color`（`out = base·k + toward·(1−k)`，与烘焙同一公式）。
否则填充会比周边更饱和，边界处出现一圈色差。

## 3. 理由（Why This）

- **复用而非新写**：EDT / marching squares / Chaikin / DP / earcut 全部已有测试
  锚点；新代码只是「接线 + 洞 + 缓存」，风险面小。
- **只做可见组**：两个组覆盖了专业制图里**全部**有色面要素，且不需要为不可见
  颜色付 EDT 成本。
- **与既有分层一致**：距离场是数据层（零 Bevy），提取是纯函数，成面在渲染层——
  与 ADR-0054 / ADR-0053 的分工同构。

## 4. 代价与风险（Cost）

- **重建预算**：1024² 图每组两趟 EDT（O(N)）+ marching squares，内容变化时在
  几十毫秒量级；成面再走 DP + 嵌套。缓解：编辑主要发生在 CellMap（`Topographic`），
  本模块在该模式退场，不参与笔刷热路径。
- **开链丢弃**：延伸到图幅外的群系（森林压到图边）是开口链，本版按「不填」处理
  （面填充需要完整边界）。观感上表现为幅面边缘的绿地缺一块，属已知降级。
- **Chaikin 削角**：凸角收缩约 0.1–0.2 格；纹理里的绿边可能在多边形外露出
  不到一个格子宽的一线。
- **远观无降采样**：提取仍按全分辨率做，只有成面按 DP 档抽稀。极大图（2048²+）
  首次进入可能有一次可感知的停顿，后续走缓存。

## 5. 被否决的备选（Alternatives）

- **只开 `kind_segments` 的线**：阶梯感 + 没有面，等于没解决风险 1。
- **提高纹理超采样倍率**：格子边界仍在（只是更细），且填充边与矢量描边不吻合。
- **新增 `PassId::BiomeFill`**：`PassId::COUNT` 是编译期常量，8 行模式表 + 多条
  测试要同步；群系面在语义上就是底图，用 Terrain 门已足够。
- **为全部 16 个 biome 各做一组**：其中 12 个在专业制图里折叠为近白，没有可见面。
- **把 EDT 挪进 `wv-terrain`**：`coast_sdf` 已在 `wv-world-cell-map` 且有 GPU 场
  管线的既有消费者；迁移是独立重构，不在本 ADR 范围内。

## 6. 验收（Acceptance）

1. `mask_sdf` 5 条单测：单格菱形、2×2 倒角方（钉「不整体偏移半格」）、同质无等值、
   符号方向、直边。
2. `biome_fill` 6 条单测：凸环 n−2 三角形、洞被扣、洞中岛再填、世界化换算、
   空输入不出 mesh、4×4 森林块端到端（边界贴格线 + Chaikin 加密）。
3. 色板真相源归一：`shade_google` 读 `CellPalette.core`（哨兵色测试）；专业模式
   海配方中性化 + 分层设色归零（`conv_pack_with` 测试）。
4. 门禁：`wv-render` 372 测、`wv-world-cell-map` 299 测、workspace（除 wv-io 的
   临时目录环境约束）、`app-test` 311 测、`smoke-gui.sh` PASS。

## 7. 遗留

- **国境线 / 行政边界线**：已由 **ADR-0063** 落地（borders-only 展示态 +
  `GOOGLE_BORDER` 灰虚线 + Z 0.086）。
- **POI 分类与密度稀释**：`Place` 无分类字段；`select_pois` 是全局上限 400，
  没有屏幕空间配额 → 另立 ADR-0064。
- **图幅边缘开链补线**：让压到图边的群系也能成面。
