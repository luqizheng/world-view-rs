# ADR-0058：CellMap 面板统一属性表单——作用域驱动的单份属性控件

**状态**：已接受（Accepted）
**日期**：2026-10-25
**决策者**：用户（对话裁定「按照你推荐跑」= A 方案按 C→A 两步走；单格海拔**绝对** / 批量海拔**相对**各自保留；派生运算并入属性段尾）
**关联**：[ADR-0052](ADR-0052-cellmap-terrain-workbench.md)（**修正其 D4**——「落笔值区」不再独立成段，成为作用域 = 落笔的表单形态；正文不改）、[ADR-0057](ADR-0057-cellmap-unified-selection.md)（D6 分派的**呈现层细化**；D4 蒙版裁剪、D9 半径沿用）、[ADR-0040](ADR-0040-cell-inspector-tool.md)（决策 8「每格 1 command」沿用；提交时机 = 手势完成帧已在 `wip/brush-panel-p0-i18n` 落地）、[ADR-0018](ADR-0018-i18n.md)（本 ADR 附带清零面板硬编码中文）
**原则**：P5（图层化编辑不受影响）、P6 / P7（写路径不变，仍全部经 `EditCommand → History`）

> **配套说明**：本 ADR 只锁「地形设计器浮窗的**呈现层信息架构**」。
> **不**触碰选区模型（ADR-0057 D1–D9 全部沿用）、**不**触碰命令 / 撤销语义、
> **不**触碰数据形态与渲染。

---

## 1. 处境（Context）

统一 Inspector 迁入 + 落笔值区合并后（2026-10-24/25），「地形设计器」浮窗
**同屏堆叠五段**：重置到底图、读数条、落笔值区、派生运算、单格/批量表单。
实机截图（2026-10-25 用户）暴露两个结构性问题：

1. **同一组属性控件出现两遍**——地表、群系、海拔在「落笔值」区各一份
   （地表 segmented / 群系 swatch / 海拔相对增减），在单格表单里又各一份
   （地表 segmented / 群系 7 组 radio / 海拔绝对 stepper）。三种控件形态
   堆在一屏，面板长度接近两屏。
2. **段落可见性与工具 / 选区脱钩**——选中 1 格做精确编辑时，落笔值区
   （拖绘颜料盒）与派生运算照常全量展示，全是噪音。

根源不是内容多，而是**缺一个「作用域」概念**：三个区编辑的其实是同样的
三个字段（地表 / 群系 / 海拔），区别只是**写到哪**。

## 2. 决策（Decision）

### D1 面板骨架：四段，属性段唯一

```
读数条                 （常驻；D8 双段「光标 | 选中」不变）
泛洪判据               （仅 FloodSelect 工具激活——工具参数，维持现状）
属性段                 （全浮窗唯一一份地表 / 群系 / 海拔控件）
派生运算               （仅选区非空时显示；作用范围 = 当前选区）
```

「重置到底图」维持面板顶部（2026-10-25 用户裁定暂不挪）。

### D2 作用域规则：工具驱动，无模式控件

属性段头部显示当前作用域，**由激活工具决定**（ADR-0057 D3 的职责分野
直接给出判据），不做任何切换控件：

| 激活工具 | 作用域 | 表单形态 |
|---|---|---|
| `Brush(PaintKind)` 或 `EditCell`（**只画不选**的落笔工具） | **落笔 · 下一笔** | 落笔值：地表绝对 / 群系绝对 / 海拔相对增减 / 笔刷半径 |
| 其余（PointSelect / 框选 / 套索 / 泛洪 / 橡皮 / 未激活） | **选区** | 按选区格数分派：0 = 空态；1 = 单格绝对表单；N = 批量表单 |

选区跨工具保留（ADR-0057 D5），故「选区内拖绘」（D4 蒙版）时切回落笔
工具即见落笔表单；要改选区属性则切回选择工具——两态互斥但切换零成本，
选区不会丢。

### D3 属性段唯一化

地表（segmented）、群系（swatch）、海拔（数值框）控件**各只出现一次**，
随作用域切语义；作用域头一行标明当前写入目标（「落笔 · 下一笔」/
「Cell · x, y」/「选中 N 格」）。

### D4 海拔语义保留分档（用户裁定）

- 落笔 / 批量 = **相对增减**（绝对设值会抹平「这一片本来多高」，2026-10-20 裁定）；
- 单格 = **绝对设值**（最 detail 的精修，键入 / scrub 皆可）；
- 提交时机三档自洽，**本 ADR 不改**：落笔 = 不产生命令；单格 = 手势完成帧
  （1 手势 = 1 command）；批量 = 显式「应用」按钮。

### D5 群系控件统一（P0-2 一并收口）

radio（7 组文字版）退役，swatch 色块网格成为**唯一**群系选择控件：
单格 / 批量 / 落笔三处共用一个组件。数据源收敛——名称取
`BIOME_NAMES_ZH`、色取 `BIOME_RAW_COLORS`、排列取 7 组序（常量引用
`wv_terrain` 冻结编号）；`cell.rs::biome_groups()` 的内联中文名随之退役。

### D6 单格「位置」区退役

坐标只读框（X / Y value_box + 🔒 徽标）删除——作用域头已含
「Cell · x, y」，读数条双段亦常显坐标。`section_heading`（只读徽标行）
随之失去唯一调用方，一并退役。

### D7 派生运算并入属性段尾

平滑 / 量化维持独立小节（标题 + 参数行），但**移到属性段尾部**且仅选区
非空时显示；作用范围 = 统一选区（ADR-0052 D6 语义不变）。

## 3. 理由（Rationale）

- **控件重复是乱的直接成因**：作用域显式化后属性控件三变一，面板高度
  约减半，且「我在编辑谁的属性」任何时候都有明确答案（作用域头）。
- **工具驱动 = 零模式控件**：ADR-0057 D3 已把「画 / 选」职责劈开
  （EditCell / Brush 只画不选，S / R / V / 泛洪只选不画），工具激活态天然
  就是作用域判据，不需要发明新的切换状态。
- **提交语义三档本已自洽**（落笔不落盘 / 单格手势帧 / 批量显式应用），
  本 ADR 纯呈现层重构，写路径零改动——回归风险集中在 UI。

## 4. 代价（Consequences）

- **选区内拖绘时看不到选区表单**（D2 两态互斥的直接后果）：蒙版拖绘中要
  查 / 改选区属性须切回选择工具。缓解：选区跨工具保留 + Esc / 切图才清，
  切换零成本；实测若频繁往返再议「作用域头加临时预览」。
- **swatch 替代 radio**：单格表单失去群系文字常显（色块 3 字截断 +
  hover 全名兜底）；对高频「按名找群系」的用户有回退空间（保留 ADR-0057
  D7 的「按属性选择」为未来入口）。
- `biome_groups()` / `section_heading` / 位置区等既有代码退役，涉及
  `cell.rs` 重排 + `cell_paint_panel.rs` 组件化，改动面约 400 行（含测试）。

## 5. 被否决的备选

| 备选 | 否决理由 |
|---|---|
| **B · 页签制**（笔刷页 / 选区页自动切换） | 两页仍是两份字段定义（复用组件只能减半重复），多一层 tab 状态与切换成本；作用域头已提供等价的「当前在编辑谁」信息 |
| **C · 仅收紧可见性**（不动结构） | 治标——笔刷工具 + 非空选区同用时两份控件仍同屏；**采纳为 A 的先行里程碑**（先落可见性，再落结构），不作为终态 |
| **强统一海拔语义**（单格也改相对，或批量加绝对） | 单格绝对 = 最 detail 精修诉求；批量绝对已被 2026-10-20 裁定否决（抹平信息）。两档各有职责，不强行合并 |
| **作用域头加切换控件**（手动选落笔 / 选区） | 违背 ADR-0057 D6「无模式切换控件」；工具驱动已无歧义 |

## 6. 验收标准（Acceptance）

- **A1** 任意时刻属性段至多一份；地表 / 群系 / 海拔控件全浮窗各至多出现一次。
- **A2** 激活 `Brush(PaintKind)` 或 `EditCell` → 显示落笔表单（含半径）；
  切走 → 按选区分派（空态 / 单格 / 批量）。
- **A3** 派生运算仅选区非空时可见；播放中禁用语义不变（Gate-1）。
- **A4** 单格海拔拖拽仍 1 手势 = 1 command（沿用 `height_commit_decision`）。
- **A5** 群系名称全面板单一来源（`BIOME_NAMES_ZH`）；排列 7 组序且覆盖
  全部冻结编号（测试锚定）。
- **A6** EN 语言下面板无硬编码中文（i18n Key 全覆盖）。
- **A7** `cargo test --workspace` / 双 clippy / fmt / smoke-gui 全绿。
