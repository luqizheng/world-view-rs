# ADR-0072: biome 界距离场——色块边界的亚格连续平滑

- **状态**：提议态（2026-10-26 起草，待主理人确认后转「已接受」）
- **关联**：ADR-0053（GPU 场管线）/ ADR-0051（biome 固定色块）/ `TERRAIN_FIELD_P0_SPEC_LOCK_v1.0.md`
  §追记十三（海岸屏幕封顶 + Signed 编码默认）/ Q3 裁定 A（本 ADR 推翻之）/ T24、T27（biome 墨线）

## 处境

1. 场管线（`terrain_field.wgsl`）的 biome 填色按最近采样 ID 逐格硬切：绿地等
   色块边界在放大后是**一格宽的正交台阶**（2026-10-26 用户实机截图确认，
   与海岸线粗带同批反馈）。
2. T27 的 4 邻检测墨线只能给出**整格**带宽，近观自动淡出（追记一 §5.1
   「T24 做不到 0.8 屏幕像素」）；Q3 当时裁定「不做 biome SDF，P4 复评」。
3. 对标 Google/百度（2026-10-26 用户给出南加州截图）：地块边界是矢量多边形
   的 AA 边，任何缩放都平滑；地块之间靠颜色区分、无描边或极细描边。
4. 海岸已经落地同构解：Signed 距离场 + Linear 采样 + 屏幕封顶过渡
   （追记十三）。「格网数据的矢量边 = 距离场等值线」这条语法在岸线上已被验证。

## 决策

给 biome 界烘一张**到最近异类格的距离场**，shader 侧消费等值线，替换逐格硬切：

1. **烘焙（CPU，一次性 + 脏区增量）**：新增 biome 距离场生成器，复用
   `coast_sdf.rs` 的 Felzenszwalb EDT 模板（O(W·H)，1024² 毫秒级），
   两个输出：
   - `d`：每格到最近**异类** biome 格的欧氏距离（格）；
   - `nb_id`：该最近异类格的 biome ID（EDT 下包络时顺带传播 argmin）。
   打包进 pack（候选形态：单张 `R16RG` 或 `RGBA8`，与 coast 同行主序、
   同补丁框架），`pack_content_hash` 与 `patch_region` 一致性测试照
   海岸模板 parameterized 扩展。
2. **运行时消费（纯 GPU）**：填色改为
   `t = smoothstep(0.5, 0.5 + half, d)`、`rgb = mix(nb_color, own_color, t)`，
   其中 `half = min(0.5, BIOME_EDGE_HALF_PX / px_per_cell)`——与海岸
   `COAST_EDGE_HALF_PX` 同款屏幕封顶：远观一格宽 AA，近观 ~2 px 锐利边。
   过渡带语义：每格向**自己的**最近异类过渡，两侧对称拼成连续边界；
   采样仍走 Linear。
3. **墨线（可选增强，计划阶段定去留）**：岸线语法推广到 `d = 0.5` 等值线
   （fwidth 定位），可真正达成 T24 的 0.8 px 目标；现状 4 邻淡出墨线
   （T27）在连续边界落地后失去存在意义，退役或保留由实现计划评估。
4. **不引入 compute 管线**：烘焙仍是 CPU EDT（毫秒级 + 脏区半径 ≥2 格增量，
   海岸同款 `update_dirty_region` 一致性模板）。JFA GPU 烘焙留待格网
   上了 4096² 再议（见被否决备选 B3）。

## 理由

- **对齐裁定**：2026-10-26 用户明确「平滑全部收进 GPU 管线做」——本方案
  每帧只多一次纹理采样，零 CPU 几何重建。
- **复用已验证语法**：EDT 生成器、Signed/Unsigned 打包、补丁一致性测试、
  屏幕封顶常量全部有海岸先例（追记十三当日落地），增量实现风险低。
- **观感目标可达**：亚格连续等值线 + fwidth AA = 矢量级平滑边界，
  即「格网世界的矢量边」。

## 代价

- **显存**：+1 张 ~2–3 MB/1024² 纹理（与 coast_tex 同量级）。
- **烘焙成本**：全量 +1 遍 EDT（毫秒级）；编辑增量补丁半径 ≥2 格。
- **三界角点近似**：角点处每格只向自己的最近异类过渡，三色交汇的过渡
  优先级取 argmin 结果，可能有一格级的细微不对称——登记为已知边界，
  视觉可忽略（海岸在角点同款近似）。
- **同源耦合点 +1**：pack 编码 ↔ shader 解码 ↔ 补丁编码三处必须同源，
  沿用「唯一耦合点」注释纪律。

## 被否决的备选

- **B1 · 矢量填色**（marching squares 提取 + Chaikin + mesh 平涂，即
  VectorFlat M2 后半路线）：CPU 几何随编辑重提取，违背「GPU 加速」裁定；
  且与场管线并行第二套填色路径，双轨维护。保留为未来「真矢量模式」选项，
  不在本 ADR 范围。
- **B2 · 片元内 4-tap 超采样**：仍是格子对齐，台阶只是变矮不变平滑，
  不解决问题。
- **B3 · JFA compute shader 烘焙**：1024² 下 CPU EDT 已是毫秒级，
  为此引入 compute 栈属过度工程（AGENTS §9 默认拒绝）；4096²+ 触发时另开 ADR。
- **B4 · 不做**（延续 Q3 裁定 A）：2026-10-26 用户实机确认台阶不可接受，
  维持现状与「协助创作者整理世界设定」的呈现定位冲突。
