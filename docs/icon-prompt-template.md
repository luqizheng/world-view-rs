# 世界地图 POI 图钉含义图标 · AI 生成提示词模板 v1.0

> 用途：为 world-view 项目的「世界地图 POI 图钉」家族持续产出钉身中央的白色含义图形。
> 本模板为可复用、可批量、防风格漂移的提示词骨架；新增家族成员一律按本模板填充槽位后投递 AI。
> 维护规则：改风格 = 升版本号；旧族图标按版本归档，不混用。

---

## 一、主提示词模板（可直接喂给 AI）

```text
你是一位资深图标设计师，专精 Lucide / Feather 风格的 24×24 线条图标系统。
当前任务是为「世界地图 POI 图钉」家族持续产出钉身中央的白色含义图形。
所有输出必须与同家族其他成员共用同一套视觉锚点，不允许单枚漂移。

【风格锚点 · Lucide 视觉特征】
- 几何中正、曲线圆润、端点圆头；优先用流畅贝塞尔，避免硬角与抖动锚点
- 视觉重量均衡：图形占画面 60%–75%，四周留白对称
- 概念极简：一个图标只表达一个语义，剥离场景性装饰

【硬性规格 · 不可变】
- 网格：viewBox="0 0 24 24"，图形居中、画满可用空间
- 描边：stroke="#ffffff" fill="none" stroke-width="2"
        stroke-linecap="round" stroke-linejoin="round"
- 配色：扁平单色白；禁止渐变 / 阴影 / 滤镜 / 内嵌位图 / 半透明
- 密度：视觉层次 ≤ 3 层；缩到 14px 仍可辨认核心语义
- 留白：图形四周安全边距 ≥ 2px（有效绘制区 2–22）
- 路径：闭合处显式 Z；剔除冗余锚点；不写 metadata / 不嵌 base64

【输出契约】
- 仅输出完整 <svg>…</svg> 代码，不附解释、不附位图、不附文字说明
- 只画含义图形本身：不画图钉外形（钉身由程序合成）、不画背景、不画边框、不画文字

【本次内容】
- 语义：{semantic}
- 要画：{draw}
- 不要画：{avoid}

【产出前自检 · 必过】
1. stroke-width / linecap / viewBox 是否与同家族其他图标完全一致？
2. 视觉重量是否落在 60%–75% 区间，与同族图标（地标/据点/资源）平衡？
3. 14px 缩放后，核心识别特征是否仍清晰可辨？
4. 是否剥离了场景性装饰（火焰光环、骑士、山洞、交叉骨等）？
5. 路径是否全部闭合或自然收尾，无悬挂线段？
```

## 二、风格参数表（用于规范沉淀 / 交接前端）

| 参数 | 值 | 说明 |
|---|---|---|
| 网格基准 | 24×24 | Lucide 标准 |
| 描边宽度 | 2px | 1px 在 14px 缩放下会失真 |
| 端点 / 转角 | round / round | 与 Lucide 一致 |
| 填充 | none | 纯线条图风格 |
| 主色 | `#ffffff` | 钉身中央反白 |
| 安全边距 | ≥ 2px | 避免贴边裁切 |
| 视觉层次上限 | ≤ 3 层 | 保证小尺寸可辨 |
| 最小可用尺寸 | 14px | POI 图钉最小渲染尺寸 |
| 视觉重量区间 | 60%–75% | 跨图标平衡锚点 |

## 三、内容槽位填充示例

### 填充 A · 龙巢 / 险地
```
- 语义：龙巢 / 险地（danger）
- 要画：蜷卧的龙侧面剪影，收翼，头抬起
- 不要画：火焰喷吐、骑士、山洞
```

### 填充 B · 骷髅头变体（同义 danger）
```
- 语义：险地 / 死亡陷阱（danger）
- 要画：正面骷髅头，含头骨上半圆、两个圆形眼窝、倒三角鼻孔、下方颌部牙齿
- 不要画：交叉骨、火焰、阴影、场景元素
```

### 填充 C · 同族「据点」图标（验证家族一致性）
```
- 语义：据点（stronghold）
- 要画：城墙塔楼正面剪影，中央拱门，两侧齿垛
- 不要画：旗帜飘带、守卫、火把
```

## 四、批量产出防漂移要点

1. **单次会话只产一枚**：避免 AI 在一轮里给多枚不同 stroke-width 的图标；家族成员逐枚生成、共用同一提示词骨架。
2. **新增成员先比对**：每产一枚，与已落库的家族代表图标做 14px 并排缩略比对，视觉重量明显偏轻或偏重则回炉。
3. **改风格 = 改模板版本号**：若日后描边宽度从 2 改 1.75、或主色由白改黑，必须同步更新模板版本（v1.0 → v1.1），并标记切换日，旧族图标按版本归档，不混用。
4. **语义槽位收敛**：同一语义（如 danger）允许多个候选画法（龙 / 骷髅 / 警示三角），但**同族内只能选一种**落地，避免用户在地图上看到「龙」与「骷髅」混标。
