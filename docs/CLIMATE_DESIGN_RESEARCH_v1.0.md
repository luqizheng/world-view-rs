## 0. 结论

**civ-atlas 是「模拟派」的完整形态**：气候不是贴在地图上的标签，而是一组物理量（年均温 °C、年降水 mm、风向），从纬度、海拔、风带、洋流一路算出，再经「生物群落 → 宜居度 → 民族/国家扩张」三层投影，最终决定地图的颜色、河流走向、文明分布。**其他游戏几乎都是「查表派」**：气候预定义成几类，各自挂一组数值修正（补给、产量、疾病、发展度）——正因如此，它们在「气候如何变成玩法优势」上的设计模式更可直接借鉴。

总纲：成熟做法从不把气候写成直接数值加减，而是让它充当**中间层**（habitability / 生长季 / 补给系数 / 商品权重），向上投影为人口、军事、经济、文明分布四条链。

## 1. civ-atlas 的做法（源码：`src/gen/`）

### 1.1 生成管线（world.ts 实际顺序）

板块构造 → **粗气候**（不算洋流的简化版）→ 河流侵蚀 → 洋流 → **终气候** → 海冰 → 生物群落 → 河流 → 宜居度 → 文明推演。

最特别的一点：**气候被算两次以上，且先于侵蚀**。侵蚀模型为流水功率侵蚀定律（dh/dt = U − K·A^m·S，Braun & Willett 2013 隐式格式；排水路径 Priority-Flood，Barnes 2014），其中上游汇水量 A 按**降雨加权**——山谷、山脊、水系是被雨水「冲」出来的，气候反过来雕刻地形。绝大多数游戏不做这件事（地形定死、气候往上涂色）。

### 1.2 气候本体（climate.ts，349 行）

| 环节 | 做法 |
|---|---|
| 温度 | 纬度查表（赤道 27°C → 极地 −24°C）+ 海拔递减 6.5°C/km + 噪声 ±1.5°C + 洋流海温偏差 |
| 风带 | 信风（0–30°，向西）、西风带（30–60°，向东）、极地东风；交界 ±5° 内风向按 smoothstep 平滑转向、交界线上风弱（副热带无风带 / 副极地低压带）——过渡带中间的风偏向赤道吹，不会抵消成零 |
| 降水 | 水汽**顺风拓扑排序搬运**：海面蒸发补水、上陆逐步下雨、遇山猛下（迎风坡湿，0.00018/m 抬升系数）、翻山后所剩无几（背风坡干 = 雨影）；陆地降水 70% 再蒸发回空气（水汽再循环） |
| 洋流 | 暖流/寒流改海面温度，海风把冷暖带上岸（每 1500km 淡到三分之一、翻山再减）；寒流岸边空气稳定不爱下雨（海边的沙漠），贴岸处不管风向都沾一点（COAST_PULL 0.85） |
| 纬度带 | 赤道辐合带多雨、副热带高压（~25°）干、中纬锋面多雨、极地干——纬向降水系数查表 |
| 终值 | 年降水 = 相对湿度 × 纬向系数 × 1500mm × 全局降水倍率；用户可调旋钮仅两个：**全局温度偏移 °C、降水倍率** |

工程细节：风向在风带交界随纬度转弯后，「位置在风向上的投影」不再处处一致，所以拓扑排序遇到环路时用投影挑先算的，再补扫第二遍；与网格（纬度）相关而与种子无关的部分按网格缓存（WeakMap）。

### 1.3 海冰（seaice.ts）

冰缘不是笔直的纬度线：冬季大陆冷空气顺盛行风推到下风向海面（鄂霍次克海型）、三面环陆的浅湾先冻（哈德逊湾型）、开阔大洋环流带来热量冰缘缩回、洋流冷暖再叠低频噪声。冻海（海冰过半，或年均温 < −8°C）不能航行、不能靠港。

### 1.4 气候 → 地图的三层投影

**① 生物群落（biomes.ts）**：16 类，按「年均温 × 年降水」阈值查表（Whittaker 图逻辑）。例：t<−9 冰原；温带 5–18°C 内按降水 250/600/1700mm 分温带荒漠/草原/温带森林/温带雨林；热带按 320/950/1800mm 分热漠/稀树草原/季雨林/雨林。每类群落带**两套配色**——写实风与手绘水彩风，是「气候影响地图外观」的直接落点。

**② 宜居度（civ/habitat.ts，注释明说量级沿用 Azgaar）**：

```
s = 群落底分（温带森林 100 最高，季雨林 75，温带雨林 60，草原 35，雨林仅 35
     ——土薄多病难开垦，苔原/热漠 4，冰原 0 = 直接不可居）
  + 淡水 min(40, 12·log2(1+径流/河流阈值)) × 灌溉系数
      （降水 ≤600mm 为 1：干旱处全靠河 = 荒漠绿洲；≥2000mm 降到 0.35：
       雨水本来就足，河多也不多养人）
  + 冲积平原 18（大河 + 海拔<250m + 坡度<3m/km）
  + 湖岸 30（冻湖 1）· 海岸 5 · 河口 15 · 天然良港 20（冻住的海不算）
  − 海拔/150 − 坡度罚（1.6/m/km，封顶 30）
宜居分 = max(0, s)/5；人口上限 = 宜居分 × 格面积
```

**③ 文明推演（cultures.ts / polities.ts）**：七类民族（游牧/高地/湖/海/河/森林/默认）各有群落通行代价表（草原 50 最低 → 冰原/海冰 5000）；**游牧在草原荒漠不算贫瘠（habF=1、mod 0.7–0.8）、进森林 ×4**；国家吞一州的年数 = 距离 × 群落系数 × √贫瘠 × 种类偏好（海权国只要沿海 ×0.7、高地国偏爱高原、河国沿河 ×0.7）；本土群落再 ×0.6（民族在家乡跑得快）。

**分层上最值得学的一点**：气候本身只在三处被直接消费——侵蚀的雨量加权、群落分类、文明里的冻海判断与灌溉系数——其余一切都经 biome / habitat 间接消费。物理量归物理量，玩法语义全部收在中间层。

## 2. 其他游戏的做法与优势

| 游戏 | 气候的定位 | 代表性数值 |
|---|---|---|
| EU4 | 军事后勤与殖民惩罚器 | 四类气候：temperate 零修正最优；tropical 补给约 −25% + 殖民减速；冬季 severe −50% 补给 +5% 敌军损耗。**不直接**修正发展度/人力 |
| 文明6（Gathering Storm） | 产量梯度 + 动态灾害系统 | 草地 2 食 / 苔原 1 食 / 沙漠 0；泛洪平原 +3 食但洪水毁田（水坝免灾、沃土沉积 −50%）；**7 相位全球变暖**：排放 → 升温 → 融冰 → 海平面上升永久淹没沿海低地 |
| Old World | 效率修正层 | Lush 农场 +40% / Arid −40% 但采石 +20%（干旱区=石料奇观经济区）/ 苔原不支持任何改良；城市只能建在预设 City Site |
| CK3 | 没有气候，只有 14 种地形 | 农田发展度 +20%/月全游戏最高、山地战场宽度 50% 补给 −25%；发展度从富邻扩散——地理梯度自我强化 |
| RimWorld | biome = 一整套生存参数 | 生长季 = ≥10°C 天数（冰原 0 天）；疟疾/昏睡病只在热带，雨林疾病频率是沙漠 3 倍；沼泽移动难度 4~6 |
| 矮人要塞 | 文明存在性的硬约束 | 温度 6 档 + 阵营×残酷度矩阵；矮人必须山地、精灵森林、哥布林邪恶区——删掉某类 biome，对应文明**整个不存在** |
| Azgaar | civ-atlas 宜居度公式出处 | habitability 表（温带落叶林 100 基准、冰川 0）；人口 = (habitability + 河流 250×归一 − 海拔/5 + 海岸修正)/5 × 面积；温度 6.5°C/km 递减；降水纬向系数（赤道 ×4、副热带 ×1、极地 ×0.5） |
| Kenshi | 区域环境统计驱动经济与危险 | 地下水 % / 肥力 / 酸雨 % / 矿石倍率逐区可查；作物按 Arid/Green/Swamp 硬分组，水培绕过一切限制 |
| Songs of Syx | 土壤 × 湿度 | 农场需全格约 90% 平均湿度满产，河流/湖泊向周边渗透湿度，旱地靠灌溉渠 |

三个特别值得注意的「优势」设计：

- **EU4「Used to Tropical」适应修正**：殖民者「学会」热带后惩罚整个清零——气候劣势是**可征服的叙事**，不是永久税。
- **文明6 把气候劣势做成文明差异化卖点**：俄罗斯冻土扩领土、加拿大苔原建农场、沙漠民歌万神殿——同一套气候表，有人受罚有人靠它吃饭。
- **CK3 的反例价值**：没做气候，靠地形 + 发展度扩散就够用——气候系统的投入要和它承担的玩法深度匹配。

### 六种可复用的设计模式

1. **军事损耗惩罚器**——恶劣气候削补给、加损耗（EU4、CK3、Kenshi 酸雨区）
2. **人口承载力天花板**——气候给系数，人口间接求出（Azgaar、RimWorld、Old World）
3. **开局/扩张位置筛选器**——气候决定哪里能立国（矮人要塞、Old World）
4. **风险-回报对赌**——高产挂灾害，收益前置风险后置（文明6 泛洪平原、RimWorld 雨林疾病）
5. **资源/产业类型决定因素**——气候决定「长什么」而非「长多少」（EU4 棉花、Old World 采石、Kenshi 作物分组）
6. **文化/文明差异与叙事来源**——气候标记成为种族归属与适应叙事的锚点（矮人要塞、EU4）

### 与本项目的接口（观察，非决议）

- 已有基础：`BiomeFamily`（wv-terrain）、群系驱动的森林密度场（864436c）、ADR-0036 沙漠类；2026-10-17 曾裁定「气候带忽略」（大陆生成工作流）。
- 文明6 GS 的**随时间演化的气候**与 P7 时间轴驱动的世界观天然契合——若未来做气候，区间化（P6）+ 时间求值（P7）的存储形态是现成的。
- 本项目是设定整理工具而非推演游戏：civ-atlas 的「玩法链」在这里的对应物更接近「作者视野下的合理性提示 / 生成建议」，与 §7.5 V1「校验只提示不阻止」同族。
