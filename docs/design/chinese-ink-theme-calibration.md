## 1. Tl;DR

水墨包的占位方向（civ-atlas 墨青海色 + 宣纸底 + 淡墨陆地 + 更疏更沉的装饰 + 无浅滩带）**基本正确，予以保留**；本方案做四类校准：

1. **TreatmentFlags 从 `EMPTY` 改为「水墨手绘」定制组**（§4）——这是当前最大的观感缺陷：`EMPTY` 关掉了 `water_gradient`，海的深浅墨阶整层失效（退回深/浅两档平涂），「墨分五色」无从谈起；同时关掉了纸纹、边界扰动、墨晕——宣纸感尽失。水墨是手绘的一种，不是干净矢量。
2. **补齐 26 个沿用日间值的槽位**（§3）——POI / 道路 / 标签 / 文字 / 建筑 / 网格等全部换入墨阶体系（焦浓重淡清），重点保证宣纸底 `#E8E0CE` 上的 WCAG 对比度。
3. **海配方强度校准**（§5）——皴线墨色从暖褐改青墨（与墨青海面同族），深度曲线定为 0.65 指数（近岸墨阶展开但远海安静），积墨环锁定在岸线（顿笔）。
4. **覆盖物裁定**（§7/§8）——森林族「苔点」演绎（文人画点皴），其余 7 族**留白不画**；区域四键微调。

所有定稿值可直接抄进 `lib.rs` 常量；`lib.rs` 现有 4 条测试的锚点值（`core[0]` / `core[1]` / `soften_toward` / 森林规则纯色路径）全部保留，**零测试破坏**。

## 2. 风格语言：宋元文人山水 → 地图语义

### 2.1 墨分五色 → 数据分层

「墨分五色」（焦、浓、重、淡、清）是本主题的**全局明度语法**。宣纸底 `#E8E0CE` 之上，五阶墨色各司其职：

| 墨阶 | 定稿色族 | 承载的地图要素 |
|---|---|---|
| **焦墨**（最干最重） | `#26241F` | 国名/大区标签、最深描线档 |
| **浓墨** | `#2E2B26` / `#322F29` | 地名/POI 标签、城市连线、中描线档 |
| **重墨** | `#3A3834` / `#3A3731` | 等值线、山符号、浅底描线档 |
| **淡墨** | `#6E685C` 族 + 地形 core 10 槽 | 陆地基色、装饰符号、网格 |
| **清墨**（最淡） | `#A89F8C` 族 + 雾霭 | 次级街巷、远景雾霭（veil 洗向纸色）、雪影 |

海是「墨阶的横向铺陈」：深度即墨色——`core[1]` 淡青灰（清）→ `core[0]` 墨青（淡）→ `deep_ocean_blue` 深墨青（重）。因此 `water_gradient` 必须开（§4）。

### 2.2 留白原则（哪些要素不画）

留白不是空，是**取舍**。水墨包明确不画的清单（每一项都对应一个已验证的数据开关）：

| 不画的要素 | 实现方式 | 依据 |
|---|---|---|
| 近岸浅滩色带 | `shore_band_cells: 0.0` + `shore_shallow: false` 双保险 | 留白为语法；色带是水彩的「发光」 |
| 近岸排线 | `shore_hatch: None` | 排线是钢笔/铜版画手法，不是毛笔 |
| 白色浪花 | `foam_break: 0.0`，泡沫色改青墨（淡墨皴痕而非白浪） | 水墨的岸线是连续皴笔 |
| 海岸双晕圈 | `coast_halo: false` | 岸线由单线等值线 + 顿笔积墨表达 |
| 草原/荒漠/寒带/高地/水域/道路 7 族的 Place 演绎符号 | `FeatureOverlaySet` 对应族 `None` | 平原与漠野在文人画中即留白；山由地形装饰皴法承担 |
| 雪的冷蓝阴影 | `snow_shadow` 改灰墨 `#A8A496` | 雪是留白（`core[7]`≈纸白），影是淡墨不是蓝 |

**事实不消失**：族无规则时渲染侧仍画「回退晕 + 地界 + 名字」（§7.4 评估其水墨兼容性）。

### 2.3 皴法 → 地貌符号

| 皴法 | 地貌 | 渲染词汇（ADR-0048） | 定稿参数落点 |
|---|---|---|---|
| **点皴（苔点/介字点）** | 森林 | 森林族覆盖符号（纯色 quad 墨点） | §7.1：7.5px 墨绿点、36wu 疏距 |
| **披麻皴**（长线披拂） | 丘陵 | 丘陵族装饰 + 等值线淡墨 | §6：`hills_ink #55503E`、步距放宽 |
| **斧劈皴**（方硬斫擦） | 山地 | 山符号重墨 + 山背光面 | §6：`mountain_ink #33322E`、`mountain_shade_ink` 压深 |
| **水纹皴**（平行波纹线） | 海面 | 离岸墨线波纹（RippleSpec） | §5.4：两圈青墨、近浓远清 |

## 4. TreatmentFlags 定稿（新增校准项，2 处翻转）

**当前 `TreatmentFlags::EMPTY` 是水墨包最大的观感缺陷。** 经渲染源码核实（`wv-world-cell-map/terrain_view/cells.rs`）：

- `water_gradient: false` → 海**不做深度渐变**，`water_shade_at` 整条不执行，SeaRecipe 的 `depth_scale_m` / `depth_exponent` 全部失效，海退回 core[0]/core[1] 两档平涂；
- `watercolor_bleed: false` → 群系边界硬切格边（无墨晕）；
- `boundary_wobble: false` → 格边笔直（无手绘线感）；
- `land_grain / paper_grain / paper_fog: false` → 无墨色颗粒、无纸纹、无远景雾霭。

「干净矢量」是未来 Skyline 类主题的基准，**不是**水墨——水墨是宣纸上的手绘，纸感与墨晕就是媒介本身。

### 定稿：`INK_TREATMENT`（包内 const，纯数据）

| 旗标 | 定稿 | 与 HAND_DRAWN 差异 | 理由 |
|---|---|---|---|
| coast_halo | **false** | ✂️ 关 | 水墨海岸不画双晕圈——岸线 = 等值线单墨 + 顿笔积墨（§5.6），再叠晕圈就「腻」 |
| water_gradient | **true** | ✂️ 开（vs EMPTY） | 墨分五色：海的深浅墨阶是本主题的水彩感来源（ADR-0048 评审结论的水墨版） |
| snow_shade | true | = | 雪影=灰墨淡施（§3.2 已把 snow_shadow 改灰墨），高海拔层次保留 |
| sea_ice | true | = | 渲染未接线，恒 true 无副作用；ice_* 槽位已按水墨校准，未来接线即正确 |
| paper_grain | true | = | 宣纸纤维是媒介 |
| river_centerline | true | = | 河中线=水纹一笔 |
| boundary_wobble | true | = | 墨线不规则=笔触 |
| ink_sublinear | true | = | 墨线随缩放亚线性=笔迹观感 |

## 7. 8 族 FeatureOverlay 裁定

机制前提：族规则是给 **feature 地点**（有地界的 Place）画的「远带晕 + 近带符号」；族无规则 → 渲染侧回退晕（固定色 `[0x6A,0x70,0x5A]` @ 0.12）+ 地界 + 名字，事实不消失。

| 族 | 裁定 | 定稿规则 | 理由 |
|---|---|---|---|
| **forest** | ✅ 有演绎（苔点） | 见 §7.1 | 森林是文人画点皴的主角 |
| grassland | ⬜ 留白 | `None` | 平原即留白（平淡天真） |
| desert | ⬜ 留白 | `None` | 大漠不点苔；地形色 + 装饰符号已足 |
| wetland | ⬜ 留白 | `None` | 沼泽由地形色 + marsh 装饰承担 |
| cold | ⬜ 留白 | `None` | 雪原即留白（§2.2） |
| highland | ⬜ 留白 | `None` | 山由 DecorRecipe 皴法 + 等值线承担，再画地界晕会双料 |
| water | ⬜ 留白 | `None` | 海由 SeaRecipe 演绎，水域地界走回退晕即可 |
| road | ⬜ 留白 | `None` | 道路由墨线色族（§3.2）演绎 |

> **2026-10-25 落地更新**：7 个留白族的实现从 `None` 升级为**显式零规则**（`INK_BLANK_RULE`：`halo_alpha = 0` + `symbol_spacing_wu = 0` + `symbol_size_px = 0`）——裁定不变（仍为「留白不画」），实现方式改为主题显式声明，渲染侧据此绕开 §7.2 评估的暖绿回退晕。裁定语义以本注为准。

### 7.1 森林族定稿（占位 6px 方点 → 苔点）

```rust
forest: Some(FeatureRule {
    halo_color: [0x3E, 0x4C, 0x3E],   // 淡墨绿晕（占位 0x445242 压沉一档）
    halo_alpha: 0.14,                  // 极淡（水彩日间 0.30 / 暮色 0.20；水墨最轻）
    symbol_color: [0x2A, 0x34, 0x2A],  // 墨绿点
    symbol_size_px: 7.5,               // 苔点尺寸（占位 6.0 偏小——远看融不成林影）
    symbol_spacing_wu: 36.0,           // 疏距（占位 32.0；近看是点、远看成影）
    symbol_texture: None,              // v1 纯色（测试锚定，§9）
    halo_texture: None,                // 同上
}),
```

设计意图：**近看是「点皴」苔点，远看融成淡墨林影**——这正是文人画树「个字点/介字点」的观感来源。晕浓度 0.14 是水墨对水彩的第三次让位（0.30→0.20→0.14）：地界晕只作「此处有林」的提示，不参与造型。

### 7.2 回退晕的水墨兼容性评估（6 族留白的代价）

`FALLBACK_HALO_COLOR [0x6A,0x70,0x5A] @ 0.12`（渲染层常量）叠在宣纸上读作**极淡的灰绿晕**——色相中性偏冷、浓度极低，在 `#E8E0CE` 上观感接近一层淡墨水渍，**可接受**。v1 不动它；若后续想彻底归墨，见待裁项 §12.1。

### 10.2 编辑态信息密度 ×「雅」的平衡

三条已内化进定稿的原则：
1. **要素分层让墨**：编辑辅助层（网格、回退晕）全部压到清墨档以下（CR 2.0~3.0），创作内容层（标签、道路、POI）全部焦浓档（CR ≥4.7）——「雅」来自辅助层的退让，不是内容层的削弱；
2. **密度让位**：装饰步距 40/64/96、森林增益 0.72、覆盖物间距 1.2×——留白是数据上的疏，不是视觉上的糊；
3. **色弱冗余**：地形 core 全系低饱和 + 明度差区分（森林 vs 草靠明度），语义色（派系/事件）保色相、压明度——四类圆点在灰阶打印下仍可辨（明度各异）。

## 14 校准修订 1（2026-10-25 · 截图评审后）

**性质**：追加式修订。结构、契约、红线全部不动（ADR-0043 零改渲染运行时保持），只重定色板两族的**明度归属**。本节只写差异，未提及的章节维持原定稿。

### 14.0 修订动因

截图实测暴露两条结构性缺陷，都不是「新诉求」，而是**占位色相没脱干净**：

1. **海是整套色板里唯一的「彩」。** 海色族 `core[0] 0x6F8F99` / `core[1] 0x8FABB0` / `deep_ocean_blue 0x4A6B78` / `water_shore 0xB4C7C0` 的 B−R 差为 **+25~+30**，是 36 槽中色相最饱和的一族。在宣纸 `#E8E0CE` 上它读作「淡彩水彩的蓝」，不是墨——「墨分五色」的语法恰好在画面面积最大的一块上失效。附带一处**实测可访问性缺陷**：海名 `label_water 0x35464A` 实际压在海面上，与旧墨青海底比对仅 **CR 2.85**（§10.1 的 7.5 是拿它跟宣纸底比出来的——测法错位），低于 AA 4.5。
2. **地形 8 槽各带色相，且明度阶梯非单调。** 旧值 L：**丘陵 0.397 > 草 0.368 > 沼泽 0.282 > 山地 0.236 > 森林 0.194**——丘陵比草和森林都浅，「越高越深」的空间直觉被打破；同时赭/墨绿/灰绿在连片区域上读作彩色地形图，与「雅致灰调」冲突。

**定稿方向一句话**：**海归纸（海＝纸之阳面）、陆入墨阶（陆＝墨之阴面）。** 色相不再承担语义，只保留 ≤6% 彩度的**温度差**（陆暖、海冷）作冗余线索。

> 术语口径：「去色相」＝去彩（chroma ≤6%，R−B ≤16），**不是**去温度。温度是 A/B 两族之间唯一残留的色相线索，也是灰阶退化前的第二道冗余，故意保留。

#### (3) 海陆二分的承重变化（**必须登记的风险**）

海归纸后，海与陆的**填色**差降到 CR 1.06–1.17（例：草 vs 浅水 1.14；沙 vs 深水 **1.00**——同亮度，仅靠温度差 R−B +16 vs −8 区分）。海陆边界从此**主要由 `isoline_ink` 海岸线承担**（在新的浅水面上 CR 7.61，够强）。

这不是缺陷，是水墨的正法（水不画，界线一笔），但它把海岸线从「装饰」升级为「承重构件」——见 D4。

#### (4) 灰阶 / 色盲退化

- 地形：8 槽明度单调，灰度化后阶梯完整保留 ✅（优于旧值）
- 海色：4 槽明度单调，灰度化后仍是一条 wash ✅
- 海陆：灰度化后**依赖海岸线**（与 (3) 同源）🟡
- 语义圆点（dot_faction 等）：本次未改，仍按 §10.2 的「保色相、压明度」策略
