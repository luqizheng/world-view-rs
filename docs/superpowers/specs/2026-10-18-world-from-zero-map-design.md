## 1. 意图与为什么

创作者打开新工程面对的是**一片大海洋**。本稿回答：从这张白纸到「一块有势力、有名字的大陆」，完整动线是什么。

三段式工作流：

> **大陆**（多边形画布局 → 生成 → 笔刷修）→ **势力**（多边形圈国 → 贴地/越地 → 划分）→ **命名**（圈地放标记 → 类型算法生成边界 → 贴合）。

三段同构：**作者只给粗略意图（一个多边形，或一个名字+一个包络）加一个类型/模式选择，精确形状由系统根据地物算出来。**这与既有的意图包络（大陆生成）、意图笔刷（地形六意图）、选择优先（圈区→意图菜单）一脉相承——本稿把这条线延伸到势力与命名，铺完地理维度的地板。

**范围**：地图上的一切——查看、编辑。
**非目标**：历史、文明、人物、事件的生成（用户裁定「后期再加」，照旧手工编辑）。
**反目标**：一键种子生成整个世界（civ-atlas 哲学：种子生成/球面网格不学，只学交互；AGPL 代码不抄）。

## 3. 数据底座：三层格子模型

一格 = 三个通道：

| 通道 | 取值域 | 语义 |
|---|---|---|
| **Terrain** | `水 / 陆地` 二值 | 水陆由**生成动作**决定（标记/海生成写入），不由高度推断。`is_water_cell` 从「水类型 ‖ 高度<0」混合判定简化为单通道判定 |
| **高度** | `i16` 米，纯海拔 | 描述性数字。海 −3000、高原湖 +10、山脊 +2400 各是各 |
| **biome** | `u8` 开放集 | 生物群系编号。开放集与现有 `TerrainKind = u8` 设计同源：编号→名称→色值由 Theme Pack 承载，底层只做载体 |

**与现状的迁移**（builder 落地点）：现有 `KIND_*` 8 编号（深水0/浅水1/沙2/草原3/森林4/丘陵5/山地6/雪7）拆解为——水(0/1)→Terrain 水；丘陵/山地/雪→高度派生（continent.rs `band_kind` 已按阈值派生，正是 D16 精神）；森林/沙/草原→biome 通道。`apply_lake` 现为挖碗物理派（碗掩膜→溢出口→抛物面挖深→标浅水），标记语义派（D14：高度就地）与之的取舍见 §7。二进制迁移预案已被 `docs/BINARY_FORMAT_SPEC.md` §3 版本策略预写（「新增第三通道 → 升 version 保留旧解码分支」）。

## 4. 大陆段

既有裁定不动，此处只引用：意图包络 → 八参面板 → 宏命令 + 撤销恢复圈；默认海洋世界；16:9 缺省（四份计划 `2026-10-17-continent-*.md`）。本稿追加两点：

- 生成后的**修改**走笔刷（涂=分配 biome / 塑=调高度，即 D13 的例外分支）；
- 大陆生成的噪声派生植被（forest_cover/desert_cover）落到 **biome 通道**（D12），与标记生成同源。

## 5. 势力段

数据模型由 ADR-0027 承载（FactionLayer / Faction.layer+rank+seat+memberships / Membership.target / GeometrySpan.relation），本节定其上的**交互与生成语义**：

1. **初始态**：大陆生成后整片地属一个空势力（D4）。
2. **画势力**：在宿主中间画意图多边形 → 弹框选模式（贴地 / 越地）→ 创建 → 从宿主划分出新势力，国境自动闭合（D2/D5/D8）。
3. **贴地**：边界吸附河流中线/山脊线（线状水按中线切、湖沿湖界切——湖界切法见 §7）；越地保留直边。
4. **共享边界**：相邻势力是同一条边（D3），重调一国重生成牵动邻国。
5. **时间**：划分带时间区间（D6），时间轴回拨可见旧划分；变迁动画为可能的未来渲染件。
6. **调整**：重圈多边形重生成（D13）。

## 6. 命名段 = 标记段

### 6.1 生物群系清单（开放，D10）

森林 Forest · 平原 Plains · 草原 Grassland/Steppe · 戈壁 Gobi · 沙漠 Desert · 沼泽 Swamp/Marsh · 湿地 Wetland · 苔原 Tundra · 雪原 Snowfield · 丛林 Jungle · 热带雨林 Tropical Rainforest · 丘陵 Hills · 山地 Mountains · 海洋 Ocean · 湖泊 Lake · 河流 River · 绿洲 Oasis · 稀树草原 Savanna · 盐碱地 Salt Flat/Pan

（「可细分/可补充」为用户原注；丘陵/山地/雪原同时有高度派生通道，见 §3。）

### 6.2 操作模型

圈地（Pen 方法多边形）→ 放置标记（名字 + 群系类型）→ 类型算法在包络内**生成边界 + 贴合**（D9）。两面性：已有同类则**贴合圈出**，没有则**生成**（推断获默许）。

- **面状**（森林/平原/…）：种子点 + 格子 biome 连通生长（连通判定扫格子）；被山隔断即分片（D15）。
- **线状**（河流/道路式）：沿链生成（现有 `Intent::River` 拓扑路线可参考）。
- **湖**（D14）：圈内 Terrain=水、高度=就地海拔、biome=湖泊。山上的湖湖面在山上。
- **名字是纯标签**：站森林里起名「达拉斯平原」圈出来的还是森林（作者想叫什么叫什么）。

### 6.3 组合表达（D16）

无「盆地」类型：草原 + 压低海拔 = 盆地表达。将来若需「平原且海拔<X」的复合贴合条件（v1 只按类型），见 §7。

**我的判断（写进本稿，用户可推翻）**：

1. **D3 与 ADR-0027 的调和口径**：共享边界拼满是**同层内**的约束（每个 FactionLayer 是一张独立分区）；**跨层重叠仍合法**（政治层与军事层的划分可以交叠）——两者不矛盾。

## 追记二：命名段（生物群系标记）实现口径（2026-10-18）

- **数据**：`Place.biome: Option<u8>` + `Place.envelope: Option<Vec<f32>>`（serde default，旧 YAML 零迁移）；生成边界存既有 `place_geometry`（单环）。详见 ADR-0029。
- **识别/生成**：包络内目标群系占比 ≥8% 且 ≥4 格 → 识别（不写格子，边界=已有格子的连通边界最大外环）；否则生成（写群系；陆群系跳过水格；水群系写水 + 就地海拔）。
- **湖（D14 落地）**：`LAKE` 标记 = 包络陆格 → `surface=WATER`、`biome=LAKE`、`height=包络中位海拔`（湖面平）。既有 `LakeRegion` 挖碗意图保留为地形工具，两者互不覆盖。
- **RIVER 群系**：M1 不做（线状标记另立 M2）。
- **渲染过渡**：主题覆盖物规则仍以旧 feature 4 为键；`biome` 森林族（森林/丛林/热带雨林）映射到 4，其余 None；`place.feature` 作旧工程回退。词汇统一仍归 D18 后续。
- **调整路径**：重圈包络重生成（D13）；笔刷不自动改标记边界（M2 再评派生渲染）。

## 追记三：标记重生成（命名段 M2，2026-10-18）

ADR-0029 D2 把边界定为「生成快照」后，笔刷改格会让快照过期。M2 补调整路径，
四项裁定（用户授权按推荐执行）：

- **R2 替换语义**：重生成 = 以 Place 已存的 `envelope` + `biome` 重跑识别/生成，
  **删除** owner 旧 span、写入一条 `[当前日, ∞)`，并重拟合锚点——不追加历史。
  理由：地形格本身不分区间版本化，保留旧 span 会在时间轴回拨时出现「旧边界盖
  新地形」的错位；且回拨后重生成会产出 `to < from` 非法区间。P6 不受影响——它
  约束的是领域状态的存储形态，边界快照不是领域状态（V2 作者主权：改稿即改史）。
- **格尺寸唯一口径**：重生成（及一切后续标记命令）的 `cell_size` 由
  `wv-edit::command::marker_cell_size` 在 apply 内从目标图 raster 推导
  （图幅 extent / 栅格宽，回退链本图 → 根图 → 4096，与渲染层 `grid_sync` 同
  口径但纯从 World 数据算）——ADR-0029 终审 C1 教训的结构性杜绝：wv-edit 摸
  不到会话态 `GridConfig`，调用方也无从传错。
- **边界带洞**：生成区域带洞（包络圈住湖 / 草地芯等）时存
  `GeometryData::PolygonWithHoles`（创建与重生成共用 `marker_geometry`，形态
  永不漂移）；`place_territory_at` 返回 `TerritoryShape`（Solid / WithHoles），
  feature overlay 的晕走 earcut 带洞三角化、近带符号采样避开洞。**多块**
  （不连通）仍只取最大外环——io 层 `geometry/place/` 文件键 `map__owner__from`
  同 owner 同 from 会互相覆盖，多块需 io 侧改造，留待后续批次。
- **入口**：区域面板「生物群系标记」小节（列当前图标记 + 逐个 [重生成边界]）；
  重圈改 envelope 的完整 D13 路径不在本批。

## 追记四：Place 词汇统一（D18 收口，ADR-0032，2026-10-18）

- **唯一词汇 = `biome`（冻结群系表）**：`Place.feature`（旧 TerrainKind 0–9）降级为
  serde 只读迁移脚手架（`skip_serializing`），加载时按 wv-io `place_feature_to_biome`
  表迁移为群系编号并发诊断提示；写回只写 biome。迁移窗口一个版本周期，下版本删字段。
- **迁移表**：{2,3,4,8,9} 与格子侧 `migrate_v1_kind(f).1` 同值（诊断逐位不变）；
  {0,1} → 海洋、{5,6,7} → 丘陵/山地/雪原（升级为真实群系，纠正旧「归 0」假阴性）；
  词汇表外垃圾值 → 不迁移 + 未映射提示。
- **主题规则键 = 群系族**：`BiomeFamily` 落 `wv_terrain::biome`（21 编号 → 8 族全覆盖，
  族界与 `display_kind` 陆面槽位对齐）；`FeatureOverlaySet` 全族字段 + `rule_for(family)`；
  `FEATURE_FOREST=4` 与渲染三臂桥退役，渲染取 `place.biome.and_then(family_of)`。
- **旧工程视觉不回退**：森林（含旧 `feature: 4`）迁移为 biome 1 后晕与树符号照旧；
  POI 抑制窗口内保持 `feature||biome` 双条件。
- **round-trip 修订**：迁移窗口内 `load(save(w))==w` 仅对无旧字段世界字面成立；
  收敛性 `load(save(save(w)))==load(save(w))` 由测试钉死。详见 ADR-0032 D8。
