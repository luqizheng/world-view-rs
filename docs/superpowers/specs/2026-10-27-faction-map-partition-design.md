# 势力图切蛋糕分区 — 设计文档

- 日期：2026-10-27（brainstorming 会话收敛，用户已批准完整图景）
- 状态：设计定稿；builder check 已完成（2026-10-27，6 问全数落定：4 问设计定夺 + 3 问用户拍板 D7–D9），待用户批准设计 → ADR-0074 落盘 → 实施计划
- 触及原则：P3（矢量拓扑走 YAML，不进二进制）、P4（脸归属只存 Faction 引用）、P6/P7（划分状态区间化、无「当前划分」字段）、V1/V2（校验只提示不阻止；改旧划分不质问）。

---

## 1. 动机

会话起点是「layout（图层）不够用」。逐轮收敛出三条痛点 + 一个核心语义：

1. **势力图应有多个命名层**（国界 / 贵族 / 宗教覆盖……），每层独立看 / 不看——数据层已有（ADR-0027），但**眼睛开关没有任何 UI 入口**。
2. **region 的自然图可看可不看**——今天只有会话级 Terrain 开关，关掉也不是用户要的政治图集页形态。
3. **「UI 上现在没有画势力图的工具」**——唯一沾边的入口是圈地一次性指派（ADR-0028），不是画图工具。
4. 核心语义（用户原话）：**「这些势力没有空隙，拖动某边界的扩大，那么就意味着某个地方缩小」**——势力图 = 区划拼图（partition），不是各势力独立多边形。

## 3. 用户裁定（全部已确认）

| # | 裁定 | 原话锚点 |
|---|---|---|
| D1 | 命名一族势力图（国界层 / 贵族层 / 宗教覆盖层……），每层独立看 / 不看 | 「势力图下应该有多个层，可以选择看或者不看」 |
| D2 | 自然图关 = **素底上只看势力填色的政治地图页**（图集 political page） | 「素底上只看势力填色的政治地图页」 |
| D3 | **切蛋糕模型**：新层初始一整块（起始归属）；画一条线 = 切一刀分出两块；再画再分；所有边界为相邻两方共享，拖任何一段两边此消彼长、总面积不变、**天然无空隙**；各层是独立的蛋糕 | 「是这么想的」 |
| D4 | 工具入口：在某势力层点 **pen 按钮** → 弹框问**新增还是修改**；新增要**填生效时间**；修改 = 选历史段 → **地图跳到那一段**显示当时划分、直接编辑 | 「点击 pen 的按钮，弹出框……」「地图跳到那一段」 |
| D5 | 编辑态要有**地图属性**，其中有**当前时间的选择** | 「edit 要有地图属性。地图属性上要有当前时间的选择」 |
| D6 | 划分随时间变（P7）：每刀 / 每拖都落「自第 X 天起划分如此」；时间轴拖到哪天画哪天；改旧 = V2 历史可重写，不质问 | 「会的。……要区分是新增，还是原来的时间点进行划分」 |
| D7 | **切后点选定归属**：切完后两块高亮，点一块 → 小窗选「既有势力 / 新建势力」（builder check 轮拍板） | 2026-10-27 追加裁定 |

## 4. 设计默认（我定，用户放行）

用户在完整图景 playback 中批准了以下默认项（未逐条指定，标 *(我定)* 放行）：

- **眼睛开关的家 = 图层面板**：势力层成组列出（自然图一行 + 势力图层组），不在 Inspector 页签里找；
- 弹框**生效时间预填时间轴当前日**（可改）；
- 政治页**海岸线保留**（仍有海陆判读）；
- **蛋糕 = 该图的陆地**，海不参与切分；
- 新层起始归属**建层时指定**（或默认「无主」占位势力）；
- **层是全局列表，划分挂具体图**（世界图的国界层、某区域的贵族层各是一份分区数据）；
- 切割手势：**手绘折线、一笔从边到边**（穿过一整块），贴格沿用 magnet 开关；
- **ADR-0028 圈地指派流被新工具取代退役**（存量 `faction_geometry` 的迁移/并存关系进 ADR-0074）；
- pen / 编辑态在 **Browse / Edit 档可得，CellMap 工作区不出**（沿用意图菜单既有门控口径）。

**builder check 后追加（2026-10-27，设计定夺，待用户核）：**

- **蛋糕来源** = 该图**自有地形栅格的海陆掩膜**；划分几何在落刀时**快照为权威存储**——之后作者改地形挪了海岸线，已画分区**不自动重切**，海陆错配只进校验面板提示（与 N3「只提示不强制」同口径）；
- **pen 门控** = 当前图为 World/Region ∧ 有自有地形栅格（意图菜单同款合取；「选区闭合」一条对笔不适用）；City / Interior 图不可分区；
- **修改跳段 = 移动全局时间轴**到该段（本项目单时间轴哲学，不引入第二个「编辑时钟」；地图属性里的「当前时间」选择器就是时间轴当前日）；退编辑态不自动跳回；
- **无主 = 脸归属可空**（`Option<Id>` 语义，不因建层造合成占位势力实体）；无主渲染灰色；建层弹框起始归属可留空；
- **自然图关 = 只替换底图**（地形 → 素底 + 海岸线）；地点 / 事件 / 道路等其余内容层开关**独立照旧**——「只看势力填色」是作者顺手关掉其余层的常见组合，不做硬 suppression。

## 5. 目标 / 非目标 / 反目标

**目标**

- G1 每层独立显隐：图层面板成组 + 眼睛 → `UpdateFactionLayerCommand`（已有命令，接线）。
- G2 自然图开关落盘 + 关 = 政治图集页形态。
- G3 分区数据模型（边界网络 + 脸归属 + span）——**ADR-0074**。
- G4 画势力图的工具：pen → 弹框（新增/修改）→ 图上切与拖。
- G5 时间轴求值与播放随动：时间轴拖到哪天画哪天的划分。

**非目标**

- N1 不做边界自动模拟 / 推演（sim 引擎是另一议题）。
- N2 不做多层同时填色（维持 ADR-0027 D6：一层填色、其余画边）。
- N3 不做跨层级划分一致性强制（世界图国界与区域图划分的一致性**只提示不强制**，V1）。
- N4 `Membership` 归属边语义不动；**声称（claim）不再可新建**（D9）——存量 claim 多边形保留渲染兼容、逐步退役，不做新的声称编辑入口。
- N5 老圈地指派流（ADR-0028）不扩展，直接退役。

**反目标（出现即失败）**

- A1 出现「当前划分」类字段（非区间化）——违反 P6/P7。
- A2 拖边界 / 切分后出现空隙或重叠而工具静默。
- A3 分区数据绕过 `EditCommand` 被 System 直改。
- A4 分区拓扑写进二进制（P3：只有超大网格数组可用二进制）。

## 6. 设计（定下来的 how）

### 6.1 数据模型（wv-core，ADR-0074 详化）

- 一层 × 一图 = 一份**分区**（partition）：
  - **边界网络**：顶点 + 边；一条边界边被两侧势力**共享**；
  - **脸（face）**：被边界围出的连通块，归属 = `Faction` id 引用（P4）；
  - 铺满不变量：该图陆地每一点属于恰好一张脸（海不参与）。
- **时间**：脸归属带 `[from, to)` span（`to == None` = 至今）；某天的划分 = 查询求值（参照 `territories_at` 的 API 形态）。切一刀 / 拖边界 = 旧脸关闭 span + 新脸开启新 span。
- 拓扑表示（半边 / 邻接表）、YAML schema、round-trip、与存量 `faction_geometry` 的迁移/并存——**留给 ADR-0074 与实施计划**。
- 查询 API 落 wv-core（如 `partition_at(map, layer, day)`）；渲染层禁自比时间（AGENTS §3.2）。

### 6.2 看图

- **图层面板**新增分组：自然图（一行）+ 势力图层组（每层一行：名字 + 眼睛）；
- 层眼睛 → `UpdateFactionLayerCommand`（已有）；自然图开关升为**落盘**（挂 `MapNode` 层声明走 `UpdateLayerCommand`，还是独立偏好——实施计划定，但必须跨会话）；
- 政治图集页 = 自然图关时的呈现配方（素底 + 势力填色 + 海岸线），落 wv-render 呈现层。

### 6.3 画图工具

- 入口：势力层列表行 **pen 按钮**（Lucide `pencil`）；
- 弹框第一问：**新增 / 修改**；
  - 新增：填**生效时间**（预填当前日）→ 进入切分；
  - 修改：列该层历史分段 → 选一段 → **地图跳到那一段**（显示当时划分）；
- 编辑态带**地图属性**（含**当前时间**选择器）——始终可见可改「正在改哪个时间点」；
- 手势三种（D7/D8）：
  - **切分笔画**：边到边折线，magnet 可选贴格；切完两块高亮，**点一块 → 小窗选既有 / 新建势力**；
  - **拖边界**：零和（邻接两侧联动）；
  - **整块易主**：点击一块 → 改归属 + 填生效时间（几何不动，关旧 span 开新 span）；
- 提交一律经 `EditCommand` → `History`（可撤销，每刀/每拖一个事务）。

### 6.4 时间

- 时间轴求值：渲染每帧经 wv-core 查询取「本日划分」；
- 播放随动：边界随剧情日子变化（既有播放器，Browse 档）；
- 改旧划分落到选中历史段（V2：不弹窗质问矛盾）。

## 7. 留给 builder / ADR-0074 的

- 拓扑数据结构选型 + YAML schema（round-trip 测试必须，手算期望值）；
- 零和拖动的几何算法（顶点合并、边界分裂、多点共边——势力划分 M2 的共边弧经验可参考）；
- **修改历史段对后续 span 的影响策略**（快照式：每段独立完整划分，改旧段不传染后段——倾向此案；操作日志式：改旧需重放后段）；
- 存量 `faction_geometry` 数据迁移或并存方案；
- 政治页素底配方（海色 / 陆色 / 海岸线粗细）；
- 工具在地图工具条 / 意图体系的集成（槽位、快捷键、与 PointSelect 上下文化的关系）；
- i18n key 与 Lucide 图标选型；
- 校验面板条目（悬空 Faction 引用、拓扑破损、跨层级划分不一致——全部只提示，V1）。

## 8. 验收清单

- [ ] 图层面板：势力层成组、每层眼睛可开关且**落盘**；
- [ ] 自然图开关跨会话生效；关 = 素底 + 势力填色 + 海岸线的政治页；
- [ ] 建层 → pen → 新增（填生效日）→ 切两刀 → 时间轴拨回生效日前**看不到**这两刀；播放推进能看到边界变化；
- [ ] 拖边界后无空隙、无重叠（校验面板可查）；
- [ ] 切后点选：切完两块高亮，点一块可指定既有 / 新建势力（D7）；
- [ ] 整块易主：点击一块 → 改归属 + 生效日，几何不动，可撤销（D8）；
- [ ] 改地形挪海岸线后，已画分区不重切、校验面板列出海陆错配（设计默认）；
- [ ] 每刀 / 每拖可撤销（Ctrl+Z 各回一步）；
- [ ] 修改历史段：选段 → 地图跳转 → 编辑只影响该段（V2 不质问）；
- [ ] 悬空引用 / 拓扑异常只在校验面板列出，不阻止保存（V1）。
