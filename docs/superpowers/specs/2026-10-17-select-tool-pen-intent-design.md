## 1. 意图与为什么

右侧地图工具条今天**没有「选择」这个概念**：大陆圈画、城市落点、测量折线各自为政——
逐点画多边形的手感分裂、多边形闭合后锚点动不了也删不了、没有「先圈一块地方、再对它干活」的统一入口。

本稿确立**选择优先（selection-first）交互模型**：

> 无论世界图还是城市图，先用**选择工具**圈一个区域 → 画布底部浮现**意图菜单** → 点意图生效。
> 多边形绘制/编辑抽成共享的 **Pen 方法**（Figma pen 手感），所有「多边形选择」类工具共用。

它同时是三笔欠账的清偿：

1. **大陆圈画**被吸收（选区 = 意图包络，喂已有八参面板）；
2. **城市创建**升级为「圈位置 → 填名字面积 → 自动钻入编辑器」；
3. 长期欠着的**区域绘制工具**（`region_panel.rs` 头注明写「几何绘制是未来工具的职责」）与未来**父图城市轮廓**（ADR-0022 D1）有了可骑的底座。

## 3. Pen 方法交互规格（手势全集）

**画中（Drawing 态）**

| 手势 | 行为 |
|---|---|
| 左键点击 | 落一个锚点；末锚点 → 光标画橡皮筋线，锚点序列实时连线 |
| 点击第一个锚点 | **闭合**（悬停首锚时光标变闭合圈——Figma 惯例） |
| 双击 / Enter | **闭合** |
| Backspace | 删除上一锚点 |
| Esc | 丢弃整条草稿 |
| 拖拽（按下并移动） | **【勘误 2026-10-17】**平移是**右 / 中键**拖拽（`camera_pan` 缺省，左键不参与）；左键按在选中锚点上拖动 = 移动该锚点（`drag_selected_anchor`），按在空白处无操作 |
| 点数 < 3 时尝试闭合 | 丢弃整条草稿（沿用 `ContinentSketch::try_close` 语义） |

**闭合后（Closed 态，选区活动）**

| 手势 | 行为 |
|---|---|
| 单击锚点 | 选中（实心/空心区分），拖动改位 |
| 双击锚点 | 删除该锚点 |
| 点击边线 | 该边中点插入新锚点（随后可拖） |
| 点空白 / Esc | 取消选择 |
| 切工具 / 切图 | 取消选择（`draft_map_id` 防跨图泄漏，沿用 `MeasureState::on_map_change` 模式） |

**通用规则**

- ≥ 3 点才允许闭合；锚点数下限对全部意图统一。
- 自交多边形**不拦**（§7.5 V1：校验只提示）——校验面板提示「自交选区」，生成按栅格化掩膜处理，行为在代码注释指回本节。
- 意图菜单在 Closed 态常驻；编辑锚点菜单不消失。
- 选区 Gizmos（草稿线 / 橡皮筋 / 顶点 / 闭合区域描边环 / 选中锚点高亮）沿 `draw_continent_sketch` 家族画法。**【偏差 2026-10-17】**bevy Gizmos 没有多边形填充原语，「闭合区域半透明填充」延后——v1 只有描边 + 顶点。
- **左键归属（选择工具激活时的命中优先级）**：锚点 / 边线编辑 > 下钻图标（Closed 态仅**双击**响应下钻；**Drawing 态吞掉图标的单击/双击语义**，防止「在图标旁收笔」被误判成下钻、草稿随切图蒸发）> 空白（取消选区，兼清实体选中）。标签点选在选择工具激活时**让位**（不拦截落锚）。为此 `drill.rs::drill_pick` 需加 Drawing 态守卫（→ §9）。

## 4. 意图目录与算法映射（世界图 v1）

| 意图 | 算法（全部有家底） | 落点 | 选区在纯海上的行为 |
|---|---|---|---|
| 生成大陆 | 选区 → 八参面板的意图包络；`GenerateContinentCommand` 宏命令（生成即消费、撤销地形回滚**且选区回驻留**——沿用「大陆配方」裁定） | 网格双通道 | 正常（生成陆地正是本意） |
| 生成城市 | 见 §5 | 新子图 + 图标 | 正常（城市可落海边，底图作者选） |
| 高山 | 选区内派生脊线（主轴/最长对角线为主脊）跑 `Intent::MountainRange` 同款 ridged 噪声，半径 ≈ 短轴之半 | 网格高度 | **特性**：跨海段自动冒岛链/半岛（既有语义） |
| 丘陵 | `Intent::Hills` 区域掩膜版（≤ 300 m × strength，只在陆上生效） | 网格高度 | 无操作 + 通知 |
| 平原 | 选区内**主动压平**到海平面以上低海拔带（初值中值 ≈ 60 m）——注意与 `Intent::Plateau`「不压低已有更高地形」语义**相反**：生成平原就是要把区域内高地抹平 | 网格高度 | 无操作 + 通知（与丘陵同语义，本稿裁定） |
| 湖泊 | `Intent::Lake` 碗形洼地：选区定湖界，碗底低于溢出口才积水 | 网格高度 | 无操作 + 通知（湖心必须在陆上，既有语义） |

- **一键应用**（D10）：无弹窗；几何参数自选区尺寸派生（如高山半径 = 短轴之半），起伏 / 深度类 strength 初值固定 1.0；全部常数**集中 `wv-terrain` 一处**，沿用 intent.rs 标定先例（`RANGE_PEAK_M` / `HILLS_AMP_M` / `LAKE_DEPTH_M`），待实机校准；种子沿 `Intent::derive_seed` 先例从 (图 ID, 意图, 质心) 派生——确定性，重算不跳变。
- **目录过滤谓词**：意图目录出现条件 = 该图有自有地形栅格 **且** 图级 ∈ {World, Region}（City / Interior 不出地形意图；「生成城市」在 World / Region 级都出现）。本稿裁定，作者可收紧为仅 World。
- **撤销与选区回驻留**：生成大陆撤销 → 地形回滚**且选区回驻留**（沿用「大陆配方」裁定；回驻留仅在当前**无活动选区**时生效——作者已画新选区则新选区赢、stash 丢弃）。地形四意图撤销 → 地形回滚、**选区不回驻留**（一键无参数可调，确定性 seed 下重画同结果，回驻留无工作流价值）。
- **一意图一事务**：每意图一条命令打包进一个 `Transaction`，撤销一步还原（P6）。
- 目录为空的图（City / Interior）上闭合选区后菜单区显示占位（「本图暂无可用意图」），具体呈现 builder 定。

## 5. 生成城市流程（portal 收敛细化）

1. 闭合选区 → 菜单点「生成城市」。
2. **质心 = 落点**；对话框预填：名字（空）/ ID（手输 + 重名检测，沿用）/ 底图（海洋/陆地，沿用）/ **面积**（= 选区包围盒面积，可改）。
3. 确认 → `extent` 按面积生成 **16:9 方正画布**：`w = √(A·16/9)`、`h = √(A·9/16)`（wu²；km² 显示等 ADR-0022 D4 `unit_per_km` 落地后再接——本稿裁定 v1 用 wu²）；`extent.origin = 质心 − (w/2, h/2)`（画布以质心居中，「质心 = 落点」才成立）。
4. `AddCityCommand` 入一个 `Transaction` → `History.commit` → `ShellNotice` → **自动 `DrillToNode` 钻入新城市图**。
5. 钻入图标（`drill_into`）的 `IconSpec.anchor` 显式写成质心的本图归一化坐标——**不能**留给哈希回退摆位（否则图标位置与作者圈的点无关）。
6. 返回父图：面包屑 / 换级往外（均已有）。

## 6. v1 范围与验收画面

1. 世界图上用选择工具圈 ≥3 锚点闭合 → 底部菜单浮现。
2. 锚点拖动 / 双击删 / 点边插入 / Backspace / Esc 全部按 §3 生效；编辑时菜单不消失。
3. 生成大陆：八参面板包络预填选区 → 生成 → 撤销：地形回滚且选区回驻留。
4. 生成城市：确认后自动钻入新城市图；面包屑返回，父图上城市图标落在质心处；Closed 态双击城市图标可下钻，Drawing 态双击**不**触发下钻（§3 命中优先级）。
5. 地形四意图一键生效：掩膜内高度变化、**掩膜外逐位不变**（测试断言）；纯海选区无操作 + 通知；撤销一步还原。
6. 自交选区不崩，校验面板可见提示。
7. 切图 / 切工具 / 点空白：选区清空，无跨图泄漏。
8. 工具条：大陆圈画、城市落点两块瓷砖消失，选择瓷砖上岗（「生成大陆…」面板瓷砖**保留**，文案去掉「先圈出意图包络」的圈画指法）；`map_control_tests` 布局计数同步；命令面板不受影响。
9. `bash scripts/smoke-gui.sh` 通过（新增系统 / 资源 / Plugin 装配）。

## 7. 非目标（v1 明确不做）

- 城市图内的意图目录（场景编辑器 M1 的地盘，本稿只留占位机制）。
- 多选区、选区跨会话持久化（会话态，不落盘）。
- 测量折线迁移 pen 方法；「存为区域」；火山/河/山脉/高原意图。
- 父图城市轮廓绘制（outline_polygon 的绘制手势）。
- 森林意图的实现本体（M4 只做菜单入口，骑覆盖物 v1）。
- zoom-through（跨图连续缩放）——portal 已定，反方向提案不收。

**反目标（做砸了长这样）**：圈完区域误触即生成（生成城市/大陆各有对话框/面板这道确认闸）；菜单常驻挡画布（浮动条克制，可 Esc 收）；`wv-render` 里出现 `EditCommand` 构造（§2.1 红线）。

## 12. 本稿裁定的缺省（作者/评审可复核推翻）

| 裁定 | 内容 | 一句话理由 |
|---|---|---|
| 地形一键应用 | 无弹窗、参数派生（D10） | §7.5：作者随便改，撤销兜底 |
| 平原只在陆上 | 纯海选区无操作 + 通知 | 与 Hills 既有语义对齐 |
| 面积单位 v1 = wu² | km² 等 ADR-0022 D4 | 不被未接受 ADR 阻塞 |
| 自交处理 | 栅格化掩膜 + 校验提示，不阻止 | V1；算法行为写进注释指回本稿 |
| 钻入图标 anchor 显式化 | 城市创建写质心 anchor | 哈希回退摆位与作者意图无关 |
| 无意图图级的菜单 | 占位文案，不隐藏工具 | 选择优先模型要全图级一致 |
| 图级谓词 | 意图目录 = 有自有栅格 ∧ 图级 ∈ {World, Region} | Region 图也是地形编辑图；City/Interior 不该出地形意图 |
| 撤销回驻留 | 大陆回驻留（仅当无活动新选区）；地形四意图不回驻留 | 大陆要进面板调参故回驻留；一键无参数，回驻留无价值 |
| 左键命中优先级 | 锚点/边 > 图标下钻（Closed 态双击）> 空白取消；标签让位 | 不裁定则双击收笔误触下钻、草稿蒸发 |

## 13. 测试要求（§7.2 对照）

- Pen 状态机（`wv-render` 单测）：`closed_selection_rejects_fewer_than_three_anchors`、`backspace_removes_last_anchor_while_drawing`、`escape_discards_draft_keeps_closed_selection`、`map_change_clears_selection`、`edge_click_inserts_anchor_between_neighbors`、`first_anchor_click_closes_draft`。
- 区域算法（`wv-terrain` 单测，**手算期望值** + 数值上下文）：掩膜内目标高度、掩膜外逐位不变、边缘衰减有界。
- 命令（`wv-edit` 单测）：`undo_region_terrain_restores_prior_heights`、每意图一事务、seed 同参重算结果一致。
- 城市流：`area_maps_to_16_9_extent`（数学断言）、钻入 anchor = 质心归一化、自动钻入状态断言。
- GUI 烟测：新增 Plugin / 系统 / 资源装配后必跑（§7.1）。
