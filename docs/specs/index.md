# 规格参考

本区收录 **基线 / 美术 / 音频 / 地形 / 渲染** 等规格文档，以及仓库根的两份协作规约。

> [!IMPORTANT] 与「现行口径」的区别
> 规格文档是**发散的研究与设计正文**，可能包含已被后续决策取代的历史小节。
> 判断「现在到底是什么」请以 [现行口径](/current/) 为准；本区用于追溯**当时的完整论证**。
