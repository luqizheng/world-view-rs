## 二、SPEC §3.8「渲染实现契约」增补草案（确认后写入，原文不改）

> 按 SPEC §6.3「追写不改机制」，作为新的一节追加（不动 §3.1–§3.7 任何条目）。

| 条目 | 内容 |
|---|---|
| **§3.8.1 线宽以屏幕像素定义** | 所有线（海岸 1.2 / biome 界 0.8 / 河流 1.8 / 道路 2.4/1.2）宽度以**屏幕像素**为单位，渲染层按当前缩放折算；`tile_size/16` 的图块内描线规格**仅适用于位图 pack** |
| **§3.8.2 连续性优先于格子精度** | 海岸 / biome 边界由**距离场**驱动，不得逐格改色表达；允许视觉边界与格子事实 ≤0.45 格偏差（域扭曲），近观编辑态收敛 ≤0.05 格 |
| **§3.8.3 三阶色阶参数化** | 亮 +8% / 暗 −15% / 描线 −45%（§1.5）改为可配置令牌 `shade.light / shade.dark / shade.ink`，默认值不变 |
| **§3.8.4 海岸三段色带** | 滩 0–1 / 浅 1–3 / 深 3–9 格（累计边界 1:3:9，带宽 1:2:6；表述以 Q1 拍板为准），色带宽度随 `tile_size` 等比折算 |
| **§3.8.5 符号图集画布规格** | 128px 画布 / 25% 安全边 / `bottom_center` 锚点 / 阴影 `+0.35×高, α0.18` |
| **§3.8.6 变体选择确定性** | 变体 / 翻转 / 尺寸抖动一律由 `(cx, cy, salt)` 哈希决定，不使用随机数 |
