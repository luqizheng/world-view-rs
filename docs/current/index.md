## 阅读顺序建议

1. 先看本页表格定位主题域 → 进对应页面看**合并后的现行口径**
2. 对某条口径有疑问 → 沿**溯源链**进 [原文档案](/adr/) 看原始决策与理由
3. 想看「为什么当初那么定、后来为什么改」→ [演化史](/evolution)
4. 想知道「哪些还没定」→ [待决问题](/pending) 与 [提议区](/proposed/)
