## 〇、一句话总纲与贯穿全文的裁定

> **这是编辑器，不是游戏。动效的唯一职责是「让作者看懂状态变化发生在哪里、什么时候」，而不是「让画面好看」。凡是不能帮助作者理解状态的动效，一律不做。**

三条贯穿全文的裁定（后续所有参数都服从这三条）：

| # | 裁定 | 一句话依据 |
|---|---|---|
| **AD-1** | **动效一律「短、小、可中断」**。默认过渡时长落在 **80–200 ms**，绝大多数 ≤ 160 ms | 作者连续工作数小时，长动效 = 每次操作都欠一杯奶茶的时间债 |
| **AD-2** | **「进行中」的一切强调必须可关闭，且默认低强度、慢周期**（周期 ≥ 2 s、幅度 ≤ 视觉基线 ±6%） | 基线 §1.9「作者可能长时间盯着」——脉冲是唯一可能被长时间注视的动效，必须「看久了不烦」 |
| **AD-3** | **精度场景零惯性、零延迟、零补间**（笔刷涂抹、缩放、平移）。反馈必须「跟我手一样快」 | 基线 §1.13「反馈必须精准不延迟」；编辑器里「跟手」比「顺滑」重要 |

**动效分级（本文全篇使用的强度标尺）**：

| 级别 | 名称 | 时长区间 | 用途 | 可关闭 |
|---|---|---|---|---|
| **L0** | 瞬变（无动效） | 0 ms | 精度优先的操作、拖动跟随 | — |
| **L1** | 微反馈 | 80–120 ms | 悬停、按下、图标点亮 | 否（过短，无干扰） |
| **L2** | 状态过渡 | 140–200 ms | 面板展开、状态切换、淡入淡出 | 否 |
| **L3** | 强调动效 | 循环 / 240–400 ms | 「进行中」脉冲、轨迹生长 | ✅ **可关闭** |

> **「可关闭」的范围**：L3 全部可关闭；设置项 `animation.intensity`（`full` / `reduced` / `off`）三档。`reduced` = L3 幅度减半、周期翻倍；`off` = 全部 L3 退化为静态高亮（不闪、不动，只保留色/形区分）。**L0/L1/L2 不受 intensity 影响**（它们已经足够克制，关掉反而失去状态可见性）。

## 一、时间轴播放动画（最高优先级）

> 基线 §1.8：播放 = 时间轴自动推进，锁定事态 `span`，1/5/30 天每秒，~20 秒播完。
> 基线 §1.6：轨迹三种形态（带时间戳点 / 顺序点 / 只两端点）。
> **所有位置计算必须走 `TimelineQuery::at` 的投影结果，渲染层禁止做时间比较（AGENTS §3.2 硬约束）。**

### 1.1 核心时间模型（播放推进）

| 项 | 规范 |
|---|---|
| 推进方式 | `current_day += speed * dt`，`speed ∈ {1, 5, 30}` 天/秒 |
| `dt` 取值 | **用真实帧 `dt`（`Time::delta_secs`），不用固定步长**——播放是视图状态，抖动可接受，但**顶栏日期必须每帧重算** |
| 起点/终点 | `current_day` 在 `[situation.span.from, situation.span.to]` 内循环（`to` 含端点，播到头后回 `from`） |
| 循环交接 | 播到 `to` 后**停顿 400 ms**（`accent.cursor` 轻微呼吸一次）再回绕，避免「瞬跳」造成作者跟丢 |
| 播放中只读 | ✅ 播放中 `undo/redo`、编辑命令全部禁用（基线 §1.8 / V37） |

**速率 → 每帧行进量（60 FPS 参考）**：

| 速率 | 每帧行进（天） | 说明 |
|---|---|---|
| 1 天/秒 | 0.0167 | 低速率，可看清逐日变化 |
| 5 天/秒 | 0.0833 | 中速率，主力档 |
| 30 天/秒 | 0.5 | 高速率，看整体态势 |

### 1.2 轨迹「逐段生长」动画（核心）

**裁定：轨迹按 waypoint 的 `day` 顺序**依次点亮，两点之间**线性插值生长**。

**生长关系（必须写死）**：设轨迹 `waypoints = [p0, p1, …, pn]`，当前时刻 `t`：

| 情形 | 该时刻轨迹的可见形态 |
|---|---|
| `t ≤ p0.day` | 只显示 `p0` 一个点（起点标记），线长为 0 |
| `p0.day < t < p1.day` | `p0→p1` 段**部分生长**：可见终点 = `lerp(p0.pos, p1.pos, (t − p0.day) / (p1.day − p0.day))` |
| `pi.day ≤ t < p(i+1).day` | `p0..pi` 全亮 + `pi→p(i+1)` 部分生长 |
| `t ≥ pn.day` | **整条轨迹全亮**（生长完成态） |

**生长视觉参数**：

| 参数 | 数值 | 依据 |
|---|---|---|
| 已生长段线宽 | `tile_size / 8`（32px → 4px），与道路同宽 | 美术 §3.3「路宽 = tile_size/8」 |
| 未生长段 | **不显示**（不是灰线，是还没有） | 生长语义 = 「还没走到」 |
| 「已生长」末端（笔尖） | 一个 **6px 实心圆点**，色 `accent.cursor` | 让作者一眼看到「当前走到哪」 |
| 生长段颜色 | `accent.event`（紫，与地形/派系色相均远，美术 §1.4.2） | 轨迹是「事件维」的产物 |
| 拐点标记（waypoint 点） | 到达时该点**放大 1.0× → 1.4× → 1.0× 的 120 ms 弹一下**（L1） | 提示「此处是一个有意义的节点」 |
| 轨迹淡化（旧段） | 已生长超过 **2 段**后，最早段透明度降到 **0.55**（保留可见，不消失） | 避免长轨迹变成一坨亮线 |

> **与原裁定的一致性**：基线 §1.8 World 层「轨迹逐段生长」→ 本节即其参数化。

### 1.3 无时间戳轨迹（顺序点）怎么播

基线 T2：无 `day` 的点 = 顺序点，由插值决定，**不参与校验**。

**插值规则（裁定：均分到事态 span）**：

| 项 | 规范 |
|---|---|
| 归属时段 | 该轨迹的 `TimeSpan [from, to]`（若轨迹自身无 span，落到**所在事态节点的 `event.span`**；若事件也无 span，落到**整个事态的 span**） |
| 均分公式 | 有 `k` 个无时间戳点（含两端），第 `i` 个点的虚拟时刻 = `from + (to − from) * i / (k − 1)` |
| 混合情形 | 部分点带 `day`、部分不带：**带 day 的点固定**，无 day 的点在相邻两个「已定时刻」之间**均分** |
| 视觉 | 与 1.2 完全一致（生长、拐点点亮、笔尖）——**作者无法从视觉分辨「这是一个推算的插值轨迹」** |
| 提示（重要） | 轨迹的**起点标记用「空心圆」**表示「时间由推算给出」，带时间戳轨迹起点用**实心圆** | 让作者知道「这条轨迹的时间是工具替我算的」 |

> **为什么混合情形要均分而非按段长**：顺序点语义是「顺序」不是「距离」，按段长插值会把「顺序」偷偷变成「等速」。**均分是最保守的假设**（不臆造额外信息）。

### 1.4 只两端点轨迹怎么播

基线 T3：「只填两端点的轨迹，其时间由两端点事件的时间范围给出」。

| 项 | 规范 |
|---|---|
| 时间来源 | `p0.day = event.span.from`，`p1.day = event.span.to`（两端点事件的 span） |
| 播放形态 | **与 1.2 完全相同**：`t` 从 `from` 到 `to` 期间，线从起点均匀生长到终点 |
| 视觉标识 | 起点标记用**空心圆**（与 1.3 的推算轨迹一致），并在轨迹中段显示一个极淡的 **`≈` 波形标记**（alpha 0.3），提示「这是粗轨迹」 | 
| 线宽 | 与精轨迹相同（**不因「粗」而变细**，作者不该因「写得省事」被惩罚） |
| 生长速度 | 由 span 长度自动决定，与精轨迹同一公式 |

> **设计意图**（对应基线风险 R「轨迹变成隐性必填」）：**粗轨迹零成本可用，且视觉上不被歧视**。只给一个极淡的 `≈` 提示，作者不去纠结它，程序也能算。

### 1.5 角色图标沿轨迹移动（城市/室内图）

基线 §1.8：City 层「角色沿路径平滑移动，不是瞬移」；Interior 层「轨迹默认只画起点终点」。

| 项 | 规范 |
|---|---|
| 位置计算 | **同 1.2 的线性插值**：`pos(t) = lerp(pi.pos, p(i+1).pos, u)`，`u = (t − pi.day) / (p(i+1).day − pi.day)`。**共享同一插值函数**，禁止角色移动另写一套 |
| 平滑增强 | 城市图（City/Interior）上，对插值结果叠加**一阶低通**（`pos' = lerp(pos_prev, pos_target, 1 − exp(−dt/τ))`，`τ = 60 ms`） | 消除折线在拐角处的硬折（人走路不走直角），但**τ 极小，不产生「滞后感」** |
| 图标尺寸 | 地点符号尺寸的 **0.5×**（即 1×1 格的一半，16px），bottom_center 锚点 | 美术 §3.4 |
| 朝向 | **角色图标朝向 = 路径切向**（若 pack 提供有向图标）；无向图标则不改 | 走路的自然感 |
| 移动速度 | **不单独定义速度**——位置完全由 `t` 与 waypoint 时间戳决定。**「速度」= 段长 / 段时长，是数据的产物** | 避免引入第二个速度参数与数据打架 |
| 到达 Place 高亮 | 角色图标中心进入 Place 半径内 → 该 Place 符号**外描边 2px `accent.select`**（L1，120 ms 淡入） | 基线 §1.8「到达 Place 时高亮」 |
| 多角色同时播 | ✅ 允许。多个图标各自插值，**互不干扰透明度** | 基线 §1.8 City「多角色可同时播」 |
| 拖尾 | ❌ **不做**。角色位置是「事实」不是「特效」 | 克制原则 |

> **为什么不做拖尾/残影**：拖尾会让作者误以为「角色同时存在于多个位置」——而四维校验的核心正是**位置唯一性**。视觉上暗示「多位置」= 与工具的校验语义冲突。

### 1.6 势力易主过渡（`GeometrySpan` 边界跨越）— 与特效规格的接口

> 视觉形态归特效总监（`VFX_SPEC_v0.1.md` §2.6.2：描边淡入/淡出 + 边界扫光）；**播放节奏归本文**。
> 硬约束 **T1（特效规格）**：过渡时长**必须由 `current_day` 推进速率派生，不得独立计时**。

**核心机制：过渡进度是 `current_day` 的纯函数（day 空间插值），不是壁钟计时。**

| 迁移 | 进度公式 | `Δ_day`（day 空间过渡带宽） | 稳态目标 |
|---|---|---|---|
| **出现**（appeared） | `alpha = clamp((current_day − span.from) / 0.25, 0, 1)` | **0.25 天** | 填充 alpha 0.45 |
| **消失**（vanished） | `alpha = clamp((span.to − current_day) / 0.20, 0, 1)` | **0.20 天** | 0 |
| **新旧交替**（同一块换色） | 旧色 `alpha = 1 − p`、新色 `alpha = p`，`p = clamp((current_day − swap_day) / 0.35, 0, 1)` | **0.35 天** | 新色稳态 |

**由此得到的壁钟时长（自动派生，无需单独配置）**：`壁钟时长 = Δ_day / 推进速率`

| 推进速率 | 出现 | 消失 | 交替 | 对照特效上限（0.40 / 0.30 / 0.50 s） |
|---|---|---|---|---|
| 1 天/秒（慢拖） | 0.25 s | 0.20 s | 0.35 s | ✅ 全部在上限内 |
| 5 天/秒 | 0.05 s | 0.04 s | 0.07 s | ✅ |
| 30 天/秒 | 0.008 s | 0.007 s | 0.012 s | ✅ **等于瞬变**（T1 满足：拖得快 = 立即完成） |
| 快速拖拽（速率极大） | **当帧落终态** | 同 | 同 | ✅ |

**曲线（本文裁定）**：ease-out-cubic（在 **day 参数**上，非壁钟上）。即 `alpha = ease_out_cubic(progress)`。
**边界扫光**（特效的 `u_sweep`）：与描边 alpha 用**同一 `progress`**驱动，随 day 推进扫过，**不另立计时器**。

**其余规则**：

| 项 | 规范 |
|---|---|
| 可逆 | ✅ **天然可逆**——`current_day` 回拖时 `progress` 同步回退（公式是对称的）。这是选「day 空间插值」而非「壁钟计时」的最大收益 |
| 大幅跨越 | 一帧内跨越多 span：**每个 span 各按自身公式求值**，天然合并，无需排队 |
| 常驻态 | T3：稳定时**完全静止**（`progress` 恒为 1 或 0，无动画） |
| 不做粒子 | T4：确认——粒子在这里是纯噪音 | 
| 实现归属 | 该插值函数放 `wv-core`（纯函数，可单测）；`wv-app` 只把结果喂给描边 shader 的 uniform |
| Alpha 取值 | **填充稳态 alpha = 0.45**（**服从特效规格 §2.2**，本文原 0.35 作废——单一权威：填充不透明度归特效） |

> **注意与 §2.4 的关系**：这里说的是**几何（势力版图）**的进出；「声称/实控」双语义（K9）本轮不做。

### 1.7 播放速率适配（是否降采样）

**裁定：不同速率下，动效参数按「每秒事件数」而非「天」适配。**

| 速率 | 轨迹生长 | 势力易主过渡 | 事件脉冲 | 说明 |
|---|---|---|---|---|
| **1 天/秒** | 正常（§1.2） | day 派生：0.25/0.20/0.35 s（§1.6） | 底环 + 涟漪全开（§2.2） | 所有动效全参数 |
| **5 天/秒** | 正常 | day 派生：≈0.05 s | 底环 + 涟漪全开 | 主力档，无特殊处理 |
| **30 天/秒** | **段级采样**：每帧只更新「当前段」的插值，**跳过的中间段直接标为已亮**（不逐段播放拐点弹跳） | day 派生：≈0（瞬变） | **暂停涟漪环，保留底环**（见下） | 高速播放下，拐点弹跳会变成「一路爆闪」，**必须抑制** |

**「降采样」的确切含义**（避免误解）：

1. **降采样的是「装饰性微动效」，不是「位置精度」**。角色位置、轨迹生长端点在任何速率下都按真实 `t` 计算，**绝不跳帧**。
2. **30 天/秒 时抑制的项**：
   - 拐点点亮的 120 ms 弹跳 → **直接跳过**（点直接以终态出现）
   - §2.2 的事件**涟漪环** → **暂停**（连续往复的 alpha 0.5→0 在高速扫过时会「一路爆闪」）
3. **30 天/秒 时保留的项**：轨迹生长、势力易主过渡、顶栏日期刷新、当前节点高亮、**事件脉冲的底环**。
4. **判定阈值**：`speed ≥ 10 天/秒` 即进入「高速档」（当前三档中只有 30 命中）。

> **⚠️ 裁定修订（采纳特效总监反保留 A）**：原表述「30 天/秒 脉冲**暂停**」**已作废**，改为「**暂停涟漪环、保留底环**」。理由（三条，本文认同）：
> ① **底环属「状态」不属「动效」**——「此刻有事件在发生」是状态指示器，与「第几个事件节点被点亮」同级；**任何 intensity / 任何速率下底环都不该被抑制**（与 §2.2 `intensity=off` 时只留底环同一逻辑）。
> ② **30 天/秒 的用途就是看总体态势**，此时作者**最需要**「现在哪些事件在活跃」的全局提示——关掉反而丢了最该看的信息。
> ③ 30 天/秒下一帧跨 0.5 天，一个 3 天 span 的事件**持续约 6 帧（~100 ms）**才扫过，并非「一闪而过」；**真正的闪烁源是涟漪环的往复，而非底环**（底环是恒定值，不闪）。

### 1.8 播放期间的镜头

| 项 | 裁定 |
|---|---|
| 自动跟随镜头（K7） | ❌ **本轮不做**（基线 K7 阶段二）。播放时镜头**保持不动** |
| 跨图播放（World → City） | 基线 §2.14：`Situation.maps` 跨图时**自动切换当前渲染地图**。切换时给 **200 ms 交叉淡化**（旧图 alpha→0，新图 alpha 0→1），**不移动镜头** |
| 越界提示 | 若某轨迹点超出当前视口，**不做镜头拉回**，只在时间轴上高亮「越界段」，由作者手动导航 |

> **为什么不做自动跟随**：镜头自动移动 = 作者失去空间锚点。TRPG 主持人看图时，「我地图没动」比「镜头追着人跑」重要得多。此裁定**强化**了基线 K7 的「可砍」判断。

## 二、事件与事态的状态动效

### 2.1 事件三态（未开始 / 进行中 / 已结束）

术语对齐：**未开始（Pending）/ 进行中（Active）/ 已结束（Past）**。三态来自 `TimelineQuery::at` 对 `t` 的投影（AGENTS §3.2）。

| 状态 | 事件点视觉 | 静态基线 | 强调 |
|---|---|---|---|
| **未开始 Pending** | 空心点，`accent.event` @ alpha 0.45 | 无 | 无 |
| **进行中 Active** | 实心点 `accent.event` + **1px 外圈** | alpha 1.0 | **脉冲（§2.2）** |
| **已结束 Past** | 实心点，`accent.event` @ alpha 0.6 | 无 | 无 |

**状态切换过渡规范**（L2，**由 `t` 决定，非用户操作**）：

| 迁移 | 时长 | 曲线 | 变化内容 |
|---|---|---|---|
| Pending → Active | 120 ms | ease-out | 空心→实心（半径 3px→4px）+ alpha 0.45→1.0 + 出现外圈 |
| Active → Past | 160 ms | ease-in-out | 外圈淡出 + alpha 1.0→0.6（**实心保持**，不缩回空心） |
| 反向（时间轴回拖） | 同上但**反向播放**（Past→Active、Active→Pending） | 对称 | 回拖是编辑常态，过渡必须可逆、对称 |

> **关键**：**状态过渡必须可反向播放**。作者拖时间轴来回看是最高频动作，正向/反向用不同时长会让人「感觉时间轴在撒谎」。

### 2.2 「进行中」的脉冲强调（可关闭）

> **视觉形态归特效总监**（`VFX_SPEC_v0.1.md` §4.2：外扩环 1.0R→1.6R、alpha 0.5→0、周期 2.4s、同屏 ≤5）；**缓动曲线与播放节奏归本文**。
> 这是全文唯一可能被长时间注视的动效，参数必须最保守。

**结构（本文裁定，与特效形态的合成）**：脉冲由**两层**构成——

| 层 | 形态 | 来源 | 作用 |
|---|---|---|---|
| **底环**（常驻，不闪） | 固定在 `1.0R`，alpha **0.25** 恒定 | 本文新增 | **保证「标记永不消失」**——消除外扩环 alpha 归零时的「闪烁感」 |
| **涟漪环**（脉冲） | `1.0R → 1.6R` 外扩，alpha `0.5 → 0`，每 **2.4 s** 一次 | 特效 §4.2（形态）+ 本文（曲线） | 表达「此刻正在发生」 |

> **为什么加底环**：特效方案的外扩环在 alpha 归零后有一段「无环」空窗，循环往复对长时间注视而言是**闪烁**。底环把标记的基线存在感固定住，涟漪只是其上的一圈**扩散波**——视觉上从「闪烁的环」变成「一次心跳/一次雷达波」，**显著更可长看**。这是本文对特效形态的唯一增补，**不改变其视觉语汇**。

**参数与曲线（本文裁定）**：

| 参数 | 数值 | 依据 |
|---|---|---|
| 周期 | **2400 ms** | 与特效规格一致 |
| 扩张半径 | `1.0R → 1.6R` | 特效规格 |
| **扩张曲线** | **ease-out-cubic**（先快后慢，向外减速） | 特效写「线性」，本文**建议改为 ease-out**——真实涟漪/消散是减速的；线性扩张会显得机械。**可回退为线性**（若特效坚持） |
| 透明度 | `0.5 → 0` | 特效规格；本文**维持线性**（线性消散读作「能量耗散」，此处线性正确） |
| 全屏相位 | **同相位**（所有进行中事件的涟漪同时发出） | 随机相位 = 满屏杂乱 |
| **同屏脉冲上限** | **≤ 5 个**（第 6 个起只静态点亮） | 特效 §4.2 / 本文一致 |
| **可关闭** | ✅ `animation.intensity`：`full` / `reduced`（周期 4.8 s、半径 1.0R→1.3R、alpha 0.5→0）/ `off`（**仅保留底环 alpha 0.25，无涟漪**） | AD-2 核心；**关掉后仍有底环 = 状态不丢** |
| **背景事态叠加** | 非焦点事态：标记整体 alpha ×0.40（本文 §2.4）**且** 涟漪幅度 ×0.5（特效 §4.2）——**两者相乘，不取其一** | 焦点层次 |

**关于 AGENTS §3.2 的说明（预答质疑）**：脉冲是**时间驱动**的（静止未播放时同样运行），**不是 day 驱动**。这不违反 §3.2——因为「事件是否进行中」这一**世界状态**已由 `TimelineQuery::at(current_day)` 求出；脉冲只是叠加在**已解析状态**上的一个局部 UI 循环计时器，**不参与任何时间语义判断**。渲染层据此只做「资源值 → 视觉属性」映射，无 `if time > event.day`。

> **自检标准（写进验收）**：让测试者**注视一个进行中事件 60 秒**，若任何一人表示「眼睛累」或「想把它关掉」，则强度需再降。默认参数必须先通过这个测试。

### 2.3 事态节点点亮（当前节点高亮，其他降透明度）

基线 §1.9：「当前节点高亮；整条链可在图上显示为淡色路径；只有当前节点是亮的」。

| 元素 | 当前节点 | 其他节点 | 过渡 |
|---|---|---|---|
| 节点（事件点） | alpha 1.0 + `accent.select` 2px 外描边 | alpha 0.4 | **180 ms ease-out** |
| 事态链路径（淡色） | 已走过的段 alpha 0.6 | 未走过的段 alpha 0.25 | 180 ms |
| 节点标签 | 显示 | 隐藏（除非悬停） | 140 ms 淡入淡出 |

**当前节点切换**（`t` 跨过一个节点边界时）：

1. 旧节点：外描边 2px→0、alpha 1.0→0.4（180 ms ease-out）
2. 新节点：**先到 alpha 1.0（120 ms），再接外描边淡入（60 ms 后启动，140 ms）**——即**分两级到达**，避免「两个节点同时全亮」的瞬间
3. 若 `t` 在短时间内跨越多个节点（高速播放）：**跳过中间节点的外描边动画**，直接落到最终节点（复用 §1.7 降采样规则）

### 2.4 多事态同时显示（其余降至 ~40%）

基线 §1.9：「播放时只锁定一个事态，其余按 `t` 投影但降透明度至 ~40%」。

| 项 | 规范 |
|---|---|
| 目标 alpha | **0.40**（精确值，非模糊的「~40%」） |
| 过渡时长 | **200 ms ease-in-out**（L2 区间上限，因为这是「切换焦点」级的变化） |
| 过渡方向 | 被锁定事态：0.40→1.0；其余：1.0→0.40 |
| 触发 | ① 用户点播放 ② 用户在事态面板选中一个事态 |
| **40% 的叠加** | 与 §2.2 脉冲**相乘**：若非锁定事态恰好有 Active 事件，其脉冲振幅**同步降至 40%**（不叠加，取乘积） |
| 退出焦点 | 停止播放 / 取消选中 → 所有事态回到 1.0（200 ms） |

> **为什么是 0.40 而不是 0.3/0.5**：0.3 以下会「看不见」从而让作者忘了还有别的事态；0.5 以上则与锁定态区分不明显。0.40 是「余光可见、主眼不抢」的经验值。

## 三、编辑操作动效

### 3.1 笔刷涂抹的实时反馈（精度优先）

基线 §1.13：笔刷涂抹 + 松手后自动自然化 + 参数实时预览。

**裁定：涂抹过程零动效（L0）。**

| 项 | 规范 | 理由 |
|---|---|---|
| 涂抹跟随 | **光标拖到哪，地形改到哪，当帧生效**。无任何延迟、无补间 | AD-3；基线 §2.19「笔刷响应 ≤ 16 ms」 |
| 「墨水扩散」动效 | ❌ **不做**（明确裁定） | 扩散会让作者看到的「已改区域」滞后于「已改数据」——**编辑器里「所见即所得」不可妥协** |
| 笔刷光标 | 圆形/方形/套索的轮廓（美术侧归属，本文只要求**光标形状实时跟随笔刷尺寸，无动画**） | 见特效稿 |
| 参数实时预览（如自然化强度） | 拖滑块时**逐帧重算预览**（L0），松手才提交 `EditCommand` | 预览是视图态，不落盘 |
| 脏块上传 | 脏块 ≤ 64×64 当帧上传；> 64×64 分帧（基线 §2.19 自动降级） | 与「响应 ≤16 ms」配套 |

> **唯一的例外**：涂抹**结束**（抬笔）时，笔刷光标轮廓**淡出（120 ms）**，这是光标生命周期，不是地形动效——**不违反 L0**。

### 3.2 自动自然化的过渡（瞬变 vs 补间）

基线 §1.13：松手后自动自然化；**非破坏、可反悔**（P6）。

**裁定：瞬变（L0），但有 60 ms 的「呼吸」作为可撤销的视觉锚点。**

| 项 | 规范 |
|---|---|
| 边界变化 | **当帧瞬变**（锯齿 → 平滑），**不做补间** | 补间会让作者无法判断「哪个是最终结果」；且自然化是**数据变更**不是状态动画 |
| 为什么瞬变正确 | 自然化的结果是**一个新的确定数据状态**，不是「一个过程」。动画属于「状态过渡」，而这里是「数据替换」 |
| 视觉锚点 | 自然化发生的边界，做一次**「亮起 → 淡出」高亮**：attack 60 ms（alpha 0→1，ease-out） + decay 240 ms（alpha 1→0，ease-in-out），**总计 300 ms** | 让作者知道「这里刚刚被改过」，降低「我没动它它怎么变了」的困惑 |
| ↳ 与特效规格对齐 | 时长**服从特效 §3.3 的 0.3 s**（本文原 60 ms 闪一次作废）；本文只定**曲线**：快起（60 ms）+ 缓落（240 ms） | 单一权威：视觉形态与时长归特效，曲线归本文 |
| 撤销 | 闪一次后，`Ctrl+Z` 可回到自然化前（进 Undo 栈，P6） | 基线 §1.13「可反悔」 |
| 连续涂抹 | 只有**抬笔**才触发自然化；同一区域内连涂不重复播放呼吸 | 避免涂抹中途「闪个不停」 |

### 3.3 海拔升降动效

基线 §1.14：圈选 → 海拔浮层 → 拖滑块/输入；羽化抬升默认。

| 项 | 规范 |
|---|---|
| 拖动滑块时 | 高度场**逐帧重算预览（L0）**，与笔刷同精度策略 |
| 真实地形模式（ViewMode A） | 若启用光照，高度变化的阴影/明暗当帧重算 |
| 提交（松手/确认） | 瞬变（L0）；无过渡 |
| 选区边界（羽化区） | 选中的羽化边界**常驻显示**（虚线 + 半透明遮罩），**不闪动**；无呼吸 |
| 视觉参考（可选，需特效总监确认） | 可在圈选中心显示一个**高度数值浮标**（跟随鼠标，实时显示 `±X 米`） | 属 UI 标注，非动效 |

### 3.4 撤销 / 重做的视觉反馈

| 项 | 规范 |
|---|---|
| 反馈形式 | 操作**瞬变**还原（L0）；顶栏「撤销」图标**闪一次 120 ms 高亮（L1）** |
| 还原粒度 | 一次 `Ctrl+Z` = 还原一个 `EditCommand` 的完整影响块（与命令栈对齐，不做「逐帧回放」） |
| 「回放」动效 | ❌ **不做**。撤销是「回到某个确定状态」，不是「倒放录像」 | 与 3.2 同理：数据替换 ≠ 状态动画 |
| 无东西可撤销 | 「撤销」按钮 + 图标**置灰（disabled 态，美术 §4.4）**，按下无反馈 | — |
| 连续撤销 | 每次都闪一次，但**同一图标的高亮不叠加**（`t` 后到的高亮覆盖前一个） | 避免快速连按时图标「一直亮着」 |

## 四、UI 过渡动效

### 4.1 面板展开 / 折叠（含 R4 折叠拖拽停靠）

基线 §1.11：8 个面板；R4 可折叠、可拖拽、可停靠；美术 §4.6 折叠后收成 24px 竖条。

| 过渡 | 时长 | 曲线 | 变化 |
|---|---|---|---|
| **展开** | 160 ms | ease-out-cubic | 宽度 24px → 目标宽（240/320px），内容 alpha 0→1（内容延迟 40 ms 启动） |
| **折叠** | 120 ms | ease-in-cubic | 宽度 → 24px，内容 alpha 1→0（内容立即开始） |
| **切换停靠位置（拖拽）** | **实时跟随（L0）** | — | 拖动中面板跟随指针；松手后有 **< 1 帧**的吸附，无补间 | 拖拽是直接操作，必须跟手 |
| **吸附到停靠位（松手瞬间）** | 100 ms | ease-out | 位置补间到最近停靠槽 | 唯一允许「松手有补间」的场景（距离通常 < 40px） |
| **标签页切换**（Inspector/事态/势力/校验） | 140 ms | ease-in-out | 交叉淡化（旧内容 alpha→0、新内容 0→1，**不位移**） |

> **R2 重申**：面板动画**绝不改变地图坐标系**——面板从左展开时，地图画面的世界原点不动，只是可视区变化。

### 4.2 沉浸模式（所有面板淡出至 10%）

基线 §1.11：`Tab` 键一键，所有面板淡出至 10% 透明度。

| 项 | 规范 |
|---|---|
| 触发 | `Tab` 切换（进入/退出） |
| 目标 alpha | **0.10**（所有面板，含顶栏、状态栏、时间轴） |
| 时长 | **200 ms**（L2 上限；比单面板长，因为是整体氛围变化） |
| 曲线 | ease-in-out |
| 淡出后交互 | 面板**仍可点击**（alpha 0.1 但命中区不变）——**渐隐≠禁用** | 作者可能想「淡出着直接点一下」 |
| 悬停唤醒 | 鼠标悬停某个淡出面板 → **该面板恢复到 alpha 1.0（160 ms）**，移开后回 0.10（160 ms） | 兼顾「看全地图」与「随手操作」 |
| 地图区 | **完全不受影响**（沉浸模式只动 UI 层） | 基线 §1.11「要看全地图」 |
| intensity 影响 | 沉浸模式的 alpha 是**交互承诺**，**不受 intensity 关闭**（它不是 L3 装饰，是功能） | — |

### 4.3 缩放 / 平移的平滑处理（惯性裁定）

**裁定：无惯性，刚性跟随（L0）。**

| 操作 | 行为 | 理由 |
|---|---|---|
| **滚轮缩放** | **锚点 = 鼠标位置**，按档位离散缩放（美术 §3.1 白名单 `{0.5,1,1.5,2,3}` 及扩展档）；**缩放本身瞬变（L0），但有 ≤ 60 ms 的短补间让连续滚轮平滑** | 白名单缩放天然离散，60 ms 补间把「跳档」抹平，同时不引入惯性 |
| **拖动平移**（右键/中键/空格拖） | **当帧跟随指针，零惯性、零缓动、零残影** | AD-3；地图编辑要「指哪打哪」，惯性会让作者对不齐要素 |
| **松开平移** | **立即停止**，无滑行 | 惯性滑行 = 精度杀手 |
| **键盘平移**（WASD/方向键） | 恒定速度（如 400 px/s），**无加速无减速** | 可预测 |
| **预设缩放级按钮** | 200 ms ease-in-out 平移 + 缩放**同步**补间到目标（这是唯一允许缩放有动画的场景，因为它是「跳转到某视图」而非「连续操作」） | 跳转是状态过渡，不是直接操作 |
| **双击 / 框选缩放** | 同预设缩放级（200 ms 补间） | 同上 |

> **裁定一句话**：**用户的鼠标拖动 = 零惯性（L0）；按钮触发的视图跳转 = 200 ms 补间（L2）。** 分界线是「是否由指针直接操控」。

### 4.4 视图模式切换（四态互斥）

基线 §1.10：真实地形 / 色块地形 / 势力图 / 事件图；切换**保留 `t`、保留缩放**（§1.10、V25）。

| 项 | 规范 |
|---|---|
| 过渡形式 | **交叉淡化（cross-fade）**，不是滑动 |
| 时长 | **220 ms** ease-in-out（比一般面板稍长，因为整张基底都变） |
| 实现语义 | 旧基底 alpha 1→0、新基底 alpha 0→1，**同时进行**；不得出现「中间全白/全黑」帧 |
| 图层可见性 | 属于「视图模式」的图层组合开关**随基底一起淡**（用同一 220 ms），不单独跳变 |
| `t` 与缩放 | **完全保留**（切换不动时间轴、不动镜头） |
| 可用工具集切换 | 工具集（如势力图→国境工具）**立即生效（L0）**，不做动画 | 工具是逻辑状态，不是视觉 |
| 事件图的特殊性 | 切到事件图（ViewMode D）时，事件点/轨迹/事态链**淡入比基底晚 80 ms**，让基底先就位 | 事件层是主角，晚到一点点更清晰 |

### 4.5 LOD 切换（五级）

基线 §1.16：LOD 只改显示不改数据（L1 规则）；轨迹低缩放简化（L3）；文字永不重叠（L4）。
基线 §1.16 五级：全图概览 / 战略 / 战术 / 局部 / 室内街道。

| 项 | 规范 |
|---|---|
| LOD 切换触发 | 由缩放值跨过阈值触发，**不是用户显式操作** |
| 过渡策略 | **不做整体淡化**（会造成「地图一直在闪」）。改为**元素级软切换**：新增显示的元素淡入 120 ms，移除显示的元素淡出 120 ms，**各自独立** |
| 为什么不做全屏淡化 | 缩放是连续操作，若每次跨阈值都全屏淡化，作者滚轮时画面会「一节一节地闪」——**这是最常见的 LOD 闪烁来源** |
| 轨迹简化（L3） | 降级时：被简化的点 120 ms 淡出；升级时：恢复的点 120 ms 淡入 | 保证「缩回原级完全恢复」（基线风险兜底） |
| 文字标签（L4） | 标签出现/消失用 **100 ms 淡入淡出**，**不缩放、不位移** | 文字缩放会糊 |
| 纹理降采样 | `scale < 0.3` 换 1/4 分辨率纹理时，**当帧替换（L0）**，靠淡化遮住接缝：替换瞬间给一个 **80 ms 的轻微亮起脉冲**（不超过 +4% 明度） | 遮盖 mip 切换的接缝闪烁，同时不显眼 |
| 防抖 | 缩放值在阈值 ±2% 区间内**不反复触发切换**（滞回） | 避免阈值附近高频抖动导致连续淡入淡出 |

### 4.6 选区蚂蚁线（`[交动画]` 项 4：爬行速率裁定）

> 视觉形态归特效（`VFX_SPEC_v0.1.md` §3.2：2px `accent.select` 虚线，沿选区周长）；**爬行速率归本文**。

| 参数 | 数值 | 依据 |
|---|---|---|
| **爬行速率** | **6 px/s**（屏幕空间，恒定） | 蚂蚁线是「选区活着」的通用符号；6 px/s 是**能察觉在动、但不催促**的速率。快于 12 px/s 会变成「跑马灯」，慢于 3 px/s 会「看不出在动」 |
| 爬行方向 | **沿周长顺时针**，恒定 | 方向恒定 = 可预测；不随选区形状反转 |
| 虚线规格 | dash **6 on / 4 off**（px），宽 **2 px** | 与特效 §2.3.1 的「虚线 dash 6-4」语汇一致 |
| **相位连续性** | ✅ **跨选区改动保持相位连续**（不重置） | 否则每改一次选区，蚂蚁线「跳一下」——高频编辑时会晕 |
| **可关闭** | ✅ `intensity = off` → **静态虚线**（不爬行，线型保留） | AD-2/L3 纪律；关掉后「这是选区」的信息仍在（靠虚线+填充） |
| 抖动 | 沿周长相位可叠加 **±0.5 px 的慢速扰动**（周期 1.2 s，正弦） | 轻微「手绘感」，与美术 §3.3「手绘地图」气质一致；**幅度 ≤ 0.5 px 不构成干扰** |
| 性能 | 纯 shader（`arclen` 偏移），零额外顶点/drawcall | 复用 `SH_Vector_Outline` |

## 五、实现约束（重要）

### 5.1 AGENTS §3.2 硬约束（动画参数必须来自投影）

> **禁止渲染层做时间比较。任何动画的「当前时刻」必须来自 `TimelineQuery::at(t)` 的投影结果。**

| 约束 | 具体要求 |
|---|---|
| 时间来源 | 动画的所有 time 参数 = `PlaybackState.current_day`（视图资源），**不是**渲染层自己算的时间 |
| 求值路径 | `current_day` → `TimelineQuery::at` → 投影结果写入 Bevy Resource（`EventHighlights` / `TrackPositions` / `FactionAlpha`）→ 渲染 System **只读资源，只做「资源值 → 视觉属性」的映射** |
| 禁止项 | ❌ 渲染 System 里出现 `if t > event.day`；❌ 渲染 System 里读取 `Event.span` 自行比较；❌ 动画层持有权威数据 |
| 插值位置 | **插值计算放 `wv-core` 的纯函数**（如 `Track::sample_at(waypoints, day) -> Pos`），可单测；`wv-app` 只调用 |
| 可测试性（AGENTS §7） | 插值函数必须有单测：段内插值、端点外推、零长度段、单点轨迹、乱序 day |
| 动画即视图状态 | 动画进度（如某过渡的 0→1 进度）是**渲染层局部状态**，不落盘、不进 Undo、不进世界数据 |
| **day 空间插值（推荐范式）** | 凡「由时间轴跨越边界触发」的过渡（势力易主 §1.6），**其进度一律写成 `current_day` 的纯函数**（如 `clamp((current_day − 边界day)/Δ, 0, 1)`），**而非壁钟计时**。这样：① 时长天然由推进速率派生（满足 T1）② 天然可逆 ③ 无独立计时器 ④ 可放 `wv-core` 单测。**这是本文对「时间轴驱动动画」的默认实现范式** |
| 唯一的时间驱动例外 | **脉冲涟漪**（§2.2）用局部循环计时器——因其表示的是「已由 `TimelineQuery::at` 解析出的状态」的装饰，不参与时间语义判断（详见 §2.2 说明） |

### 5.2 帧率预算（基线 §2.19：60 FPS 目标）

| 项 | 预算 | 说明 |
|---|---|---|
| 总帧预算 | **16.6 ms / 帧**（60 FPS） |
| 动画求值预算 | **≤ 0.5 ms / 帧** | 投影 + 插值 + 资源写入。这部分是纯计算，应极快 |
| 动画渲染预算 | **≤ 1.5 ms / 帧** | 更新变换/材质/透明度。**合批**（美术 §3.6）是前提 |
| 脉冲动效 | 单帧更新**全部** Active 事件的脉冲属性能在 **0.1 ms** 内完成（同一相位，可批量计算） | 同相位设计的性能红利 |
| 超阈处置 | 若动画求值 + 渲染 > 2 ms，**降级顺序**：① 关脉冲（等价 `intensity=off`）② 降低过渡帧率（过渡按 30 FPS 步进）③ 禁用 LOD 软切换（改瞬时） | 与基线 §2.19「自动降级」一致 |
| 测量 | 用 `FrameTimeDiagnosticsPlugin`（同基线 §2.19）；开发模式在状态栏暴露「动画耗时」 | 美术 §4.6 状态栏位 |

### 5.3 缓动曲线：库 vs 手写

**裁定：手写 easing 函数，不引入依赖（基线 §2.18「默认拒绝」）。**

| 项 | 规范 |
|---|---|
| 需要的曲线 | 全集只需 **4 条**：`ease_out_cubic`、`ease_in_cubic`、`ease_in_out`（smoothstep）、`sin`（脉冲） |
| 实现 | `fn ease_out_cubic(t: f32) -> f32 { 1.0 - (1.0 - t).powi(3) }` 等，**合计 < 20 行** |
| 位置 | `wv-app` 的 `anim/easing.rs`（渲染层，不进 `wv-core`——easing 是视觉工具，不是领域逻辑） |
| 明确拒绝的依赖 | `easing` crate / `bevy_tweening` 等——**理由**：① 需求只有 4 条曲线 ② 引依赖违反 AGENTS §9 默认拒绝 ③ 手写可测试、可控、无常量魔法 |
| 常量定义 | 时长常量集中定义（如 `pub const D_PANEL_EXPAND: f32 = 0.16;`），**禁止在调用点写字面量 0.16** |
| 曲线可测 | 单测：`ease_out_cubic(0)==0`、`ease_out_cubic(1)==1`、单调性 |

### 5.4 其他实现约束

| 项 | 约束 |
|---|---|
| `intensity` 设置 | 存于工程设置（YAML），**不是**全局注册表/AppData（P2） |
| 动画与 Undo | 任何动画**不产生 `EditCommand`**、不进 Undo 栈（纯视图） |
| 动画与世界数据 | 动画**不修改世界数据**；所有形变只作用于投影资源与渲染组件 |
| 主题包无关性 | 动效参数**不属于 Theme Pack**（Pack 换皮不改动效，美术 §2.A）；时长/曲线属壳 |
| 资源释放 | 过渡进行中切换视图模式/关面板，**必须安全中断**（进度丢弃，直接落终态），不残留状态 |
| 时钟无关 | 动画**不用挂钟时间**，只用 `Time::delta_secs` 累积；暂停/失焦时不推进（避免「回来发现动画跳完了」） |

| 场景 | 裁定 | 理由 |

| **自然化边界补间** | ❌ 不做（§3.2） | 让作者看不清终态 |
| **轨迹拖尾/残影** | ❌ 不做（§1.5） | 与「位置唯一性」校验语义冲突 |
| **LOD 全屏淡化** | ❌ 不做（§4.5） | 连续缩放时会「一节一节闪」 |

| **数字/日期的滚动动画** | ❌ 不做 | 美术 §4.2 要求数字等宽不跳动；滚动数字会破坏「可读性」 |
| **面板弹出的弹跳/回弹（bounce/elastic）** | ❌ 不做 | 工具型壳，非玩具 |
| **背景/装饰的循环动画** | ❌ 不做 | 长时工作场景，任何常驻循环动画都是干扰源 |

## 七、术语登记建议（供 GLOSSARY.md 更新）

> 登记格式对齐基线 §5：`术语 | 英文 | 定义 | 所属维度`

### 7.1 本文新增术语

| 术语 | 英文 | 定义 | 所属维度 |
|---|---|---|---|
| **动效分级** | Animation Tier | 动效的 4 级强度标尺（L0 瞬变 / L1 微反馈 / L2 状态过渡 / L3 强调动效），决定时长区间与是否可关闭 | 动效（UI） |
| **轨迹生长** | Track Growth | 播放时轨迹按 waypoint 时间戳顺序、逐段线性插值出现的动画；未到位段不显示 | 动效（时间轴） |
| **生长笔尖** | Growth Head | 轨迹已生长段末端的实心圆点，标示「当前已行进到哪」；与特效的「发光游标」为同一物（**已统一命名**），色 `accent.cursor` | 动效（时间轴） |
| **当前时刻指示色** | Current-time Accent | `accent.cursor` 的**语义定义**（对齐特效反保留 B）：它表示「当前时刻 `current_day`」，**呈现于两个位置**：① 时间轴游标　② 轨迹生长笔尖。二者**共用一色是正确的**——它们是同一个 `current_day` 的两个视图；不得因「两处同色」而拆成两个令牌 | 动效（时间轴 / 视觉） |
| **推算轨迹** | Interpolated Track | 由顺序点（无 `day`）均分到时段推算出的轨迹；视觉上以空心起点标记提示「时间为推算」 | 动效（时间轴 / 距离） |
| **粗轨迹** | Coarse Track | 只填两端点、时间由两端事件 span 给出的轨迹（基线 T3）；`≈` 标记，视觉上不被歧视 | 距离 |
| **节点点亮** | Node Highlight | 当前时间 `t` 落在其 span 内的事态节点被高亮的视觉状态 | 动效（时间轴） |
| **焦点事态 / 背景事态** | Focused / Background Situation | 播放或选中时被锁定的任一事态；其余事态降至 40% 透明度 | 动效（时间轴） |
| **强度档位** | Intensity Tier | `full` / `reduced` / `off` 三档动画强度设置，仅影响 L3 | 动效（UI） |
| **滞回** | Hysteresis | LOD 阈值附近防止反复切换的 ±2% 防抖区间 | 动效（渲染） |
| **刚性跟随** | Rigid Follow | 零惯性、零缓动的直接操控响应；用于涂抹、缩放、平移 | 动效（交互） |
| **软切换** | Soft Switch | LOD 变化时元素级独立淡入淡出（非全屏淡化） | 动效（渲染） |
| **底环** | Baseline Ring | 脉冲结构中恒定不闪的 1.0R 底环（alpha 0.25），保证「进行中」标记永不消失 | 动效（时间轴） |
| **涟漪环** | Ripple Ring | 脉冲结构中每 2.4 s 外扩一次的环（1.0R→1.6R，alpha 0.5→0） | 动效（时间轴） |
| **蚂蚁线** | Marching Ants | 选区边界的虚线爬行（6 px/s、dash 6-4、2 px 宽、可关闭） | 动效（编辑） |
| **day 空间插值** | Day-space Interpolation | 过渡进度是 `current_day` 的纯函数（而非壁钟计时）；时长自动由推进速率派生，天然可逆 | 动效（时间轴） |
| **抑制三分类**（上位概念） | Suppression Classes | 元素按抑制行为分三类，决定其在高速档与 `intensity=off` 下的行为。**含成员：状态 / 动效 / 语义动效**（见下三行）。与特效 §10 登记结构一致 | 动效（UI） |
| ↳ **状态** | State | 成员①：表达「是什么/在哪里/多少」的确定信息，**永不抑制**（底环、事件三态、光标 falloff 双环、势力描边） | 动效（UI） |
| ↳ **动效** | Motion | 成员②：往复/扫掠/弹跳等装饰性运动，**高速档或 `intensity=off` 时抑制**（涟漪环、扫光、蚂蚁线爬行） | 动效（UI） |
| ↳ **语义动效** | Semantic Motion | 成员③：运动本身携带「世界正在变化」语义，**仅受触发条件控制、不受速率抑制**（流光线） | 动效（时间轴） |

| 术语 | 说明 |
|---|---|
| **脉冲** | 建议在字典中明确：「进行中」事件的**外扩涟漪 + 常驻底环**（周期 2400 ms、可关闭）；**非**正弦呼吸 |
| **沉浸模式** | 补注：目标 alpha 为 **0.10**（基线 §1.11 的「10%」精确值）；仍可点击、悬停唤醒 |

## 八、与特效规格（`VFX_SPEC_v0.1.md`）的接口裁定

> 特效总监 §1.2 划分：**视觉形态/触发时机/时长上限归特效，缓动曲线与播放节奏归动画**。以下 4 条为其 §9.3 标注的 `[交动画]` 项，逐条裁定。**凡冲突处，本文按「单一权威」原则指定归属，并同步修改本文前文对应条目。**

### 8.1 四条 `[交动画]` 项的裁定汇总

| # | 条目 | 特效给的上限/参数 | 本文裁定（曲线与节奏） | 落点 |
|---|---|---|---|---|
| 1 | **势力易主过渡** | 入 ≤0.4 s / 出 ≤0.3 s / 交替 ≤0.5 s | **改「壁钟计时」为「day 空间插值」**：`progress = clamp((current_day − 边界day)/Δ_day, 0, 1)`，`Δ_day` = 0.25/0.20/0.35 天；曲线 **ease-out-cubic**（作用在 day 参数上）。时长**自动派生**：1 天/秒 → 0.25/0.20/0.35 s（均在上限内）；30 天/秒 → ≈0（**满足 T1/T2：拖得快立即完成**）；**天然可逆** | §1.6 |
| 2 | **事件「进行中」脉冲** | 周期 2.4 s、半径 1.0R→1.6R、alpha 0.5→0 | 采纳形态；**扩张曲线由「线性」改「ease-out-cubic」**（减速扩散更自然，**可回退**）；alpha **维持线性**；**增补常驻底环**（1.0R, alpha 0.25）消除「alpha 归零」的闪烁感；同屏 ≤5；非焦点 ×0.40（本文）× 0.5（特效）**相乘** | §2.2 |
| 3 | **自然化边界高亮淡出** | 0.3 s（alpha 1→0） | 采纳 0.3 s；本文定曲线 = **attack 60 ms（ease-out）+ decay 240 ms（ease-in-out）** | §3.2 |
| 4 | **选区蚂蚁线爬行速率** | 未定（2px 虚线） | 裁定 **6 px/s**，顺时针恒定，dash 6-4，**相位连续**，`intensity=off` → 静态虚线 | §4.6 |

### 8.3 特效提议的轨迹生长配合（回特效总监）

**统一后的硬规则（写入双方共识）**：
> **「状态」不被任何 intensity / 速率抑制；「动效」（往复、扫掠、弹跳）才被抑制。**
> 判别口诀（**两步，特效 §1.3 定稿版**，见 §7.2）：① 「去掉它，作者会少看懂什么吗？」不会 → ② 动效；② 会 → 「丢的是事实还是『正在变化』？」丢事实 → ① 状态；丢「正在变化」 → ③ 语义动效。

### 8.5 抑制分类的补全（采纳特效 §1.3 的细化，回写本文）

> 特效将 §8.4 的硬规则提炼至其 §1.3，并补出**第三类「语义动效」**与**边界案例表**。本文**全部采纳并回写**，使两文分类完全同构。

**抑制三分类**（本文原先只分「状态 / 动效」两类，现补第三类）：

| 类 | 定义 | 抑制规则 | 本文实例 |
|---|---|---|---|
| **① 状态** | 表达「是什么 / 在哪里 / 多少」的确定信息 | **永不抑制**（任何 intensity / 速率） | 底环、节点点亮、光标 falloff 双环、易主过渡的**终态 alpha** |
| **② 动效** | 往复 / 扫掠 / 弹跳等装饰性运动 | **可抑制**（30 天/秒 或 `intensity=off`） | 涟漪环、拐点点亮弹跳、易主过渡的**边界扫光**、LOD 元素淡化 |
| **③ 语义动效** | 运动本身携带「世界正在变化」的语义 | **不适用「高速抑制」**，仅适用「触发条件消失即停」 | 流光线（播放中才开，停止播放即关，**不随速率抑制**） |

**边界案例裁定表**（采纳特效版，两文一致）：

| 元素 | 判定 | 理由 |
|---|---|---|
| **流光线** | ③ 语义动效 | 携带「时间正在推进」语义；只受「是否播放」控制，不受速率抑制 |
| **笔刷光标 falloff 双环** | ① 状态 | 表达「影响范围」这一**精度信息**（特效 §3.1 硬契约）；`intensity` 与 LOD 均不得降级 |
| **易主过渡的描边淡入** | **① + ② 混合** | **拆分处置**：alpha **终态**是状态（不抑制），**扫光**是动效（可抑制） |

**由混合案例导出的实现结构（本文认同，与特效 `u_sweep` 口径相容）**：

> **同一个 `progress`（day 空间插值，§1.6）+ 两个独立的强度乘子**：
> - `alpha = 终态alpha × ease_out_cubic(progress) × k_state`（`k_state ≡ 1`，永不抑制）
> - `sweep = progress × k_motion`（`k_motion ∈ {0, 1}`，高速档或 `intensity=off` 时为 0）
>
> **关键**：两者**共享 `progress`** 以保证扫光与 alpha 不脱节；**各自独立乘子**以保证「终态 alpha 不被抑制、扫光可被抑制」。这是本文对特效「为什么 `u_sweep` 必须复用同一 `progress`」的**规格化回答**——不是因为省事，而是因为**状态与动效必须共享同一时间参数、却能各自独立降级**。
